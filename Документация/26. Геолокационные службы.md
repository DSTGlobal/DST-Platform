# 26. Геолокационные службы

Данный документ содержит исчерпывающую техническую спецификацию подсистемы геолокационных сервисов в рамках платформы DST Platform. Система использует библиотеку **GeoIP2** от MaxMind и базу данных **GeoLite2 City** для определения географической информации по IP-адресам пользователей в режиме реального времени.

> **Важно**: Данный документ описывает архитектуру и технические детали интеграции геолокационных сервисов. Для получения информации о компоненте `auth` и его использовании для обнаружения мошенничества см. раздел *«Компонент — Маркетплейс и электронная коммерция»*. Общую архитектуру внешних интеграций см. в разделе *«Внешняя интеграция»*.

---

## 26.1. Обзор системы

Подсистема геолокационных сервисов обеспечивает сопоставление IP-адресов с географическим местоположением. Это позволяет реализовать следующие функции:

| Функция | Описание | Статус |
|---------|----------|--------|
| **Локализация** | Автоматическое определение страны/города пользователя для персонализации контента | ✅ Реализовано |
| **Выявление мошенничества** | Обнаружение подозрительных транзакций на основе географических аномалий | ✅ Реализовано |
| **Аналитика** | Сбор данных о географическом распределении посетителей для анализа их поведения | ✅ Реализовано |
| **Доставка контента** | Региональная фильтрация контента и контроль доступа | ✅ Реализовано |

Система использует **автономный поиск в базе данных** вместо вызовов внешних веб-сервисов, что обеспечивает:
- Высокую производительность (миллионы запросов в секунду)
- Отсутствие зависимостей от внешних сервисов во время выполнения
- Полный контроль над данными и конфиденциальностью

## 26.3. Зависимости и конфигурация

### Управление зависимостями через Composer

Библиотека **GeoIP2** управляется через Composer с ограничением по версии, что позволяет вносить незначительные обновления, сохраняя при этом совместимость с API.

| Пакет | Ограничение версии | Цель |
|-------|-------------------|------|
| `geoip2/geoip2` | ~2.0 | Основная библиотека геолокации |
| `maxmind-db/reader` | ~1.5 | Считыватель двоичных баз данных |
| `maxmind/web-service-common` | ~0.6 | Общие утилиты веб-сервисов |
| `guzzlehttp/guzzle` | ~6.0 | HTTP-клиент для вызовов веб-сервиса (опционально) |

Ограничение по версиям `~2.0` допускает использование версий `>=2.0` и `<3.0`, обеспечивая совместимость с версией API GeoIP2 v2, а также получение исправлений ошибок и незначительных обновлений функций.

### Установка через Composer

```bash
composer require geoip2/geoip2 ~2.0
```

### Дерево зависимостей


## 26.4. Библиотека GeoIP2 для PHP

### Структура библиотеки

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/149.png" alt="DST Platform">

Библиотека предоставляет следующие ключевые классы:

| Класс | Пространство имён | Назначение |
|-------|-------------------|------------|
| `Reader` | `GeoIp2\Database\Reader` | Основной класс для чтения базы данных |
| `Client` | `GeoIp2\WebService\Client` | Клиент веб-сервиса (опционально) |
| `City` | `GeoIp2\Model\City` | Модель данных для уровня города |
| `Country` | `GeoIp2\Model\Country` | Модель данных для уровня страны |
| `Record` | `GeoIp2\Record\*` | Вспомогательные классы для записи данных |

### Основной класс API

Класс `GeoIp2\Database\Reader` предоставляет основной интерфейс для поиска по IP-адресам:

```php
// Типичная инициализация
$reader = new GeoIp2\Database\Reader('/path/to/GeoLite2-City.mmdb');

// Выполнение поиска
$record = $reader->city($ipAddress);

// Доступ к географическим данным
$country = $record->country->name;        // например, "Россия"
$city = $record->city->name;              // например, "Москва"
$latitude = $record->location->latitude;  // например, 55.7558
$longitude = $record->location->longitude; // например, 37.6173
```

### Модель данных

Объект `GeoIp2\Model\City`, возвращаемый при выполнении запросов, содержит иерархическую географическую информацию:

| Свойство | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `country` | `Record\Country` | Информация о стране | Код ISO, название |
| `city` | `Record\City` | Информация о городе | Имя, степень доверия |
| `location` | `Record\Location` | Географические координаты | Широта, долгота, радиус точности |
| `postal` | `Record\Postal` | Почтовый индекс | Код, уверенность |
| `subdivisions` | `Record\Subdivision[]` | Данные по областям/краям | Коды ISO, названия |
| `traits` | `Record\Traits` | Дополнительные характеристики | Интернет-провайдер, организация, домен |

## 26.5. База данных GeoLite2

### Характеристики базы данных

Файл `GeoLite2-City.mmdb` представляет собой бинарную базу данных в формате **MaxMind DB**:

| Характеристика | Значение |
|----------------|----------|
| **Размер файла** | 64+ МБ (двоичный формат) |
| **Формат** | MaxMind DB (пользовательский бинарный формат) |
| **Периодичность обновлений** | Ежемесячные релизы от MaxMind |
| **Структура данных** | Отображается в память для быстрого поиска |
| **Зона покрытия** | Глобальные адреса IPv4 и IPv6 |
| **Точность** | Страна: 99.8%, Регион: 80%, Город: 67% |

Для оптимальной производительности чтение базы данных осуществляется с использованием **ввода-вывода с отображением в память** (memory-mapped I/O), что позволяет выполнять миллионы запросов в секунду без загрузки всей базы данных в память.

### Интеграция контроллера

```php
// /system/controllers/auth/model.php
use GeoIp2\Database\Reader;
use GeoIp2\Exception\AddressNotFoundException;

class modelAuth extends cmsModel {
    private $geoip_reader;

    /**
     * Инициализация читателя базы данных геолокации
     * @return Reader|null
     */
    private function initGeoIpReader() {
        if (!$this->geoip_reader) {
            $db_path = PATH . '/system/libs/GeoLite2-City.mmdb';
            
            if (!file_exists($db_path)) {
                error_log('[GEOIP] Database not found: ' . $db_path);
                return null;
            }
            
            try {
                $this->geoip_reader = new Reader($db_path);
            } catch (\Exception $e) {
                error_log('[GEOIP] Reader initialization error: ' . $e->getMessage());
                return null;
            }
        }
        return $this->geoip_reader;
    }

    /**
     * Получение данных о местоположении по IP-адресу
     * @param string $ip IP-адрес
     * @return array|null
     */
    public function getLocationByIp($ip) {
        $reader = $this->initGeoIpReader();
        
        if (!$reader) {
            return null;
        }
        
        try {
            $record = $reader->city($ip);
            
            return [
                'ip' => $ip,
                'country' => [
                    'code' => $record->country->isoCode,
                    'name' => $record->country->name
                ],
                'region' => [
                    'code' => $record->subdivisions[0]->isoCode ?? null,
                    'name' => $record->subdivisions[0]->name ?? null
                ],
                'city' => [
                    'name' => $record->city->name,
                    'geoname_id' => $record->city->geonameId
                ],
                'location' => [
                    'latitude' => $record->location->latitude,
                    'longitude' => $record->location->longitude,
                    'time_zone' => $record->location->timeZone,
                    'accuracy_radius' => $record->location->accuracyRadius
                ],
                'postal' => [
                    'code' => $record->postal->code
                ],
                'traits' => [
                    'autonomous_system_number' => $record->traits->autonomousSystemNumber,
                    'autonomous_system_organization' => $record->traits->autonomousSystemOrganization,
                    'isp' => $record->traits->isp,
                    'organization' => $record->traits->organization
                ]
            ];
            
        } catch (AddressNotFoundException $e) {
            error_log('[GEOIP] IP not found in database: ' . $ip);
            return null;
        } catch (\Exception $e) {
            error_log('[GEOIP] Error: ' . $e->getMessage());
            return null;
        }
    }

    /**
     * Определение страны по IP-адресу
     * @param string $ip IP-адрес
     * @return string|null Код страны (например, 'RU')
     */
    public function getCountryCodeByIp($ip) {
        $location = $this->getLocationByIp($ip);
        return $location['country']['code'] ?? null;
    }

    /**
     * Антифрод: проверка подозрительных локаций
     * @param string $ip IP-адрес
     * @param string $user_country Страна пользователя из профиля
     * @return bool true если подозрительно
     */
    public function isSuspiciousLocation($ip, $user_country) {
        $location = $this->getLocationByIp($ip);
        
        if (!$location) {
            return false; // Не удалось определить
        }
        
        $ip_country = $location['country']['code'];
        
        // Если страна не совпадает с профилем — подозрительно
        if ($ip_country && $user_country && $ip_country !== $user_country) {
            error_log(sprintf(
                '[FRAUD] Suspicious location: User country=%s, IP country=%s, IP=%s',
                $user_country,
                $ip_country,
                $ip
            ));
            return true;
        }
        
        return false;
    }

    /**
     * Локализация: определение локали по стране
     * @param string $ip IP-адрес
     * @return string Код локали (например, 'ru_RU')
     */
    public function getLocaleByIp($ip) {
        $country = $this->getCountryCodeByIp($ip);
        
        $locales = [
            'RU' => 'ru_RU',
            'UA' => 'uk_UA',
            'BY' => 'be_BY',
            'KZ' => 'ru_KZ',
            'US' => 'en_US',
            'GB' => 'en_GB',
            'DE' => 'de_DE',
            'FR' => 'fr_FR'
        ];
        
        return $locales[$country] ?? 'en_US';
    }

    /**
     * Получение часового пояса по IP-адресу
     * @param string $ip IP-адрес
     * @return string|null
     */
    public function getTimezoneByIp($ip) {
        $location = $this->getLocationByIp($ip);
        return $location['location']['time_zone'] ?? null;
    }
}
```

## 26.7. Типичные сценарии использования

### 1. Локализация контента

Автоматическое определение страны пользователя для выбора языка и контента:

```php
// Определение страны и установка локали
$record = $reader->city($userIp);
$countryCode = $record->country->isoCode; // например, "RU", "US", "DE"

// Использование кода страны для локализации
$locale = $this->getLocaleForCountry($countryCode);
```

### 2. Выявление мошенничества

Выявление подозрительных географических закономерностей в транзакциях электронной коммерции:

```php
// Сравнение страны оплаты с адресом доставки
$record = $reader->city($orderIp);
$ipCountry = $record->country->isoCode;

if ($ipCountry !== $billingCountry) {
    // Пометить для ручной проверки
    $this->flagSuspiciousOrder($orderId, 'country_mismatch');
}

// Проверка расстояния между местом доставки и местом оплаты
$distance = $this->calculateDistance(
    $record->location->latitude,
    $record->location->longitude,
    $shippingLatitude,
    $shippingLongitude
);

if ($distance > 1000) { // Более 1000 км
    $this->addFraudScore($orderId, 'geographic_anomaly');
}
```

### 3. Аналитика и отчетность

Сбор данных о географическом распределении:

```php
// Логирование местоположения посетителя
$record = $reader->city($visitorIp);

$analyticsData = [
    'country' => $record->country->isoCode,
    'city' => $record->city->name,
    'lat' => $record->location->latitude,
    'lon' => $record->location->longitude,
    'timestamp' => time()
];

$this->logAnalytics($analyticsData);
```

### 4. Региональный контроль доступа

Ограничение доступа к контенту на основе географического местоположения:

```php
// Проверка, находится ли пользователь в разрешённом регионе
$record = $reader->city($userIp);
$countryCode = $record->country->isoCode;

$allowedCountries = ['RU', 'BY', 'KZ', 'UA'];

if (!in_array($countryCode, $allowedCountries)) {
    throw new AccessDeniedException('Content not available in your region');
}
```

## 26.8. Обработка исключений

Библиотека геолокации генерирует определённые исключения, которые следует обрабатывать соответствующим образом:

| Исключение | Состояние | Стратегия обращения |
|------------|-----------|---------------------|
| `AddressNotFoundException` | IP-адрес не найден в базе данных | Возвращает местоположение по умолчанию/неизвестное местоположение |
| `InvalidDatabaseException` | Файл базы данных поврежден. | Зарегистрируйте ошибку, используйте резервный метод. |
| `GeoIp2Exception` | Общая ошибка | Зарегистрируйте и плавно деградируйте |

```php
try {
    $record = $reader->city($ipAddress);
} catch (\GeoIp2\Exception\AddressNotFoundException $e) {
    // IP не в базе данных (например, частный адрес, новое выделение)
    $record = null;
} catch (\GeoIp2\Exception\InvalidDatabaseException $e) {
    // Проблема с файлом базы данных — критическая ошибка
    error_log("GeoIP2 database error: " . $e->getMessage());
    $record = null;
} catch (\Exception $e) {
    // Любая другая ошибка
    error_log("GeoIP2 lookup error: " . $e->getMessage());
    $record = null;
}
```

```
│                              │                              │
│                              ▼                              │

│                     │  данных (64 МБ) │                     │
│                     └─────────────────┘                     │
└─────────────────────────────────────────────────────────────┘
```

### Советы по оптимизации

| Совет | Описание | Выгода |
|-------|----------|--------|
| **Использование одного экземпляра для чтения** | Повторное использование объекта `Reader` между запросами вместо создания новых экземпляров | Снижение накладных расходов |
| **Предварительная загрузка не требуется** | ОС автоматически обрабатывает кэширование с помощью отображения в память | Оптимальное использование памяти |
| **Минимальное потребление памяти** | В памяти остаются только страницы базы данных, к которым был осуществлен доступ | Эффективное использование ресурсов |
| **Потокобезопасность** | Несколько процессов могут совместно использовать один и тот же файл базы данных | Возможность параллельной обработки |

### Реализация кэширования результатов

```php
class GeoIpCache {
    private $cache;
    
    public function __construct($cache) {
        $this->cache = $cache;
    }
    
    /**
     * Получение данных о местоположении с кэшированием
     */
    public function getLocation($ip) {
        $cache_key = 'geoip_' . md5($ip);
        
        // Попытка получить из кэша
        $cached = $this->cache->get($cache_key);
        if ($cached !== false) {
            return $cached;
        }
        
        // Запрос к базе данных
        $location = $this->getLocationFromDatabase($ip);
        
        if ($location) {
            // Сохранение в кэш (1 час)
            $this->cache->set($cache_key, $location, 3600);
        }
        
        return $location;
    }
    
    /**
     * Очистка кэша для конкретного IP
     */
    public function clearCache($ip) {
        $cache_key = 'geoip_' . md5($ip);
        $this->cache->delete($cache_key);
    }
}
```

### Автоматизация обновления

```bash
#!/bin/bash
# update_geoip.sh - Скрипт автоматического обновления базы данных геолокации

GEOIP_DB_PATH="/var/www/site/system/libs/GeoLite2-City.mmdb"
GEOIP_LICENSE_KEY="your_license_key_here"
DOWNLOAD_URL="https://download.maxmind.com/app/geoip_download?license_key=${GEOIP_LICENSE_KEY}&edition_id=GeoLite2-City&suffix=tar.gz"

echo "Starting GeoIP2 database update..."

# Загрузка архива
wget -O /tmp/GeoLite2-City.tar.gz "$DOWNLOAD_URL"

if [ $? -ne 0 ]; then
    echo "Error: Failed to download database"
    exit 1
fi

# Распаковка архива
tar -xzf /tmp/GeoLite2-City.tar.gz -C /tmp/

# Поиск файла базы данных
DB_FILE=$(find /tmp/ -name "GeoLite2-City.mmdb" -type f)

if [ -z "$DB_FILE" ]; then
    echo "Error: Database file not found"
    exit 1
fi

# Резервное копирование старой базы
if [ -f "$GEOIP_DB_PATH" ]; then
    cp "$GEOIP_DB_PATH" "${GEOIP_DB_PATH}.backup"
    echo "Backup created: ${GEOIP_DB_PATH}.backup"
fi

# Копирование новой базы
cp "$DB_FILE" "$GEOIP_DB_PATH"

if [ $? -eq 0 ]; then
    echo "Success: GeoIP2 database updated"
    rm -rf /tmp/GeoLite2-City*
    rm -f /tmp/GeoLite2-City.tar.gz
else
    echo "Error: Failed to copy database"
    exit 1
fi
```

### Интеграция с компонентом аутентификации

```php
// /system/controllers/auth/model.php
class modelAuth extends cmsModel {
    /**
     * Аутентификация с проверкой геолокации
     */
    public function authenticate($username, $password) {
        // Получение пользователя
        $user = $this->getUserByUsername($username);
        
        if (!$user) {
            return false;
        }
        
        // Проверка пароля
        if (!password_verify($password, $user['password'])) {
            return false;
        }
        
        // Проверка геолокации для обнаружения мошенничества
        $ip = $_SERVER['REMOTE_ADDR'] ?? '127.0.0.1';
        
        if ($this->isSuspiciousLocation($ip, $user['country'])) {
            // Отправка уведомления администратору
            $this->sendSuspiciousLoginAlert($user['id'], $ip);
            
            // Можно заблокировать вход или запросить дополнительную аутентификацию
            // $this->requireTwoFactorAuth($user['id']);
        }
        
        // Обновление последнего местоположения входа
        $this->updateUserLastLoginLocation($user['id'], $ip);
        
        return $user;
    }
    
    /**
     * Обновление последнего местоположения входа пользователя
     */
    private function updateUserLastLoginLocation($user_id, $ip) {
        $location = $this->getLocationByIp($ip);
        
        if ($location) {
            $this->update('users', $user_id, [
                'last_login_country' => $location['country']['code'],
                'last_login_city' => $location['city']['name'],
                'last_login_ip' => $ip,
                'last_login_latitude' => $location['location']['latitude'],
                'last_login_longitude' => $location['location']['longitude']
            ]);
        }
    }
}
```

## 26.16. Заключение

Подсистема геолокационных сервисов обеспечивает необходимые возможности сопоставления IP-адресов с местоположением с помощью библиотеки **GeoIP2** и базы данных **GeoLite2**. Ключевые характеристики:

| Категория | Реализация |
|-----------|------------|
| **Работа в автономном режиме** | Используется локальный файл базы данных, внешние вызовы веб-сервисов не требуются |
| **Высокая производительность** | Доступ к базе данных через отображение в память обеспечивает миллионы запросов в секунду |
| **Расширенные данные** | Предоставляет информацию о стране, городе, координатах, часовом поясе и почтовом индексе |

| **Низкие затраты на обслуживание** | Ежемесячное обновление базы данных путем простой замены файлов |

Система использует эту инфраструктуру для локализации, обнаружения мошенничества, аналитики и контроля доступа на всей платформе.
