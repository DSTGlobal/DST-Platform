# 47. Примеры CLI-задач

Данный раздел демонстрирует практические примеры создания и использования CLI-задач в DST Platform. CLI-задачи выполняются через системный планировщик cron и предназначены для фоновой обработки данных, синхронизации, генерации отчётов и других операций, не требующих интерактивного взаимодействия с пользователем.

Для теоретических основ см. раздел *«Создание запланированных задач»*. Информацию о кэшировании в CLI-задачах см. в разделе *«Производительность и кэширование»*.

---

## 47.1. Общая структура CLI-скрипта

Все CLI-скрипты в DST Platform следуют единому шаблону:

```php
#!/usr/bin/env php
<?php
/**
 * cron_example_task.php
 * Пример структуры CLI-скрипта
 */

// Настройка DOCUMENT_ROOT для CLI-совместимости
if (!isset($_SERVER['DOCUMENT_ROOT']) || empty($_SERVER['DOCUMENT_ROOT'])) {
    $_SERVER['DOCUMENT_ROOT'] = getenv('DOCUMENT_ROOT') ?: dirname(__DIR__);
}
define('PATH', dirname(__FILE__));
define('NO_SESSION', true); // Отключение сессии для CLI

// 1. Проверка: только CLI-доступ
if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    die('Access denied. CLI only.');
}

// 2. Инициализация системы
require_once PATH . '/bootstrap.php';

// 3. Блокировка файла для предотвращения параллельного запуска
$lock_file = cmsConfig::get('cache_path') . 'cron_example_task_lock';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp || !flock($lockfp, LOCK_EX | LOCK_NB)) {
    error_log('[EXAMPLE_TASK] Another process is already running. Exiting.');
    exit(1);
}

// Гарантированная очистка блокировки при завершении
register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);
    }
});

// 4. Установка лимита времени выполнения (для долгих задач)
set_time_limit(0); // Без ограничения
ini_set('memory_limit', '512M'); // Увеличение лимита памяти

// 5. Загрузка контроллера
$controller = cmsCore::getController('your_controller');

if (!$controller || !$controller->isEnabled()) {
    error_log('[EXAMPLE_TASK] Controller not available or disabled');
    exit(1);
}

// 6. Выполнение хука с обработкой ошибок
try {
    error_log('[EXAMPLE_TASK] Starting execution at ' . date('Y-m-d H:i:s'));
    
    $result = $controller->runHook('cron_example_task_job');
    
    error_log(sprintf(
        '[EXAMPLE_TASK] Completed successfully at %s. Result: %s',
        date('Y-m-d H:i:s'),
        json_encode($result)
    ));
    
    exit(0);
    
} catch (Exception $e) {
    error_log(sprintf(
        '[EXAMPLE_TASK] ERROR: %s at %s:%d',
        $e->getMessage(),
        $e->getFile(),
        $e->getLine()
    ));
    
    // Логирование стека вызовов для отладки
    error_log($e->getTraceAsString());
    
    exit(1);
}
```

## 47.3. Пример 2: Импорт данных от партнёров

Скрипт `cron_partner_import.php` — пример импорта данных от внешних поставщиков.

```php
#!/usr/bin/env php
<?php
/**
 * cron_partner_import.php
 * Импорт данных партнёров/поставщиков
 */

if (!isset($_SERVER['DOCUMENT_ROOT']) || empty($_SERVER['DOCUMENT_ROOT'])) {
    $_SERVER['DOCUMENT_ROOT'] = dirname(__DIR__);
}
define('PATH', dirname(__FILE__));
define('NO_SESSION', true);

if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    exit('Access denied. CLI only.');
}

require_once PATH . '/bootstrap.php';

// Блокировка файла
$lock_file = cmsConfig::get('cache_path') . 'cron_partner_import_lock';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp || !flock($lockfp, LOCK_EX | LOCK_NB)) {
    error_log('[PARTNER_IMPORT] Another process is running. Exiting.');
    exit(1);
}

register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);
    }
});

set_time_limit(0);
ini_set('memory_limit', '512M');

// Загрузка контроллера
$controller = cmsCore::getController('partner');

if (!$controller || !$controller->isEnabled()) {
    error_log('[PARTNER_IMPORT] Partner controller is disabled. Exiting.');
    exit(0);
}

$start_time = microtime(true);
error_log('[PARTNER_IMPORT] Starting import at ' . date('Y-m-d H:i:s'));

try {
    // Получение списка активных партнёров
    $model = cmsCore::getModel('partner');
    $partners = $model->getActivePartners();
    
    $stats = [
        'total_partners' => count($partners),
        'successful' => 0,
        'failed' => 0,
        'total_items' => 0
    ];
    
    foreach ($partners as $partner) {
        error_log(sprintf(
            '[PARTNER_IMPORT] Processing partner: %s (%d)',
            $partner['name'],
            $partner['id']
        ));
        
        try {
            // Выполнение импорта для партнёра
            $result = $controller->runHook('cron_partner_import_job', $partner);
            
            if ($result && !empty($result['imported'])) {
                $stats['successful']++;
                $stats['total_items'] += $result['imported'];
                error_log(sprintf(
                    '[PARTNER_IMPORT] Partner %s: %d items imported',
                    $partner['name'],
                    $result['imported']
                ));
            } else {
                $stats['failed']++;
                error_log(sprintf(
                    '[PARTNER_IMPORT] Partner %s: Import returned no data',
                    $partner['name']
                ));
            }
            
            // Пауза между партнёрами для снижения нагрузки
            usleep(100000); // 100 мс
            
        } catch (Exception $e) {
            $stats['failed']++;
            error_log(sprintf(
                '[PARTNER_IMPORT] Error importing partner %s: %s',
                $partner['name'],
                $e->getMessage()
            ));
            // Продолжаем обработку остальных партнёров
        }
    }
    
    $duration = microtime(true) - $start_time;
    error_log(sprintf(
        '[PARTNER_IMPORT] Completed. Duration: %.2f sec. Partners: %d/%d successful. Items: %d',
        $duration,
        $stats['successful'],
        $stats['total_partners'],
        $stats['total_items']
    ));
    
    // Отправка отчёта администратору при ошибках
    if ($stats['failed'] > 0) {
        $admin_email = cmsConfig::get('admin_email');
        $mailer = cmsMailer::getInstance();
        $mailer->setTo($admin_email);
        $mailer->setSubject('Отчёт об импорте партнёров');
        $mailer->setBody(sprintf(
            "Импорт партнёров завершён с ошибками:\n\n" .
            "Успешно: %d из %d партнёров\n" .
            "Ошибок: %d\n" .
            "Импортировано товаров: %d\n" .
            "Время выполнения: %.2f сек",
            $stats['successful'],
            $stats['total_partners'],
            $stats['failed'],
            $stats['total_items'],
            $duration
        ));
        $mailer->send();
    }
    
    exit(0);
    
} catch (Exception $e) {
    error_log('[PARTNER_IMPORT] Fatal error: ' . $e->getMessage());
    error_log($e->getTraceAsString());
    exit(1);
}
```

**Ключевые особенности:**
- Обработка нескольких партнёров в одном запуске
- Продолжение работы при ошибках с одним партнёром
- Пауза между обработкой партнёров для снижения нагрузки
- Отправка отчёта администратору при наличии ошибок
- Детальная статистика по каждому партнёру

## 47.4. Пример 3: Генерация YML-фида для маркетплейсов

```php

<?php
/**
 * cron_yml_create.php
 * Генерация YML-фида для маркетплейсов

if (!isset($_SERVER['DOCUMENT_ROOT']) || empty($_SERVER['DOCUMENT_ROOT'])) {
    $_SERVER['DOCUMENT_ROOT'] = dirname(__DIR__);
}

define('NO_SESSION', true);

if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    exit('Access denied. CLI only.');
}

// Блокировка файла
$lock_file = cmsConfig::get('cache_path') . 'cron_lock_yml';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp || !flock($lockfp, LOCK_EX | LOCK_NB)) {
    error_log('[YML] Another process is running. Exiting.');
    exit(1);
}

register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);

    error_log('[YML] Shop controller is disabled. Exiting.');
    exit(0);

$start_time = microtime(true);

    // Генерация основного фида
    $result = cmsEventsManager::hook('cron_yml_create_files');
    
    if ($result === false) {
        throw new Exception('Main feed generation failed');
    }
    
    // Генерация фида для Яндекс.Маркета (если компонент доступен)
    if (cmsCore::isControllerExists('market')) {
        $market_controller = cmsCore::getController('market');
        if ($market_controller && $market_controller->isEnabled()) {
            $market_result = cmsEventsManager::hook('cron_yml_market_create_files');
            
            if ($market_result === false) {
                error_log('[YML] Warning: Market feed generation failed, but main feed succeeded');
            }
        }
    }
    
    $duration = microtime(true) - $start_time;
    error_log(sprintf(
        '[YML] Completed successfully. Duration: %.2f sec. Products: %d',
        $duration,
        $result['products_count'] ?? 0
    ));
    
    // Создание символической ссылки на последний фид
    $latest_path = PATH . '/exports/jobs/latest_yml_feed.xml';
    $current_path = PATH . '/exports/jobs/yml_feed_' . date('YmdHis') . '.xml';
    
    if (file_exists($current_path)) {
        if (file_exists($latest_path)) {
            unlink($latest_path);
        }
        symlink(basename($current_path), $latest_path);
        error_log('[YML] Created symlink to latest feed: ' . $latest_path);
    }
    
    exit(0);
    
} catch (Exception $e) {
    error_log('[YML] Exception: ' . $e->getMessage());
    error_log($e->getTraceAsString());
    exit(1);
}
```

**Ключевые особенности:**
- Генерация нескольких фидов в одном скрипте
- Проверка существования компонентов перед вызовом
- Создание символической ссылки на последний фид для удобства доступа
- Продолжение работы при частичных ошибках (рыночный фид)

## 47.5. Пример 4: Асинхронный запуск задачи через exec()

Пример из компонента AI — запуск фоновой задачи без блокировки основного процесса.

```php
<?php
/**
 * Запуск фоновой задачи генерации контента через exec()
 * Используется в контроллере AI для асинхронной обработки
 */

// В контроллере AI
public function actionGenerateProductDescription() {
    // ... валидация и подготовка данных ...
    
    // Создание задачи в БД
    $task_id = $this->model->insert('ai_generate_jobs', [
        'content' => $content,
        'model' => $model_name,
        'status' => 'pending',
        'created_at' => date('Y-m-d H:i:s')
    ]);
    
    // Асинхронный запуск обработчика через CLI
    $php_path = PHP_BINDIR . '/php';
    $cron_script = $_SERVER['DOCUMENT_ROOT'] . '/system/controllers/ai/hooks/cron_ai_generate_product.php';
    
    // Формирование команды с перенаправлением вывода в /dev/null
    $cmd = "nohup $php_path -f $cron_script > /dev/null 2>&1 < /dev/null &";
    
    // Альтернатива: с логированием (раскомментировать при отладке)
    // $log = $_SERVER['DOCUMENT_ROOT'] . '/ai_exec_debug.log';
    // $cmd = "nohup $php_path -f $cron_script >> $log 2>&1 < /dev/null &";
    
    exec($cmd);
    
    // Возврат немедленного ответа клиенту
    return $this->cms_template->renderJSON([
        'error' => false,
        'status' => 'pending',
        'job_id' => $task_id
    ]);
}
```

**Скрипт обработчика `cron_ai_generate_product.php`:**

```php
#!/usr/bin/env php
<?php
/**
 * cron_ai_generate_product.php
 * Обработчик фоновых задач генерации контента AI
 */

if (!isset($_SERVER['DOCUMENT_ROOT']) || empty($_SERVER['DOCUMENT_ROOT'])) {
    $_SERVER['DOCUMENT_ROOT'] = dirname(__DIR__, 4);
}
require_once $_SERVER['DOCUMENT_ROOT'] . '/bootstrap.php';

// Блокировка файла
$lock_file = cmsConfig::get('cache_path') . 'cron_ai_generate_product_lock';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp || !flock($lockfp, LOCK_EX | LOCK_NB)) {
    exit(0); // Уже запущен, выходим тихо
}

register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);
    }
});

set_time_limit(300); // 5 минут на задачу
ini_set('memory_limit', '256M');

$model = cmsCore::getModel('ai');
$config = cmsConfig::getInstance();
$parsedown = new Parsedown();

// Получение ожидающих задач (лимит 10 за запуск)
$tasks = $model->filterEqual('status', 'pending')
    ->limit(10)
    ->get('ai_generate_jobs');

if (empty($tasks)) {
    exit(0);
}

foreach ($tasks as $task) {
    // Обновление статуса задачи
    $model->update('ai_generate_jobs', $task['id'], ['status' => 'processing']);
    
    // Выбор модели и эндпоинта
    $task_model = $task['model'] ?? 'deepseek-chat';
    
    if ($task_model === 'deepseek-chat') {
        $api_key = $config->deepseek_api_key;
        $endpoint = 'https://api.deepseek.com/v1/chat/completions';
    } elseif ($task_model === 'gpt-5') {
        $api_key = $config->openai_api_key;
        $endpoint = 'https://api.openai.com/v1/chat/completions';
    } else {
        $model->update('ai_generate_jobs', $task['id'], [
            'status' => 'error',
            'result' => 'Неизвестная модель: ' . $task_model
        ]);
        continue;
    }
    
    // Формирование запроса к API
    $context = <<<EOT
Вы — профессиональный копирайтер для маркетплейса {$config->context_site_name}.
Создайте описание товара на основе предоставленной информации.
Требования:
- Объём: 150-300 слов
- Структура: краткое введение, ключевые характеристики, преимущества, призыв к действию
- Стиль: нейтральный, коммерческий, без рекламных клише
- Формат: валидный HTML (разрешены теги p, ul, li, strong, em)
EOT;
    
    $postData = [
        'model' => $task_model,
        'messages' => [
            ['role' => 'system', 'content' => $context],
            ['role' => 'user', 'content' => $task['content']],
        ],
    ];
    
    // Выполнение запроса к API
    $ch = curl_init($endpoint);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_HTTPHEADER, [
        'Content-Type: application/json',
        'Authorization: Bearer ' . $api_key
    ]);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($postData));
    curl_setopt($ch, CURLOPT_TIMEOUT, 300);
    
    $response = curl_exec($ch);
    $http_code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);
    
    // Обработка ответа
    if ($http_code == 402) {
        // Недостаточно средств на балансе
        $model->update('ai_generate_jobs', $task['id'], [
            'status' => 'error',
            'result' => 'Недостаточно средств на балансе API'
        ]);
        break; // Прекращаем обработку всех задач
    }
    
    $data = json_decode($response, true);
    
    if (isset($data['choices'][0]['message']['content'])) {
        $html_content = $parsedown->text($data['choices'][0]['message']['content']);
        
        $model->update('ai_generate_jobs', $task['id'], [
            'status' => 'done',
            'result' => $html_content
        ]);
    } else {
        $model->update('ai_generate_jobs', $task['id'], [
            'status' => 'error',
            'result' => 'Некорректный ответ от API: ' . ($data['error']['message'] ?? 'unknown')
        ]);
    }
    
    // Пауза между запросами для соблюдения рейт-лимитов
    sleep(2);
}

exit(0);
```

**Ключевые особенности:**
- Асинхронный запуск через `exec()` с `nohup`
- Обработка нескольких задач в одном запуске (лимит 10)
- Соблюдение рейт-лимитов API через паузы
- Поддержка нескольких моделей AI (DeepSeek, GPT)
- Преобразование Markdown в HTML через Parsedown

## 47.6. Пример 5: Очистка временных файлов (универсальный планировщик)

Пример задачи, управляемой через универсальный планировщик (`cron.php`).

**Регистрация задачи в БД:**
```sql
INSERT INTO scheduler_tasks (
    title, 
    controller, 
    hook, 
    period, 
    is_enabled, 
    next_run
) VALUES (
    'Очистка временных файлов',
    'admin',
    'clean_temp_files',
    1440,  -- Каждые 24 часа
    1,
    DATE_ADD(NOW(), INTERVAL 1440 MINUTE)
);
```

**Реализация хука в `admin/hooks.php`:**
```php
<?php
// /system/controllers/admin/hooks.php
class admin extends cmsAction {
    
    /**
     * Очистка временных файлов старше 24 часов
     */
    public function cron_clean_temp_files() {
        $start_time = microtime(true);
        $stats = [
            'deleted_files' => 0,
            'deleted_dirs' => 0,
            'errors' => 0
        ];
        
        // Каталоги для очистки
        $cleanup_dirs = [
            PATH . '/cache/tmp/',
            PATH . '/upload/tmp/',
            PATH . '/exports/jobs/tmp/'
        ];
        
        $cutoff_time = time() - (24 * 60 * 60); // 24 часа
        
        foreach ($cleanup_dirs as $dir) {
            if (!is_dir($dir)) {
                continue;
            }
            
            $iterator = new RecursiveIteratorIterator(
                new RecursiveDirectoryIterator($dir, RecursiveDirectoryIterator::SKIP_DOTS),
                RecursiveIteratorIterator::CHILD_FIRST
            );
            
            foreach ($iterator as $file) {
                try {
                    // Пропускаем файлы, изменённые менее 24 часов назад
                    if ($file->getMTime() > $cutoff_time) {
                        continue;
                    }
                    
                    if ($file->isDir()) {
                        if (@rmdir($file->getRealPath())) {
                            $stats['deleted_dirs']++;
                        }
                    } else {
                        if (@unlink($file->getRealPath())) {
                            $stats['deleted_files']++;
                        }
                    }
                } catch (Exception $e) {
                    $stats['errors']++;
                    error_log(sprintf(
                        '[CLEANUP] Error deleting %s: %s',
                        $file->getRealPath(),
                        $e->getMessage()
                    ));
                }
            }
        }
        
        $duration = microtime(true) - $start_time;
        error_log(sprintf(
            '[CLEANUP] Completed. Duration: %.2f sec. Files: %d, Dirs: %d, Errors: %d',
            $duration,
            $stats['deleted_files'],
            $stats['deleted_dirs'],
            $stats['errors']
        ));
        
        return $stats;
    }
}
```

**Ключевые особенности:**
- Использование универсального планировщика через таблицу `scheduler_tasks`
- Рекурсивная очистка вложенных директорий
- Пропуск недавно изменённых файлов
- Обработка ошибок без прерывания всего процесса
- Детальная статистика выполнения

## 47.7. Лучшие практики для CLI-задач

### ✅ Рекомендуется

| Практика | Обоснование | Пример |
|----------|-------------|--------|
| **Использовать блокировку файлов** | Предотвращение параллельного выполнения | `flock($fp, LOCK_EX \| LOCK_NB)` |
| **Логировать ключевые метрики** | Отслеживание производительности и ошибок | `error_log('[TASK] Processed: ' . $count)` |
| **Устанавливать адекватные лимиты** | Предотвращение аварийного завершения | `set_time_limit(0)`, `ini_set('memory_limit', '512M')` |
| **Обрабатывать ошибки на уровне записей** | Продолжение работы при частичных сбоях | `try/catch` внутри цикла обработки |
| **Использовать чанкирование** | Обработка больших объёмов данных порциями | `LIMIT 1000` в SQL-запросах |
| **Добавлять паузы между операциями** | Снижение нагрузки на сервер и внешние API | `usleep(100000)` между запросами |
| **Проверять существование компонентов** | Избежание фатальных ошибок | `cmsCore::isControllerExists('market')` |
| **Использовать абсолютные пути** | Предотвращение проблем с путями в CLI | `PATH . '/exports/jobs/'` |

### ❌ Избегайте

| Антипаттерн | Риск | Решение |
|-------------|------|---------|
| **Отсутствие блокировки** | Параллельное выполнение → конфликты данных | Всегда использовать файловую блокировку |
| **Игнорирование ошибок** | Невидимые сбои, повреждение данных | Логировать все исключения |
| **Жёсткое кодирование путей** | Проблемы при развёртывании на разных серверах | Использовать константы `PATH`, `cmsConfig::get()` |
| **Долгие операции без прогресса** | Сложность диагностики зависаний | Логировать прогресс каждые N записей |
| **Прямые SQL-запросы без транзакций** | Риск частичного обновления данных | Использовать транзакции для критических операций |
| **Хранение учётных данных в коде** | Утечка секретов в репозиторий | Использовать переменные окружения или конфигурацию |

## 47.9. Интеграция с системным cron

### Примеры записей в crontab

```bash
# Ежедневный экспорт каталога в 02:00
0 2 * * * /usr/bin/php /var/www/site/cron_export.php >> /var/log/dst_cron_export.log 2>&1

# Экспорт каждые 6 часов (для синхронизации с 3PL)

# Импорт данных партнёров каждые 15 минут

# Генерация YML-фида каждый час
0 * * * * /usr/bin/php /var/www/site/cron_yml_create.php >> /var/log/dst_cron_yml.log 2>&1

# Универсальный планировщик каждые 5 минут
*/5 * * * * /usr/bin/php /var/www/site/cron.php >> /var/log/dst_cron.log 2>&1

# Очистка временных файлов ежедневно в 03:00
0 3 * * * /usr/bin/php /var/www/site/cron.php yourdomain.com 123 >> /var/log/dst_cron_cleanup.log 2>&1
```

### Настройка уведомлений об ошибках

```bash
# Отправка email при ненулевом коде возврата
0 2 * * * /usr/bin/php /var/www/site/cron_export.php || echo "Export failed" | mail -s "CRON ERROR" admin@example.com

# Использование утилиты ts для добавления временных меток в лог
*/5 * * * * /usr/bin/php /var/www/site/cron.php 2>&1 | /usr/bin/ts '[%Y-%m-%d %H:%M:%S]' >> /var/log/dst_cron.log
```

### Ротация логов

```bash
# /etc/logrotate.d/dst_cron
/var/log/dst_cron*.log {

    rotate 30
    compress
    delaycompress
    missingok
    notifempty

        /usr/bin/systemctl reload rsyslog.service > /dev/null 2>&1 || true
    endscript
```

## 47.10. Заключение

CLI-задачи в DST Platform предоставляют мощный механизм для автоматизации фоновых операций:

**Ключевые преимущества:**
- **Надёжность**: Файловая блокировка предотвращает параллельное выполнение

- **Интеграция**: Использование системы хуков для расширения функциональности

- Для задач с изменяемым расписанием — использовать универсальный планировщик (`cron.php`)
- Для критически важных операций — создавать специализированные скрипты
- Всегда реализовывать блокировку файлов и обработку ошибок
