# 16. Функции социальной платформы

Данный документ содержит исчерпывающую техническую спецификацию **социальных функций** платформы DST Platform, составляющих «социальную половину» двойной архитектуры системы. Эти компоненты обеспечивают создание сообществ, управление пользовательским контентом, социальное взаимодействие и интеграцию с бизнес-логикой маркетплейса.

> **Важно**: Социальные компоненты и бизнес-компоненты используют **единое ядро** (`cmsCore`, `cmsUser`, `cmsPermissions`, `cmsEventsManager`), что позволяет создавать гибридные экосистемы (социальные маркетплейсы, сообщества продавцов, совместные закупки и др.).

---

## 16.1. Архитектурная философия

Уникальная архитектура DST Platform объединяет возможности социальных сетей с бизнес-логикой посредством единого ядра. Социальные компоненты используют ту же базовую инфраструктуру, что и бизнес-компоненты, включая cmsCore, cmsUser, cmsPermissions, и cmsEventsManager.

### Двойная архитектура: социальное + бизнес

| Аспект | Социальные компоненты | Бизнес-компоненты |
|--------|----------------------|-------------------|
| **Философия** | Расширение парадигмы сообществ (в духе Drupal) | Корпоративные платформы электронной коммерции |
| **Основная цель** | Взаимодействие пользователей, пользовательский контент, вовлечение | Автоматизация продаж, логистики, B2B-операций |
| **Ключевые компоненты** | `groups`, `forum`, `wall`, `photos`, `comments`, `activity` | `shop`, `partner`, `orders`, `delivery`, `payment`, `tenders` |
| **Типовые приложения** | Соцсети, новостные порталы, образовательные платформы, клубы | Маркетплейсы, B2B-порталы, e-commerce, сервисные системы |
| **Модель данных** | Пользовательский контент, активность, связи | Товары, заказы, инвентарь, рабочие процессы |

### Гибридные сценарии

Благодаря единому ядру возможны следующие гибридные экосистемы:

| Сценарий | Социальные компоненты | Бизнес-компоненты | Интеграция |
|----------|----------------------|-------------------|------------|
| **Социальный маркетплейс** | `groups`, `forum`, `reviews`, `activity` | `shop`, `orders`, `payment` | Обсуждения товаров, рейтинги продавцов, пользовательские отзывы |
| **Корпоративный портал** | `users`, `groups`, `messages`, `wall` | `partner`, `tenders`, `purchase_requisition` | Внутренние сети + инструменты закупок |
| **Образовательная платформа** | `content`, `forum`, `groups`, `comments` | `shop` (курсы), `payment` | Курсы + сообщества учащихся |
| **Социальная коммерция** | `wall`, `stories`, `photos` | `shop`, `cart` | Продвижение товаров через стены и истории |

Интеграция позволяет создавать гибридные экосистемы, такие как:

- Торговые площадки с социальными функциями (обсуждение товаров, рейтинги продавцов, контент, создаваемый пользователями)
- Корпоративные порталы с внутренними социальными сетями и инструментами закупок.
- Образовательные платформы с курсами (бизнес-логика) и студенческими сообществами (социальные функции)

## 16.4. Система профилей пользователей

### Компонент `users`

Управляет профилями пользователей, настройками аккаунтов и личным кабинетом покупателя.

#### Структура файлов

| Файл | Класс | Назначение |
|------|-------|------------|
| `/system/controllers/users/frontend.php` | `users` | Фронтенд-контроллер (публичные профили) |
| `/system/controllers/users/backend/controller.php` | `backendUsers` | Административный интерфейс |
| `/system/controllers/users/model.php` | `modelUsers` | Модель данных пользователей |
| `/templates/default/controllers/users/profile.tpl.php` | — | Шаблон профиля пользователя |
| `/templates/default/controllers/users/profile/` | — | Подшаблоны разделов ЛК |

#### Основные функции

| Функция | Метод контроллера | Описание |
|---------|-------------------|----------|
| Просмотр профиля | `actionProfile($username)` | Публичная страница профиля |
| Редактирование профиля | `actionEdit()` | Форма редактирования данных |
| История заказов | `actionOrders()` | Список заказов пользователя |

#### Пример реализации профиля

```php
// /system/controllers/users/frontend.php
class users extends cmsFrontend {
    
    /**
     * Просмотр профиля пользователя
     */
    public function actionProfile($username = null) {
        // Получение пользователя по имени
        $user = $this->model->getUserByUsername($username);
        
        if (!$user) {
            cmsCore::error404('Пользователь не найден');
        }
        
        // Проверка прав доступа к профилю
        if (!$this->checkProfileAccess($user)) {
            cmsCore::error404('Доступ запрещён');
        }
        
        // Получение дополнительных данных
        $user['stats'] = $this->model->getUserStats($user['id']);
        $user['friends_count'] = $this->model->getFriendsCount($user['id']);
        $user['groups'] = $this->model->getUserGroups($user['id']);
        
        // Установка мета-тегов
        $this->setPageTitle($user['nickname']);
        $this->setPageDescription('Профиль пользователя ' . $user['nickname']);
        
        return $this->render('profile', ['user' => $user]);
    }
    
    /**
     * Редактирование профиля
     */
    public function actionEdit() {
        // Проверка аутентификации
        $user = $this->getUser();
        if (!$user) {
            $this->redirect('/auth/login');
        }
        
        // Обработка формы
        if ($this->request->has('submit')) {
            $data = $this->request->get('user', []);
            
            // Валидация данных
            $errors = $this->validateProfileData($data);
            if (!empty($errors)) {
                return $this->render('profile_edit', [
                    'user' => $user,
                    'errors' => $errors
                ]);
            }
            
            // Обновление профиля
            $this->model->updateUserProfile($user['id'], $data);
            
            cmsUser::addSessionMessage('Профиль успешно обновлён', 'success');
            $this->redirect('/users/' . $user['username']);
        }
        
        return $this->render('profile_edit', ['user' => $user]);
    }
    
    /**
     * Проверка доступа к профилю
     */
    private function checkProfileAccess($user) {
        $current_user = cmsUser::getInstance();
        
        // Владелец профиля всегда имеет доступ
        if ($current_user->id == $user['id']) {
            return true;
        }
        
        // Проверка настроек приватности
        if ($user['privacy_profile'] == 'private') {
            return false;
        }
        
        if ($user['privacy_profile'] == 'friends') {
            return $this->model->isFriend($current_user->id, $user['id']);
        }
        
        return true;
    }
}
```

#### Модель данных пользователя

```php
// /system/controllers/users/model.php
class modelUsers extends cmsModel {
    
    /**
     * Получение пользователя по имени
     */
    public function getUserByUsername($username) {
        return $this->getItemByField('users', 'username', $username);
    }
    
    /**
     * Получение статистики пользователя
     */
    public function getUserStats($user_id) {
        return [
            'posts_count' => $this->getCount('content', ['user_id' => $user_id]),
            'comments_count' => $this->getCount('comments', ['user_id' => $user_id]),
            'photos_count' => $this->getCount('photos', ['user_id' => $user_id]),
            'groups_count' => $this->getCount('groups_members', ['user_id' => $user_id, 'is_approved' => 1]),
            'rating' => $this->getRating($user_id)
        ];
    }
    
    /**
     * Обновление профиля пользователя
     */
    public function updateUserProfile($user_id, $data) {
        // Фильтрация полей
        $allowed_fields = ['nickname', 'about', 'phone', 'city', 'website', 'privacy_profile'];
        $update_data = array_intersect_key($data, array_flip($allowed_fields));
        
        // Обновление основной таблицы
        $this->update('users', $user_id, $update_data);
        
        // Обновление дополнительных полей
        $this->updateUserProfileFields($user_id, $data);
        
        // Запуск события
        cmsEventsManager::hook('user_profile_updated', [
            'user_id' => $user_id,
            'data' => $update_data
        ]);
    }
    
    /**
     * Получение рейтинга пользователя
     */
    public function getRating($user_id) {
        $rating = $this->select('user_karma')
            ->filterEqual('user_id', $user_id)
            ->select('SUM(value) as total')
            ->getItem();
        
        return $rating['total'] ?? 0;
    }
}
```

## 16.5. Система аутентификации

### Компонент `auth`

Отвечает за регистрацию, вход, восстановление пароля и управление сессиями.

#### Основные функции

| Функция | Метод | Описание |
|---------|-------|----------|
| Регистрация | `actionRegister()` | Создание нового аккаунта |
| Вход | `actionLogin()` | Аутентификация пользователя |
| Выход | `actionLogout()` | Завершение сессии |
| Восстановление пароля | `actionRecover()` | Сброс пароля по email |
| Подтверждение email | `actionConfirmEmail()` | Верификация адреса электронной почты |
| Социальная авторизация | `actionSocialLogin()` | Вход через соцсети (расширяемо) |

#### Пример реализации регистрации

```php
// /system/controllers/auth/frontend.php
class auth extends cmsFrontend {
    
    /**
     * Регистрация нового пользователя
     */
    public function actionRegister() {
        // Если пользователь уже авторизован — редирект
        if (cmsUser::getInstance()->is_logged) {
            $this->redirect('/');
        }
        
        // Обработка формы
        if ($this->request->has('submit')) {
            $data = $this->request->get('user', []);
            
            // Валидация данных
            $errors = $this->validateRegistration($data);
            if (!empty($errors)) {
                return $this->render('register', [
                    'data' => $data,
                    'errors' => $errors
                ]);
            }
            
            // Хеширование пароля
            $data['password'] = password_hash($data['password'], PASSWORD_DEFAULT);
            
            // Создание пользователя
            $user_id = $this->model->addUser($data);
            
            if (!$user_id) {
                cmsUser::addSessionMessage('Ошибка создания аккаунта', 'error');
                return $this->render('register', ['data' => $data]);
            }
            
            // Отправка письма с подтверждением
            $this->sendConfirmationEmail($user_id, $data['email']);
            
            // Автоматический вход (опционально)
            $this->autoLogin($user_id);
            
            cmsUser::addSessionMessage(
                'Регистрация успешна! На ваш email отправлено письмо с подтверждением.',
                'success'
            );
            
            $this->redirect('/');
        }
        
        return $this->render('register');
    }
    
    /**
     * Валидация данных регистрации
     */
    private function validateRegistration($data) {
        $errors = [];
        
        // Проверка имени пользователя
        if (empty($data['username'])) {
            $errors['username'] = 'Введите имя пользователя';
        } elseif (strlen($data['username']) < 3) {
            $errors['username'] = 'Имя пользователя должно быть не менее 3 символов';
        } elseif ($this->model->usernameExists($data['username'])) {
            $errors['username'] = 'Это имя пользователя уже занято';
        }
        
        // Проверка email
        if (empty($data['email'])) {
            $errors['email'] = 'Введите email';
        } elseif (!filter_var($data['email'], FILTER_VALIDATE_EMAIL)) {
            $errors['email'] = 'Некорректный формат email';
        } elseif ($this->model->emailExists($data['email'])) {
            $errors['email'] = 'Этот email уже зарегистрирован';
        }
        
        // Проверка пароля
        if (empty($data['password'])) {
            $errors['password'] = 'Введите пароль';
        } elseif (strlen($data['password']) < 6) {
            $errors['password'] = 'Пароль должен быть не менее 6 символов';
        } elseif ($data['password'] !== $data['password_confirm']) {
            $errors['password_confirm'] = 'Пароли не совпадают';
        }
        
        // Проверка CAPTCHA (если включена)
        if (cmsConfig::get('recaptcha_enabled')) {
            $recaptcha_response = $this->request->get('g-recaptcha-response');
            if (!$this->validateRecaptcha($recaptcha_response)) {
                $errors['recaptcha'] = 'Подтвердите, что вы не робот';
            }
        }
        
        return $errors;
    }
    
    /**
     * Отправка письма с подтверждением
     */
    private function sendConfirmationEmail($user_id, $email) {
        // Генерация токена подтверждения
        $token = $this->generateConfirmationToken($user_id);
        
        // Формирование ссылки
        $confirm_url = cmsConfig::get('host') . '/auth/confirm-email/' . $token;
        
        // Отправка письма
        $mailer = cmsMailer::getInstance();
        $mailer->setTo($email);
        $mailer->setSubject('Подтверждение регистрации');
        $mailer->setBody($this->renderMailTemplate('confirm_email', [
            'confirm_url' => $confirm_url
        ]));
        $mailer->send();
    }
}
```

#### Пример реализации

```php
// /system/controllers/groups/frontend.php
class groups extends cmsFrontend {
    
    /**
     * Список групп
     */
    public function actionIndex() {
        $filters = [
            'type' => $this->request->get('type'),
            'search' => $this->request->get('search')
        ];
        
        $groups = $this->model->getGroups($filters, [
            'page' => $this->request->get('page', 1),
            'perpage' => 20
        ]);
        
        return $this->render('index', [
            'groups' => $groups,
            'filters' => $filters
        ]);
    }
    
    /**
     * Просмотр группы
     */
    public function actionView($id) {
        $group = $this->model->getGroupById($id);
        
        if (!$group) {
            cmsCore::error404('Группа не найдена');
        }
        
        // Проверка доступа
        if (!$this->checkGroupAccess($group)) {
            cmsCore::error404('Доступ запрещён');
        }
        
        // Получение участников
        $members = $this->model->getGroupMembers($id, [
            'role' => 'member',
            'limit' => 20
        ]);
        
        // Получение контента группы
        $content = $this->model->getGroupContent($id, [
            'limit' => 10
        ]);
        
        return $this->render('view', [
            'group' => $group,
            'members' => $members,
            'content' => $content
        ]);
    }
    
    /**
     * Вступление в группу
     */
    public function actionJoin($id) {
        $user = $this->getUser();
        if (!$user) {
            $this->redirect('/auth/login?redirect=' . urlencode($this->request->uri));
        }
        
        $group = $this->model->getGroupById($id);
        
        // Проверка, не состоит ли уже пользователь в группе
        if ($this->model->isMember($id, $user->id)) {
            cmsUser::addSessionMessage('Вы уже состоите в этой группе', 'error');
            $this->redirect('/groups/' . $id);
        }
        
        // Добавление участника
        $this->model->addMember($id, $user->id);
        
        // Отправка уведомления владельцу группы (если требуется)
        if ($group['type'] == 'private') {
            $this->model->sendJoinRequestNotification($id, $user->id);
        }
        
        cmsUser::addSessionMessage('Вы успешно вступили в группу', 'success');
        $this->redirect('/groups/' . $id);
    }
    
    /**
     * Проверка доступа к группе
     */
    private function checkGroupAccess($group) {
        $user = cmsUser::getInstance();
        
        // Владелец и администраторы всегда имеют доступ
        if ($user->id == $group['owner_id'] || $this->model->isAdmin($group['id'], $user->id)) {
            return true;
        }
        
        // Проверка членства
        if ($this->model->isMember($group['id'], $user->id)) {
            return true;
        }
        
        // Публичные группы доступны всем
        if ($group['type'] == 'public') {
            return true;
        }
        
        return false;
    }
}
```

### Компонент `comments` — система комментариев

Универсальная древовидная система комментариев для любого контента.

#### Архитектура

```
┌────────────────────────────────────────────────────────────┐
│                   КОМПОНЕНТ comments                       │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Полиморфная привязка:                                     │
│  • target_controller — имя компонента (например, 'shop')   │
│  • target_id — ID сущности в компоненте                    │
│                                                            │
│  Примеры использования:                                    │
│  • Комментарии к товарам: target_controller='shop',        │
│                            target_id=123                   │
│  • Комментарии к статьям: target_controller='content',     │
│                            target_id=456                   │
│  • Комментарии к фото:    target_controller='photos',      │
│                            target_id=789                   │
│                                                            │
│  Древовидная структура:                                    │
│  • Комментарий может иметь родителя (parent_id)            │
│  • Поддержка вложенных ответов (до N уровней)              │
│  • Модерация (одобрение/отклонение)                        │
└────────────────────────────────────────────────────────────┘
```

#### Структура таблицы

```sql
CREATE TABLE `comments` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `target_controller` varchar(50) NOT NULL,
  `target_id` int(11) NOT NULL,
  `parent_id` int(11) DEFAULT NULL,
  `user_id` int(11) NOT NULL,
  `content` text NOT NULL,
  `is_approved` tinyint(1) DEFAULT 1,
  `rating` int(11) DEFAULT 0,
  `created_at` datetime,
  `updated_at` datetime,
  PRIMARY KEY (`id`),
  KEY `target` (`target_controller`, `target_id`),
  KEY `parent_id` (`parent_id`),
  KEY `user_id` (`user_id`),
  KEY `is_approved` (`is_approved`)
);
```

#### Пример реализации

```php
// /system/controllers/comments/frontend.php
class comments extends cmsFrontend {
    
    /**
     * Получение комментариев для сущности
     */
    public function actionGet($controller, $id) {
        $comments = $this->model->getComments($controller, $id, [
            'is_approved' => 1,
            'order_by' => 'created_at',
            'order_dir' => 'ASC'
        ]);
        
        // Форматирование в древовидную структуру
        $tree = $this->buildCommentsTree($comments);
        
        return $this->json([
            'success' => true,
            'comments' => $tree,
            'count' => count($comments)
        ]);
    }
    
    /**
     * Добавление комментария
     */
    public function actionAdd() {
        $user = $this->getUser();
        if (!$user) {
            return $this->json(['success' => false, 'error' => 'Требуется авторизация']);
        }
        
        $data = $this->request->get('comment', []);
        
        // Валидация
        if (empty($data['content'])) {
            return $this->json(['success' => false, 'error' => 'Введите текст комментария']);
        }
        
        if (strlen($data['content']) > 5000) {
            return $this->json(['success' => false, 'error' => 'Комментарий слишком длинный']);
        }
        
        // Добавление комментария
        $comment_id = $this->model->addComment([
            'target_controller' => $data['controller'],
            'target_id' => $data['id'],
            'parent_id' => $data['parent_id'] ?? null,
            'user_id' => $user->id,
            'content' => $data['content'],
            'is_approved' => $this->needModeration($data['controller']) ? 0 : 1
        ]);
        
        if (!$comment_id) {
            return $this->json(['success' => false, 'error' => 'Ошибка добавления комментария']);
        }
        
        // Запуск события
        $comment = $this->model->getCommentById($comment_id);
        cmsEventsManager::hook('comment_added', $comment);
        
        return $this->json([
            'success' => true,
            'comment_id' => $comment_id,
            'message' => $this->needModeration($data['controller']) 
                ? 'Комментарий добавлен и будет опубликован после модерации'
                : 'Комментарий успешно добавлен'
        ]);
    }
    
    /**
     * Проверка необходимости модерации
     */
    private function needModeration($controller) {
        // Модерация для товаров включена по умолчанию
        if ($controller == 'shop') {
            return true;
        }
        
        // Проверка настроек компонента
        $config = $this->model->getComponentConfig($controller);
        return $config['moderate_comments'] ?? false;
    }
    
    /**
     * Построение древовидной структуры
     */
    private function buildCommentsTree($comments, $parent_id = null) {
        $tree = [];
        
        foreach ($comments as $comment) {
            if ($comment['parent_id'] == $parent_id) {
                $children = $this->buildCommentsTree($comments, $comment['id']);
                
                $tree[] = [
                    'id' => $comment['id'],
                    'user' => $this->model->getUserById($comment['user_id']),
                    'content' => $comment['content'],
                    'created_at' => $comment['created_at'],
                    'rating' => $comment['rating'],
                    'children' => $children
                ];
            }
        }
        
        return $tree;
    }
}
```

#### Пример реализации

```php
// /system/controllers/notifications/model.php
class modelNotifications extends cmsModel {
    
    /**
     * Добавление уведомления
     */
    public function addNotification($data) {
        $notification_id = $this->insert('notifications', [
            'user_id' => $data['user_id'],
            'type' => $data['type'],
            'sender_id' => $data['sender_id'] ?? null,
            'target_controller' => $data['target_controller'] ?? null,
            'target_id' => $data['target_id'] ?? null,
            'message' => $data['message'],
            'is_read' => 0,
            'created_at' => date('Y-m-d H:i:s')
        ]);
        
        // Отправка email (если настроено)
        if ($this->shouldSendEmail($data['user_id'], $data['type'])) {
            $this->sendEmailNotification($notification_id);
        }
        
        // Отправка push-уведомления (если настроено)
        if ($this->shouldSendPush($data['user_id'], $data['type'])) {
            $this->sendPushNotification($notification_id);
        }
        
        return $notification_id;
    }
    
    /**
     * Получение уведомлений пользователя
     */
    public function getUserNotifications($user_id, $filters = []) {
        $query = $this->select('notifications')
            ->filterEqual('user_id', $user_id)
            ->orderBy('created_at', 'DESC');
        
        if (isset($filters['is_read'])) {
            $query->filterEqual('is_read', $filters['is_read']);
        }
        
        if (isset($filters['type'])) {
            $query->filterEqual('type', $filters['type']);
        }
        
        return $query->limit($filters['limit'] ?? 20)->getItems();
    }
    
    /**
     * Пометка уведомления как прочитанного
     */
    public function markAsRead($notification_id, $user_id) {
        return $this->update('notifications', $notification_id, [
            'is_read' => 1
        ], ['user_id' => $user_id]);
    }
    
    /**
     * Получение количества непрочитанных уведомлений
     */
    public function getUnreadCount($user_id) {
        return $this->select('notifications')
            ->filterEqual('user_id', $user_id)
            ->filterEqual('is_read', 0)
            ->getCount();
    }
    
    /**
     * Отправка уведомления через событие
     */
    public function notify($event, $data) {
        // Получение подписчиков события
        $subscribers = $this->getSubscribers($event, $data);
        
        foreach ($subscribers as $subscriber) {
            $this->addNotification([
                'user_id' => $subscriber['user_id'],
                'type' => $event,
                'sender_id' => $data['sender_id'] ?? null,
                'target_controller' => $data['target_controller'] ?? null,
                'target_id' => $data['target_id'] ?? null,
                'message' => $this->formatMessage($event, $data)
            ]);
        }
    }
}
```

| **Рейтинг** | Рейтинги продавцов | `rating` оценивает как пользователей, так и продавцов |

### Пример интеграции: отзывы о товарах

```php
// /system/controllers/reviews/frontend.php
class reviews extends cmsFrontend {
    
    /**
     * Добавление отзыва о товаре
     */
    public function actionAdd() {
        $user = $this->getUser();
        if (!$user) {
            return $this->json(['success' => false, 'error' => 'Требуется авторизация']);
        }
        
        $data = $this->request->get('review', []);
        
        // Проверка, покупал ли пользователь этот товар
        if (!$this->model->userPurchasedProduct($user->id, $data['product_id'])) {
            return $this->json(['success' => false, 'error' => 'Вы можете оставить отзыв только о купленном товаре']);
        }
        
        // Проверка, не оставлял ли уже отзыв
        if ($this->model->reviewExists($user->id, 'shop', $data['product_id'])) {
            return $this->json(['success' => false, 'error' => 'Вы уже оставляли отзыв об этом товаре']);
        }
        
        // Добавление отзыва
        $review_id = $this->model->addReview([
            'user_id' => $user->id,
            'target_controller' => 'shop',
            'target_id' => $data['product_id'],
            'rating' => $data['rating'],
            'content' => $data['content'],
            'pros' => $data['pros'] ?? '',
            'cons' => $data['cons'] ?? '',
            'is_approved' => 1
        ]);
        
        // Обновление рейтинга товара
        $this->updateProductRating($data['product_id']);
        
        // Добавление в ленту активности
        $activity = cmsCore::getModel('activity');
        $activity->addActivity([
            'user_id' => $user->id,
            'action_type' => 'review_added',
            'target_controller' => 'shop',
            'target_id' => $data['product_id'],
            'data' => json_encode([
                'rating' => $data['rating'],
                'product_title' => $data['product_title']
            ])
        ]);
        
        return $this->json(['success' => true, 'review_id' => $review_id]);
    }
    
    /**
     * Обновление рейтинга товара
     */
    private function updateProductRating($product_id) {
        $shop_model = cmsCore::getModel('shop');
        
        // Получение всех отзывов о товаре
        $reviews = $this->model->getReviews('shop', $product_id, ['is_approved' => 1]);
        
        if (empty($reviews)) {
            return;
        }
        
        // Расчёт среднего рейтинга
        $total_rating = array_sum(array_column($reviews, 'rating'));
        $avg_rating = round($total_rating / count($reviews), 1);
        
        // Обновление рейтинга в товаре
        $shop_model->update('shop_products', $product_id, [
            'rating' => $avg_rating,
            'reviews_count' => count($reviews)
        ]);
    }
}
```

Функции:

- Рейтинг в виде звезд (обычно от 1 до 5 звезд)
- Письменные отзывы
- модерация отзывов
- Оценка отзывов (полезные/бесполезные)
- Отзывы (от владельцев/продавцов товаров)

### Пример проверки прав доступа

```php
// В любом контроллере социальных компонентов
class groups extends cmsFrontend {
    
    /**
     * Удаление группы
     */
    public function actionDelete($id) {
        $group = $this->model->getGroupById($id);
        
        if (!$group) {
            cmsCore::error404();
        }
        
        $user = cmsUser::getInstance();
        
        // Проверка: является ли пользователь владельцем группы?
        if ($user->id != $group['owner_id']) {
            // Проверка: является ли пользователь администратором?
            if (!$this->model->isAdmin($id, $user->id)) {
                cmsCore::error404('Доступ запрещён');
            }
        }
        
        // Удаление группы
        $this->model->deleteGroup($id);
        
        cmsUser::addSessionMessage('Группа успешно удалена', 'success');
        $this->redirect('/');
    }
}
```

### Пример кэширования ленты активности

```php
// /system/controllers/activity/model.php
class modelActivity extends cmsModel {
    
    /**
     * Получение ленты активности с кэшированием
     */
    public function getActivities($filters = [], $options = []) {
        // Генерация ключа кэша
        $cache_key = 'activity_' . md5(json_encode($filters) . json_encode($options));
        
        // Попытка получить из кэша
        $cached = cmsCache::getInstance()->get($cache_key);
        if ($cached !== false) {
            return $cached;
        }
        
        // Запрос к БД
        $query = $this->select('activity_stream');
        
        foreach ($filters as $field => $value) {
            if (is_array($value)) {
                $query->filterIn($field, $value);
            } else {
                $query->filterEqual($field, $value);
            }
        }
        
        $activities = $query
            ->orderBy($options['order_by'] ?? 'created_at', $options['order_dir'] ?? 'DESC')
            ->limit($options['limit'] ?? 20)
            ->getItems();
        
        // Сохранение в кэш (5 минут)
        cmsCache::getInstance()->set($cache_key, $activities, 300);
        
        return $activities;
    }
    
    /**
     * Инвалидация кэша при добавлении активности
     */
    public function addActivity($data) {
        $activity_id = $this->insert('activity_stream', array_merge($data, [
            'created_at' => date('Y-m-d H:i:s')
        ]));
        
        // Очистка кэша для всех пользователей
        $this->clearActivityCache();
        
        return $activity_id;
    }
    
    /**
     * Очистка кэша активности
     */
    private function clearActivityCache() {
        // Удаление всех ключей, начинающихся с 'activity_'
        cmsCache::getInstance()->deleteByTag('activity');
    }
}
```

```php
// /system/controllers/analytics/hooks.php
class analytics {
    /**
     * Отслеживание публикации контента
     */
    public function hookContentAfterAdd($content) {
        // Отправка данных в аналитическую систему
        $this->model->trackEvent('content_published', [
            'content_id' => $content['id'],
            'content_type' => $content['ctype_name'],
            'user_id' => $content['user_id'],
            'timestamp' => time()
        ]);
        
        // Обновление статистики пользователя
        $this->model->incrementUserStat($content['user_id'], 'content_count');
        
        return $content;
    }
    
    /**
     * Отслеживание добавления комментария
     */
    public function hookCommentAdded($comment) {
        $this->model->trackEvent('comment_added', [
            'comment_id' => $comment['id'],
            'target_type' => $comment['target_controller'],
            'target_id' => $comment['target_id'],
            'user_id' => $comment['user_id']
        ]);
        
        // Инкремент счётчика комментариев пользователя
        $this->model->incrementUserStat($comment['user_id'], 'comments_count');
        
        return $comment;
    }
}
```

## 16.22. Междоменная интеграция: Социальные сети ↔ Бизнес

Двойная архитектура платформы DST обеспечивает бесшовную интеграцию между социальными и бизнес-компонентами:

### Примеры интеграции:

| Социальная функция | Интеграция бизнеса | Механизм |
|--------------------|---------------------|----------|
| **Отзывы** | Отзывы о товарах в магазине (shop) | Компонент `reviews` работает с товарами компонента `shop` |
| **Лента активности** | Обновления статуса заказа | Компонент `activity` отслеживает события компонента `shop` |
| **Уведомления** | «Заказ отправлен», «Оплата получена» | Компонент `notifications` активируется через хуки компонента `shop` |
| **Профили пользователей** | Профили продавцов в партнёрской системе (partner) | Компонент `users` расширен для продавцов |
| **Группы** | Сообщества поставщиков, B2B-группы | Компонент `groups` может быть связан с сущностями компонента `partner` |
| **Форум** | Обсуждение товара | Темы форума (компонент `forum`) привязываются к товарам (компонент `shop`) |
| **Рейтинг** | Рейтинги продавцов | Компонент `rating` оценивает как пользователей, так и продавцов |

## 16.23. Заключение

Социальные функции платформы DST представляют собой **комплексную, модульную экосистему** для создания сообществ и управления пользовательским взаимодействием. Ключевые преимущества:

| Категория | Реализация |
|-----------|------------|
| **Архитектура** | Модульная структура с единым ядром |
| **Интеграция** | Слабая связанность через систему событий |
| **Гибкость** | Полиморфные компоненты (комментарии, отзывы работают с любым контентом) |
| **Безопасность** | Многоуровневая система приватности и контроля доступа |
| **Производительность** | Кэширование, оптимизация запросов, ленивая загрузка |
| **Расширяемость** | Точки расширения через хуки и наследование |
| **Гибридность** | Бесшовная интеграция с бизнес-компонентами |

Социальная платформа работает в тесном взаимодействии с бизнес-модулями, что позволяет создавать **гибридные приложения**:
- Социальные маркетплейсы с обсуждениями товаров и рейтингами продавцов
- Образовательные платформы с курсами и студенческими сообществами
- Корпоративные порталы с инструментами закупок и внутренними сетями
- Платформы совместной работы с социальными функциями и бизнес-процессами
