# 19. Задания экспорта продукции

Данный документ содержит техническую спецификацию системы автоматизированного экспорта данных о продукции в табличные форматы (Excel/CSV) на платформе DST Platform. Система предназначена для периодической выгрузки каталогов товаров, данных об инвентаризации и связанной информации во внешние системы без прямого доступа к базе данных.

> **Важно**: Данный документ описывает систему экспорта продукции через специализированный cron-скрипт. Для генерации фидов, специфичных для маркетплейсов (формат YML), см. раздел *«Генерация фидов для маркетплейсов»*. Для импорта данных партнёров (обратная операция) см. раздел *«Импорт данных партнёров»*. Общую архитектуру планировщика Cron см. в разделе *«Архитектура планировщика Cron»*.

## 19.1. Обзор системы

Система экспорта продукции реализована в виде специализированного cron-скрипта, работающего независимо от универсального планировщика задач (`cron.php`). Она преобразует данные о товарах из компонента `shop` в табличные форматы с использованием библиотеки **Box Spout**, что позволяет внешним системам получать информацию о товарах без прямого доступа к базе данных.

### Ключевые характеристики

| Характеристика | Реализация |
|----------------|------------|
| **Точка входа** | `cron_export.php` |
| **Контроллер** | `shop` |
| **Название хука** | `cron_export_products_job` |
| **Файл блокировки** | `{cache_path}/cron_export_lock` |
| **Модель параллелизма** | Неблокирующая блокировка файла (предотвращает повторные запуски) |
| **Требования к окружению** | Только командная строка (HTTP-доступ запрещён) |
| **Библиотека экспорта** | Box Spout ^3.3 (зависимость Composer) |
| **Форматы экспорта** | XLSX, CSV, ODS |

### Типичные сценарии использования

| Сценарий | Описание | Частота |
|----------|----------|---------|
| **Ежедневный экспорт каталога** | Полная выгрузка каталога для внешних систем отчётности | Ежедневно |
| **Синхронизация с 3PL** | Передача данных об остатках в центры выполнения заказов | Каждые 6 часов |
| **Резервное копирование** | Создание периодических снимков данных о товарах | Еженедельно |
| **Аналитика и отчёты** | Предоставление данных бизнес-аналитикам | Ежедневно |

## 19.3. Механизм блокировки файлов

Система использует блокировку на основе файлов для предотвращения одновременного выполнения нескольких экземпляров скрипта экспорта.

### Реализация блокировки

```php
#!/usr/bin/env php
<?php
// cron_export.php

// 1. Проверка: только для CLI
if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    exit('Access denied. CLI only.');
}

// 2. Инициализация ядра
require_once __DIR__ . '/bootstrap.php';

// 3. Получение пути к файлу блокировки
$lock_file = cmsConfig::get('cache_path') . 'cron_export_lock';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp) {
    error_log('[EXPORT] Cannot create lock file: ' . $lock_file);
    exit(1);
}

// 4. Попытка получить эксклюзивную неблокирующую блокировку
if (!flock($lockfp, LOCK_EX | LOCK_NB)) {
    error_log('[EXPORT] Another process is running. Exiting.');
    fclose($lockfp);
    exit(0); // Тихий выход — ожидаемое поведение
}

// 5. Гарантированная очистка блокировки при завершении
register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);
    }
});

// ... остальная логика экспорта ...
```

### Параметры блокировки

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **Тип блокировки** | `LOCK_EX | LOCK_NB` | Эксклюзивная, неблокирующая |
| **Поведение при конфликте** | Немедленный выход с кодом 0 | Предотвращение накопления процессов |
| **Область действия** | Глобальная для сервера | Предотвращение конфликтов между cron-задачами |
| **Очистка** | Автоматическая через `register_shutdown_function` | Гарантия очистки даже при аварийном завершении |

### Жизненный цикл блокировки

```
1. Создание файла блокировки
   ↓
2. Попытка получения эксклюзивной блокировки
   ↓
3. Если блокировка получена → продолжение экспорта
   Если блокировка занята → немедленный выход
   ↓
4. Выполнение бизнес-логики экспорта
   ↓
5. Автоматическая очистка блокировки (гарантированно)
```

## 19.5. Конфигурация и планирование

### Настройка системного cron

Пример записи в crontab:
```bash
# Ежедневный экспорт каталога в 02:00
0 2 * * * /usr/bin/php /var/www/site/cron_export.php >> /var/log/dst_cron_export.log 2>&1

# Экспорт каждые 6 часов (для синхронизации с 3PL)
0 */6 * * * /usr/bin/php /var/www/site/cron_export.php >> /var/log/dst_cron_export.log 2>&1
```

### Рекомендации по планированию

| Фактор | Рекомендация | Обоснование |
|--------|--------------|-------------|
| **Частота** | 1-4 раза в день | Баланс между актуальностью и нагрузкой |
| **Время запуска** | Ночное время (02:00–05:00) | Минимальная нагрузка на сервер |
| **Таймаут** | ≥ 300 секунд | Для каталогов > 10 000 товаров |
| **Логирование** | В отдельный файл | Упрощает отладку и мониторинг |
| **Уведомления** | Email при ошибках | Быстрое реагирование на сбои |

### Пример конфигурации с переменными окружения

```bash
# В crontab с явным указанием переменных
0 2 * * * DOCUMENT_ROOT=/var/www/site PHP_MEMORY_LIMIT=512M /usr/bin/php /var/www/site/cron_export.php >> /var/log/dst_cron_export.log 2>&1
```

## 19.6. Бизнес-логика экспорта

### Структура хука экспорта

```php
// /system/controllers/shop/hooks.php
class shop {
    /**
     * Хук: экспорт товаров в электронные таблицы
     * Вызывается из cron_export.php
     */
    public function hookCronExportProductsJob() {
        $start_time = microtime(true);
        
        try {
            // 1. Получение товаров для экспорта
            $products = $this->model->getProductsForExport([
                'is_published' => 1,
                'in_stock' => true,
                'limit' => 10000 // Ограничение для больших каталогов
            ]);
            
            if (empty($products)) {
                error_log('[EXPORT] No products to export');
                return true; // Не ошибка — просто нет данных
            }
            
            // 2. Инициализация Box Spout
            $writer = \Box\Spout\Writer\Common\Creator\WriterFactory::create(
                \Box\Spout\Common\Type::XLSX
            );
            
            // 3. Генерация пути к файлу с временной меткой
            $export_file = PATH . '/exports/jobs/products_' . date('Y-m-d_H-i-s') . '.xlsx';
            $writer->openToFile($export_file);
            
            // 4. Запись заголовков
            $writer->addRow([
                'ID', 'Название', 'Артикул', 'Цена', 'Остаток',
                'Категория', 'Производитель', 'Дата создания',
                'URL', 'Изображения'
            ]);
            
            // 5. Потоковая запись товаров
            $count = 0;
            foreach ($products as $product) {
                // Формирование строки для экспорта
                $row = [
                    $product['id'],
                    $product['title'],
                    $product['sku'] ?? '',
                    $product['price'],
                    $product['quantity'],
                    $product['category_title'] ?? '',
                    $product['manufacturer'] ?? '',
                    $product['date_created'],
                    $this->getProductUrl($product),
                    $this->getProductImagesCsv($product)
                ];
                
                $writer->addRow($row);
                $count++;
                
                // Прогресс-логирование каждые 1000 товаров
                if ($count % 1000 === 0) {
                    error_log("[EXPORT] Processed {$count} products...");
                }
            }
            
            $writer->close();
            
            // 6. Логирование результатов
            $duration = round(microtime(true) - $start_time, 2);
            $file_size = filesize($export_file);
            
            $this->model->logExport($export_file, $count, $duration, $file_size);
            
            error_log(sprintf(
                '[EXPORT] Successfully exported %d products to %s (%.2f MB) in %.2f seconds',
                $count,
                basename($export_file),
                $file_size / 1024 / 1024,
                $duration
            ));
            
            // 7. Очистка старых файлов (хранить 7 дней)
            $this->cleanupOldExports(7);
            
            return true;
            
        } catch (\Exception $e) {
            error_log('[EXPORT] Exception: ' . $e->getMessage());
            error_log($e->getTraceAsString());
            
            // Не выбрасываем исключение — возвращаем false
            return false;
        }
    }
    
    /**
     * Получение абсолютного URL товара
     */
    private function getProductUrl($product) {
        $config = cmsConfig::getInstance();
        return $config->get('host') . '/shop/item/' . $product['id'];
    }
    
    /**
     * Получение изображений товара в формате CSV
     */
    private function getProductImagesCsv($product) {
        $images = $this->model->getProductImages($product['id']);
        $urls = array_map(function($img) {
            $config = cmsConfig::getInstance();
            return $config->get('host') . $img['url'];
        }, $images);
        
        return implode('|', $urls);
    }
    
    /**
     * Очистка старых файлов экспорта
     */
    private function cleanupOldExports($days_to_keep) {
        $cutoff = strtotime("-{$days_to_keep} days");
        $export_dir = PATH . '/exports/jobs/';
        
        $files = glob($export_dir . 'products_*.xlsx');
        
        foreach ($files as $file) {
            if (filemtime($file) < $cutoff) {
                unlink($file);
                error_log("[EXPORT] Deleted old export: " . basename($file));
            }
        }
    }
}
```

### Фильтры товаров для экспорта

| Фильтр | Условие | Конфигурируемость |
|--------|---------|-------------------|
| **Статус публикации** | `is_published = 1` | Нет |
| **Наличие на складе** | `quantity > 0` (если включено) | Да (в настройках компонента) |
| **Цена** | `price > 0` | Нет |
| **Категория** | Принадлежит экспортируемой категории | Да |
| **Модерация** | `is_approved = 1` (если включена) | Нет |
| **Видимость** | Не скрыт от экспорта | Да |

## 19.7. Интеграция с библиотекой Box Spout

### Возможности библиотеки

| Возможность | Преимущество для экспорта |
|-------------|---------------------------|
| **Потоковая обработка** | Экспорт больших каталогов без загрузки всего набора данных в память |
| **Поддержка форматов** | XLSX, CSV, ODS |
| **Типобезопасность** | Корректная обработка чисел, дат, строк |
| **Форматирование ячеек** | Жирный, курсив, цвета, границы |
| **Работа с большими данными** | Оптимизировано для обработки миллионов строк |

### Типичная структура экспорта

```php
// Инициализация писателя
$writer = \Box\Spout\Writer\Common\Creator\WriterFactory::create(
    \Box\Spout\Common\Type::XLSX // или Type::CSV, Type::ODS
);

// Открытие файла
$writer->openToFile('/path/to/export.xlsx');

// Запись заголовков
$writer->addRow(['ID', 'Название', 'Цена', 'Остаток']);

// Потоковая запись данных
foreach ($products as $product) {
    $writer->addRow([
        $product['id'],
        $product['title'],
        $product['price'],
        $product['quantity']
    ]);
}

// Закрытие файла
$writer->close();
```

### Оптимизация для больших каталогов

```php
// Чанкирование для обработки больших каталогов
$chunk_size = 1000;
$offset = 0;
$total_exported = 0;

do {
    $products = $this->model->getProductsForExport([
        'limit' => $chunk_size,
        'offset' => $offset
    ]);
    
    if (empty($products)) {
        break;
    }
    
    foreach ($products as $product) {
        $writer->addRow($this->formatProductRow($product));
        $total_exported++;
    }
    
    $offset += $chunk_size;
    
    // Небольшая пауза между чанками
    usleep(10000); // 10 мс
    
} while (count($products) === $chunk_size);
```

## 19.10. Мониторинг и диагностика

### Ключевые метрики для мониторинга

| Метрика | Пороговое значение | Действие при превышении |
|---------|-------------------|-------------------------|
| **Время выполнения** | > 300 секунд | Оптимизация запросов, чанкирование |
| **Размер файла** | > 100 МБ | Разделение на несколько файлов |
| **Количество товаров** | Резкое падение (>50%) | Проверка фильтров и источника данных |
| **Частота ошибок** | > 5% от общего количества | Диагностика источника данных |

### Инструменты диагностики

```bash
# Проверка блокировки
ls -la cache/cron_export_lock

# Просмотр логов
tail -f /var/log/dst_cron_export.log

# Проверка последнего экспорта
cat exports/jobs/.last_export_info

# Проверка размера файлов экспорта
du -sh exports/jobs/products_*.xlsx

# Мониторинг процессов экспорта
ps aux | grep cron_export
```

### Типичные проблемы и решения

| Проблема | Симптом | Причина | Решение |
|----------|---------|---------|---------|
| **Зависший процесс** | Файл блокировки существует > 1 часа | Сбой в логике экспорта | Удалить блокировку вручную |
| **Пустой экспорт** | Файл создан, но без данных | Фильтры слишком строгие | Проверить условия выборки |
| **Ошибка памяти** | `Allowed memory size exhausted` | Большой каталог без чанкирования | Увеличить `memory_limit`, оптимизировать запросы |
| **Неверные пути к изображениям** | Ссылки не работают | Неправильный `host` в конфигурации | Проверить `cmsConfig::get('host')` |
| **Превышение времени выполнения** | Процесс завершается без результата | Таймаут PHP | Увеличить `max_execution_time` |

### Пример интеграции с внешней системой через FTP

```php
// В хуке после успешной генерации
public function hookCronExportProductsJob() {
    // ... генерация файла ...
    
    // Отправка на FTP-сервер партнёра
    $this->uploadToPartnerFTP($export_file);
    
    return true;
}

private function uploadToPartnerFTP($file_path) {
    $ftp_server = 'ftp.partner.com';
    $ftp_user = 'username';
    $ftp_pass = getenv('PARTNER_FTP_PASSWORD'); // Из переменных окружения
    
    $conn = ftp_connect($ftp_server);
    ftp_login($conn, $ftp_user, $ftp_pass);
    
    $remote_file = 'imports/products_' . date('Y-m-d') . '.xlsx';
    ftp_put($conn, $remote_file, $file_path, FTP_BINARY);
    
    ftp_close($conn);
    
    error_log("[EXPORT] Uploaded to partner FTP: {$remote_file}");
}
```

| **Кастомные форматы** | В хуке экспорта | Генерация специфичных форматов |
| **Интеграция с внешними системами** | После генерации файла | Отправка в 1С, BI-системы |

### Пример кастомного формата экспорта

```php
// В кастомном компоненте
class custom_export {
    public function hookCronExportProductsJob() {
        // Генерация специфичного формата для 1С
        $writer = \Box\Spout\Writer\Common\Creator\WriterFactory::create(
            \Box\Spout\Common\Type::CSV
        );
        
        $file = PATH . '/exports/jobs/1c_import_' . date('Y-m-d_H-i-s') . '.csv';
        $writer->openToFile($file);
        
        // Заголовки в формате 1С
        $writer->addRow([
            'НоменклатураКод',
            'НоменклатураНаименование',
            'ЦенаРозничная',
            'Остаток'
        ]);
        
        // Данные в формате 1С
        $products = cmsCore::getModel('shop')->getProductsFor1C();
        
        foreach ($products as $product) {
            $writer->addRow([
                $product['guid'],
                $product['name'],
                $product['price'],
                $product['stock']
            ]);
        }
        
        $writer->close();
        
        return true;
    }
}
```
