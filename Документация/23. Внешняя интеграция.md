# 23. Внешняя интеграция

Данный документ содержит исчерпывающую техническую спецификацию внешних интеграций платформы DST Platform. Система использует шесть ключевых сторонних сервисов и библиотек, управляемых через Composer, для реализации критически важных бизнес-функций: обработки платежей, логистики, геолокации, кэширования и обмена данными.

> **Важно**: Данный документ описывает архитектурные принципы и технические детали внешних интеграций. Для получения информации о конкретных реализациях см.:
> - *«Интеграция с платежным шлюзом»* — обработка платежей через ЮKassa
> - *«Доставка и логистика»* — интеграция с CDEK
> - *«Геолокационные службы»* — определение местоположения по IP
> - *«Почтовые сервисы»* — отправка электронной почты
> - *«Взаимодействие HTTP-клиента и API»* — работа с внешними API
> - *«Импорт/экспорт данных»* — операции с электронными таблицами
> - *«Производительность и кэширование»* — стратегии кэширования

## 23.1. Архитектурный обзор

DST Platform интегрируется с шестью основными внешними сервисами и библиотеками, управление которыми осуществляется через Composer. Эти интеграции поддерживают основные бизнес-функции, включая платежи в электронной коммерции, логистику, обмен данными и улучшение пользовательского опыта за счет геолокации.

В стратегии интеграции делается акцент на:

- Централизованная HTTP-связь через HTTP-клиент Guzzle.
- Соответствие стандартам PSR для кэширования (PSR-6, PSR-16) и ведения журналов (PSR-3)
- Версионирование зависимостей для обеспечения стабильности и совместимости.
- Разделение задач с помощью специализированных SDK для сложных интеграций.

## 23.2. Управление зависимостями через Composer

Все внешние интеграции управляются через Composer, зависимости объявляются в файле composer.json, а заблокированные версии — в файле composer.lock.

### Стратегия версионирования

Платформа использует два оператора для управления версиями:

| Оператор | Синтаксис | Диапазон версий | Использование |
|----------|-----------|-----------------|---------------|
| **`^` (caret)** | `^3.3` | `>=3.3.0 <4.0.0` | Минорные и патч-обновления |
| **`~` (tilde)** | `~6.0` | `>=6.0.0 <6.1.0` | Только патч-обновления |

**Примеры:**
- `^2.1` → `2.1.0` до `2.999.999` (блокирует мажорные версии)
- `~6.0` → `6.0.0` до `6.0.999` (блокирует минорные версии)

## 23.3. Ограничения версий

Платформа использует две стратегии версионирования:

- Символ "^" : позволяет обновлять минорные и патч-версии (например, ^3.3 от 3.3.0 до 3.999.999).
- Тильда (~) : Позволяет обновлять только версии патчей (например, ~6.0 версии от 6.0.0 до 6.999.999).

Это обеспечивает совместимость, позволяя при этом выпускать обновления, повышающие безопасность и исправляющие ошибки.

### Инициализация клиента

```php
// /system/controllers/payment/model.php
use YooKassa\Client as YooKassaClient;
use YooKassa\Model\PaymentInterface;

class modelPayment extends cmsModel {
    private $yookassa_client;

    /**
     * Инициализация клиента ЮKassa
     * @return YooKassaClient
     */
    private function initYooKassaClient() {
        if (!$this->yookassa_client) {
            $config = cmsConfig::getInstance();
            
            $this->yookassa_client = new YooKassaClient();
            $this->yookassa_client->setAuth(
                $config->get('yookassa_shop_id'),
                $config->get('yookassa_secret_key')
            );
        }
        return $this->yookassa_client;
    }

    /**
     * Создание платежа
     * @param int $order_id ID заказа
     * @param float $amount Сумма платежа
     * @param string $currency Валюта (по умолчанию RUB)
     * @param string $return_url URL возврата после оплаты
     * @return array Данные платежа
     */
    public function createPayment($order_id, $amount, $currency = 'RUB', $return_url) {
        $client = $this->initYooKassaClient();
        
        try {
            $payment = $client->createPayment([
                'amount' => [
                    'value' => number_format($amount, 2, '.', ''),
                    'currency' => $currency
                ],
                'confirmation' => [
                    'type' => 'redirect',
                    'return_url' => $return_url
                ],
                'capture' => true,
                'description' => 'Оплата заказа #' . $order_id,
                'metadata' => [
                    'order_id' => $order_id,
                    'platform' => 'DST Platform'
                ]
            ], uniqid('', true));

            // Сохранение идентификатора платежа в БД
            $this->update('shop_orders', $order_id, [
                'payment_id' => $payment->getId(),
                'payment_status' => $payment->getStatus(),
                'payment_created_at' => date('Y-m-d H:i:s')
            ]);

            return [
                'id' => $payment->getId(),
                'status' => $payment->getStatus(),
                'confirmation_url' => $payment->getConfirmation()->getConfirmationUrl(),
                'paid' => $payment->getPaid()
            ];

        } catch (\Exception $e) {
            error_log('[PAYMENT] YooKassa error: ' . $e->getMessage());
            throw new \Exception('Ошибка создания платежа: ' . $e->getMessage());
        }
    }

    /**
     * Обработка webhook от ЮKassa
     * @param array $event_data Данные события
     * @return bool
     */
    public function handleWebhook($event_data) {
        $payment_id = $event_data['object']['id'];
        $status = $event_data['object']['status'];
        
        // Поиск заказа по payment_id
        $order = $this->getItemByField('shop_orders', 'payment_id', $payment_id);
        
        if (!$order) {
            error_log('[PAYMENT] Order not found for payment: ' . $payment_id);
            return false;
        }

        // Обновление статуса заказа при успешной оплате
        if ($status === PaymentInterface::STATUS_SUCCEEDED) {
            $this->update('shop_orders', $order['id'], [
                'payment_status' => 'paid',
                'status' => 'paid',
                'paid_at' => date('Y-m-d H:i:s')
            ]);
            
            // Запуск события для других компонентов
            cmsEventsManager::hook('shop_order_paid', $order);
            
            error_log('[PAYMENT] Order #' . $order['id'] . ' marked as paid');
            return true;
        }

        // Обработка отмены платежа
        if ($status === PaymentInterface::STATUS_CANCELED) {
            $this->update('shop_orders', $order['id'], [
                'payment_status' => 'canceled',
                'status' => 'canceled'
            ]);
            
            error_log('[PAYMENT] Order #' . $order['id'] . ' payment canceled');
            return true;
        }

        return false;
    }

    /**
     * Проверка статуса платежа
     * @param string $payment_id ID платежа в ЮKassa
     * @return array|null
     */
    public function checkPaymentStatus($payment_id) {
        $client = $this->initYooKassaClient();
        
        try {
            $payment = $client->getPaymentInfo($payment_id);
            
            return [
                'id' => $payment->getId(),
                'status' => $payment->getStatus(),
                'paid' => $payment->getPaid(),
                'amount' => $payment->getAmount()->getValue(),
                'currency' => $payment->getAmount()->getCurrency(),
                'created_at' => $payment->getCreatedAt(),
                'paid_at' => $payment->getPaidAt()
            ];
        } catch (\Exception $e) {
            error_log('[PAYMENT] Error checking payment status: ' . $e->getMessage());
            return null;
        }
    }

    /**
     * Возврат средств
     * @param string $payment_id ID платежа
     * @param float $amount Сумма возврата
     * @return bool
     */
    public function refundPayment($payment_id, $amount) {
        $client = $this->initYooKassaClient();
        
        try {
            $refund = $client->createRefund([
                'amount' => [
                    'value' => number_format($amount, 2, '.', ''),
                    'currency' => 'RUB'
                ],
                'payment_id' => $payment_id
            ]);
            
            error_log('[PAYMENT] Refund created: ' . $refund->getId());
            return true;
        } catch (\Exception $e) {
            error_log('[PAYMENT] Refund error: ' . $e->getMessage());
            return false;
        }
    }
}
```

```php
// /system/controllers/delivery/model.php
use CdekSDK\Client;
use CdekSDK\Requests\CalculatorRequest;
use CdekSDK\Requests\CreateOrderRequest;
use CdekSDK\Requests\DeliveryPointsRequest;

class modelDelivery extends cmsModel {
    private $cdek_client;

    /**
     * Инициализация клиента CDEK
     * @return Client
     */
    private function initCdekClient() {
        if (!$this->cdek_client) {
            $config = cmsConfig::getInstance();
            
            $this->cdek_client = new Client(
                $config->get('cdek_account'),
                $config->get('cdek_secure')
            );
        }
        return $this->cdek_client;
    }

    /**
     * Расчёт стоимости доставки
     * @param array $params Параметры расчёта
     * @return array Массив тарифов
     */
    public function calculateDelivery($params) {
        $client = $this->initCdekClient();
        
        try {
            $request = (new CalculatorRequest())
                ->setSenderCityId($params['sender_city_id'])
                ->setReceiverCityId($params['receiver_city_id'])
                ->addPackage([
                    'weight' => $params['weight'], // в граммах
                    'length' => $params['length'],
                    'width' => $params['width'],
                    'height' => $params['height']
                ]);
            
            $response = $client->sendCalculatorRequest($request);
            $tariffs = [];
            
            foreach ($response->getTariffs() as $tariff) {
                $tariffs[] = [
                    'tariff_id' => $tariff->getTariffId(),
                    'tariff_name' => $tariff->getTariffName(),
                    'delivery_sum' => $tariff->getDeliverySum(),
                    'delivery_days' => $tariff->getDeliveryPeriod(),
                    'delivery_date_min' => $tariff->getPeriodMin(),
                    'delivery_date_max' => $tariff->getPeriodMax(),
                    'currency' => $tariff->getCurrency()
                ];
            }
            
            return $tariffs;
            
        } catch (\Exception $e) {
            error_log('[DELIVERY] CDEK calculation error: ' . $e->getMessage());
            return [];
        }
    }

    /**
     * Поиск пунктов выдачи заказов (ПВЗ)
     * @param int $city_id ID города
     * @param string $type Тип точки (PVZ, POSTOMAT)
     * @return array Массив ПВЗ
     */
    public function getDeliveryPoints($city_id, $type = 'PVZ') {
        $client = $this->initCdekClient();
        
        try {
            $points = $client->getDeliveryPoints()
                ->setCityId($city_id)
                ->setType($type)
                ->execute();
            
            $result = [];
            foreach ($points as $point) {
                $result[] = [
                    'code' => $point->getCode(),
                    'name' => $point->getName(),
                    'address' => $point->getAddress(),
                    'address_full' => $point->getFullAddress(),
                    'work_time' => $point->getWorkTime(),
                    'phones' => $point->getPhones(),
                    'email' => $point->getEmail(),
                    'location' => [
                        'latitude' => $point->getLatitude(),
                        'longitude' => $point->getLongitude()
                    ],
                    'is_dressing_room' => $point->hasDressingRoom(),
                    'have_cashless' => $point->hasCashless(),
                    'have_cash' => $point->hasCash(),
                    'allowed_cod' => $point->isAllowedCod(),
                    'nearest_station' => $point->getNearestStation(),
                    'work_time_list' => $point->getWorkTimeList()
                ];
            }
            
            return $result;
            
        } catch (\Exception $e) {
            error_log('[DELIVERY] CDEK points error: ' . $e->getMessage());
            return [];
        }
    }

    /**
     * Создание заказа в CDEK
     * @param array $order_data Данные заказа
     * @return array Результат создания
     */
    public function createCdekOrder($order_data) {
        $client = $this->initCdekClient();
        
        try {
            $request = (new CreateOrderRequest())
                ->setNumber($order_data['order_number'])
                ->setSenderCityId($order_data['sender_city_id'])
                ->setReceiverCityId($order_data['receiver_city_id'])
                ->setReceiverAddress($order_data['receiver_address'])
                ->setReceiverName($order_data['receiver_name'])
                ->setReceiverPhone($order_data['receiver_phone'])
                ->setReceiverEmail($order_data['receiver_email'] ?? null)
                ->setComment($order_data['comment'] ?? '')
                ->setDeliveryRecipientCost($order_data['delivery_cost'] ?? 0)
                ->setTariffId($order_data['tariff_id']);
            
            // Добавление товаров в заказ
            foreach ($order_data['items'] as $item) {
                $request->addPackage([
                    'number' => $item['package_number'] ?? '1',
                    'weight' => $item['weight'],
                    'length' => $item['length'],
                    'width' => $item['width'],
                    'height' => $item['height'],
                    'items' => [[
                        'ware_key' => $item['sku'],
                        'cost' => $item['price'],
                        'payment' => 0,
                        'weight' => $item['weight'],
                        'amount' => $item['quantity'],
                        'name' => $item['name'],
                        'payment' => 0
                    ]]
                ]);
            }
            
            $response = $client->sendCreateOrderRequest($request);
            
            if ($response->hasErrors()) {
                throw new \Exception(implode(', ', $response->getErrors()));
            }
            
            return [
                'cdek_order_uuid' => $response->getOrder()->getUUID(),
                'cdek_order_number' => $response->getOrder()->getDispatchNumber(),
                'barcode' => $response->getOrder()->getBarcode(),
                'status' => $response->getOrder()->getStatus()
            ];
            
        } catch (\Exception $e) {
            error_log('[DELIVERY] CDEK order creation error: ' . $e->getMessage());
            throw $e;
        }
    }

    /**
     * Отслеживание статуса заказа
     * @param string $dispatch_number Номер отправления CDEK
     * @return array|null
     */
    public function trackOrder($dispatch_number) {
        $client = $this->initCdekClient();
        
        try {
            $order = $client->getOrderByDispatchNumber($dispatch_number);
            
            if (!$order) {
                return null;
            }
            
            $statuses = [];
            foreach ($order->getStatuses() as $status) {
                $statuses[] = [
                    'code' => $status->getCode(),
                    'name' => $status->getName(),
                    'date' => $status->getDate(),
                    'description' => $status->getDescription()
                ];
            }
            
            return [
                'dispatch_number' => $order->getDispatchNumber(),
                'status_code' => $order->getStatusCode(),
                'status_name' => $order->getStatusName(),
                'status_date' => $order->getStatusDate(),
                'statuses' => $statuses,
                'delivery_date' => $order->getDeliveryDate(),
                'recipient_name' => $order->getRecipientName(),
                'recipient_address' => $order->getRecipientAddress()
            ];
            
        } catch (\Exception $e) {
            error_log('[DELIVERY] CDEK tracking error: ' . $e->getMessage());
            return null;
        }
    }
}
```

### Инициализация и использование

```php
// /system/controllers/auth/model.php
use GeoIp2\Database\Reader;
use GeoIp2\Exception\AddressNotFoundException;

class modelAuth extends cmsModel {
    private $geoip_reader;

    /**
     * Инициализация читателя GeoIP2
     * @return Reader|null
     */
    private function initGeoIpReader() {
        if (!$this->geoip_reader) {
            $db_path = PATH . '/system/libs/GeoLite2-City.mmdb';
            
            if (!file_exists($db_path)) {
                error_log('[GEOIP] Database not found: ' . $db_path);
                return null;
            }
            
            try {
                $this->geoip_reader = new Reader($db_path);
            } catch (\Exception $e) {
                error_log('[GEOIP] Reader initialization error: ' . $e->getMessage());
                return null;
            }
        }
        return $this->geoip_reader;
    }

    /**
     * Получение данных о местоположении по IP
     * @param string $ip IP-адрес
     * @return array|null
     */
    public function getLocationByIp($ip) {
        $reader = $this->initGeoIpReader();
        
        if (!$reader) {
            return null;
        }
        
        try {
            $record = $reader->city($ip);
            
            return [
                'ip' => $ip,
                'country' => [
                    'code' => $record->country->isoCode,
                    'name' => $record->country->name
                ],
                'region' => [
                    'code' => $record->subdivisions[0]->isoCode ?? null,
                    'name' => $record->subdivisions[0]->name ?? null
                ],
                'city' => [
                    'name' => $record->city->name,
                    'geoname_id' => $record->city->geonameId
                ],
                'location' => [
                    'latitude' => $record->location->latitude,
                    'longitude' => $record->location->longitude,
                    'time_zone' => $record->location->timeZone,
                    'accuracy_radius' => $record->location->accuracyRadius
                ],
                'postal' => [
                    'code' => $record->postal->code
                ],
                'traits' => [
                    'autonomous_system_number' => $record->traits->autonomousSystemNumber,
                    'autonomous_system_organization' => $record->traits->autonomousSystemOrganization,
                    'isp' => $record->traits->isp,
                    'organization' => $record->traits->organization
                ]
            ];
            
        } catch (AddressNotFoundException $e) {
            error_log('[GEOIP] IP not found in database: ' . $ip);
            return null;
        } catch (\Exception $e) {
            error_log('[GEOIP] Error: ' . $e->getMessage());
            return null;
        }
    }

    /**
     * Определение страны по IP
     * @param string $ip IP-адрес
     * @return string|null Код страны (например, 'RU')
     */
    public function getCountryCodeByIp($ip) {
        $location = $this->getLocationByIp($ip);
        return $location['country']['code'] ?? null;
    }

    /**
     * Антифрод: проверка подозрительных локаций
     * @param string $ip IP-адрес
     * @param string $user_country Страна пользователя из профиля
     * @return bool true если подозрительно
     */
    public function isSuspiciousLocation($ip, $user_country) {
        $location = $this->getLocationByIp($ip);
        
        if (!$location) {
            return false; // Не удалось определить
        }
        
        $ip_country = $location['country']['code'];
        
        // Если страна не совпадает с профилем — подозрительно
        if ($ip_country && $user_country && $ip_country !== $user_country) {
            error_log(sprintf(
                '[FRAUD] Suspicious location: User country=%s, IP country=%s, IP=%s',
                $user_country,
                $ip_country,
                $ip
            ));
            return true;
        }
        
        return false;
    }

    /**
     * Локализация контента по стране
     * @param string $ip IP-адрес
     * @return string Код локали (например, 'ru_RU')
     */
    public function getLocaleByIp($ip) {
        $country = $this->getCountryCodeByIp($ip);
        
        $locales = [
            'RU' => 'ru_RU',
            'UA' => 'uk_UA',
            'BY' => 'be_BY',
            'KZ' => 'ru_KZ',
            'US' => 'en_US',
            'GB' => 'en_GB',
            'DE' => 'de_DE',
            'FR' => 'fr_FR'
        ];
        
        return $locales[$country] ?? 'en_US';
    }

    /**
     * Получение часового пояса по IP
     * @param string $ip IP-адрес
     * @return string|null
     */
    public function getTimezoneByIp($ip) {
        $location = $this->getLocationByIp($ip);
        return $location['location']['time_zone'] ?? null;
    }
}
```

### Конфигурация клиента Guzzle

```php
// /system/libs/http_client.php
use GuzzleHttp\Client;
use GuzzleHttp\HandlerStack;
use GuzzleHttp\Middleware;
use GuzzleHttp\Handler\CurlHandler;
use Psr\Log\LoggerInterface;

class DSTHttpClient {
    private $client;
    private $logger;
    private $config;

    /**
     * Конструктор
     * @param LoggerInterface $logger
     * @param array $config
     */
    public function __construct(LoggerInterface $logger = null, array $config = []) {
        $this->logger = $logger;
        $this->config = array_merge([
            'base_uri' => null,
            'timeout' => 30,
            'connect_timeout' => 10,
            'verify' => true, // SSL verification
            'allow_redirects' => true,
            'http_errors' => true,
            'debug' => false,
            'headers' => [
                'User-Agent' => 'DST Platform/' . DST_VERSION,
                'Accept' => 'application/json',
                'Content-Type' => 'application/json'
            ]
        ], $config);
        
        $this->initClient();
    }

    /**
     * Инициализация клиента
     */
    private function initClient() {
        $handler = HandlerStack::create(new CurlHandler());
        
        // Middleware для логирования
        if ($this->logger) {
            $handler->push(Middleware::log(
                $this->logger,
                new \GuzzleHttp\MessageFormatter(
                    \GuzzleHttp\MessageFormatter::DEBUG
                )
            ));
        }
        
        // Middleware для повторных попыток
        $handler->push(Middleware::retry(
            $this->retryDecider(),
            $this->retryDelay()
        ));
        
        $this->client = new Client(array_merge($this->config, [
            'handler' => $handler
        ]));
    }

    /**
     * Логика повторных попыток
     * @return callable
     */
    private function retryDecider() {
        return function (
            $retries,
            \GuzzleHttp\Psr7\Request $request,
            \GuzzleHttp\Psr7\Response $response = null,
            \Exception $exception = null
        ) {
            // Не более 3 попыток
            if ($retries >= 3) {
                return false;
            }
            
            // Повтор при ошибках сети
            if ($exception instanceof \GuzzleHttp\Exception\ConnectException) {
                return true;
            }
            
            // Повтор при 500-х ошибках сервера
            if ($response && $response->getStatusCode() >= 500) {
                return true;
            }
            
            return false;
        };
    }

    /**
     * Задержка между повторными попытками (экспоненциальная)
     * @return callable
     */
    private function retryDelay() {
        return function ($numberOfRetries) {
            return 1000 * $numberOfRetries; // 1с, 2с, 3с
        };
    }

    /**
     * Выполнение GET-запроса
     * @param string $uri
     * @param array $options
     * @return \Psr\Http\Message\ResponseInterface
     */
    public function get($uri, array $options = []) {
        return $this->client->get($uri, $options);
    }

    /**
     * Выполнение POST-запроса
     * @param string $uri
     * @param array $options
     * @return \Psr\Http\Message\ResponseInterface
     */
    public function post($uri, array $options = []) {
        return $this->client->post($uri, $options);
    }

    /**
     * Выполнение запроса с обработкой ошибок
     * @param string $method
     * @param string $uri
     * @param array $options
     * @return array|null
     */
    public function request($method, $uri, array $options = []) {
        try {
            $response = $this->client->request($method, $uri, $options);
            
            $body = (string)$response->getBody();
            
            // Попытка декодирования JSON
            $data = json_decode($body, true);
            
            if (json_last_error() === JSON_ERROR_NONE) {
                return $data;
            }
            
            return $body;
            
        } catch (\GuzzleHttp\Exception\ClientException $e) {
            $this->logError('Client error', $e, $uri);
            return null;
        } catch (\GuzzleHttp\Exception\ServerException $e) {
            $this->logError('Server error', $e, $uri);
            return null;
        } catch (\GuzzleHttp\Exception\ConnectException $e) {
            $this->logError('Connection error', $e, $uri);
            return null;
        } catch (\Exception $e) {
            $this->logError('Unknown error', $e, $uri);
            return null;
        }
    }

    /**
     * Асинхронный запрос
     * @param string $method
     * @param string $uri
     * @param array $options
     * @return \GuzzleHttp\Promise\PromiseInterface
     */
    public function requestAsync($method, $uri, array $options = []) {
        return $this->client->requestAsync($method, $uri, $options);
    }

    /**
     * Логирование ошибки
     * @param string $type
     * @param \Exception $e
     * @param string $uri
     */
    private function logError($type, \Exception $e, $uri) {
        $message = sprintf(
            '[HTTP] %s: %s (URI: %s)',
            $type,
            $e->getMessage(),
            $uri
        );
        
        if ($this->logger) {
            $this->logger->error($message, ['exception' => $e]);
        } else {
            error_log($message);
        }
    }

    /**
     * Получение базового клиента
     * @return Client
     */
    public function getClient() {
        return $this->client;
    }
}
```

### Middleware для кэширования ответов

```php
use GuzzleHttp\Middleware;
use Psr\Cache\CacheItemPoolInterface;

class CacheMiddleware {
    private $cache;
    private $ttl;

    public function __construct(CacheItemPoolInterface $cache, $ttl = 3600) {
        $this->cache = $cache;
        $this->ttl = $ttl;
    }

    public function __invoke(callable $handler) {
        return function (\Psr\Http\Message\RequestInterface $request, array $options) use ($handler) {
            // Создание ключа кэша на основе метода и URI
            $cacheKey = 'guzzle_' . md5($request->getMethod() . '_' . (string)$request->getUri());
            
            // Попытка получить из кэша
            $item = $this->cache->getItem($cacheKey);
            
            if ($item->isHit()) {
                $cachedResponse = $item->get();
                
                if ($cachedResponse instanceof \Psr\Http\Message\ResponseInterface) {
                    return \GuzzleHttp\Promise\Create::promiseFor($cachedResponse);
                }
            }
            
            // Выполнение запроса
            return $handler($request, $options)->then(
                function (\Psr\Http\Message\ResponseInterface $response) use ($cacheKey) {
                    // Кэширование успешного ответа
                    if ($response->getStatusCode() >= 200 && $response->getStatusCode() < 300) {
                        $item->set($response);
                        $item->expiresAfter($this->ttl);
                        $this->cache->save($item);
                    }
                    
                    return $response;
                }
            );
        };
    }
}

// Использование

$client = new Client(['handler' => $stack]);
```

```php
// /system/controllers/shop/model.php
class modelShop extends cmsModel {
    
    /**
     * Получение товаров с кэшированием
     * @param int $category_id ID категории
     * @param int $limit Количество товаров
     * @return array
     */
    public function getProducts($category_id, $limit = 20) {
        // Создание ключа кэша
        $cache_key = 'shop_products_' . $category_id . '_' . $limit;
        
        // Попытка получить из кэша
        $cached = cmsCache::getInstance()->get($cache_key);
        
        if ($cached !== false) {
            return $cached;
        }
        
        // Запрос к БД
        $products = $this->select('shop_products')
            ->filterEqual('category_id', $category_id)
            ->filterEqual('is_published', 1)
            ->orderBy('date_pub', 'DESC')
            ->limit($limit)
            ->getItems();
        
        // Сохранение в кэш (1 час)
        cmsCache::getInstance()->set($cache_key, $products, 3600);
        
        return $products;
    }
    
    /**
     * Инвалидация кэша при обновлении товара
     * @param int $id ID товара
     * @param array $data Данные для обновления
     * @return bool
     */
    public function updateProduct($id, $data) {
        $result = parent::update('shop_products', $id, $data);
        
        if ($result) {
            // Очистка всех кэшей, связанных с товарами
            cmsCache::getInstance()->delete('shop_products_*');
            cmsCache::getInstance()->delete('shop_product_' . $id);
            
            // Очистка кэша по тегам
            cmsCache::getInstance()->deleteByTag('product_' . $id);
            cmsCache::getInstance()->deleteByTag('category_' . $data['category_id']);
        }
        
        return $result;
    }
    
    /**
     * Кэширование с использованием тегов
     * @param int $vendor_id ID продавца
     * @return array
     */
    public function getVendorProducts($vendor_id) {

        // Попытка получить из кэша
        $cached = cmsCache::getInstance()->get($cache_key);
        
        if ($cached !== false) {
            return $cached;
        }
        
        // Запрос к БД
        $products = $this->select('shop_products')
            ->filterEqual('vendor_id', $vendor_id)
            ->filterEqual('is_published', 1)
            ->getItems();
        
        // Сохранение в кэш с тегами

        $item->set($products);
        $item->expiresAfter(3600);
        $item->addTag('vendor_' . $vendor_id);
        $item->addTag('products');

    }
```

```php
            case 'ftp':
                return $this->fetchFromFTP($partner);
            case 'api':
                return $this->fetchFromAPI($partner);

                return $this->fetchFromFile($partner);
            case 'sftp':
                return $this->fetchFromSFTP($partner);
            default:
                throw new \Exception('Unsupported import source type: ' . $source_type);
        }
    }
    
    /**
     * Получение данных через FTP
     */
    private function fetchFromFTP($partner) {
        $ftp_server = $partner['ftp_host'];
        $ftp_user = $partner['ftp_user'];
        $ftp_pass = $partner['ftp_password'];
        $remote_file = $partner['ftp_path'];
        
        $conn = ftp_connect($ftp_server);
        
        if (!$conn) {
            throw new \Exception('Cannot connect to FTP server');
        }
        
        if (!ftp_login($conn, $ftp_user, $ftp_pass)) {
            ftp_close($conn);
            throw new \Exception('FTP login failed');
        }
        
        // Скачивание файла во временную директорию
        $local_file = PATH . '/cache/tmp/partner_' . $partner['id'] . '_' . time() . '.xlsx';
        
        if (!ftp_get($conn, $local_file, $remote_file, FTP_BINARY)) {
            ftp_close($conn);
            throw new \Exception('Failed to download file from FTP');
        }
        
        ftp_close($conn);
        
        // Чтение файла через Box Spout
        return $this->parseSpreadsheet($local_file);
    }
    
    /**
     * Парсинг табличного файла
     */
    private function parseSpreadsheet($file_path) {
        $extension = pathinfo($file_path, PATHINFO_EXTENSION);
        
        if (!in_array($extension, ['xlsx', 'xls', 'csv', 'ods'])) {
            throw new \Exception('Unsupported file format: ' . $extension);
        }
        
        $reader = ReaderFactory::create(strtoupper($extension));
        $reader->open($file_path);
        
        $products = [];
        
        foreach ($reader->getSheetIterator() as $sheet) {
            foreach ($sheet->getRowIterator() as $row_index => $row) {
                // Пропускаем заголовок
                if ($row_index === 1) {
                    continue;
                }
                
                // Ожидаемая структура: [SKU, Название, Цена, Остаток, Категория]
                $products[] = [
                    'sku' => $row[0],
                    'title' => $row[1],
                    'price' => (float)$row[2],
                    'quantity' => (int)$row[3],
                    'category' => $row[4] ?? null
                ];
            }
        }
        
        $reader->close();
        unlink($file_path); // Удаление временного файла
        
        return ['products' => $products];
    }
    
    /**
     * Валидация структуры импортируемых данных
     */
    private function validateImportData($data) {
        if (!isset($data['products']) || !is_array($data['products'])) {
            throw new \Exception('Invalid data structure: missing "products" array');
        }
        
        foreach ($data['products'] as $index => $product) {
            // Обязательные поля
            if (empty($product['sku'])) {
                throw new \Exception(sprintf(
                    'Product #%d missing required field: sku',
                    $index
                ));
            }
            
            if (!isset($product['price']) || $product['price'] <= 0) {
                throw new \Exception(sprintf(
                    'Product #%d has invalid price: %s',
                    $index,
                    $product['sku'] ?? 'unknown'
                ));
            }
            
            // Опциональная валидация
            if (isset($product['quantity']) && $product['quantity'] < 0) {
                throw new \Exception(sprintf(
                    'Product #%d has negative quantity',
                    $index
                ));
            }
        }
        
        return true;
    }
}
```

```php
        ));
        
        return $metrics;
    }
```
