# 14. Компонент - Партнерская система

Система для партнеров и поставщиков предоставляет продавцам/партнерам, работающим на торговой площадке DST Platform, функциональные возможности личного кабинета и автоматизированное управление данными. Эта система позволяет внешним поставщикам управлять своими каталогами продукции, заказами и бизнес-операциями через выделенный интерфейс.

Данный документ содержит техническую спецификацию компонента **«Партнёрская система»** (`partner`), предоставляющего продавцам (партнёрам, вендорам) на торговой площадке DST Platform персонализированный интерфейс управления товарами, заказами, аналитикой и бизнес-настройками. Компонент реализует изолированную панель управления для каждого поставщика с гарантией разделения данных и прав доступа.

> **Терминологическое примечание**: В контексте документа термины *«партнёр»*, *«продавец»*, *«поставщик»*, *«вендор»* используются как синонимы. Официальное название в архитектуре — **партнёр** (partner).

## 14.1. Архитектурный обзор

Компонент `partner` функционирует как **специализированный слой над компонентом `shop`**, расширяя его функциональность для сценариев многопоставщикового маркетплейса. Он не дублирует бизнес-логику, а фильтрует и адаптирует данные под контекст конкретного продавца.

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/89.png" alt="DST Platform">

### Ключевые архитектурные принципы

| Аспект | Реализация | Обоснование |
|--------|------------|-------------|
| **Тип компонента** | Полноценный MVC: фронтенд + бэкенд + модель | Поддержка публичной части (профиль продавца) и приватной панели управления |
| **Уровень данных** | Расширение `modelShop` через наследование | Повторное использование логики каталога и заказов без дублирования |
| **Изоляция данных** | Автоматическая фильтрация по `vendor_id` во всех запросах | Гарантия, что партнёр видит только свои товары и заказы |
| **Автоматизация** | Специализированный cron-скрипт `cron_partner_import.php` | Синхронизация данных с внешними источниками (прайс-листы, остатки) |
| **Контроль доступа** | RBAC через `cmsPermissions` + проверка `vendor_id` | Многоуровневая защита от несанкционированного доступа |
| **Интеграция** | Событийная связь с `shop`, `orders`, `payment`, `delivery` | Слабая связанность, расширяемость без модификации ядра |

### Изоляция данных

Каждый запрос к БД автоматически фильтруется по `vendor_id` текущего продавца:

```php
// В modelPartner::getProducts()
public function getProducts($filters = []) {
    // Автоматическая фильтрация по текущему продавцу
    $vendor_id = cmsUser::getInstance()->id;
    
    return $this->select('shop_products')
        ->filterEqual('vendor_id', $vendor_id) // Критически важный фильтр
        ->applyFilters($filters)
        ->getItems();
}

// В modelPartner::getOrders()
public function getOrders($filters = []) {
    $vendor_id = cmsUser::getInstance()->id;
    
    return $this->select('shop_orders o')
        ->join('shop_order_items oi', 'oi.order_id = o.id')
        ->filterEqual('oi.vendor_id', $vendor_id) // Фильтрация по товарам в заказе
        ->groupBy('o.id')
        ->applyFilters($filters)
        ->getItems();
}
```

> **Гарантия безопасности**: Даже при ошибке в шаблоне или контроллере, уровень модели предотвращает доступ к данным других продавцов.

### Архитектура процесса импорта

```

│                   ПРОЦЕСС ИМПОРТА ДАННЫХ                             │
├──────────────────────────────────────────────────────────────────────┤

│ 11. Завершение                                                       │
└──────────────────────────────────────────────────────────────────────┘
```

### Реализация скрипта `cron_partner_import.php`

```php
#!/usr/bin/env php
<?php
/**
 * Автоматический импорт данных партнёров
 * Запускается по расписанию через системный cron
 */

// Определение корневого пути для CLI-окружения
if (!defined('PATH')) {
    define('PATH', dirname(__DIR__));
}

// Только для CLI (защита от HTTP-вызова)
if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    exit('Access denied. CLI only.');
}

// Инициализация ядра
require_once PATH . '/bootstrap.php';

// Блокировка файла для предотвращения параллельного запуска
$lock_file = cmsConfig::get('cache_path') . 'cron_partner_import_lock';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp || !flock($lockfp, LOCK_EX | LOCK_NB)) {
    error_log('[PARTNER IMPORT] Another process is running. Exiting.');
    exit(1);
}

// Гарантированная очистка блокировки при завершении
register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);
    }
});

// Проверка: компонент включён?
$controller = cmsCore::getController('partner');
if (!$controller || !$controller->isEnabled()) {
    error_log('[PARTNER IMPORT] Component is disabled. Exiting.');
    exit(0);
}

// Логирование старта
$start_time = microtime(true);
error_log('[PARTNER IMPORT] Starting import process at ' . date('Y-m-d H:i:s'));

// Выполнение хука импорта
try {
    $result = cmsEventsManager::hook('cron_partner_import_job');
    
    if ($result === false) {
        throw new Exception('Import hook returned false');
    }
    
    $duration = microtime(true) - $start_time;
    error_log(sprintf(
        '[PARTNER IMPORT] Completed successfully. Duration: %.2f sec',
        $duration
    ));
    
    exit(0);
    
} catch (Exception $e) {
    error_log('[PARTNER IMPORT] Exception: ' . $e->getMessage());
    error_log($e->getTraceAsString());
    exit(1);
}
```

### Механизм блокировки

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **Файл блокировки** | `{cache_path}/cron_partner_import_lock` | Уникальный для задачи |
| **Тип блокировки** | `LOCK_EX \| LOCK_NB` | Эксклюзивная, неблокирующая |
| **Поведение при конфликте** | Немедленный выход с кодом 1 | Предотвращение накопления процессов |
| **Очистка блокировки** | Автоматическая через `register_shutdown_function` | Гарантия очистки даже при ошибке |
| **Область действия** | Глобальная для сервера | Предотвращение конфликтов между cron-задачами |

Импорт данных использует событийную архитектуру DST Platform для разделения инфраструктуры и бизнес-логики.

### Архитектура выполнения хуков

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/93.png" alt="DST Platform">

### Цепочка вызовов

```
cron_partner_import.php
    ↓

    ↓
partner::hookCronPartnerImportJob()  [в /system/controllers/partner/hooks.php]
    ↓

    ↓

```

### Пример реализации хука импорта

```php
// /system/controllers/partner/hooks.php
class partner {
    /**
     * Хук для автоматического импорта данных партнёра
     * Вызывается из cron_partner_import.php
     */
    public function hookCronPartnerImportJob() {
        // Получение списка активных партнёров с настройками импорта
        $vendors = $this->model->getVendorsWithImportSettings();
        
        $import_stats = [
            'total_vendors' => count($vendors),
            'processed' => 0,
            'errors' => []
        ];
        
        foreach ($vendors as $vendor) {
            try {
                // Получение данных из внешнего источника
                $import_data = $this->fetchImportData($vendor);
                
                if (empty($import_data)) {
                    throw new Exception('No data received from source');
                }
                
                // Валидация структуры данных
                $this->validateImportData($import_data);
                
                // Импорт товаров
                $result = $this->model->importProducts($vendor['id'], $import_data);
                
                // Логирование успешного импорта
                $this->model->logImport($vendor['id'], [
                    'status' => 'success',
                    'products_count' => $result['imported'],
                    'updated' => $result['updated'],
                    'skipped' => $result['skipped']
                ]);
                
                // Запуск события для других компонентов
                cmsEventsManager::hook('partner_products_imported', [
                    'vendor_id' => $vendor['id'],
                    'import_result' => $result
                ]);
                
                $import_stats['processed']++;
                
            } catch (Exception $e) {
                // Логирование ошибки
                $this->model->logImport($vendor['id'], [
                    'status' => 'error',
                    'error_message' => $e->getMessage()
                ]);
                
                $import_stats['errors'][] = [
                    'vendor_id' => $vendor['id'],
                    'error' => $e->getMessage()
                ];
                
                // Продолжаем обработку других партнёров
                continue;
            }
        }
        
        // Финальное логирование
        error_log(sprintf(
            '[PARTNER IMPORT] Processed %d/%d vendors. Errors: %d',
            $import_stats['processed'],
            $import_stats['total_vendors'],
            count($import_stats['errors'])
        ));
        
        return $import_stats;
    }
    
    /**
     * Получение данных из внешнего источника
     */
    private function fetchImportData($vendor) {
        // Поддержка различных источников
        switch ($vendor['import_source_type']) {
            case 'ftp':
                return $this->fetchFromFTP($vendor);
                
            case 'api':
                return $this->fetchFromAPI($vendor);
                
            case 'file':
                return $this->fetchFromFile($vendor);
                
            default:
                throw new Exception('Unsupported import source type: ' . $vendor['import_source_type']);
        }
    }
    
    /**
     * Валидация структуры импортируемых данных
     */
    private function validateImportData($data) {
        if (!isset($data['products']) || !is_array($data['products'])) {
            throw new Exception('Invalid data structure: missing "products" array');
        }
        
        foreach ($data['products'] as $product) {
            if (empty($product['sku'])) {
                throw new Exception('Product missing required field: sku');
            }
            if (!isset($product['price']) || $product['price'] <= 0) {
                throw new Exception('Product has invalid price: ' . ($product['sku'] ?? 'unknown'));
            }
        }
        
        return true;
    }
}
```

### Преимущества событийной архитектуры

| Преимущество | Описание |
|--------------|----------|
| **Слабая связанность** | Скрипт cron не зависит от деталей реализации импорта |
| **Расширяемость** | Новые компоненты могут подписаться на `partner_products_imported` |
| **Тестируемость** | Хуки можно тестировать изолированно |
| **Многоканальность** | Одна логика импорта работает для FTP, API, файлов |
| **Аудит** | Все операции логируются на уровне модели |

Этот шаблон позволяет выполнять одну и ту же логику импорта из следующих источников:

- Запланированные задания cron
- Триггеры ручного администрирования
- API-конечные точки
- Фреймворки тестирования

```php
class modelPartner extends modelShop {
    
    /**
     * Получение товаров текущего продавца
     * Автоматически фильтрует по vendor_id
     */
    public function getVendorProducts($vendor_id, $filters = []) {
        return $this->select('shop_products')
            ->filterEqual('vendor_id', $vendor_id)
            ->filterEqual('is_deleted', 0)
            ->applyFilters($filters)
            ->getItems();
    }
    
    /**
     * Получение заказов, содержащих товары продавца
     */
    public function getVendorOrders($vendor_id, $filters = []) {
        return $this->select('shop_orders o')
            ->joinInner('shop_order_items oi', 'oi.order_id = o.id')
            ->filterEqual('oi.vendor_id', $vendor_id)
            ->groupBy('o.id')
            ->applyFilters($filters)
            ->getItems();
    }
    
    /**
     * Импорт товаров из внешнего источника
     */
    public function importProducts($vendor_id, $products_data) {
        $imported = 0;
        $updated = 0;
        $skipped = 0;
        
        foreach ($products_data as $product) {
            // Поиск существующего товара по SKU
            $existing = $this->getItemByField(
                'shop_products', 
                'sku', 
                $product['sku'],
                ['vendor_id' => $vendor_id]
            );
            
            if ($existing) {
                // Обновление существующего товара
                $this->update('shop_products', $existing['id'], [
                    'price' => $product['price'],
                    'quantity' => $product['quantity'],
                    'is_published' => $product['is_published'] ?? 1,
                    'updated_at' => date('Y-m-d H:i:s')
                ]);
                $updated++;
            } else {
                // Создание нового товара
                $this->insert('shop_products', [
                    'vendor_id' => $vendor_id,
                    'sku' => $product['sku'],
                    'title' => $product['title'],
                    'price' => $product['price'],
                    'quantity' => $product['quantity'],
                    'category_id' => $product['category_id'],
                    'is_published' => $product['is_published'] ?? 1,
                    'created_at' => date('Y-m-d H:i:s'),
                    'updated_at' => date('Y-m-d H:i:s')
                ]);
                $imported++;
            }
        }
        
        return [
            'imported' => $imported,
            'updated' => $updated,
            'skipped' => $skipped
        ];
    }
    
    /**
     * Получение статистики продаж продавца
     */
    public function getVendorSalesStats($vendor_id, $period = 'month') {
        $date_from = date('Y-m-d', strtotime("-{$period}"));
        
        return $this->select('shop_orders o')
            ->joinInner('shop_order_items oi', 'oi.order_id = o.id')
            ->filterEqual('oi.vendor_id', $vendor_id)
            ->filterGte('o.date_created', $date_from)
            ->filterEqual('o.status', 'completed')
            ->select('SUM(oi.total) as total_sales, COUNT(DISTINCT o.id) as orders_count')
            ->getItem();
    }
}
```

### Общие таблицы и изоляция данных

| Таблица | Общая для | Изоляция через |
|---------|-----------|----------------|
| `shop_products` | Все продавцы | `vendor_id` |
| `shop_orders` | Все заказы | Связь через `shop_order_items.vendor_id` |
| `shop_order_items` | Позиции заказов | `vendor_id` |
| `shop_payments` | Платежи | Связь через заказ |
| `shop_reviews` | Отзывы | `vendor_id` или `product_id` |
| `partner_vendors` | Метаданные продавцов | `user_id` |

> **Важно**: Все запросы в `modelPartner` автоматически добавляют фильтр по `vendor_id`, что гарантирует изоляцию данных даже при ошибке в контроллере.

Партнерская модель расширяет функциональность модели маркетплейса за счет:

- Добавление фильтрации по конкретному поставщику ко всем запросам.

- Предоставление операций CRUD в рамках компетенции поставщика.
- Обеспечение изоляции данных между поставщиками.

## 14.7. Настройка планировщика Cron

Скрипт импорта предназначен для периодического выполнения через системный cron.

### Рекомендуемая конфигурация

```bash
# Импорт данных партнёров каждые 15 минут
*/15 * * * * /usr/bin/php /var/www/site/cron_partner_import.php >> /var/log/dst_partner_import.log 2>&1

# Альтернатива с явным указанием DOCUMENT_ROOT
*/15 * * * * DOCUMENT_ROOT=/var/www/site /usr/bin/php /var/www/site/cron_partner_import.php >> /var/log/dst_partner_import.log 2>&1
```

### Параметры выполнения

| Параметр | Рекомендуемое значение | Обоснование |
|----------|------------------------|-------------|
| **Частота** | Каждые 15 минут | Баланс между актуальностью и нагрузкой |
| **Время запуска** | Круглосуточно | Для поддержки глобальных партнёров |
| **Таймаут скрипта** | ≥ 300 секунд | Для обработки больших прайс-листов |
| **Логирование** | В отдельный файл | Упрощает отладку и мониторинг |
| **Уведомления** | Email при ошибках | Быстрое реагирование на сбои |

### Требования к окружению

| Требование | Проверка | Решение при проблеме |
|------------|----------|----------------------|
| **CLI-only** | `PHP_SAPI === 'cli'` | Запрет HTTP-доступа через `.htaccess` |
| **DOCUMENT_ROOT** | Автоопределение в скрипте | Явное указание в команде cron |
| **Права на запись** | `cache/` доступен для веб-сервера | `chmod 775 cache/` |
| **Память PHP** | ≥ 256M | Настройка `memory_limit` в `php.ini` |

Подходящая частота зависит от:

- Частота обновления импортируемого источника данных
- Количество товаров поставщика
- Доступность серверных ресурсов
- Требования бизнеса к актуальности данных

```php
// /system/controllers/partner/backend/controller.php
class backendPartner extends cmsBackend {
    
    public function __construct($request) {
        parent::__construct($request);
        
        // Проверка: пользователь авторизован?
        if (!cmsUser::getInstance()->is_logged) {
            cmsCore::error404();
        }
        
        // Проверка: пользователь является продавцом?
        if (!cmsPermissions::getInstance()->isVendor(cmsUser::getInstance()->id)) {
            cmsCore::error404();
        }
        
        // Установка vendor_id для текущего пользователя
        $this->vendor_id = cmsUser::getInstance()->id;
    }
    
    /**
     * Действие: список товаров продавца
     */
    public function actionProducts() {
        // Данные автоматически фильтруются по vendor_id в модели
        $products = $this->model->getVendorProducts($this->vendor_id, [
            'page' => $this->request->get('page', 1),
            'perpage' => 20
        ]);
        
        return $this->render('products/index', [
            'products' => $products,
            'vendor_id' => $this->vendor_id
        ]);
    }
    
    /**
     * Действие: редактирование товара
     */
    public function actionProductEdit($id) {
        // Получение товара с проверкой принадлежности
        $product = $this->model->getVendorProductById($this->vendor_id, $id);
        
        if (!$product) {
            cmsCore::error404('Товар не найден или недоступен');
        }
        
        // Обработка формы
        if ($this->request->has('submit')) {
            $data = $this->request->get('product', []);
            
            // Валидация данных
            $errors = $this->validateProductData($data);
            if (!empty($errors)) {
                return $this->render('products/edit', [
                    'product' => $product,
                    'errors' => $errors
                ]);
            }
            
            // Обновление товара (автоматически привязано к vendor_id)
            $this->model->updateProduct($this->vendor_id, $id, $data);
            
            cmsUser::addSessionMessage('Товар успешно обновлён', 'success');
            $this->redirect('/partner/products/');
        }
        
        return $this->render('products/edit', ['product' => $product]);
    }
}
```

### Мониторинг и диагностика

| Метрика | Как отслеживать | Пороговое значение |
|---------|-----------------|---------------------|
