# 36. Детали структуры проекта

В данном разделе описана организация файловой системы, каталогов и конфигурации проекта на базе DST Platform. Понимание структуры проекта критично для эффективной разработки, настройки окружения и сопровождения системы.

**Связанные разделы:**
- *«Руководство по разработке»* — основные подходы к созданию функциональности
- *«Создание компонентов»* — разработка пользовательских модулей
- *«Инициализация и настройка системы»* — загрузка зависимостей и конфигурация

---

## 36.1. Обзор файловой структуры

Структура проекта DST Platform следует принципу разделения ответственности между ядром, компонентами, темами и пользовательскими данными.

### Дерево каталогов проекта
```
/
├── system/                      # Ядро платформы и компоненты
│   ├── core/                    # Базовые классы ядра
│   │   ├── cmsCore.php          # Главный класс ядра
│   │   ├── cmsConfig.php        # Управление конфигурацией
│   │   ├── cmsTemplate.php      # Система шаблонов
│   │   ├── cmsModel.php         # Базовый класс моделей
│   │   ├── cmsFrontend.php      # Базовый класс фронтенд-контроллеров
│   │   ├── cmsBackend.php       # Базовый класс бэкенд-контроллеров
│   │   ├── cmsEventsManager.php # Система событий
│   │   └── cmsCache.php         # Абстракция кэширования
│   │
│   ├── controllers/             # Компоненты приложения
│   │   ├── shop/                # Компонент маркетплейса
│   │   ├── users/               # Компонент пользователей
│   │   ├── content/             # Компонент контента
│   │   ├── partner/             # Компонент партнёров
│   │   └── ...                  # Остальные компоненты
│   │
│   ├── bootstrap.php            # Точка входа и инициализация
│   └── config/                  # Конфигурация ядра
│       ├── autoload.php         # Настройки автозагрузки
│       └── routes.php           # Маршрутизация (опционально)
│
├── templates/                   # Темы оформления
│   ├── default/                 # Базовая тема
│   │   ├── main.tpl.php         # Главный макет
│   │   ├── admin.tpl.php        # Макет админ-панели
│   │   ├── css/                 # Стили темы
│   │   ├── js/                  # Скрипты темы
│   │   ├── controllers/         # Шаблоны компонентов
│   │   ├── widgets/             # Шаблоны виджетов
│   │   └── options.css.php      # Динамические стили
│   │
│   └── {custom_theme}/          # Кастомные темы
│       ├── inherit.php          # Указатель родительской темы
│       └── ...                  # Переопределённые файлы
│
├── vendor/                      # Зависимости Composer
│   ├── guzzlehttp/
│   ├── box/
│   ├── phpfastcache/
│   ├── sanmai/
│   ├── yoomoney/
│   └── geoip2/
│
├── cache/                       # Кэш-файлы
│   ├── pages/                   # Кэш страниц
│   ├── data/                    # Кэш данных
│   ├── sql.log                  # Лог запросов (отладка)
│   └── .htaccess                # Защита каталога
│
├── upload/                      # Загруженные пользователем файлы
│   ├── images/                  # Изображения
│   ├── documents/               # Документы
│   ├── avatars/                 # Аватары пользователей
│   └── .htaccess                # Защита каталога
│
├── exports/                     # Экспортированные данные
│   ├── jobs/                    # Результаты экспорта
│   └── tmp/                     # Временные файлы
│
├── config/                      # Конфигурация приложения
│   ├── config.php               # Основная конфигурация
│   ├── config.php.dist          # Шаблон конфигурации
│   └── autoload.php             # Автозагрузка пользовательских классов
│
├── cron/                        # CLI-скрипты для cron
│   ├── cron_price_update.php
│   ├── cron_export_products.php
│   └── ...
│
├── index.php                    # Точка входа (фронтенд)
├── admin.php                    # Точка входа (админ-панель)
├── .htaccess                    # Настройки веб-сервера Apache
├── composer.json                # Зависимости Composer
├── composer.lock                # Фиксированные версии зависимостей
└── README.md                    # Документация проекта
```

## 36.2. Каталог `/system/` — ядро платформы

Каталог `/system/` содержит ядро платформы и все компоненты приложения.

### Подкаталог `/system/core/`
Содержит базовые классы, от которых наследуются все компоненты.

| Файл | Класс | Назначение | Синглтон |
|------|-------|------------|----------|
| `cmsCore.php` | `cmsCore` | Главный класс ядра, точка входа | Да |
| `cmsConfig.php` | `cmsConfig` | Управление конфигурацией | Да |
| `cmsTemplate.php` | `cmsTemplate` | Система шаблонов и ресурсов | Да |
| `cmsModel.php` | `cmsModel` | Базовый класс моделей данных | Нет |
| `cmsFrontend.php` | `cmsFrontend` | Базовый класс публичных контроллеров | Нет |
| `cmsBackend.php` | `cmsBackend` | Базовый класс админ-контроллеров | Нет |
| `cmsEventsManager.php` | `cmsEventsManager` | Система событий и хуков | Да |
| `cmsCache.php` | `cmsCache` | Абстракция кэширования | Да |
| `cmsUser.php` | `cmsUser` | Управление пользователями и сессией | Да |
| `cmsRequest.php` | `cmsRequest` | Обработка входящих запросов | Да |

### Подкаталог `/system/controllers/`
Содержит все компоненты приложения. Каждый компонент — автономный модуль.

#### Структура типичного компонента
```
/system/controllers/shop/
├── frontend.php              # class shop extends cmsFrontend
├── backend.php               # class backendShop extends cmsBackend
├── model.php                 # class modelShop extends cmsModel
├── manifest.php              # Метаданные компонента
├── hooks.php                 # Обработчики событий
├── actions/                  # Методы действий (опционально)
│   ├── index.php            # actionIndex()
│   ├── view.php             # actionView()
│   └── ...
├── utils/                    # Вспомогательные классы
│   └── PriceCalculator.php  # namespace shopUtils;
└── export/                   # Модули экспорта
    ├── products.php
    └── orders.php
```

#### Основные компоненты платформы
| Компонент | Назначение | Бэкенд |
|-----------|------------|--------|
| `shop` | Маркетплейс и электронная коммерция | Да |
| `users` | Управление пользователями | Да |
| `content` | Универсальный контент (блоги, статьи) | Да |
| `partner` | Панель управления продавцами | Да |
| `orders` | Управление заказами | Да |
| `payment` | Интеграция платёжных систем | Да |
| `delivery` | Расчёт и управление доставкой | Да |
| `forum` | Форум и обсуждения | Да |
| `groups` | Группы пользователей | Да |
| `comments` | Система комментариев | Нет |
| `activity` | Лента активности | Нет |
| `messages` | Личные сообщения | Да |
| `api` | REST API | Нет |

```
│   │   └── cart.tpl.php      # Корзина
│   ├── users/

```
```
/templates/my_theme/
├── inherit.php               # return 'default';
├── main.tpl.php              # Переопределённый макет
├── css/
│   └── style.css             # Кастомные стили
└── controllers/
    └── shop/
        └── item.tpl.php      # Кастомная карточка товара
```

**Файл `inherit.php`:**
```php
<?php
// Указывает родительскую тему для наследования
```

## 36.4. Каталог `/vendor/` — зависимости Composer

Все сторонние библиотеки управляются через Composer и размещаются в `/vendor/`.

### Основные зависимости
| Библиотека | Версия | Назначение |
|------------|--------|------------|
| `guzzlehttp/guzzle` | ~6.0 | HTTP-клиент для интеграции API |
| `box/spout` | ^3.3 | Импорт/экспорт электронных таблиц |
| `phpfastcache/phpfastcache` | ^7.1 | Абстракция кэширования |
| `sanmai/cdek-sdk` | ^0.6.22 | Интеграция доставки CDEK |
| `yoomoney/yookassa-sdk-php` | ^2.1 | Обработка платежей |

## 36.8. Настройка веб-сервера

### Файл `/.htaccess` (Apache)
```apache
# Включение механизма перезаписи
RewriteEngine On

# Базовый путь (для подкаталогов)
# RewriteBase /

# Принудительное использование канонического домена
# RewriteCond %{HTTP_HOST} !^www\.example\.com$ [NC]
# RewriteRule ^(.*)$ https://www.example.com/$1 [R=301,L]

# Принудительное использование HTTPS
# RewriteCond %{HTTPS} !=on
# RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]

# Защита конфиденциальных файлов
RewriteRule ^(?:\.htaccess|credits\.txt|readme\.txt|license\..*\.txt)$ - [F]

# Статические ресурсы: отдача напрямую
RewriteCond %{REQUEST_FILENAME} \.(jpg|jpeg|png|gif|ico|css|js|woff|woff2|ttf|eot|svg|pdf|zip)$ [NC]
RewriteRule ^ - [L]

# Если запрошенный путь - существующий файл или каталог
RewriteCond %{REQUEST_FILENAME} -f [OR]
RewriteCond %{REQUEST_FILENAME} -d
RewriteRule ^ - [L]

# Все остальные запросы перенаправляются на index.php
RewriteRule ^(.*)$ index.php [QSA,L]
```

### Конфигурация Nginx
```nginx
server {
    listen 80;
    server_name example.com www.example.com;
    root /var/www/example.com;
    index index.php;
    
    # Принудительное использование канонического домена
    # if ($host != "www.example.com") {
    #     return 301 https://www.example.com$request_uri;
    # }
    
    # Принудительное использование HTTPS
    # return 301 https://$server_name$request_uri;
    
    # Статические файлы
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff|woff2|ttf|eot|svg|pdf|zip)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }
    
    # Защита конфиденциальных файлов
    location ~* ^/(?:\.htaccess|credits\.txt|readme\.txt|license\..*\.txt)$ {
        deny all;
    }
    
    # PHP-обработка
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_param PATH_INFO $fastcgi_path_info;
    }
    
    # Все остальные запросы на index.php
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    
    # Защита каталогов
    location ~ ^/(cache|upload|config|vendor)/ {
        deny all;
    }
}
```
