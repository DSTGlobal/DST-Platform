# 41. Вопросы безопасности

Данный документ описывает архитектуру безопасности, механизмы защиты и лучшие практики, реализованные в DST Platform. Рассматриваются аутентификация, авторизация, валидация входных данных, защита от инъекций, безопасность загрузки файлов и усиление защиты веб-сервера.

Для настройки контроля доступа в панели администратора см. раздел *«Панель администратора»*. Информацию о безопасности внешних интеграций см. в разделе *«Внешние интеграции»*.

> ⚠️ **Важно:** В данном документе описывается только базовая архитектура безопасности, доступная в открытом доступе. Дополнительные модули «Автоматизированная система комплексной безопасности», «Система мониторинга авторизаций», «Система логирования», а также закрытые и кастомизированные решения по безопасности не рассматриваются во избежание распространения конфиденциальной информации.

### Таблицы базы данных

Права доступа хранятся в следующих таблицах:

| Таблица | Назначение | Ключевые поля |
|---------|------------|---------------|
| `users_groups` | Определение групп (ролей) | `id`, `title`, `description` |
| `users_groups_members` | Членство пользователей в группах | `user_id`, `group_id` |
| `perms_rules` | Правила доступа | `subject`, `action`, `value` |
| `perms_users` | Переопределения прав для конкретных пользователей | `user_id`, `rule_id`, `value` |

### Методы проверки прав

| Метод | Назначение | Пример использования |
|-------|------------|---------------------|
| `cmsUser::is_admin` | Проверка статуса администратора | `if ($this->cms_user->is_admin)` |
| `cmsUser::isAllowed($component, $action)` | Проверка конкретного разрешения | `if ($user->isAllowed('content', 'add'))` |
| `cmsUser::isInGroups($group_ids)` | Проверка членства в группах | `if ($user->isInGroups([1, 2, 3]))` |
| `cmsPermissions::check($rule)` | Низкоуровневая проверка прав | `cmsPermissions::check('shop_edit')` |

### Проверка прав в контроллерах

```php
// Пример 1: Проверка статуса администратора
public function actionAdminPanel() {
    if (!$this->cms_user->is_admin) {
        return $this->error403('Доступ запрещён');
    }
    // ... логика админки
}

// Пример 2: Проверка конкретного разрешения
public function actionEditProduct($id) {
    if (!$this->cms_user->isAllowed('shop', 'edit')) {
        return $this->error403('У вас нет прав на редактирование товаров');
    }
    // ... логика редактирования
}

// Пример 3: Проверка принадлежности к группам
public function actionModerate() {
    $moderator_groups = [5, 10]; // ID групп модераторов
    if (!$this->cms_user->isInGroups($moderator_groups)) {
        return $this->error403('Требуются права модератора');
    }
    // ... логика модерации
}
```

### Безопасный доступ через cmsRequest

Класс `cmsRequest` обеспечивает безопасный доступ ко всем HTTP-входным данным:

```php
// В контроллерах
class MyController extends cmsController {
    
    public function actionExample() {
        // Безопасное получение целого числа
        $id = $this->request->get('id', 0); // По умолчанию: 0
        
        // Безопасное получение строки
        $name = $this->request->get('name', '');
        
        // Получение массива
        $ids = $this->request->get('ids', []);
        
        // POST-данные
        $email = $this->request->post('email', '');
        
        // Безопасное получение URL
        $url = $this->request->getUrl('redirect_url');
        
        // Безопасное получение email
        $email = $this->request->getEmail('email');
    }
}
```

### Правила санитизации

| Метод | Применяемый фильтр | Вариант использования |
|-------|-------------------|----------------------|
| `get($key, $default)` | `FILTER_SANITIZE_STRING` | Общий текстовый ввод |
| `post($key, $default)` | `FILTER_SANITIZE_STRING` | Данные из форм |
| `getInt($key)` | `FILTER_VALIDATE_INT` | Числовые идентификаторы, количество |
| `getEmail($key)` | `FILTER_VALIDATE_EMAIL` | Адреса электронной почты |
| `getUrl($key)` | `FILTER_VALIDATE_URL` | URL-адреса |
| `getFloat($key)` | `FILTER_VALIDATE_FLOAT` | Дробные числа |
| `getBool($key)` | Преобразование в булево | Флаги, чекбоксы |

### Валидация через cmsForm

Класс `cmsForm` предоставляет декларативные правила проверки:

```php
$form = new cmsForm();

// Добавление поля с правилами валидации
$form->addField('text', 'name', 'Имя')
    ->addRule('required')
    ->addRule('minlength', 3)
    ->addRule('maxlength', 100);

$form->addField('email', 'email', 'Email')
    ->addRule('required')
    ->addRule('email');

$form->addField('number', 'age', 'Возраст')
    ->addRule('min', 18)
    ->addRule('max', 100);

// Валидация формы
if ($form->validate()) {
    $data = $form->getValues(); // Очищенные и валидированные данные
    // ... обработка данных
} else {
    $errors = $form->getErrors(); // Массив ошибок валидации
    // ... отображение ошибок
}
```

### Встроенные правила валидации

| Правило | Описание | Пример |
|---------|----------|--------|
| `required` | Поле не должно быть пустым | `->addRule('required')` |
| `email` | Валидный формат email | `->addRule('email')` |
| `url` | Валидный формат URL | `->addRule('url')` |
| `minlength` / `maxlength` | Ограничения длины строки | `->addRule('minlength', 3)` |
| `min` / `max` | Числовые ограничения | `->addRule('min', 0)` |
| `number` | Числовая проверка | `->addRule('number')` |
| `regexp` | Пользовательский шаблон регулярного выражения | `->addRule('regexp', '/^[a-z]+$/')` |

### Использование подготовленных запросов

Класс `cmsModel` автоматически использует подготовленные операторы:

```php
class modelMyComponent extends cmsModel {
    
    /**
     * Получение элементов с использованием построителя запросов
     */
    public function getItems() {
        // Безопасное построение запроса
        return $this->filterEqual('status', 'active')
            ->filterGt('price', 0)
            ->limit(10)
            ->getItems('products');
    }
    
    /**
     * Сохранение данных с автоматической параметризацией
     */
    public function saveItem($data) {
        return $this->insert('products', $data);
    }
    
    /**
     * Обновление с параметризованными значениями
     */
    public function updateItem($id, $data) {
        return $this->update('products', $id, $data);
    }
}
```

### Основные функции безопасности

| Метод | Механизм безопасности | Назначение |
|-------|----------------------|------------|
| `filterEqual($field, $value)` | Параметризованное условие WHERE | Безопасные сравнения |
| `filterLike($field, $value)` | Экранирование шаблона LIKE | Поиск с подстановочными знаками |
| `filterGt($field, $value)` | Параметризованное сравнение > | Числовые сравнения |
| `filterIn($field, $values)` | Параметризованный оператор IN | Множественный выбор |
| `insert($table, $data)` | Параметризованный INSERT | Безопасное добавление |
| `update($table, $id, $data)` | Параметризованный UPDATE | Безопасное обновление |

### Прямые SQL-запросы

Если необходим прямой SQL-запрос, всегда используйте параметризованные запросы:

```php
// ✅ ПРАВИЛЬНО: Параметризованный запрос
$sql = "SELECT * FROM users WHERE email = ? AND status = ?";
$result = $this->db->query($sql, [$email, $status]);

// ✅ Альтернатива: Именованные параметры
$sql = "SELECT * FROM products WHERE category_id = :cat_id AND price > :min_price";
$result = $this->db->query($sql, [
    ':cat_id' => $category_id,
    ':min_price' => $min_price
]);

// ❌ НЕПРАВИЛЬНО: Конкатенация строк (уязвима для SQL-инъекций)
$sql = "SELECT * FROM users WHERE email = '$email'"; // НИКОГДА ТАК НЕ ДЕЛАЙТЕ!
```

### Пример безопасной загрузки файлов

```php
// Белый список разрешенных расширений
const ALLOWED_EXTENSIONS = [
    'jpg', 'jpeg', 'png', 'gif', 'bmp',  // Изображения
    'pdf', 'doc', 'docx', 'xls', 'xlsx',  // Документы
    'txt', 'rtf'                          // Текстовые файлы
];

// Максимальный размер файла (64 МБ)
const MAX_FILE_SIZE = 67108864;

// Путь для загрузки (вне корня веб-сервера, рекомендуется)
$uploadPath = dirname(dirname(__FILE__)) . '/uploads_files';

// Проверка наличия загруженного файла
if (!isset($_FILES['file']) || $_FILES['file']['error'] !== UPLOAD_ERR_OK) {
    die('Ошибка загрузки файла');
}

// Получение расширения файла
$filename = $_FILES['file']['name'];
$extension = mb_strtolower(pathinfo($filename, PATHINFO_EXTENSION));

// Проверка расширения (белый список)
if (!in_array($extension, ALLOWED_EXTENSIONS)) {
    die('Недопустимый тип файла');
}

// Проверка размера файла
if ($_FILES['file']['size'] > MAX_FILE_SIZE) {
    die('Файл слишком большой');
}

// Генерация уникального имени файла
$newFilename = uniqid('upload_', true) . '.' . $extension;
$destination = $uploadPath . '/' . $newFilename;

// Безопасное перемещение файла
if (move_uploaded_file($_FILES['file']['tmp_name'], $destination)) {
    // Установка прав доступа (только чтение для веб-сервера)
    chmod($destination, 0644);
    
    // Логирование успешной загрузки
    error_log(sprintf(
        '[UPLOAD] File uploaded: %s (original: %s, size: %d bytes)',
        $newFilename,
        $filename,
        $_FILES['file']['size']
    ));
    
    echo "Файл успешно загружен";
} else {
    die('Ошибка при перемещении файла');
}
```

### Использование класса cmsUploader

Базовая структура предоставляет класс `cmsUploader` для более продвинутой обработки файлов:

```php
class cmsUploader {
    
    /**
     * Валидация типа файла
     */
    public function validateType($file) {
        $allowed_types = ['image/jpeg', 'image/png', 'application/pdf'];
        $finfo = finfo_open(FILEINFO_MIME_TYPE);
        $mime_type = finfo_file($finfo, $file['tmp_name']);
        finfo_close($finfo);
        
        return in_array($mime_type, $allowed_types);
    }
    
    /**
     * Валидация размера файла
     */
    public function validateSize($file, $max_size = 10485760) { // 10MB
        return $file['size'] <= $max_size;
    }
    
    /**
     * Генерация безопасного имени файла
     */
    public function getSafeFilename($filename) {
        $extension = pathinfo($filename, PATHINFO_EXTENSION);
        return uniqid('file_', true) . '.' . $extension;
    }
    
    /**
     * Безопасное перемещение загруженного файла
     */
    public function uploadFile($file, $destination_path) {
        $safe_filename = $this->getSafeFilename($file['name']);
        $destination = $destination_path . '/' . $safe_filename;
        
        if (move_uploaded_file($file['tmp_name'], $destination)) {
            chmod($destination, 0644);
            return $safe_filename;
        }
        
        return false;
    }
    
    /**
     * Валидация изображения (дополнительная проверка)
     */
    public function validateImage($file) {
        $image_info = getimagesize($file['tmp_name']);
        if ($image_info === false) {
            return false;
        }
        
        // Проверка допустимых форматов изображений
        $allowed_formats = [IMAGETYPE_JPEG, IMAGETYPE_PNG, IMAGETYPE_GIF];
        return in_array($image_info[2], $allowed_formats);
    }
```

## 41.6. Экранирование вывода (защита от XSS)

### Контекстно-зависимое экранирование

Все данные, выводимые в HTML, должны быть экранированы для предотвращения XSS-атак:

```php
// ✅ ПРАВИЛЬНО: Экранирование вывода в HTML

    <?php echo htmlspecialchars($user_input, ENT_QUOTES, 'UTF-8'); ?>
</div>

// ✅ Альтернатива: Использование функции шаблона
<div>
    <?php echo $this->escape($user_input); ?>
</div>

// ❌ НЕПРАВИЛЬНО: Прямой вывод без экранирования
<div>
    <?php echo $user_input; ?> <!-- Уязвимость XSS! -->
</div>
```

### Экранирование в различных контекстах

| Контекст | Метод экранирования | Пример |
|----------|---------------------|--------|
| **HTML** | `htmlspecialchars()` | `htmlspecialchars($data, ENT_QUOTES, 'UTF-8')` |
| **JavaScript** | `json_encode()` | `var data = <?php echo json_encode($data); ?>;` |
| **URL** | `urlencode()` | `<a href="page.php?id=<?php echo urlencode($id); ?>">` |

## 41.7. Защита от CSRF-атак

### Генерация и проверка токенов CSRF

DST Platform реализует защиту от CSRF-атак с помощью токенов форм:

```php
// В классе cmsForm
class cmsForm {
    
    /**
     * Добавление CSRF-токена к форме
     */
    public function addCSRFToken() {
        // Генерация уникального токена для сессии
        if (!isset($_SESSION['csrf_token'])) {
            $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
        }
        
        // Добавление скрытого поля к форме
        $this->addField('hidden', 'csrf_token', '')
            ->setValue($_SESSION['csrf_token']);
        
        return $this;
    }
    
    /**
     * Валидация CSRF-токена
     */
    public function validateCSRFToken() {
        $submitted = $this->getValue('csrf_token');
        $expected = $_SESSION['csrf_token'] ?? '';
        
        // Использование сравнения за постоянное время для защиты от атак по времени
        return hash_equals($expected, $submitted);
    }
}
```

### Аутентификация для конечных точек API

Для доступа к API-интерфейсам следует использовать токены аутентификации:

```php
// В контроллере API
class api extends cmsController {
    
    public function before() {
        // Требование API-ключа или JWT-токена
        $api_key = $this->request->getHeader('X-API-Key');
        $auth_token = $this->request->getHeader('Authorization');
        
        if (!$this->validateApiKey($api_key) && !$this->validateAuthToken($auth_token)) {
            return $this->error401('Неавторизован');
        }
        
        return parent::before();
    }
    
    /**
     * Валидация API-ключа
     */
    private function validateApiKey($api_key) {
        if (empty($api_key)) {
            return false;
        }
        
        // Проверка ключа в базе данных
        $valid_key = $this->model->getApiKey($api_key);
        
        if (!$valid_key || !$valid_key['is_active']) {
            return false;
        }
        
        // Логирование использования ключа
        $this->model->logApiKeyUsage($api_key, $_SERVER['REMOTE_ADDR']);
        
        return true;
    }
    
    /**
     * Валидация JWT-токена
     */
    private function validateAuthToken($auth_header) {
        if (empty($auth_header) || !preg_match('/Bearer\s+(.*)$/i', $auth_header, $matches)) {
            return false;
        }
        
        $token = $matches[1];
        
        try {
            // Валидация и декодирование JWT
            $decoded = \Firebase\JWT\JWT::decode(
                $token,
                getenv('JWT_SECRET'),
                ['HS256']
            );
            
            // Проверка срока действия
            if ($decoded->exp < time()) {
                return false;
            }
            
            return true;
            
        } catch (\Exception $e) {
            error_log("JWT validation error: " . $e->getMessage());
            return false;
        }
    }
}
```

### Ограничение скорости запросов (Rate Limiting)

```php
/**
 * Ограничение скорости запросов к API
 */
class ApiRateLimiter {
    
    private $cache;
    
    public function __construct($cache) {
        $this->cache = $cache;
    }
    
    /**
     * Проверка лимита запросов
     * @param string $identifier Идентификатор (IP, API-ключ, пользователь)
     * @param int $max_requests Максимальное количество запросов
     * @param int $window_size Размер временного окна в секундах
     * @return bool
     */
    public function checkRateLimit($identifier, $max_requests = 100, $window_size = 60) {
        $cache_key = 'api_rate_limit:' . $identifier;
        $requests = $this->cache->get($cache_key) ?? 0;
        
        if ($requests >= $max_requests) {
            return false; // Превышен лимит
        }
        
        // Увеличение счётчика
        $this->cache->set($cache_key, $requests + 1, $window_size);
        return true;
    }
    
    /**
     * Получение информации о лимите
     */
    public function getRateLimitInfo($identifier, $max_requests = 100, $window_size = 60) {
        $cache_key = 'api_rate_limit:' . $identifier;
        $requests = $this->cache->get($cache_key) ?? 0;
        
        return [
            'limit' => $max_requests,
            'remaining' => max(0, $max_requests - $requests),
            'reset' => time() + $window_size
        ];
    }
}

    }
    
    // Добавление заголовков лимита в ответ
    $limit_info = $rate_limiter->getRateLimitInfo($ip);
    header('X-RateLimit-Limit: ' . $limit_info['limit']);
    header('X-RateLimit-Remaining: ' . $limit_info['remaining']);
```

```php
/**

class SecureTokenGenerator {

     * Генерация криптографически безопасного токена

     * Генерация UUID v4
     */
    public static function generateUUID() {

        $data[8] = chr(ord($data[8]) & 0x3f | 0x80);
        
        // Форматирование в стандартный UUID
        return vsprintf('%s%s-%s-%s-%s-%s%s%s', str_split(bin2hex($data), 4));
    }
}
```

```php
/**
 * Безопасное хеширование паролей

class PasswordHasher {
    
    /**
     * Хеширование пароля
     * @param string $password Пароль в открытом виде
     * @return string Хеш пароля
     */
    public static function hashPassword($password) {
        // Использование bcrypt с автоматической генерацией соли
        $hash = password_hash($password, PASSWORD_BCRYPT, [
            'cost' => 12 // Сложность хеширования (рекомендуется 10-12)
        ]);

            throw new \Exception('Ошибка хеширования пароля');
        }
        
        return $hash;
    }
    
    /**
     * Проверка пароля
     * @param string $password Пароль в открытом виде
     * @param string $hash Хеш из базы данных
     * @return bool
     */
    public static function verifyPassword($password, $hash) {
        return password_verify($password, $hash);
    }
    
    /**
     * Проверка необходимости перехеширования
     * @param string $hash Текущий хеш
     * @return bool
     */
    public static function needsRehash($hash) {
        return password_needs_rehash($hash, PASSWORD_BCRYPT, ['cost' => 12]);
    }
}

// Использование при регистрации
$password_hash = PasswordHasher::hashPassword($plain_password);
$this->model->insert('users', [
    'username' => $username,
    'password_hash' => $password_hash,
    'email' => $email
]);

// Использование при аутентификации
$user = $this->model->getUserByUsername($username);
if ($user && PasswordHasher::verifyPassword($password, $user['password_hash'])) {
    // Успешная аутентификация
    
    // Проверка необходимости перехеширования
    if (PasswordHasher::needsRehash($user['password_hash'])) {
        $new_hash = PasswordHasher::hashPassword($password);
        $this->model->updatePasswordHash($user['id'], $new_hash);
    }
} else {
    // Неверные учётные данные
}
```

### Шифрование и дешифрование данных

```php
/**
 * Класс для шифрования/дешифрования данных
 */
class DataEncryptor {
    
    private $key;
    private $cipher = 'aes-256-cbc';
    
    public function __construct($key = null) {
        $this->key = $key ?? getenv('ENCRYPTION_KEY');
        
        if (empty($this->key)) {
            throw new \Exception('Encryption key not configured');
        }
    }
    
    /**
     * Шифрование данных
     */
    public function encrypt($data) {
        $iv = openssl_random_pseudo_bytes(openssl_cipher_iv_length($this->cipher));
        $encrypted = openssl_encrypt($data, $this->cipher, $this->key, 0, $iv);
        
        // Возвращаем IV + зашифрованные данные (в base64)
        return base64_encode($iv . $encrypted);
    }
    
    /**
     * Дешифрование данных
     */
    public function decrypt($encrypted_data) {
        $data = base64_decode($encrypted_data);
        $iv_length = openssl_cipher_iv_length($this->cipher);
        
        if ($iv_length === false || mb_strlen($data, '8bit') < $iv_length) {
            throw new \Exception('Invalid encrypted data');
        }
        
        $iv = mb_substr($data, 0, $iv_length, '8bit');
        $encrypted = mb_substr($data, $iv_length, null, '8bit');
        
        $decrypted = openssl_decrypt($encrypted, $this->cipher, $this->key, 0, $iv);
        
        if ($decrypted === false) {
            throw new \Exception('Decryption failed');
        }
        
        return $decrypted;
    }
}

// Использование
$encryptor = new DataEncryptor();

// Шифрование чувствительных данных перед сохранением в БД
$encrypted_api_key = $encryptor->encrypt($api_key);
$this->model->saveEncryptedData('api_keys', [
    'service' => 'payment_gateway',
    'encrypted_key' => $encrypted_api_key
]);

// Дешифрование при использовании
$stored = $this->model->getEncryptedData('api_keys', 'payment_gateway');
$api_key = $encryptor->decrypt($stored['encrypted_key']);
```

## 41.11. Безопасность заданий Cron

### Механизм блокировки файлов

Скрипты Cron используют блокировку файлов для предотвращения одновременного выполнения:

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/261.png" alt="DST Platform">

```php
// В скриптах cron
$lockFile = cmsConfig::get('cache_path') . 'cron_export_lock';
$fp = fopen($lockFile, 'w');

if (!$fp) {
    error_log('[CRON] Cannot create lock file');
    exit(1);
}

// Попытка получения эксклюзивной неблокирующей блокировки
if (!flock($fp, LOCK_EX | LOCK_NB)) {
    error_log('[CRON] Another instance is already running. Exiting.');
    fclose($fp);
    exit(1);
}

// Гарантированная очистка блокировки при завершении
register_shutdown_function(function() use ($fp, $lockFile) {
    if ($fp) {
        flock($fp, LOCK_UN); // Снятие блокировки
        fclose($fp);         // Закрытие файла
        @unlink($lockFile);  // Удаление файла
    }
});

// Выполнение задачи...
try {
    // Логика выполнения задачи
    $result = $this->executeCronTask();
    
    error_log('[CRON] Task completed successfully');
    
} catch (\Exception $e) {
    error_log(sprintf('[CRON] Error: %s at %s:%d', 
        $e->getMessage(),
        $e->getFile(),
        $e->getLine()
    ));
    
    // Логирование стека вызовов для отладки
    error_log($e->getTraceAsString());
    
    exit(1);
}
```

### Рекомендации по безопасности для Cron-задач

| Рекомендация | Цель |
|--------------|------|
| **Использовать блокировку файлов** | Предотвращение одновременного выполнения |
| **Ограничивать время выполнения** | `set_time_limit(3600)` |
| **Логировать ошибки** | Отслеживание сбоев для отладки |
| **Проверять источники данных** | Не доверять даже "внутренним" данным |
| **Использовать абсолютные пути** | Предотвращение путаницы в путях |
| **Проверять права доступа** | Только авторизованные пользователи |
| **Валидировать входные параметры** | Предотвращение инъекций |

```php

 * cron_secure_task.php
 * Безопасный пример cron-скрипта с защитой от атак

    // Выполнение задачи
    $result = $controller->runHook('cron_secure_task_job', $params ?? []);
    
    error_log(sprintf(
        '[SECURE_TASK] Completed successfully at %s. Result: %s',
        date('Y-m-d H:i:s'),
        json_encode($result)
    ));
    
    exit(0);
    
} catch (\Exception $e) {
    error_log(sprintf(
        '[SECURE_TASK] ERROR: %s at %s:%d',
        $e->getMessage(),
        $e->getFile(),
        $e->getLine()
    ));
    
    error_log($e->getTraceAsString());
    exit(1);
}
```

## 41.13. Распространённые уязвимости и способы их устранения

### SQL-инъекция

**Уязвимость:**
```php
// ❌ НЕПРАВИЛЬНО
$sql = "SELECT * FROM users WHERE email = '{$_POST['email']}'";
```

```php
// ✅ ПРАВИЛЬНО
$sql = "SELECT * FROM users WHERE email = ?";

```

### XSS (Межсайтовый скриптинг)

**Уязвимость:**
```php

<div><?php echo $_GET['message']; ?></div>
```

**Меры по устранению:**

**Уязвимость:**
```php

```

**Меры по устранению:**
```php
// ✅ ПРАВИЛЬНО
$file = basename($this->request->get('file'));
$allowed_files = ['page1', 'page2', 'page3'];

    include("/path/to/templates/{$file}.php");

    die('Недопустимый файл');
}
```

**Уязвимость:**

```php
public function actionLogin() {
    $username = $this->request->post('username');
    $password = $this->request->post('password');
    $ip = $_SERVER['REMOTE_ADDR'];
    
    // Проверка неудачных попыток входа
    $failed_attempts = $this->model->getFailedLogins($ip, 900); // Последние 15 минут
    
    if (count($failed_attempts) >= 5) {
        // Блокировка на 15 минут после 5 неудачных попыток
        $remaining_time = 900 - (time() - $failed_attempts[0]['timestamp']);
        $minutes = ceil($remaining_time / 60);
        
        return $this->error("Слишком много неудачных попыток входа. Попробуйте через {$minutes} минут.");
    }
    
    // Попытка входа
    $user = $this->auth->authenticate($username, $password);
    
    if ($user) {
        // Успешный вход
        $this->model->clearFailedLogins($ip);
        $this->auth->login($user);
        
        // Логирование успешного входа
        cmsEventsManager::hook('security_event', [
            'type' => 'login_success',
            'user_id' => $user['id'],
            'username' => $username,
            'ip' => $ip,
            'timestamp' => time()
        ]);
        
        $this->redirect('/dashboard');
        
    } else {
        // Неудачная попытка входа
        $this->model->recordFailedLogin($ip, $username);
        
        // Логирование неудачной попытки
        cmsEventsManager::hook('security_event', [
            'type' => 'login_failed',
            'username' => $username,
            'ip' => $ip,
            'timestamp' => time()
        ]);
        
        return $this->error('Неверное имя пользователя или пароль');
    }
}
```

### Мониторинг подозрительной активности

```php
class SecurityMonitor {
    
    private $cache;
    
    public function __construct($cache) {
        $this->cache = $cache;
    }
    
    /**
     * Проверка подозрительной активности по частоте запросов
     */
    public function isSuspiciousActivity($identifier, $threshold = 100, $window = 60) {
        $cache_key = 'security_activity:' . $identifier;
        $count = $this->cache->get($cache_key) ?? 0;
        
        // Увеличение счётчика
        $this->cache->set($cache_key, $count + 1, $window);
        
        // Если превышен порог - подозрительная активность
        return ($count + 1) >= $threshold;
    }
    
    /**
     * Проверка подозрительного местоположения (геолокация)
     */
    public function isSuspiciousLocation($ip, $user_country) {
        $geoip = new GeoIpService();
        $location = $geoip->getLocation($ip);
        
        if (!$location) {
            return false;
        }
        
        $ip_country = $location['country']['code'] ?? null;
        
        // Если страна не совпадает с профилем пользователя - подозрительно
        if ($ip_country && $user_country && $ip_country !== $user_country) {
            error_log(sprintf(
                '[FRAUD] Suspicious location: User country=%s, IP country=%s, IP=%s',
                $user_country,
                $ip_country,
                $ip
            ));
            
            // Логирование события безопасности
            cmsEventsManager::hook('security_event', [
                'type' => 'suspicious_location',
                'ip' => $ip,
                'user_country' => $user_country,
                'ip_country' => $ip_country,
                'timestamp' => time()
            ]);
            
            return true;
        }
        
        return false;
    }
    
    /**
     * Отправка алерта о подозрительной активности
     */
    public function sendSecurityAlert($event_type, $details) {
        $admin_email = cmsConfig::get('admin_email');
        
        $subject = "Алерт безопасности: {$event_type}";
        $body = "Тип события: {$event_type}\n\n";
        $body .= "Детали:\n" . print_r($details, true);
        
        // Отправка уведомления администратору
        $mailer = cmsMailer::getInstance();
        $mailer->setTo($admin_email);
        $mailer->setSubject($subject);
        $mailer->setBody($body);
        $mailer->send();
        
        error_log("[SECURITY] Alert sent for event: {$event_type}");
    }
}
```

| Тип теста | Пример полезной нагрузки | Ожидаемый результат |

| **SQL-инъекция** | `' OR '1'='1`<br>`'; DROP TABLE users--` | Отказ в доступе или ошибка валидации |
| **XSS** | `<script>alert('XSS')</script>`<br>`<img src=x onerror=alert('XSS')>` | Экранирование или удаление тегов |
| **Обход пути** | `../../etc/passwd`<br>`...\windows\system32\config\sam` | Отказ в доступе |
| **Загрузка файлов** | `.php`, `.exe` файлы<br>Файлы с двойным расширением | Отклонение загрузки |
| **Обход аутентификации** | Доступ к `/admin` без входа | Перенаправление на страницу входа |
| **Обход авторизации** | Манипулирование идентификаторами (например, `?id=123` → `?id=124`) | Отказ в доступе к чужим данным |
| **CSRF** | Отправка формы без действительного токена | Ошибка 403 |
| **Фиксация сессии** | Попытка установить пользовательские идентификаторы сессий | Отказ или генерация нового идентификатора |

### Пример скрипта для автоматизированного тестирования

```php
#!/usr/bin/env php
<?php
/**
 * security_test.php
 * Скрипт для автоматизированного тестирования безопасности
 */

require_once 'bootstrap.php';

class SecurityTester {
    
    private $results = [];
    private $passed = 0;
    private $failed = 0;
    
    /**
     * Тестирование защиты от SQL-инъекций
     */
    public function testSqlInjection() {
        $test_cases = [
            "' OR '1'='1",
            "'; DROP TABLE users--",
            "admin'--",
            "' UNION SELECT * FROM users--"
        ];
        
        foreach ($test_cases as $payload) {
            try {
                // Попытка инъекции через cmsRequest
                $result = cmsRequest::get('test', $payload);
                
                // Если результат не экранирован - уязвимость
                if (strpos($result, $payload) !== false) {
                    $this->recordFailure('SQL Injection', $payload);
                } else {
                    $this->recordSuccess('SQL Injection', $payload);
                }
                
            } catch (\Exception $e) {
                $this->recordSuccess('SQL Injection', $payload);
            }
        }
    }
    
    /**
     * Тестирование защиты от XSS
     */
    public function testXssProtection() {
        $test_cases = [
            "<script>alert('XSS')</script>",
            "<img src=x onerror=alert('XSS')>",
            "<svg onload=alert('XSS')>",
            "javascript:alert('XSS')"
        ];
        
        foreach ($test_cases as $payload) {
            $sanitized = htmlspecialchars($payload, ENT_QUOTES, 'UTF-8');
            
            if (strpos($sanitized, '<script>') === false && 
                strpos($sanitized, 'javascript:') === false) {
                $this->recordSuccess('XSS Protection', $payload);
            } else {
                $this->recordFailure('XSS Protection', $payload);
            }
        }
    }
    
    /**
     * Тестирование валидации файлов
     */
    public function testFileUploadValidation() {
        $test_extensions = ['php', 'exe', 'sh', 'bat'];
        $allowed_extensions = ['jpg', 'png', 'pdf', 'doc'];
        
        foreach ($test_extensions as $ext) {
            if (in_array($ext, $allowed_extensions)) {
                $this->recordFailure('File Upload Validation', "Extension .{$ext} should be blocked");
            } else {
                $this->recordSuccess('File Upload Validation', "Extension .{$ext} is blocked");
            }
        }
    }
    
    /**
     * Запись успешного теста
     */
    private function recordSuccess($test, $details = '') {
        $this->results[] = [
            'status' => 'PASS',
            'test' => $test,
            'details' => $details
        ];
        $this->passed++;
    }
    
    /**
     * Запись неудачного теста
     */
    private function recordFailure($test, $details = '') {
        $this->results[] = [
            'status' => 'FAIL',
            'test' => $test,
            'details' => $details
        ];
        $this->failed++;
    }
    
    /**
     * Вывод результатов
     */
    public function printResults() {
        echo "\n===== РЕЗУЛЬТАТЫ ТЕСТИРОВАНИЯ БЕЗОПАСНОСТИ =====\n\n";
        
        foreach ($this->results as $result) {
            $status = $result['status'] === 'PASS' ? '✓' : '✗';
            echo "{$status} {$result['test']}\n";
            if (!empty($result['details'])) {
                echo "  {$result['details']}\n";
            }
        }
        
        echo "\n=============================================\n";
        echo "Пройдено: {$this->passed}\n";
        echo "Не пройдено: {$this->failed}\n";
        echo "Всего: " . ($this->passed + $this->failed) . "\n";
        echo "=============================================\n\n";
        
        return $this->failed === 0;
    }
}

// Запуск тестов
$tester = new SecurityTester();
$tester->testSqlInjection();
$tester->testXssProtection();
$tester->testFileUploadValidation();

$success = $tester->printResults();
exit($success ? 0 : 1);
```

## 41.16. Контрольный список безопасности

### Перед слиянием кода

Проверьте следующее:

- [ ] Все запросы к базе данных используют подготовленные операторы
- [ ] Все пользовательские данные проверяются и очищаются
- [ ] Весь вывод корректно экранируется для контекста (HTML, JS, URL)
- [ ] Загружаемые файлы проверяются (расширение, размер, тип)
- [ ] Для выполнения защищённых действий требуется аутентификация
- [ ] Перед выполнением конфиденциальных операций проверяется авторизация
- [ ] Токены CSRF используются в формах, изменяющих состояние
- [ ] Сообщения об ошибках не раскрывают конфиденциальную информацию
- [ ] Пароли хешируются (никогда не хранятся в открытом виде)
- [ ] Сессии восстанавливаются при входе/выходе из системы
- [ ] API-интерфейсы имеют ограничения по скорости запросов
- [ ] Криптографические операции используют надёжные источники случайных чисел

### Контрольный список развёртывания в продакшене

Перед развёртыванием в продакшене:

- [ ] Включить перенаправление HTTPS в `.htaccess`
- [ ] Отключить режим отладки в `config.php` (`debug => false`)
- [ ] Установить соответствующие права доступа к файлам (файлы: 644, каталоги: 755)
- [ ] Удалить или ограничить доступ к `phpinfo()` и тестовым файлам
- [ ] Включить opcache и выполнить соответствующие настройки
- [ ] Настроить брандмауэр для разрешения только необходимых портов
- [ ] Настроить пользователя базы данных с минимально необходимыми правами
- [ ] Включить запись ошибок в файл (а не в браузер)
- [ ] Настроить стратегию резервного копирования для базы данных и файлов
- [ ] Настроить мониторинг событий безопасности
- [ ] Проверить, что все секреты (ключи API, пароли) хранятся в переменных окружения
- [ ] Убедиться, что `.env` файл не попал в репозиторий
- [ ] Проверить настройки CORS для API
- [ ] Настроить заголовки безопасности (CSP, HSTS, X-Frame-Options)

## 41.17. Заключение

Архитектура безопасности DST Platform обеспечивает многоуровневую защиту:

- **Безопасность веб-сервера** — правила `.htaccess` ограничивают доступ к файлам
- **Аутентификация** — `cmsUser` обеспечивает безопасное управление сессиями
- **Авторизация** — `cmsPermissions` обеспечивает контроль доступа на основе ролей
- **Валидация входных данных** — `cmsRequest` и `cmsForm` проверяют и очищают все данные
- **Предотвращение SQL-инъекций** — `cmsModel` использует исключительно подготовленные запросы
- **Экранирование вывода** — шаблоны должны экранировать весь вывод
- **Безопасность загрузки файлов** — проверка расширений, размеров и типов
- **Защита от CSRF-атак** — проверка на основе токенов для операций изменения состояния

**Основные принципы безопасности:**

1. **Никогда не доверяйте пользовательскому вводу** — проверяйте и очищайте все данные
2. **Многоуровневая защита** — защита от сбоев обеспечивается несколькими уровнями безопасности
3. **Безопасный отказ** — по умолчанию запрещайте доступ, а не предоставляйте его
4. **Принцип минимальных привилегий** — предоставляйте минимально необходимые разрешения
5. **Безопасность заложена в основу** — безопасность интегрирована в архитектуру, а не добавлена позже

Следуя описанным здесь правилам безопасности и правильно используя встроенные функции безопасности фреймворка, разработчики могут создавать надёжные и защищённые приложения на DST Platform.

- *«Внешние интеграции»* — безопасность API и внешних сервисов
- *«Создание компонентов»* — безопасная разработка пользовательских модулей
- *«Работа с хуками»* — безопасное расширение функциональности
