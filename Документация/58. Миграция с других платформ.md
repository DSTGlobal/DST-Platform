# Часть I. Методология

## 58.1. Зачем этот раздел

В клиентской документации миграция описана как **управляемый проект из семи этапов**. Этот раздел — **техническая перспектива** тех же этапов для разработчиков: конкретные SQL, PHP-скрипты, маппинги сущностей и проверки. Здесь отвечаем на вопросы:

- «Как выгрузить данные из WordPress / Bitrix / CS-Cart?»
- «Как смапить сущности на модель DST Platform?»
- «Что делать с паролями?»
- «Как не потерять SEO?»
- «Как откатиться, если что-то пошло не так?»

**Кому адресовано:** backend-разработчикам, DBA, DevOps, SEO-инженерам, участвующим в проекте миграции.

## 58.2. Семь этапов миграции (техническая перспектива)

Из клиентской документации — семь этапов. Здесь — что делает **инженерия** на каждом:

| Этап (клиентская версия) | Техническая работа |
|---|---|
| **1. Аудит** | `mysqldump --no-data` исходной БД; анализ схемы; подсчёт объёмов; `SELECT COUNT(*)` по ключевым таблицам; снятие `EXPLAIN` по топ-запросам |
| **2. Планирование** | Маппинг сущностей (source → DST); дизайн миграционных таблиц (`_migration_*`); план поэтапного переключения; карта редиректов |
| **3. Перенос данных** | Миграционные скрипты (`migrate_*.php`); идемпотентность; батчи по 1000; логирование; валидация |
| **4. Настройка платформы** | Конфиги `config.php`; настройка интеграций (1С, CRM, ЮKassa, CDEK); OPcache; кэш; Nginx |
| **5. Тестирование** | PHPUnit-тесты; smoke-тесты; SEO-тесты (редиректы, meta); нагрузочное (ab/wrk) |
| **6. Обучение** | Технический handover: `api_docs`, runbooks, architecture-обзор |
| **7. Запуск** | DNS-switch, blue-green, мониторинг (Grafana), алерты, откат-план |

## 58.3. Стратегии миграции

### 58.3.1. Big Bang

```
1. Остановка старой системы (downtime)
2. Полный перенос
3. Переключение DNS
4. Запуск
```

| Плюсы | Минусы |
|---|---|
| Простота | Долгий downtime |
| Консистентность | Высокий риск |
| — | Нет возможности отката после запуска |

**Когда:** небольшой проект, допустим downtime 4–12 часов, простая структура.

### 58.3.2. Phased migration (поэтапная)

```
Фаза 1: Пользователи (read-only на новой платформе)
Фаза 2: Контент / каталог
Фаза 3: Заказы (новые — на новой, старые — read-only)
Фаза 4: Полное переключение
```

| Плюсы | Минусы |
|---|---|
| Минимальный downtime | Сложнее |
| Возможность отката на каждой фазе | Нужна синхронизация между системами |
| Постепенное тестирование | Двойные затраты на инфраструктуру |

**Когда:** крупный проект, критичный uptime, есть ресурсы на двойную инфраструктуру. **Рекомендуется для DST Platform.**

### 58.3.3. Blue-green (с переключением)

```
Blue  (старая) — активна
Green (новая) — готова, но не принимает трафик
    ↓
Переключение DNS / LB
    ↓
Blue  (старая) — standby, 7 дней
Green (новая) — активна
```

| Плюсы | Минусы |
|---|---|
| Мгновенный откат | Нужна полная копия |
| Минимальный downtime (минуты) | Двойная нагрузка на инфраструктуру |
| — | DNS TTL должен быть низким (60 сек) |

**Когда:** критичный проект, есть бюджет на параллельную инфраструктуру. **Идеально для DST Platform** — см. раздел 50.21.

> 💡 **Рекомендация DST.** Для 90 % проектов — **phased + blue-green**: поэтапный перенос данных + финальное переключение через blue-green. Это даёт минимальный downtime и полную откатываемость.

## 58.5. Риски и как их снимает инженерия

| Риск (из клиентского документа) | Техническая мера |
|---|---|
| **Потеря SEO-позиций** | Карта 1:1 редиректов 301; миграция meta; сохранение URL-структуры; sitemap; Schema.org; мониторинг в Search Console |
| **Простой в работе** | Blue-green; phased; низкий DNS TTL; read-only старая система |
| **Потеря / искажение данных** | Валидация до/после; checksums; тестовое восстановление; staging-прогон |
| **Срыв интеграций** | Аудит на этапе 1; staging-тесты; контрактные тесты; fallback |
| **Невозможность отката** | Двойная инфраструктура 7 дней; snapshot; DNS revert |

```sql
    p.ID,
    p.post_name,
    MAX(CASE WHEN pm.meta_key = '_yoast_wpseo_title' THEN pm.meta_value END) AS title,
    MAX(CASE WHEN pm.meta_key = '_yoast_wpseo_metadesc' THEN pm.meta_value END) AS description,
```

## 58.10. Go/No-go критерии

> 💡 **Правило.** Если хотя бы один критерий «No-go» — миграцию не начинаем.

| Критерий | Go | No-go |
|---|---|---|
| **Схема БД** | Получена полностью | Есть скрытые таблицы |
| **Объёмы** | Согласованы | Данные больше ожидаемых в 2× |
| **Интеграции** | Аудит проведён | Неизвестные / заброшенные |
| **Доступы** | Есть все | Нет доступа к БД или серверу |
| **SEO-карта** | Снята | Нет данных о структуре URL |
| **Downtime** | Согласован | Заказчик не может подтвердить окно |
| **Бюджет** | Согласован | — |
| **Сроки** | Реалистичны | Меньше 2 недель для среднего проекта |

### 58.11.2. Базовый класс

**Файл:** `/migration/lib/Migrator.php`

```php
<?php
declare(strict_types=1);

namespace Migration;

abstract class Migrator {

    protected \PDO $source;
    protected \PDO $target;
    protected array $config;
    protected string $name;
    protected array $stats = ['processed' => 0, 'skipped' => 0, 'errors' => 0];

    public function __construct(\PDO $source, \PDO $target, array $config) {
        $this->source = $source;
        $this->target = $target;
        $this->config = $config;
    }

    /** Основной метод миграции. */
    abstract public function run(): void;

    /** Проверка, что миграция может быть запущена. */
    public function preCheck(): void {}

    /** Валидация результата. */
    public function validate(): array {
        return [];
    }

    /** Имя миграции. */
    public function getName(): string {
        return static::class;
    }

    /** Батчевый проход по source-таблице. */
    protected function batch(
        string $query,
        int $batchSize,
        callable $processor
    ): void {
        $offset = 0;
        $total = (int)$this->source->query($query)->rowCount();

        while (true) {
            $rows = $this->source->query("$query LIMIT $batchSize OFFSET $offset")->fetchAll();
            if (empty($rows)) {
                break;
            }

            foreach ($rows as $row) {
                try {
                    $processor($row);
                    $this->stats['processed']++;
                } catch (\Throwable $e) {
                    $this->stats['errors']++;
                    $this->log("ERROR: " . $e->getMessage(), $row);
                }
            }

            $offset += $batchSize;
            $this->log(sprintf(
                "Progress: %d/%d (%.1f%%)",
                $offset,
                $total,
                min(100, $offset / $total * 100)
            ));
        }
    }

    protected function log(string $message, array $context = []): void {
        $line = sprintf(
            '[%s] [%s] %s %s',
            date('Y-m-d H:i:s'),
            $this->getName(),
            $message,
            $context ? json_encode($context, JSON_UNESCAPED_UNICODE) : ''
        );
        echo $line . PHP_EOL;
        file_put_contents(
            '/var/log/migration.log',
            $line . PHP_EOL,
            FILE_APPEND | LOCK_EX
        );
    }

    /** Идемпотентность: проверка, не мигрировали ли уже. */
    protected function isMigrated(string $sourceTable, int $sourceId): bool {
        $stmt = $this->target->prepare(
            "SELECT 1 FROM migration_map WHERE source_table = ? AND source_id = ? LIMIT 1"
        );
        $stmt->execute([$sourceTable, $sourceId]);
        return (bool)$stmt->fetchColumn();
    }

    /** Запись маппинга source → target. */
    protected function mapId(string $sourceTable, int $sourceId, int $targetId): void {
        $stmt = $this->target->prepare(
            "INSERT INTO migration_map (source_table, source_id, target_id, migrated_at) 
             VALUES (?, ?, ?, NOW())
             ON DUPLICATE KEY UPDATE target_id = VALUES(target_id), migrated_at = NOW()"
        );
        $stmt->execute([$sourceTable, $sourceId, $targetId]);
    }

    public function getStats(): array {
        return $this->stats;
    }
}
```

### 58.11.3. Таблица маппинга

```sql
CREATE TABLE IF NOT EXISTS `migration_map` (
    `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    `source_table` VARCHAR(100) NOT NULL,
    `source_id` BIGINT UNSIGNED NOT NULL,
    `target_id` BIGINT UNSIGNED NOT NULL,
    `migrated_at` DATETIME NOT NULL,
    UNIQUE INDEX `uniq_source` (`source_table`, `source_id`),
    INDEX `idx_target` (`target_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 58.16.2. Миграция записей

**Файл:** `/migration/migrations/wordpress/02_posts.php`

```php
<?php
declare(strict_types=1);

namespace Migration\WordPress;

use Migration\Migrator;

class Posts extends Migrator {

    public function run(): void {
        // 1. Определяем ID типа контента в DST
        $articlesCtypeId = (int)$this->target->query(
            "SELECT id FROM cms_content_types WHERE name = 'articles'"
        )->fetchColumn();

        $pagesCtypeId = (int)$this->target->query(
            "SELECT id FROM cms_content_types WHERE name = 'pages'"
        )->fetchColumn();

        // 2. Батч по 500
        $this->batch(
            "SELECT 
                ID, post_title, post_name, post_content, post_excerpt,
                post_status, post_date, post_modified, post_author,
                post_type
             FROM wp_posts
             WHERE post_type IN ('post', 'page')
               AND post_status IN ('publish', 'draft', 'pending', 'private')
             ORDER BY ID",
            500,
            function (array $row) use ($articlesCtypeId, $pagesCtypeId) {
                $this->migrateOne($row, $row['post_type'] === 'post' ? $articlesCtypeId : $pagesCtypeId);
            }
        );
    }

    private function migrateOne(array $row, int $ctypeId): void {
        // Идемпотентность
        if ($this->isMigrated('wp_posts', (int)$row['ID'])) {
            $this->stats['skipped']++;
            return;
        }

        // Подготовка данных
        $data = [
            'ctype_id'      => $ctypeId,
            'title'         => $this->decodeTitle($row['post_title']),
            'slug'          => $row['post_name'],
            'content'       => $this->cleanContent($row['post_content']),
            'excerpt'       => $row['post_excerpt'],
            'is_published'  => in_array($row['post_status'], ['publish', 'private']) ? 1 : 0,
            'date_pub'      => $row['post_date'],
            'date_mod'      => $row['post_modified'],
            'user_id'       => $this->mapUserId((int)$row['post_author']),
        ];

        // Вставка в cms_content
        $stmt = $this->target->prepare("
            INSERT INTO cms_content 
                (ctype_id, title, slug, content, excerpt, is_published, date_pub, date_mod, user_id)
            VALUES 
                (:ctype_id, :title, :slug, :content, :excerpt, :is_published, :date_pub, :date_mod, :user_id)
        ");
        $stmt->execute($data);

        $targetId = (int)$this->target->lastInsertId();
        $this->mapId('wp_posts', (int)$row['ID'], $targetId);

        // Категории и теги
        $this->migrateTerms((int)$row['ID'], $targetId);

        // SEO
        $this->migrateSeo((int)$row['ID'], $targetId);

        // Редирект: старый URL → новый
        $this->addRedirect($row);
    }

    private function decodeTitle(string $title): string {
        // HTML entities + смарт-кавычки
        return html_entity_decode($title, ENT_QUOTES | ENT_HTML5, 'UTF-8');
    }

    private function cleanContent(string $content): string {
        // 1. Удалить Gutenberg-комментарии
        $content = preg_replace('/<!--\s*\/?wp:.*?-->/s', '', $content);

        // 2. Удалить короткие коды WordPress (оставить текст)
        $content = preg_replace('/\[(\w+)[^\]]*\](.*?)\[\/\1\]/s', '$2', $content);

        // 3. Конвертировать в UTF-8
        if (!mb_check_encoding($content, 'UTF-8')) {
            $content = mb_convert_encoding($content, 'UTF-8', 'Windows-1251');
        }

        return trim($content);
    }

    private function mapUserId(int $wpUserId): int {
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map WHERE source_table = 'wp_users' AND source_id = ?"
        );
        $stmt->execute([$wpUserId]);
        $targetId = $stmt->fetchColumn();

        // Fallback на админа (ID=1)
        return $targetId ? (int)$targetId : 1;
    }

    private function migrateTerms(int $wpPostId, int $targetId): void {
        // Связи поста с терминами (категории, теги)
        $stmt = $this->source->prepare("
            SELECT t.term_id, t.name, t.slug, tt.taxonomy
            FROM wp_term_relationships tr
            JOIN wp_term_taxonomy tt ON tt.term_taxonomy_id = tr.term_taxonomy_id
            JOIN wp_terms t ON t.term_id = tt.term_id
            WHERE tr.object_id = ?
        ");
        $stmt->execute([$wpPostId]);
        $terms = $stmt->fetchAll();

        foreach ($terms as $term) {
            $categoryId = $this->ensureCategory($term);

            $this->target->prepare("
                INSERT IGNORE INTO cms_content_categories_items (content_id, category_id)
                VALUES (?, ?)
            ")->execute([$targetId, $categoryId]);
        }
    }

    private function ensureCategory(array $term): int {
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'wp_terms' AND source_id = ?"
        );
        $stmt->execute([(int)$term['term_id']]);
        $targetId = $stmt->fetchColumn();

        if ($targetId) {
            return (int)$targetId;
        }

        // Создать новую
        $this->target->prepare(
            "INSERT INTO cms_content_categories (title, slug) VALUES (?, ?)"
        )->execute([$term['name'], $term['slug']]);

        $id = (int)$this->target->lastInsertId();
        $this->mapId('wp_terms', (int)$term['term_id'], $id);

        return $id;
    }

    private function migrateSeo(int $wpPostId, int $targetId): void {
        // Yoast
        $stmt = $this->source->prepare("
            SELECT meta_key, meta_value
            FROM wp_postmeta
            WHERE post_id = ?
              AND meta_key IN ('_yoast_wpseo_title', '_yoast_wpseo_metadesc', 
                               '_yoast_wpseo_focuskw', '_yoast_wpseo_canonical')
        ");
        $stmt->execute([$wpPostId]);
        $meta = $stmt->fetchAll(\PDO::FETCH_KEY_PAIR);

        if (empty($meta)) {
            return;
        }

        $this->target->prepare("
            UPDATE cms_content
            SET seo_title = :title,
                seo_description = :description,
                seo_keys = :keys
            WHERE id = :id
        ")->execute([
            ':title' => $meta['_yoast_wpseo_title'] ?? '',
            ':description' => $meta['_yoast_wpseo_metadesc'] ?? '',
            ':keys' => $meta['_yoast_wpseo_focuskw'] ?? '',
            ':id' => $targetId,
        ]);
    }

    private function addRedirect(array $row): void {
        // /2024/01/my-post/ → /articles/my-post
        $oldUrl = sprintf(
            '/%s/%s/',
            date('Y/m', strtotime($row['post_date'])),
            $row['post_name']
        );
        $newUrl = $row['post_type'] === 'post'
            ? "/articles/{$row['post_name']}"
            : "/{$row['post_name']}";

        $this->target->prepare("
            INSERT INTO cms_redirects (from_url, to_url, code, created_at)
            VALUES (?, ?, 301, NOW())
            ON DUPLICATE KEY UPDATE to_url = VALUES(to_url)
        ")->execute([$oldUrl, $newUrl]);
    }

    public function validate(): array {
        return [
            'count_match' => $this->countMatch('wp_posts', 'cms_content'),
            'no_empty_titles' => QualityChecks::noEmptyTitles($this->target),
        ];
    }

    private function countMatch(string $src, string $tgt): bool {
        $srcCount = (int)$this->source->query(
            "SELECT COUNT(*) FROM $src WHERE post_type IN ('post','page')"
        )->fetchColumn();
        $tgtCount = (int)$this->target->query(
            "SELECT COUNT(*) FROM $tgt"
        )->fetchColumn();
        return $srcCount === $tgtCount;
    }
}

return Posts::class;
```

## 58.17. Миграция пользователей (и паролей)

### 58.17.1. Ключевая проблема

WordPress использует **`wp_hash_password`** — это **phpass** (`$P$...`), не `bcrypt` и не `argon2`. DST Platform использует `password_hash` (bcrypt/argon2).

**Прямой перенос хеша невозможен** — DST Platform не сможет его проверить.

**Стратегии:**

| Стратегия | Плюсы | Минусы |
|---|---|---|
| **A. Force reset** | Безопасно | Пользователи недовольны |
| **B. Двойной hash** | Автоматический перенос | Требует bridge-класс |
| **C. Первый вход = миграция** | Прозрачно | Сложно, но best UX |

**Рекомендация:** **C** (первый вход = миграция). Пользователь входит со старым паролем → DST Platform проверяет через phpass → пересохраняет как bcrypt.

### 58.17.2. Реализация (стратегия C)

**Файл:** `/system/libs/WordPressPasswordBridge.php`

```php
<?php
declare(strict_types=1);

/**
 * Проверка phpass-хеша (WordPress) для миграции.
 */
class WordPressPasswordBridge {

    /**
     * Проверяет пароль против phpass-хеша.
     */
    public static function verify(string $password, string $hash): bool {
        // WordPress phpass: $P$B... (34 символа) или $2y$... (bcrypt)
        if (str_starts_with($hash, '$P$') || str_starts_with($hash, '$H$')) {
            return self::checkPhpass($password, $hash);
        }

        // Уже bcrypt — обычная проверка
        return password_verify($password, $hash);
    }

    private static function checkPhpass(string $password, string $hash): bool {
        // Порт из phpass (WordPress)
        if (strlen($hash) < 34) {
            return false;
        }

        $countLog2 = strpos('./0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz', $hash[3]);
        if ($countLog2 < 7 || $countLog2 > 30) {
            return false;
        }

        $count = 1 << $countLog2;
        $salt = substr($hash, 4, 8);

        if (strlen($salt) !== 8) {
            return false;
        }

        $computed = self::cryptPrivate($password, $salt, $count);

        return hash_equals($computed, substr($hash, 0, 34));
    }

    private static function cryptPrivate(string $password, string $salt, int $count): string {
        $itoa64 = './0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz';
        $hash = md5($salt . $password, true);

        do {
            $hash = md5($hash . $password, true);
        } while (--$count);

        $output = substr($itoa64, (ord($hash[0]) & 0x3f), 1);
        $output .= substr($itoa64, ((ord($hash[0]) & 0x3f) + 1), 1); // упрощённо

        // Полная реализация — в phpass 0.5
        return self::encode64($hash);
    }

    private static function encode64(string $input): string {
        $itoa64 = './0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz';
        $output = '';
        $count = strlen($input);
        $i = 0;

        do {
            $value = ord($input[$i++]);
            $output .= $itoa64[$value & 0x3f];

            if ($i < $count) {
                $value |= ord($input[$i]) << 8;
            }
            $output .= $itoa64[($value >> 6) & 0x3f];

            if ($i++ >= $count) break;

            if ($i < $count) {
                $value |= ord($input[$i]) << 16;
            }
            $output .= $itoa64[($value >> 12) & 0x3f];

            if ($i++ >= $count) break;

            $output .= $itoa64[($value >> 18) & 0x3f];
        } while ($i < $count);

        return $output;
    }
}
```

> 💡 **Проще.** Установите `composer require hautelook/phpass` и используйте её. Пример — в `/system/libs/` (см. раздел 3).

**Интеграция в аутентификацию:**

```php
// /system/controllers/auth/model.php
public function authenticate(string $email, string $password): ?array {
    $user = $this->getUserByEmail($email);
    if (!$user) {
        return null;
    }

    // 1. Обычная проверка (bcrypt/argon2)
    if (password_verify($password, $user['password'])) {
        return $user;
    }

    // 2. Bridge: phpass (WordPress) — первый вход
    if (str_starts_with($user['password'], '$P$') || str_starts_with($user['password'], '$H$')) {

            $newHash = password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]);

                'migrated_from' => 'wordpress',
                'migrated_at' => date('Y-m-d H:i:s'),
            ]);

            return $user;
        }
    }

    return null;
```

```php
class Users extends Migrator {

             FROM wp_users
             ORDER BY ID",

                    return;

                        (email, nickname, password, date_reg, is_admin, migrated_from)
                    VALUES
```

### 58.18.1. Подход

1. Файлы из `wp-content/uploads/YYYY/MM/` → `/upload/images/original/YYYY/MM/`.
2. WordPress хранит **размеры** (`-150x150`, `-300x200` и т.д.) — их **не переносим**, регенерируем через пресеты (см. раздел 53.32).
3. Запись в `cms_attachments` с `entity_type = 'content_attachment'`.

### 58.18.2. Скрипт

**Файл:** `/migration/migrations/wordpress/04_media.php`

```php
class Media extends Migrator {

    private const WP_UPLOADS = '/var/www/source/wp-content/uploads';
    private const DST_UPLOADS = '/var/www/dst/upload/images/original';

    public function run(): void {
        $this->batch(
            "SELECT ID, post_title, guid, post_mime_type, post_parent, post_date
             FROM wp_posts
             WHERE post_type = 'attachment'
               AND post_mime_type LIKE 'image/%'
             ORDER BY ID",
            100,
            function (array $row) {
                $this->migrateOne($row);
            }
        );
    }

    private function migrateOne(array $row): void {
        if ($this->isMigrated('wp_posts', (int)$row['ID'])) {
            $this->stats['skipped']++;
            return;
        }

        // 1. Путь к файлу
        $guid = $row['guid'];
        $relativePath = preg_replace('#^https?://[^/]+/wp-content/uploads/#', '', $guid);
        $sourcePath = self::WP_UPLOADS . '/' . $relativePath;

        if (!file_exists($sourcePath)) {
            $this->log("File not found: $sourcePath", ['id' => $row['ID']]);
            $this->stats['errors']++;
            return;
        }

        // 2. Путь в DST
        $year = date('Y', strtotime($row['post_date']));
        $month = date('m', strtotime($row['post_date']));
        $filename = uniqid('wp_') . '.' . pathinfo($sourcePath, PATHINFO_EXTENSION);
        $targetRelative = "images/original/{$year}/{$month}/{$filename}";
        $targetPath = '/var/www/dst/upload/' . $targetRelative;

        // 3. Копирование
        @mkdir(dirname($targetPath), 0775, true);
        copy($sourcePath, $targetPath);
        chmod($targetPath, 0644);

        // 4. Метаданные
        [$width, $height] = getimagesize($targetPath);

        // 5. cms_attachments
        $stmt = $this->target->prepare("
            INSERT INTO cms_attachments 
                (entity_type, entity_id, filename, original_name, mime_type, size,
                 width, height, path, created_at)
            VALUES 
                ('content_attachment', 0, :filename, :original, :mime, :size,
                 :width, :height, :path, :created_at)
        ");
        $stmt->execute([
            ':filename' => $filename,
            ':original' => basename($sourcePath),
            ':mime' => $row['post_mime_type'],
            ':size' => filesize($targetPath),
            ':width' => $width,
            ':height' => $height,
            ':path' => $targetRelative,
            ':created_at' => $row['post_date'],
        ]);

        $attachmentId = (int)$this->target->lastInsertId();
        $this->mapId('wp_posts', (int)$row['ID'], $attachmentId);

        // 6. Связь с родительским контентом
        if ($row['post_parent'] > 0) {
            $stmt = $this->target->prepare(
                "SELECT target_id FROM migration_map 
                 WHERE source_table = 'wp_posts' AND source_id = ?"
            );
            $stmt->execute([(int)$row['post_parent']]);
            $contentId = $stmt->fetchColumn();

            if ($contentId) {
                $this->target->prepare(
                    "UPDATE cms_attachments SET entity_id = ? WHERE id = ?"
                )->execute([(int)$contentId, $attachmentId]);
            }
        }

        // 7. Запуск генерации пресетов (через очередь, см. 53.42)
        $this->target->prepare(
            "INSERT INTO cms_media_queue (attachment_id, preset_name, status, created_at)
             SELECT ?, name, 'pending', NOW() FROM cms_images_presets"
        )->execute([$attachmentId]);
    }
}

return Media::class;
```

```php
class SetupCtypes extends Migrator {

    public function run(): void {
        $iblocks = $this->source->query("
            SELECT ib.ID, ib.NAME, ib.CODE, ib.IBLOCK_TYPE_ID
            FROM b_iblock ib
            WHERE ib.ACTIVE = 'Y'
        ")->fetchAll();

        foreach ($iblocks as $iblock) {
            // Определяем тип в DST
            $ctypeName = match (true) {
                $iblock['IBLOCK_TYPE_ID'] === 'catalog' => 'products',
                $iblock['CODE'] === 'news' => 'news',
                $iblock['CODE'] === 'articles' => 'articles',
                default => $this->slugify($iblock['CODE']),
            };

            // Создать ctype (если нет)
            $existing = $this->target->prepare(
                "SELECT id FROM cms_content_types WHERE name = ?"
            );
            $existing->execute([$ctypeName]);

            if (!$existing->fetchColumn()) {
                $this->target->prepare("
                    INSERT INTO cms_content_types (name, title, description, is_published)
                    VALUES (?, ?, ?, 1)
                ")->execute([
                    $ctypeName,
                    $iblock['NAME'],
                    "Migrated from Bitrix iblock #{$iblock['ID']}",
                ]);
            }

            $ctypeId = (int)$this->target->query(
                "SELECT id FROM cms_content_types WHERE name = '$ctypeName'"
            )->fetchColumn();

            // Мигрировать свойства → cms_content_fields
            $this->migrateProperties((int)$iblock['ID'], $ctypeId);

            // Маппинг iblock → ctype
            $this->mapId('b_iblock', (int)$iblock['ID'], $ctypeId);
        }
    }

    private function migrateProperties(int $iblockId, int $ctypeId): void {
        $props = $this->source->query("
            SELECT ID, NAME, CODE, PROPERTY_TYPE, MULTIPLE
            FROM b_iblock_property
            WHERE IBLOCK_ID = $iblockId
        ")->fetchAll();

        foreach ($props as $prop) {
            $fieldType = match ($prop['PROPERTY_TYPE']) {
                'S' => 'text',
                'N' => 'number',
                'L' => 'select',
                'F' => 'image',
                'E' => 'select',  // Привязка к элементу
                'G' => 'select',  // Привязка к разделу
                default => 'text',
            };

            $this->target->prepare("
                INSERT INTO cms_content_fields 
                    (ctype_id, name, title, type, is_required)
                VALUES (?, ?, ?, ?, 0)
                ON DUPLICATE KEY UPDATE title = VALUES(title)
            ")->execute([
                $ctypeId,
                $prop['CODE'] ?: 'prop_' . $prop['ID'],
                $prop['NAME'],
                $fieldType,
            ]);
        }
    }

    private function slugify(string $str): string {
        $str = mb_strtolower($str);
        $str = preg_replace('/[^a-z0-9_]+/', '_', $str);
        return trim($str, '_');
    }
}
```

### 58.24.2. Миграция элементов

**Файл:** `/migration/migrations/bitrix/02_elements.php`

```php
class Elements extends Migrator {

    public function run(): void {
        // Обрабатываем по инфоблокам
        $iblocks = $this->source->query("SELECT ID FROM b_iblock WHERE ACTIVE = 'Y'")->fetchAll();

        foreach ($iblocks as $iblock) {
            $this->log("Processing iblock #{$iblock['ID']}");

            $this->batch(
                "SELECT ID, NAME, CODE, PREVIEW_TEXT, DETAIL_TEXT, 
                        ACTIVE, DATE_CREATE, TIMESTAMP_X, CREATED_BY, SORT
                 FROM b_iblock_element
                 WHERE IBLOCK_ID = {$iblock['ID']}
                   AND ACTIVE = 'Y'
                 ORDER BY ID",
                500,
                fn($row) => $this->migrateElement($row, (int)$iblock['ID'])
            );
        }
    }

    private function migrateElement(array $row, int $iblockId): void {
        if ($this->isMigrated('b_iblock_element', (int)$row['ID'])) {
            $this->stats['skipped']++;
            return;
        }

        // Найти ctype в DST
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'b_iblock' AND source_id = ?"
        );
        $stmt->execute([$iblockId]);
        $ctypeId = (int)$stmt->fetchColumn();

        // Данные
        $data = [
            'ctype_id' => $ctypeId,
            'title' => html_entity_decode($row['NAME'], ENT_QUOTES, 'UTF-8'),
            'slug' => $row['CODE'] ?: 'element-' . $row['ID'],
            'content' => $row['DETAIL_TEXT'] ?: $row['PREVIEW_TEXT'],
            'excerpt' => $row['PREVIEW_TEXT'],
            'is_published' => $row['ACTIVE'] === 'Y' ? 1 : 0,
            'date_pub' => $row['DATE_CREATE'],
            'date_mod' => $row['TIMESTAMP_X'],
            'user_id' => $this->mapUserId((int)$row['CREATED_BY']),
        ];

        $this->target->prepare("
            INSERT INTO cms_content 
                (ctype_id, title, slug, content, excerpt, is_published, date_pub, date_mod, user_id)
            VALUES 
                (:ctype_id, :title, :slug, :content, :excerpt, :is_published, :date_pub, :date_mod, :user_id)
        ")->execute($data);

        $targetId = (int)$this->target->lastInsertId();
        $this->mapId('b_iblock_element', (int)$row['ID'], $targetId);

        // Свойства
        $this->migrateProperties((int)$row['ID'], $targetId, $ctypeId);

        // Разделы
        $this->migrateSections((int)$row['ID'], $targetId, $iblockId);

        // Файлы (DETAIL_PICTURE, PREVIEW_PICTURE)
        $this->migrateFiles((int)$row['ID'], $targetId);

        // SEO
        $this->migrateSeo((int)$row['ID'], $targetId);

        // Редирект
        $this->addRedirect($row, $iblockId);
    }

    private function migrateProperties(int $elementId, int $targetId, int $ctypeId): void {
        $props = $this->source->query("
            SELECT p.CODE, p.NAME, ep.VALUE, p.PROPERTY_TYPE
            FROM b_iblock_element_property ep
            JOIN b_iblock_property p ON p.ID = ep.IBLOCK_PROPERTY_ID
            WHERE ep.IBLOCK_ELEMENT_ID = $elementId
        ")->fetchAll();

        $propsData = [];
        foreach ($props as $prop) {
            $propsData[$prop['CODE']] = $prop['VALUE'];
        }

        if (empty($propsData)) {
            return;
        }

        $this->target->prepare("
            UPDATE cms_content SET props = ? WHERE id = ?
        ")->execute([
            json_encode($propsData, JSON_UNESCAPED_UNICODE),
            $targetId,
        ]);
    }

    private function migrateSections(int $elementId, int $targetId, int $iblockId): void {
        $sections = $this->source->query("
            SELECT s.ID, s.NAME, s.CODE
            FROM b_iblock_section_element se
            JOIN b_iblock_section s ON s.ID = se.IBLOCK_SECTION_ID
            WHERE se.IBLOCK_ELEMENT_ID = $elementId
              AND s.IBLOCK_ID = $iblockId
        ")->fetchAll();

        foreach ($sections as $section) {
            $categoryId = $this->ensureCategory($section);
            $this->target->prepare("
                INSERT IGNORE INTO cms_content_categories_items (content_id, category_id)
                VALUES (?, ?)
            ")->execute([$targetId, $categoryId]);
        }
    }

    private function ensureCategory(array $section): int {
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'b_iblock_section' AND source_id = ?"
        );
        $stmt->execute([(int)$section['ID']]);
        $targetId = $stmt->fetchColumn();

        if ($targetId) {
            return (int)$targetId;
        }

        $this->target->prepare("
            INSERT INTO cms_content_categories (title, slug) VALUES (?, ?)
        ")->execute([$section['NAME'], $section['CODE'] ?: 'section-' . $section['ID']]);

        $id = (int)$this->target->lastInsertId();
        $this->mapId('b_iblock_section', (int)$section['ID'], $id);

        return $id;
    }

    private function migrateFiles(int $elementId, int $targetId): void {
        $files = $this->source->query("
            SELECT 
                e.DETAIL_PICTURE,
                e.PREVIEW_PICTURE,
                f.FILE_NAME, f.SUBDIR, f.FILE_SIZE, f.CONTENT_TYPE
            FROM b_iblock_element e
            LEFT JOIN b_file f ON f.ID IN (e.DETAIL_PICTURE, e.PREVIEW_PICTURE)
            WHERE e.ID = $elementId
        ")->fetchAll();

        foreach ($files as $file) {
            if (empty($file['FILE_NAME'])) continue;

            $sourcePath = "/var/www/source/upload/{$file['SUBDIR']}/{$file['FILE_NAME']}";
            if (!file_exists($sourcePath)) continue;

            // Копирование
            $year = date('Y');
            $month = date('m');
            $newName = uniqid('bx_') . '.' . pathinfo($file['FILE_NAME'], PATHINFO_EXTENSION);
            $targetRelative = "images/original/{$year}/{$month}/{$newName}";
            $targetPath = '/var/www/dst/upload/' . $targetRelative;

            @mkdir(dirname($targetPath), 0775, true);
            copy($sourcePath, $targetPath);

            // cms_attachments
            [$width, $height] = getimagesize($targetPath) ?: [0, 0];

            $this->target->prepare("
                INSERT INTO cms_attachments 
                    (entity_type, entity_id, filename, original_name, mime_type, size,
                     width, height, path, is_primary, created_at)
                VALUES 
                    ('content_attachment', ?, ?, ?, ?, ?, ?, ?, ?, 1, NOW())
            ")->execute([
                $targetId,
                $newName,
                $file['FILE_NAME'],
                $file['CONTENT_TYPE'],
                $file['FILE_SIZE'],
                $width,
                $height,
                $targetRelative,
            ]);
        }
    }

    private function migrateSeo(int $elementId, int $targetId): void {
        $stmt = $this->source->query("
            SELECT TITLE, DESCRIPTION, KEYWORDS
            FROM b_seo_search_engine
            WHERE ELEMENT_ID = $elementId
        ");
        $seo = $stmt->fetch();

        if ($seo) {
            $this->target->prepare("
                UPDATE cms_content 
                SET seo_title = ?, seo_description = ?, seo_keys = ?
                WHERE id = ?
            ")->execute([
                $seo['TITLE'] ?? '',
                $seo['DESCRIPTION'] ?? '',
                $seo['KEYWORDS'] ?? '',
                $targetId,
            ]);
        }
    }

    private function addRedirect(array $row, int $iblockId): void {
        // Bitrix URL: /catalog/{SECTION_CODE}/{ELEMENT_CODE}/
        // Или /news/{ELEMENT_CODE}/

        $iblockCode = $this->source->query(
            "SELECT CODE FROM b_iblock WHERE ID = $iblockId"
        )->fetchColumn();

        $oldUrl = "/{$iblockCode}/{$row['CODE']}/";
        $newUrl = "/{$row['CODE']}";  // Упрощённо — зависит от структуры

        $this->target->prepare("
            INSERT INTO cms_redirects (from_url, to_url, code, created_at)
            VALUES (?, ?, 301, NOW())
            ON DUPLICATE KEY UPDATE to_url = VALUES(to_url)
        ")->execute([$oldUrl, $newUrl]);
    }

    private function mapUserId(int $bxUserId): int {
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'b_user' AND source_id = ?"
        );
        $stmt->execute([$bxUserId]);
        return (int)($stmt->fetchColumn() ?: 1);
    }
}

return Elements::class;
```

## 58.25. Миграция пользователей

### 58.25.1. Ключевая проблема

Bitrix использует **`CMain::GetUserHash`** — кастомную схему: `md5(salt . password)` с солью в `b_user.PASSWORD`.

**Формат:** `PASSWORD` = `md5(salt . password)`, `SALT` хранится отдельно.

**Bridge:**

```php
class BitrixPasswordBridge {

    public static function verify(string $password, string $hash, string $salt): bool {
        // Bitrix: md5($salt . $password)
        return hash_equals(md5($salt . $password), $hash);
    }

    public static function isBitrixHash(string $hash, string $salt): bool {
        return strlen($hash) === 32 && strlen($salt) === 8;
    }
}
```

**Интеграция в `authenticate()`:**

```php
// Bridge: Bitrix
if (BitrixPasswordBridge::isBitrixHash($user['password'], $user['salt'] ?? '')) {
```

```php
    public function run(): void {
```

```php
            "SELECT ID, ACCOUNT_NUMBER, USER_ID, STATUS_ID, PRICE, CURRENCY,

                $productId,

                $item['QUANTITY'],
```

## 58.27. Миграция 1С-интеграции

### 58.27.1. Что мигрируется

| Компонент 1С-интеграции | Куда в DST |
|---|---|
| Каталог (CommerceML) | `cms_shop_products` |
| Цены и остатки | `cms_shop_products.price`, `.quantity` |
| Склады | `cms_shop_warehouses` (если используется) |
| Заказы (выгрузка в 1С) | `cms_shop_orders` (экспорт) |
| Контрагенты | `cms_users` + `cms_partner_profiles` |
| Договоры | `cms_shop_contracts` (если используется) |

### 58.27.2. Схема миграции

```
1С ──(CommerceML)──▶ Bitrix ──(миграция)──▶ DST Platform
                                                │
                                                └──▶ 1С (обратно)
```

**Проблема:** 1С настроен на старую систему. Нужно перенастроить выгрузку на DST.

**Подход:**

1. Настроить DST как приёмник CommerceML (`/api/1c/`).
2. Переключить 1С на новый endpoint.
3. Прогнать тестовую выгрузку на staging.
4. Проверить: товары, цены, остатки.
5. Переключить prod.

> ℹ️ Подробности — в разделе *«Внешняя интеграция»* (23). Кастомизированные конфигурации 1С — после анализа структуры учёта заказчика (см. раздел 58.9).

```php
class Products extends Migrator {

    public function run(): void {
        $this->batch(
            "SELECT 
                p.product_id, p.product_code, p.status, p.amount,
                p.list_price, p.company_id, p.timestamp, p.weight, p.shipping_freight,
                d.product AS title, d.description, d.short_description,
                d.meta_keywords, d.meta_description, d.page_title
             FROM cscart_products p
             JOIN cscart_product_descriptions d 
                ON d.product_id = p.product_id AND d.lang_code = 'ru'
             ORDER BY p.product_id",
            100,
            fn($row) => $this->migrateProduct($row)
        );
    }

    private function migrateProduct(array $row): void {
        if ($this->isMigrated('cscart_products', (int)$row['product_id'])) return;

        // Slug из cscart_seo_names
        $slug = $this->getSlug((int)$row['product_id'], 'p');

        // Vendor (partner)
        $vendorId = $this->mapCompany((int)$row['company_id']);

        // Категория (первая)
        $categoryId = $this->getPrimaryCategory((int)$row['product_id']);

        $this->target->prepare("
            INSERT INTO cms_shop_products 
                (title, slug, content, excerpt, sku, price, quantity, 
                 vendor_id, category_id, is_published, created_at, updated_at)
            VALUES 
                (:title, :slug, :content, :excerpt, :sku, :price, :quantity,
                 :vendor_id, :category_id, :is_published, :created_at, :updated_at)
        ")->execute([
            ':title' => $row['title'],
            ':slug' => $slug ?: 'product-' . $row['product_id'],
            ':content' => $row['description'],
            ':excerpt' => $row['short_description'],
            ':sku' => $row['product_code'],
            ':price' => $row['list_price'] ?: 0,
            ':quantity' => (int)$row['amount'],
            ':vendor_id' => $vendorId,
            ':category_id' => $categoryId,
            ':is_published' => $row['status'] === 'A' ? 1 : 0,
            ':created_at' => date('Y-m-d H:i:s', (int)$row['timestamp']),
            ':updated_at' => date('Y-m-d H:i:s', (int)$row['timestamp']),
        ]);

        $productId = (int)$this->target->lastInsertId();
        $this->mapId('cscart_products', (int)$row['product_id'], $productId);

        // SEO
        $this->target->prepare("
            UPDATE cms_shop_products 
            SET seo_title = ?, seo_description = ?, seo_keys = ?
            WHERE id = ?
        ")->execute([
            $row['page_title'] ?: $row['title'],
            $row['meta_description'],
            $row['meta_keywords'],
            $productId,
        ]);

        // Характеристики
        $this->migrateFeatures((int)$row['product_id'], $productId);

        // Вариации
        $this->migrateVariants((int)$row['product_id'], $productId);

        // Изображения (см. 58.35)
        // Редирект
        $this->addRedirect((int)$row['product_id'], $slug);
    }

    private function getSlug(int $productId, string $type): ?string {
        $stmt = $this->source->prepare("
            SELECT name FROM cscart_seo_names 
            WHERE object_id = ? AND type = ? AND lang_code = 'ru'
        ");
        $stmt->execute([$productId, $type]);
        return $stmt->fetchColumn() ?: null;
    }

    private function mapCompany(int $companyId): int {
        if ($companyId === 1) return 0;  // Админ-магазин — без vendor

        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'cscart_companies' AND source_id = ?"
        );
        $stmt->execute([$companyId]);
        return (int)($stmt->fetchColumn() ?: 0);
    }

    private function getPrimaryCategory(int $productId): int {
        $stmt = $this->source->prepare("
            SELECT category_id FROM cscart_products_categories 
            WHERE product_id = ? LIMIT 1
        ");
        $stmt->execute([$productId]);
        $bxCatId = (int)$stmt->fetchColumn();

        if (!$bxCatId) return 0;

        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'cscart_categories' AND source_id = ?"
        );
        $stmt->execute([$bxCatId]);
        return (int)($stmt->fetchColumn() ?: 0);
    }

    private function migrateFeatures(int $productId, int $dstProductId): void {
        $features = $this->source->query("
            SELECT f.feature_id, f.description, fv.value
            FROM cscart_product_features_values fv
            JOIN cscart_product_features_descriptions f 
                ON f.feature_id = fv.feature_id AND f.lang_code = 'ru'
            WHERE fv.product_id = $productId
        ")->fetchAll();

        if (empty($features)) return;

        $props = [];
        foreach ($features as $f) {
            $props[$f['description']] = $f['value'];
        }

        $this->target->prepare("
            UPDATE cms_shop_products SET props = ? WHERE id = ?
        ")->execute([json_encode($props, JSON_UNESCAPED_UNICODE), $dstProductId]);
    }

    private function migrateVariants(int $productId, int $dstProductId): void {
        // Опции товара (например, цвет, размер)
        $variants = $this->source->query("
            SELECT 
                v.variant_id, v.product_id, v.combination_hash, 
                v.amount, v.weight, v.position
            FROM cscart_product_options_combinations v
            WHERE v.product_id = $productId

        foreach ($variants as $variant) {

            $priceStmt = $this->source->prepare("
                SELECT price FROM cscart_product_prices 
                WHERE product_id = ? AND lower_limit = 1

            $price = (float)$priceStmt->fetchColumn();

            $this->target->prepare("
                INSERT INTO cms_shop_product_variants 
                    (product_id, combination, quantity, price, sku, created_at)
                VALUES (?, ?, ?, ?, ?, NOW())
            ")->execute([
                $dstProductId,
                $variant['combination_hash'],
                (int)$variant['amount'],
                $price,
                $variant['product_id'],
            ]);
        }

        $oldUrl = "/{$slug}.html";  // CS-Cart default

            ON DUPLICATE KEY UPDATE to_url = VALUES(to_url)
```

### 58.32.2. Категории

```php
class Categories extends Migrator {

    public function run(): void {
        // Сначала — дерево категорий (nested sets)
        $categories = $this->source->query("
            SELECT c.category_id, c.parent_id, c.id_path, c.status,
                   d.category AS title, d.description,
                   d.meta_keywords, d.meta_description
            FROM cscart_categories c
            JOIN cscart_category_descriptions d 
                ON d.category_id = c.category_id AND d.lang_code = 'ru'
            ORDER BY c.id_path
        ")->fetchAll();

        // Строим дерево
        $tree = $this->buildTree($categories);

        // Мигрируем рекурсивно
        foreach ($tree as $root) {
            $this->migrateCategory($root, 0);
        }
    }

    private function migrateCategory(array $cat, int $parentId): void {
        $slug = $this->getSlug((int)$cat['category_id'], 'c');

        $this->target->prepare("
            INSERT INTO cms_shop_categories 
                (title, slug, description, parent_id, is_published, created_at)
            VALUES (?, ?, ?, ?, ?, NOW())
        ")->execute([
            $cat['title'],
            $slug ?: 'category-' . $cat['category_id'],
            $cat['description'],
            $parentId,
            $cat['status'] === 'A' ? 1 : 0,
        ]);

        $targetId = (int)$this->target->lastInsertId();
        $this->mapId('cscart_categories', (int)$cat['category_id'], $targetId);

        // Дети
        foreach ($cat['children'] ?? [] as $child) {
            $this->migrateCategory($child, $targetId);
        }

        // Редирект
        if ($slug) {
            $this->target->prepare("
                INSERT INTO cms_redirects (from_url, to_url, code, created_at)
                VALUES (?, ?, 301, NOW())
                ON DUPLICATE KEY UPDATE to_url = VALUES(to_url)
            ")->execute(["/{$slug}/", "/shop/category/{$slug}"]);
        }
    }

    private function buildTree(array $categories): array {
        $byId = [];
        foreach ($categories as $cat) {
            $cat['children'] = [];
            $byId[$cat['category_id']] = $cat;
        }

        $roots = [];
        foreach ($byId as $id => &$cat) {
            if ($cat['parent_id'] && isset($byId[$cat['parent_id']])) {
                $byId[$cat['parent_id']]['children'][] = &$cat;
            } else {
                $roots[] = &$cat;
            }
        }

        return $roots;
    }
}
```

## 58.34. Миграция заказов

```php
class Orders extends Migrator {

    private const STATUS_MAP = [
        'O' => 'new',       // Open
        'P' => 'paid',      // Paid
        'C' => 'completed', // Complete
        'F' => 'canceled',  // Failed
        'D' => 'declined',  // Declined
        'B' => 'backordered',
    ];

    public function run(): void {
        $this->batch(
            "SELECT order_id, user_id, company_id, status, total, 
                    timestamp, payment_id, shipping_id
             FROM cscart_orders
             ORDER BY order_id",
            100,
            fn($row) => $this->migrateOne($row)
        );
    }

    private function migrateOne(array $row): void {
        if ($this->isMigrated('cscart_orders', (int)$row['order_id'])) return;

        $status = self::STATUS_MAP[$row['status']] ?? 'unknown';

        $this->target->prepare("
            INSERT INTO cms_shop_orders 
                (number, user_id, vendor_id, status, total, created_at, updated_at)
            VALUES (?, ?, ?, ?, ?, ?, ?)
        ")->execute([
            'CS-' . $row['order_id'],
            $this->mapUserId((int)$row['user_id']),
            $this->mapCompany((int)$row['company_id']),
            $status,
            $row['total'],
            date('Y-m-d H:i:s', (int)$row['timestamp']),
            date('Y-m-d H:i:s', (int)$row['timestamp']),
        ]);

        $orderId = (int)$this->target->lastInsertId();
        $this->mapId('cscart_orders', (int)$row['order_id'], $orderId);

        $this->migrateItems((int)$row['order_id'], $orderId);
    }

    private function migrateItems(int $csOrderId, int $orderId): void {
        $items = $this->source->query("
            SELECT od.product_id, od.product_code, od.price, od.amount, 
                   od.extra, od.product_options
            FROM cscart_order_details od
            WHERE od.order_id = $csOrderId
        ")->fetchAll();

        foreach ($items as $item) {
            $productId = 0;
            if ($item['product_id']) {
                $stmt = $this->target->prepare(
                    "SELECT target_id FROM migration_map 
                     WHERE source_table = 'cscart_products' AND source_id = ?"
                );
                $stmt->execute([(int)$item['product_id']]);
                $productId = (int)$stmt->fetchColumn();
            }

            $this->target->prepare("
                INSERT INTO cms_shop_order_items 
                    (order_id, product_id, title, price, quantity, total, options)
                VALUES (?, ?, ?, ?, ?, ?, ?)
            ")->execute([
                $orderId,
                $productId,
                $item['product_code'] ?: 'Product',
                $item['price'],
                $item['amount'],
                $item['price'] * $item['amount'],
                $item['product_options'],
            ]);
        }
    }

    private function mapUserId(int $csUserId): int {
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'cscart_users' AND source_id = ?"
        );
        $stmt->execute([$csUserId]);
        return (int)($stmt->fetchColumn() ?: 0);
    }

    private function mapCompany(int $companyId): int {
        if ($companyId === 1) return 0;

        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'cscart_companies' AND source_id = ?"
        );
        $stmt->execute([$companyId]);
        return (int)($stmt->fetchColumn() ?: 0);
    }
}
```

## 58.35. Миграция изображений

```php
class Images extends Migrator {

    public function run(): void {
        $this->batch(
            "SELECT 
                i.image_id, i.image_path, i.image_x, i.image_y,
                il.object_id, il.object_type
             FROM cscart_images i
             JOIN cscart_images_links il ON il.image_id = i.image_id
             WHERE il.object_type = 'product'
             ORDER BY i.image_id",
            100,
            fn($row) => $this->migrateOne($row)
        );
    }

    private function migrateOne(array $row): void {
        $sourcePath = '/var/www/source/images/' . $row['image_path'];
        if (!file_exists($sourcePath)) {
            $this->stats['errors']++;
            return;
        }

        // Найти продукт в DST
        $stmt = $this->target->prepare(
            "SELECT target_id FROM migration_map 
             WHERE source_table = 'cscart_products' AND source_id = ?"
        );
        $stmt->execute([(int)$row['object_id']]);
        $productId = $stmt->fetchColumn();
        if (!$productId) return;

        // Копирование
        $year = date('Y');
        $month = date('m');
        $newName = uniqid('cs_') . '.' . pathinfo($sourcePath, PATHINFO_EXTENSION);
        $targetRelative = "images/original/{$year}/{$month}/{$newName}";
        $targetPath = '/var/www/dst/upload/' . $targetRelative;

        @mkdir(dirname($targetPath), 0775, true);
        copy($sourcePath, $targetPath);

        [$width, $height] = getimagesize($targetPath) ?: [0, 0];

        $this->target->prepare("
            INSERT INTO cms_attachments 
                (entity_type, entity_id, filename, original_name, mime_type, size,
                 width, height, path, is_primary, created_at)
            VALUES 
                ('shop_product', ?, ?, ?, ?, ?, ?, ?, ?, ?, NOW())
        ")->execute([
            (int)$productId,
            $newName,
            basename($row['image_path']),
            mime_content_type($targetPath),
            filesize($targetPath),
            $width,
            $height,
            $targetRelative,
            (int)$row['image_id'] === $this->getPrimaryImageId((int)$row['object_id']) ? 1 : 0,
        ]);

        // Очередь пресетов
        $attachmentId = (int)$this->target->lastInsertId();
        $this->target->prepare("
            INSERT INTO cms_media_queue (attachment_id, preset_name, status, created_at)
            SELECT ?, name, 'pending', NOW() FROM cms_images_presets
        ")->execute([$attachmentId]);
    }

    private function getPrimaryImageId(int $productId): int {
        $stmt = $this->source->prepare("
            SELECT main_pair FROM cscart_products WHERE product_id = ?
        ");
        $stmt->execute([$productId]);
        $pair = unserialize($stmt->fetchColumn() ?: '');

        return $pair['image_id'] ?? 0;
    }
}
```

## 58.39. Пароли — стратегии переноса

### 58.39.1. Сравнение хешей

| Платформа | Формат | Bridge |
|---|---|---|
| **WordPress** | phpass (`$P$...`) | `WordPressPasswordBridge` |
| **Bitrix** | `md5(salt . password)` + соль в `SALT` | `BitrixPasswordBridge` |
| **CS-Cart** | `md5(salt . password)` + соль в `salt` | `CSCartPasswordBridge` |
| **DST Platform** | bcrypt / argon2 | — |

### 58.39.2. Общий паттерн

```php
public function authenticate(string $email, string $password): ?array {
    $user = $this->getUserByEmail($email);
    if (!$user) return null;

    // 1. Обычная проверка (bcrypt/argon2)
    if (password_verify($password, $user['password'])) {
        return $user;
    }

    // 2. Bridge: старый хеш
    $bridges = [
        'wordpress' => fn() => WordPressPasswordBridge::verify($password, $user['password']),
        'bitrix' => fn() => BitrixPasswordBridge::verify($password, $user['password'], $user['salt']),
        'cscart' => fn() => CSCartPasswordBridge::verify($password, $user['password'], $user['salt']),
    ];

    foreach ($bridges as $platform => $verifier) {
        if (($user['migrated_from'] ?? '') === $platform && $verifier()) {
            // Пересохранить как bcrypt
            $this->update('cms_users', $user['id'], [
                'password' => password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]),
                'salt' => null,
                'migrated_from' => null,  // Уже мигрирован
                'migrated_at' => date('Y-m-d H:i:s'),
            ]);
            return $user;
        }
    }

    return null;
}
```

## 58.48. Заключение

Миграция на DST Platform — это **проект**, а не «перенос данных». Три принципа:

1. **Аудит → План → Перенос → Тест → Запуск.** Каждый этап завершается проверяемым результатом.
2. **Сохранить всё:** данные, SEO, пользователей, интеграции. Ничего не теряется.
3. **Возможность отката** на каждом этапе. Blue-green, snapshot, DNS revert.

**Ключевые технические решения:**

| Платформа | Пароли | Каталог | Заказы | SEO |
|---|---|---|---|---|
| **WordPress** | phpass bridge | — | — | Yoast / RankMath |
| **Bitrix** | `md5(salt)` bridge | Инфоблоки | `b_sale_order` | `b_seo_search_engine` |
| **CS-Cart** | `md5(salt)` bridge | Products + options | `cscart_orders` | `cscart_seo_names` |

**Что даёт правильная миграция:**

- Сохранение SEO-позиций (301, meta, sitemap).
- Сохранение клиентской базы (пользователи, история).
- Сохранение интеграций (1С, CRM, платежи, доставка).
- Минимальный downtime (blue-green, phased).
- Возможность отката (snapshot, DNS revert).
