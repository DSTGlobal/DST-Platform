# 27. Почтовые сервисы

Данный документ содержит исчерпывающую техническую спецификацию подсистемы почтовых сервисов на платформе DST Platform. Система использует библиотеку **PHPMailer** для надёжной отправки электронной почты через внешние SMTP-серверы, в первую очередь — Яндекс. Основное применение — обработка форм обратной связи и отправка транзакционных писем в рамках экосистемы электронной коммерции.

> **Важно**: Данный документ описывает автономный обработчик контактных форм (`contact_process.php`). Для получения информации о системной интеграции почтовых сервисов через `cmsMailer` см. раздел *«Взаимодействие HTTP-клиента и API»*. Для бизнес-логики контактной формы см. раздел *«Система контактных форм»*.

## 27.1. Обзор системы

Подсистема почтовых сервисов реализована через два основных подхода:

| Подход | Реализация | Назначение | Статус |
|--------|------------|------------|--------|
| **Автономный обработчик** | `contact_process.php` | Простые формы обратной связи без интеграции с ядром | ✅ Реализован |
| **Системный сервис** | `cmsMailer` | Интеграция с ядром для транзакционных писем | ✅ Реализован |

### Ключевые характеристики автономного обработчика

| Характеристика | Реализация |
|----------------|------------|
| **Библиотека** | PHPMailer (через Composer) |
| **SMTP-сервер** | Яндекс (smtp.yandex.ru:587) |
| **Шифрование** | TLS |
| **Формат писем** | HTML с текстовой альтернативой |
| **Вложения** | Поддержка файлов до 64 МБ |
| **Санитизация** | `strip_tags()` + `htmlspecialchars()` |
| **Контекст выполнения** | Только CLI (защита от веб-вызова) |

### Архитектурные принципы

| Принцип | Реализация | Преимущество |
|---------|------------|--------------|
| **Автономность** | Не требует загрузки ядра (`cmsCore`, `cmsModel`) | Минимальные зависимости, быстрая загрузка |
| **Безопасность** | Санитизация всех входных данных, проверка расширений файлов | Защита от инъекций и выполнения кода |
| **Простота** | Единый файл обработчика | Лёгкое развёртывание на статических страницах |
| **Надёжность** | Обработка ошибок, логирование | Диагностика проблем при отправке |

## 27.2. Зависимости и установка

### Управление зависимостями через Composer

Библиотека **PHPMailer** управляется через Composer с ограничением по версии, что позволяет вносить незначительные обновления, сохраняя при этом совместимость с API.

| Пакет | Ограничение версии | Цель |
|-------|-------------------|------|
| `phpmailer/phpmailer` | ^6.0 | Основная библиотека отправки почты |

**Ограничение по версиям `^6.0`** допускает использование версий `>=6.0` и `<7.0`, обеспечивая совместимость с версией API PHPMailer v6, а также получение исправлений ошибок и незначительных обновлений функций.

### Установка через Composer

```bash
composer require phpmailer/phpmailer:^6.0
```

### Дерево зависимостей

```
phpmailer/phpmailer (6.8.0)
├── php: >=5.5.0
├── ext-ctype: *
├── ext-filter: *
└── psr/log: ^1.0|^2|^3 (опционально для логирования)
```

### Автозагрузка

Библиотека загружается через автозагрузчик Composer:

```php
require 'vendor/autoload.php';
```

Это автоматически регистрирует пространства имён:

| Пространство имён | Путь |
|------------------|------|
| `PHPMailer\PHPMailer\` | `vendor/phpmailer/phpmailer/src/` |

## 27.4. Автономный обработчик форм

### Инициализация и настройка PHPMailer

#### Загрузка библиотеки

Библиотека PHPMailer загружается через автозагрузчик Composer:

```php
require 'vendor/autoload.php';
```

#### Импорт пространств имён

Скрипт импортирует три класса PHPMailer:

```php
use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\SMTP;
use PHPMailer\PHPMailer\Exception;
```

#### Создание экземпляра объекта

PHPMailer инициализирован с включённой обработкой исключений:

```php
$mail = new PHPMailer(true);
```

Этот параметр `true` позволяет обрабатывать исключения, которые перехватываются в блоке `try-catch`.

### Настройка SMTP

#### Параметры подключения

Система подключается к Яндекс SMTP, используя следующую конфигурацию:

| Параметр | Значение | Описание |
|----------|----------|----------|
| **Протокол** | `isSMTP()` | Используйте протокол SMTP |
| **Хост** | `smtp.yandex.ru` | Почтовый сервер Яндекса |
| **Порт** | `587` | Порт отправки SMTP |
| **Безопасность** | `tls` | Шифрование TLS |
| **Аутентификация** | `true` | Требуется аутентификация SMTP |
| **Имя пользователя** | `info@my_site.com` | Адрес электронной почты отправителя |
| **Пароль** | `demo_password` | Учётные данные SMTP |
| **Набор символов** | `utf-8` | Поддержка кириллического текста |

#### Код конфигурации

```php
$mail->isSMTP();
$mail->Host = 'smtp.yandex.ru';
$mail->SMTPAuth = true;
$mail->Username = 'info@my_site.com';
$mail->Password = 'demo_password';
$mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS; // или 'tls'
$mail->Port = 57;
$mail->CharSet = 'UTF-8';
```

#### Отладка

Отладка SMTP доступна, но закомментирована по умолчанию:

```php
// $mail->SMTPDebug = SMTP::DEBUG_SERVER;
```

Раскомментируйте эту строку, чтобы включить подробное логирование транзакций SMTP.

### Константы конфигурации

Системные константы определены в начале файла `contact_process.php`:

| Константа | Значение | Цель |
|-----------|----------|------|
| `ALLOWED_EXTENSIONS` | Массив из 13 расширений | Белый список типов файлов |
| `MAX_FILE_SIZE` | 67108864 (64 МБ) | Ограничение на размер загружаемого файла |
| `IS_SENS_FILES_AS_ATTACHMENTS` | `true` | Включить функцию прикрепления файлов |
| `SEND_EMAIL` | `"info@my_site.ru"` | Адрес электронной почты получателя |

> **Примечание**: В производственных средах учётные данные следует хранить в переменных окружения или защищённых конфигурационных файлах, а не жёстко прописывать в исходных файлах.

### Реализация обработки формы

```php
// contact_process.php

// 1. Проверка метода запроса
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    http_response_code(405);
    exit('Method Not Allowed');
}

// 2. Валидация обязательных полей
$required_fields = ['name', 'email', 'sub', 'body'];
$errors = [];

foreach ($required_fields as $field) {
    if (empty($_POST[$field])) {
        $errors[] = "Поле {$field} обязательно для заполнения";
    }
}

if (!empty($errors)) {
    echo "<center><h1>Вы заполнили не все поля</h1></center>";
    echo '<div class="intro_buttons">';
    echo '    <div class="dstbut">';
    echo '        <a href="/" class="primary_btn"><span>На главную</span></a>';
    echo '    </div>';
    echo '</div>';
    exit;
}

// 3. Санитизация входных данных
$name = strip_tags(htmlspecialchars($_POST['name'], ENT_QUOTES, 'UTF-8'));
$email = filter_var($_POST['email'], FILTER_SANITIZE_EMAIL);
$sub = strip_tags(htmlspecialchars($_POST['sub'], ENT_QUOTES, 'UTF-8'));
$body = strip_tags(htmlspecialchars($_POST['body'], ENT_QUOTES, 'UTF-8'));

// 4. Проверка валидности email
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "<center><h1>Некорректный email</h1></center>";
    echo '<div class="intro_buttons">';
    echo '    <div class="dstbut">';
    echo '        <a href="/" class="primary_btn"><span>На главную</span></a>';
    echo '    </div>';
    echo '</div>';
    exit;
}

// 5. Формирование тела письма
$mes = "Имя: $name <br> E-mail: $email <br> Телефон: $sub ";

if (isset($body)) {
    $mes .= "<br> Сообщение: $body";
}

// 6. Инициализация и настройка PHPMailer
use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\SMTP;
use PHPMailer\PHPMailer\Exception;

require 'vendor/autoload.php';

$mail = new PHPMailer(true);

try {
    // Настройка сервера
    $mail->isSMTP();
    $mail->Host = 'smtp.yandex.ru';
    $mail->SMTPAuth = true;
    $mail->Username = 'info@my_site.com';
    $mail->Password = 'demo_password';
    $mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
    $mail->Port = 587;
    $mail->CharSet = 'UTF-8';
    
    // Настройка письма
    $mail->setFrom('info@my_site.com', 'DST Маркетплейс');
    $mail->addAddress('info@my_site.ru', 'Заявка на сайте');
    $mail->isHTML(true);
    $mail->Subject = 'Новая заявка на сайте';
    $mail->Body = $mes;
    
    // 7. Обработка вложений (если есть)
    $attachments = [];
    
    if (isset($_FILES['attachment']) && !empty($_FILES['attachment']['name'][0])) {
        const ALLOWED_EXTENSIONS = ['jpg', 'jpeg', 'pdf', 'xlsx', 'xls', 
                                     'png', 'pptx', 'ppt', 'txt', 'rtf', 
                                     'bmp', 'doc', 'docx'];
        const MAX_FILE_SIZE = 67108864; // 64 МБ
        
        $uploadPath = dirname(dirname(__FILE__)) . '/demo.dstglobal.ru/uploads_files/';
        
        // Создание каталога, если не существует
        if (!is_dir($uploadPath)) {
            mkdir($uploadPath, 0755, true);
        }
        
        $data = [
            'attachment' => [],
            'result' => 'success'
        ];
        
        foreach ($_FILES['attachment']['name'] as $key => $fileName) {
            $resultCheckExtension = true;
            $fileTmp = $_FILES['attachment']['tmp_name'][$key];
            $fileSize = $_FILES['attachment']['size'][$key];
            
            // Проверка расширения
            $fileExtension = mb_strtolower(pathinfo($fileName, PATHINFO_EXTENSION));
            if (!in_array($fileExtension, ALLOWED_EXTENSIONS)) {
                $resultCheckExtension = false;
                $data['attachment'][$key] = 'Файл имеет не разрешённый тип.';
                $data['result'] = 'error';
            }
            
            // Проверка размера
            if ($resultCheckExtension && ($fileSize > MAX_FILE_SIZE)) {
                $data['attachment'][$key] = 'Размер файла превышает допустимый.';
                $data['result'] = 'error';
            }
            
            // Генерация уникального имени и перемещение файла
            if ($resultCheckExtension && $data['result'] !== 'error') {
                $fileNewName = uniqid('upload_', true) . '.' . $fileExtension;
                if (!move_uploaded_file($fileTmp, $uploadPath . $fileNewName)) {
                    $data['attachment'][$key] = 'Ошибка при загрузке файла.';
                    $data['result'] = 'error';
                } else {
                    $attachments[] = $uploadPath . $fileNewName;
                }
            }
        }
        
        // Прикрепление файлов к письму
        if (!empty($attachments) && $data['result'] === 'success') {
            foreach ($attachments as $attachment) {
                $mail->addAttachment($attachment);
            }
        }
    }
    
    // 8. Отправка письма
    $send = $mail->send();
    
    // 9. Отображение результата
    if ($send) {
        echo "<center><h4>Спасибо, ваше сообщение отправлено<br>";
        echo "В ближайшее время мы обязательно свяжемся с Вами.</h4></center>";
    } else {
        echo "<center><h1>Ошибка - Сообщение не отправлено!</h1></center>";
    }
    
} catch (Exception $e) {
    echo "<center><h1>Ошибка отправки письма</h1></center>";
    error_log("PHPMailer Error: " . $mail->ErrorInfo);
}

// 10. Кнопка возврата
echo '<div class="intro_buttons">';
echo '    <div class="dstbut">';
echo '        <a href="/" class="primary_btn"><span>На главную</span></a>';
echo '    </div>';
echo '</div>';
```

## 27.7. Построение сообщений

### Санитизация входных данных

Все пользовательские данные проходят проверку на наличие ошибок с помощью функций фильтрации PHP:

```php
if (isset($_POST['name'])) {
    $name = strip_tags(filter_var($_POST['name'], FILTER_SANITIZE_STRING));
    if ($name == '') { unset($name); }
}
```

Узор повторяется в `contact_process.php` для полей: `name`, `email`, `sub`, `body`.

### Формат текста сообщения

Текст электронного письма формируется в формате HTML:

```php
$mes = "Имя: $name <br> E-mail: $email <br> Телефон: $sub ";

if (isset($body)) {
    $mes .= "<br> Сообщение: $body";
}
```

### Метаданные электронной почты

Отправитель, получатель, тема и формат электронного письма задаются следующим образом:

```php
$mail->setFrom('info@my_site.com', 'DST Маркетплейс');
$mail->addAddress('info@my_site.com', 'Заявка на сайте');
$mail->isHTML(true);
$mail->Subject = 'Новая заявка на сайте';
$mail->Body = $mes;
```

Получатель определяется константой:

```php
const SEND_EMAIL = "info@my_site.com";
```

## 27.10. Вопросы безопасности

### Санитизация входных данных

Все пользовательские данные проходят очистку двумя методами:

```php
strip_tags() - Удаляет HTML/PHP-теги
filter_var() - Применяет FILTER_SANITIZE_STRING фильтр
```

Внедрение в `contact_process.php`.

### Безопасность загрузки файлов

Система реализует ряд мер безопасности:

| Защита | Выполнение |
|--------|------------|
| **Белый список расширений** | `ALLOWED_EXTENSIONS` проверка массива |
| **Ограничение по размеру** | `MAX_FILE_SIZE` константа (64 МБ) |
| **Проверка ошибок** | `UPLOAD_ERR_OK` валидация |
| **Уникальное именование** | `uniqid()` предотвращает перезапись |
| **Нормализация случаев** | `mb_strtolower()` на расширения |

### Отсутствуют функции безопасности

В текущей реализации отсутствуют:

| Функция | Риск |
|---------|------|
| **Защита от CSRF-атак** | Отсутствие проверки токенов |
| **Ограничение скорости** | Механизм регулирования отсутствует |
| **Проверка типа контента** | Только проверка расширения |
| **Сканирование на вирусы** | Вредоносное ПО не обнаружено |
| **Защита учётных данных** | Жёстко закодированные пароли в исходном коде |
| **Ограничения на длину входных данных** | Ограничение максимальной длины текста не установлено |

### Шифрование TLS

При передаче электронных писем используется шифрование TLS:

```php
$mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
$mail->Port = 587;
```

## 27.11. Отладка и устранение неполадок

### Включение отладочного вывода SMTP

Раскомментируйте строку в `contact_process.php` для включения подробного логирования SMTP:

```php
$mail->SMTPDebug = SMTP::DEBUG_SERVER;
```

### Уровни отладки

| Уровень | Константа | Описание |
|---------|-----------|----------|
| **0** | `SMTP::DEBUG_OFF` | Нет вывода |
| **1** | `SMTP::DEBUG_CLIENT` | Сообщения клиента |
| **2** | `SMTP::DEBUG_SERVER` | Сообщения клиента и сервера |
| **3** | `SMTP::DEBUG_CONNECTION` | Все + сведения о подключении |
| **4** | `SMTP::DEBUG_LOWLEVEL` | Данные низкого уровня |

### Общие проблемы

| Проблема | Возможная причина | Решение |
|----------|------------------|---------|
| "Ошибка отправки письма" | Сбой аутентификации | Проверьте учётные данные SMTP |
| Файл не загружается | Права доступа к каталогу загрузки | Проверьте права доступа к каталогу |
| Продление отклонено | Тип файла отсутствует в белом списке | Добавить в `ALLOWED_EXTENSIONS` |
| Превышен лимит размера | Файл > 64 МБ | Увеличить `MAX_FILE_SIZE` или сжать файл |
| Таймаут соединения | Брандмауэр блокирует порт 587 | Проверьте правила брандмауэра |

### Структура ответа об ошибке

Ошибки проверки файлов сохраняются в `$data` массиве:

```php
$data['attachment'][$key] = 'Error message';
$data['result'] = 'error';
```

### Тестирование доставки электронных писем

Для проверки работы электронной почты:

1. Включить отладку SMTP
2. Отправьте тестовую форму с корректными данными
3. Проверьте журналы сервера на наличие транзакций SMTP
4. Подтвердите получение электронного письма в пункте назначения
5. Протестируйте с файлами различных типов и размеров

## 27.12. Вопросы производительности

### Влияние на размер файла

С ограничением размера файла в 64 МБ и возможностью добавления нескольких вложений, передача электронных писем может быть медленной. Система не поддерживает:

- Асинхронная отправка
- Управление очередями
- Показатели прогресса
- Обработка таймаута

### Соединение с протоколом передачи почты

Каждая отправка формы создаёт новое соединение с протоколом передачи почты. Для сценариев с большим объёмом запросов рекомендуется следующее:

- Объединение соединений
- Фоновые очереди заданий
- Системы очередей сообщений (RabbitMQ, Redis)
- Выделенный почтовый сервер
- Использование ресурсов

Загрузка больших файлов потребляет память в следующие моменты времени:

- `$_FILES` обработка
- `move_uploaded_file()` операции
- Кодирование вложений в `PHPMailer`
- Передача протокола передачи почты

### Архитектура интеграции

Для интеграции с ядром платформы используется класс `cmsMailer`, который предоставляет абстракцию над PHPMailer:

```
┌────────────────────────────────────────────────────────────┐

│  │  (любой)     │     │  (синглтон)  │     │             │ │

│         │                    │                    │        │

└────────────────────────────────────────────────────────────┘
```

### Инициализация `cmsMailer`

```php
// /system/core/mailer.php
class cmsMailer {
    private $mailer;
    private $config;
    
    public function __construct() {
        $this->config = cmsConfig::getInstance();
        $this->initMailer();
    }
    
    private function initMailer() {
        $this->mailer = new PHPMailer(true);
        
        // Настройка из конфигурации
        $this->mailer->isSMTP();
        $this->mailer->Host = $this->config->get('smtp_host', 'smtp.yandex.ru');
        $this->mailer->SMTPAuth = true;
        $this->mailer->Username = $this->config->get('smtp_username');
        $this->mailer->Password = $this->config->get('smtp_password');
        $this->mailer->SMTPSecure = $this->config->get('smtp_secure', PHPMailer::ENCRYPTION_STARTTLS);
        $this->mailer->Port = $this->config->get('smtp_port', 587);
        $this->mailer->CharSet = 'UTF-8';
    }
    
    public function setTo($email, $name = '') {
        $this->mailer->addAddress($email, $name);
        return $this;
    }
    
    public function setFrom($email, $name = '') {
        $this->mailer->setFrom($email, $name);
        return $this;
    }
    
    public function setSubject($subject) {
        $this->mailer->Subject = $subject;
        return $this;
    }
    
    public function setBody($body) {
        $this->mailer->isHTML(true);
        $this->mailer->Body = $body;
        return $this;
    }
    
    public function send() {
        try {
            return $this->mailer->send();
        } catch (Exception $e) {
            error_log("Mailer Error: " . $this->mailer->ErrorInfo);
            return false;
        }
    }
}
```

### Использование в контроллерах

```php
// В любом контроллере

$mailer->setTo('user@example.com', 'Иван Иванов')
```

## 27.16. Мониторинг и аналитика

### Логирование отправки писем

```php
// /system/core/mailer.php
class cmsMailer {
    public function send() {
        $start_time = microtime(true);
        
        try {
            $result = $this->mailer->send();
            
            // Логирование успешной отправки
            $duration = microtime(true) - $start_time;
            cmsDebugging::log('email_sent', [
                'to' => $this->mailer->getToAddresses(),
                'subject' => $this->mailer->Subject,
                'duration' => round($duration, 4),
                'size' => strlen($this->mailer->Body),
                'timestamp' => date('Y-m-d H:i:s')
            ]);
            
            return $result;
            
        } catch (Exception $e) {
            // Логирование ошибки
            cmsDebugging::log('email_error', [
                'to' => $this->mailer->getToAddresses(),
                'subject' => $this->mailer->Subject,
                'error' => $this->mailer->ErrorInfo,
                'exception' => $e->getMessage(),
                'timestamp' => date('Y-m-d H:i:s')
            ]);
            
            return false;
        }
    }
}
```

### Статистика отправки

```php
// /system/controllers/admin/backend/controller.php
class backendAdmin extends cmsBackend {
    public function getEmailStatistics() {
        $stats = [
            'total_sent' => $this->model->getCount('email_logs', [
                'date_sent' => ['>' => date('Y-m-d', strtotime('-30 days'))]
            ]),
            'failed' => $this->model->getCount('email_logs', [
                'status' => 'failed',
                'date_sent' => ['>' => date('Y-m-d', strtotime('-30 days'))]
            ]),
            'success_rate' => 0,
            'by_type' => $this->model->getEmailStatsByType(),
            'by_day' => $this->model->getEmailStatsByDay()
        ];
        
        if ($stats['total_sent'] > 0) {
            $stats['success_rate'] = round(
                (($stats['total_sent'] - $stats['failed']) / $stats['total_sent']) * 100,
                2
            );
        }
        
        return $stats;
    }
}
```

3. **Реализуйте обработку ошибок**: Обеспечьте корректную обработку всех сценариев
4. **Настройте мониторинг**: Внедрите сбор метрик и алертов
5. **Документируйте интеграцию**: Создайте внутреннюю документацию для команды разработки
6. **Тестируйте шаблоны**: Проверьте отображение писем в разных почтовых клиентах
