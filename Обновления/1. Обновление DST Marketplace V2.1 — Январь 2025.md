# Обновление DST Marketplace V2.1 — Январь 2025

Данное обновление направлено на улучшение пользовательского опыта, повышение уровня безопасности системы, а также расширение функциональных возможностей платформы для продавцов и администраторов.

## 1. Frontend

### Центр поддержки

Предназначена для предоставления пользователям быстрых доступа к FAQ, инструкциям, руководствам по использованию платформы и актуальным новостям. Реализована адаптивная верстка для комфортного просмотра на мобильных устройствах и ПК.

### Пункты выдачи

Страница с интерактивной картой и списком пунктов выдачи, позволяющая пользователям легко находить и выбирать места получения товаров. Внедрена возможность фильтрации по регионам, типам пунктов и графикам работы.

### Пункты выдачи (модуль)

Интегрирован в основной интерфейс для отображения, фильтрации и поиска пунктов выдачи.

### Справочный центр (компонент)

Обеспечивает быстрый доступ к наиболее популярным вопросам и руководствам на маркетплейсе. Встроенная поисковая строка и структурированная навигация.

### Вопросы и ответы (компонент)

Раздел FAQ с возможностью динамического обновления контента, сортировки по категориям и популярности.

### Модальное окно вариаций для товаров

В мобильной версии при выборе вариативных товаров пользователи будут видеть модальное окно, позволяющее выбрать параметры (цвет, размер и др.) без перехода на другие страницы.

### Модули "Новые акции" и "Популярные категории" для мобильного меню

Интерактивные блоки внутри мобильного меню для быстрого доступа к актуальным предложениям и популярным категориям.

### Аналитика продаж в кабинете продавца

Введена новая панель аналитики, отображающая ключевые метрики:
- Общий объем заказов
- Общий объем доставки

## 2. Панель управления

### Справочный центр

Расширенная база знаний для администраторов и менеджеров, с возможностью поиска и быстрого доступа к внутренней документации.

### Вопросы и ответы

Среди внутренних FAQ для сотрудников, включает инструкции по работе с платформой, правила безопасности и процедуры обслуживания.

### УПД (Универсальный Передаточный Документ)

Внедрение модуля для автоматического формирования и отправки электронных документов (счета, накладные, акты) с стандартными шаблонами и интеграцией с бухгалтерией.

### Настройки контроля IP-адресов

Введение системы whitelist для разрешённых IP-адресов. Администратор может добавлять или удалять IP-адреса для ограничения доступа к панели управления.

### Контроль изменений IP-адресов

Отслеживание, логирование и уведомления при попытках изменения IP-адреса входа в систему для предотвращения несанкционированного доступа.

## 3. Backend

### Аналитика продаж

Полноценный модуль для сбора, обработки и визуализации данных о продажах на маркетплейсе:
- Графики и отчёты по временным периодам
- Детализация по категориям и товарам
- Статистика по товарам в наличии
- Закрытых сделок на сумму
- Сделок в работе
- Отменённых сделок

### Разрешённые IP-адреса

Обеспечивают ограничение доступа к административной панели только для указанных IP.

### Контроль изменения IP

Внедрение системы логирования и оповещений для отслеживания попыток смены IP при входе.
