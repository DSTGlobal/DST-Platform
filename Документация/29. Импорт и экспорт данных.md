# 29. Импорт и экспорт данных

Данный документ содержит исчерпывающую техническую спецификацию подсистемы импорта/экспорта данных в рамках платформы DST Platform. Система использует библиотеку **Box Spout** (версия ^3.3) в качестве основного инструмента для операций с данными в электронных таблицах, обеспечивая высокопроизводительное чтение и запись файлов в форматах CSV, XLSX и ODS.

> **Важно**: Данный документ описывает архитектуру и технические детали интеграции с библиотекой **Box Spout**. Для получения информации о конкретных автоматизированных задачах экспорта см. раздел *«Задания экспорта продукции»*. Для автоматизации импорта данных о партнёрах см. раздел *«Импорт данных о партнёрах»*. Общую архитектуру внешних интеграций см. в разделе *«Внешняя интеграция»*.

## 29.1. Обзор системы

Подсистема импорта/экспорта данных реализована через сочетание сторонней библиотеки интеграции (Box Spout) и собственных компонентов платформы. Система обеспечивает полный жизненный цикл операций с данными — от чтения файлов до записи результатов в базу данных.

### Архитектурные принципы

| Принцип | Реализация | Выгода |

## 29.2. Зависимости и установка

### Управление зависимостями через Composer

Библиотека **Box Spout** управляется через Composer с ограничением по версии, что позволяет вносить незначительные обновления, сохраняя при этом совместимость с API.

| Пакет | Ограничение версии | Цель |
|-------|-------------------|------|
| `box/spout` | `^3.3` | Основная библиотека импорта/экспорта электронных таблиц |

**Ограничение по версиям `^3.3`** допускает использование версий `>=3.3.0` и `<4.0.0`, обеспечивая совместимость с версией API Box Spout v3, а также получение исправлений ошибок и незначительных обновлений функций.

### Установка через Composer

```bash
composer require box/spout:^3.3
```

### Требуемые расширения PHP

| Расширение | Назначение | Обязательность |
|------------|------------|----------------|
| `ext-xml` | Обработка XML для XLSX | Рекомендуется |
| `ext-zip` | Работа с архивами для XLSX | Рекомендуется |
| `ext-mbstring` | Обработка многобайтовых строк | Обязательно |
| `ext-iconv` | Конвертация кодировок | Опционально |

### Дерево зависимостей

```
box/spout (3.3.0)
├── php: >=7.0
├── ext-mbstring: *
├── ext-xml: * (рекомендуется для XLSX)
└── ext-zip: * (рекомендуется для XLSX)
```

## 29.3. Архитектура системы

### Архитектура и точки интеграции

Система импорта и экспорта данных интегрируется с несколькими компонентами платформы, в первую очередь с модулем маркетплейса для операций с данными о товарах и заказах.

### Схема интеграции компонентов

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/167.png" alt="DST Platform">

Анализ: На данной диаграмме показан полный поток данных для операций импорта/экспорта:

1. Бизнес-уровень: Контроллеры (маркетплейс, партнер) содержат бизнес-логику для определения того, какие данные следует экспортировать/импортировать.
2. Слой экспорта/импорта: Box Spout предоставляет фабричные классы и реализации чтения/записи для каждого формата.
3. Источники данных: таблицы MySQL предоставляют структурированные данные; загруженные файлы служат источниками для импорта.
4. Файловая система: в каталоге Exports хранятся сгенерированные файлы; в каталоге Uploads — импортируемые файлы.
5. Автоматизация: Задания Cron запускают запланированные операции через обработчики контроллера.

## 29.4. Библиотека Box Spout

### Структура библиотеки

Библиотека **Box Spout** предоставляет следующие ключевые классы:

| Класс | Пространство имён | Назначение |
|-------|-------------------|------------|
| `ReaderFactory` | `Box\Spout\Reader\Common\Creator` | Создание читателей для разных форматов |
| `WriterFactory` | `Box\Spout\Writer\Common\Creator` | Создание писателей для разных форматов |
| `Type` | `Box\Spout\Common\Type` | Константы типов файлов (CSV, XLSX, ODS) |
| `Row` | `Box\Spout\Reader\Common\Creator\Row` | Строка данных при чтении |
| `Style` | `Box\Spout\Writer\Common\Creator\Style\StyleBuilder` | Стилизация ячеек |

### Основные возможности

| Возможность | Преимущество | Пример использования |
|-------------|--------------|---------------------|
| **Потоковая обработка** | Экономия памяти при работе с большими файлами | Экспорт 100 000+ товаров |
| **Поддержка форматов** | Совместимость с различными системами | CSV для 1С, XLSX для аналитики |
| **Типобезопасность** | Корректная обработка чисел, дат, строк | Автоматическое определение типов |
| **Форматирование ячеек** | Жирный, курсив, цвета, границы | Выделение заголовков |
| **Работа с большими данными** | Оптимизировано для обработки миллионов строк | Массовый импорт от партнёров |

## 29.5. Экспортные операции

### Поддерживаемые форматы экспорта

Библиотека **Box Spout** позволяет платформе экспортировать данные в трёх основных форматах:

| Формат | Расширение | Вариант использования | Производительность |
|--------|------------|----------------------|-------------------|
| **CSV** | `.csv` | Простой обмен данными, устаревшие системы | Самый быстрый |
| **XLSX** | `.xlsx` | Совместимость с Excel, расширенное форматирование | Умеренный |
| **ODS** | `.ods` | Формат OpenDocument, LibreOffice | Умеренный |

### Шаблон фабрики писателей

**Box Spout** использует шаблон проектирования «фабрика» для создания соответствующих экземпляров объектов записи:

```php
use Box\Spout\Writer\Common\Creator\WriterFactory;
use Box\Spout\Common\Type;

// Создание писателя для XLSX
$writer = WriterFactory::create(Type::XLSX);

// Создание писателя для CSV
$writer = WriterFactory::create(Type::CSV);

// Создание писателя для ODS
$writer = WriterFactory::create(Type::ODS);
```

### Общие экспортные операции

#### Экспорт каталога продукции

**Запуск**: `cron_export.php` или действие администратора вручную  
**Название хука**: `cron_export_products_job`  
**Место сохранения выходных файлов**: `exports/jobs/` каталог  
**Типичные столбцы**: артикул, название, цена, наличие на складе, категории, изображения

```php
// /system/controllers/shop/export/products.php
use Box\Spout\Writer\Common\Creator\WriterFactory;
use Box\Spout\Common\Type;

class exportProducts {
    /**
     * Экспорт каталога продукции
     */
    public function exportProducts($filters = []) {
        // Получение товаров из базы данных
        $products = $this->model->getProductsForExport($filters);
        
        if (empty($products)) {
            return false;
        }
        
        // Инициализация писателя
        $writer = WriterFactory::create(Type::XLSX);
        
        // Генерация пути к файлу с временной меткой
        $export_file = PATH . '/exports/jobs/products_' . date('Y-m-d_H-i-s') . '.xlsx';
        $writer->openToFile($export_file);
        
        // Запись заголовков
        $writer->addRow([
            'ID', 'Название', 'Артикул', 'Цена', 'Остаток',
            'Категория', 'Производитель', 'Дата создания'
        ]);
        
        // Потоковая запись товаров
        $count = 0;
        foreach ($products as $product) {
            $writer->addRow([
                $product['id'],
                $product['title'],
                $product['sku'] ?? '',
                $product['price'],
                $product['quantity'],
                $product['category_title'] ?? '',
                $product['manufacturer'] ?? '',
                $product['date_created']
            ]);
            $count++;
            
            // Прогресс-логирование каждые 1000 товаров
            if ($count % 1000 === 0) {
                error_log("[EXPORT] Processed {$count} products...");
            }
        }
        
        $writer->close();
        
        // Логирование результатов
        $this->model->logExport($export_file, $count);
        
        return [
            'file' => $export_file,
            'count' => $count,
            'format' => 'XLSX'
        ];
    }
}
```

#### Экспорт выполнения заказов

**Запускается**: действием администратора вручную или запланированным заданием  
**Источник данных**: `orders` и `order_items` таблицы  
**Формат вывода**: XLSX для интеграции с хранилищем данных  
**Типичные столбцы**: Идентификатор заказа, Клиент, Товары, Адрес доставки, Статус

```php
// /system/controllers/shop/export/orders.php
class exportOrders {
    /**
     * Экспорт данных о заказах
     */
    public function exportOrders($date_from, $date_to) {
        // Получение заказов за период
        $orders = $this->model->getOrdersByPeriod($date_from, $date_to);
        
        if (empty($orders)) {
            return false;
        }
        
        // Инициализация писателя
        $writer = WriterFactory::create(Type::XLSX);
        $export_file = PATH . '/exports/jobs/orders_' . date('Y-m-d') . '.xlsx';
        $writer->openToFile($export_file);
        
        // Запись заголовков
        $writer->addRow([
            'ID заказа', 'Дата', 'Статус', 'Клиент', 'Телефон',
            'Товар', 'Количество', 'Цена', 'Сумма', 'Адрес доставки'
        ]);
        
        // Запись данных о заказах
        foreach ($orders as $order) {
            $items = $this->model->getOrderItems($order['id']);
            
            foreach ($items as $item) {
                $writer->addRow([
                    $order['id'],
                    $order['date_created'],
                    $order['status'],
                    $order['user_name'],
                    $order['user_phone'],
                    $item['title'],
                    $item['quantity'],
                    $item['price'],
                    $item['total'],
                    $order['delivery_address']
                ]);
            }
        }
        
        $writer->close();
        
        return $export_file;
    }
}
```

#### Экспорт партнерского каталога

**Инициируется запросами от партнеров-поставщиков**  
**Источник данных**: Товары, отфильтрованные по идентификатору партнера  
**Формат вывода**: Настраиваемый (CSV/XLSX)  
**Типичные столбцы**: Артикул партнера, Название, Цена, Наличие

```php
// /system/controllers/partner/export/catalog.php
class exportPartnerCatalog {
    /**
     * Экспорт каталога партнёра
     */
    public function exportCatalog($partner_id, $format = 'XLSX') {
        // Получение товаров партнёра
        $products = $this->model->getPartnerProducts($partner_id);
        
        if (empty($products)) {
            return false;
        }
        
        // Определение типа файла
        $type = ($format === 'CSV') ? Type::CSV : Type::XLSX;
        $writer = WriterFactory::create($type);
        
        // Генерация имени файла
        $partner = $this->model->getPartnerById($partner_id);
        $filename = 'catalog_' . $partner['code'] . '_' . date('Y-m-d') . '.' . strtolower($format);
        $export_file = PATH . '/exports/jobs/' . $filename;
        
        $writer->openToFile($export_file);
        
        // Запись заголовков
        $writer->addRow([
            'Артикул партнёра', 'Название', 'Цена', 'Остаток',
            'Категория', 'Описание'
        ]);
        
        // Запись товаров
        foreach ($products as $product) {
            $writer->addRow([
                $product['partner_sku'],
                $product['title'],
                $product['partner_price'],
                $product['quantity'],
                $product['category_title'],
                $product['description']
            ]);
        }
        
        $writer->close();
        
        return $export_file;
    }
}
```

```php
// /system/controllers/partner/import/products.php
use Box\Spout\Reader\Common\Creator\ReaderFactory;
use Box\Spout\Common\Type;

class importPartnerProducts {
    /**
     * Импорт товаров от партнёра
     */
    public function importProducts($file_path, $partner_id) {
        // Определение типа файла
        $extension = pathinfo($file_path, PATHINFO_EXTENSION);
        $type = ($extension === 'csv') ? Type::CSV : Type::XLSX;
        
        // Создание читателя
        $reader = ReaderFactory::create($type);
        $reader->open($file_path);
        
        $imported = 0;
        $updated = 0;
        $errors = [];
        
        // Чтение файла построчно
        foreach ($reader->getSheetIterator() as $sheet) {
            foreach ($sheet->getRowIterator() as $row_index => $row) {
                // Пропуск заголовка
                if ($row_index === 1) {
                    continue;
                }
                
                try {
                    // Валидация данных
                    $product_data = $this->validateProductRow($row, $row_index);
                    
                    if ($product_data === null) {
                        continue;
                    }
                    
                    // Поиск существующего товара
                    $existing = $this->model->getProductByPartnerSku(
                        $partner_id,
                        $product_data['partner_sku']
                    );
                    
                    if ($existing) {
                        // Обновление существующего товара
                        $this->model->updateProduct($existing['id'], $product_data);
                        $updated++;
                    } else {
                        // Создание нового товара
                        $product_data['partner_id'] = $partner_id;
                        $this->model->createProduct($product_data);
                        $imported++;
                    }
                    
                } catch (\Exception $e) {
                    $errors[] = [
                        'row' => $row_index,
                        'error' => $e->getMessage()
                    ];
                }
            }
        }
        
        $reader->close();
        
        // Логирование результатов
        $this->model->logImport([
            'partner_id' => $partner_id,
            'file' => basename($file_path),
            'imported' => $imported,
            'updated' => $updated,
            'errors' => count($errors)
        ]);
        
        return [
            'imported' => $imported,
            'updated' => $updated,
            'errors' => $errors
        ];
    }
    
    /**
     * Валидация строки данных
     */
    private function validateProductRow($row, $row_index) {
        // Проверка обязательных полей
        if (empty($row[0]) || empty($row[1]) || empty($row[2])) {
            throw new \Exception('Отсутствуют обязательные поля');
        }
        
        // Проверка формата цены
        if (!is_numeric($row[2])) {
            throw new \Exception('Некорректный формат цены');
        }
        
        // Проверка формата остатка
        if (!is_numeric($row[3]) || $row[3] < 0) {
            throw new \Exception('Некорректный формат остатка');
        }
        
        return [
            'partner_sku' => trim($row[0]),
            'title' => trim($row[1]),
            'partner_price' => (float)$row[2],
            'quantity' => (int)$row[3],
            'category' => $row[4] ?? null,
            'description' => $row[5] ?? null
        ];
    }
}
```

### Пример комплексной валидации

```php
class dataValidator {
    /**
     * Полная валидация данных импорта
     */
    public function validateImportData($file_path, $expected_columns) {
        $reader = ReaderFactory::create(Type::XLSX);
        $reader->open($file_path);
        
        $validation = [
            'valid' => true,
            'errors' => [],
            'warnings' => [],
            'stats' => [
                'total_rows' => 0,
                'valid_rows' => 0,
                'invalid_rows' => 0
            ]
        ];
        
        foreach ($reader->getSheetIterator() as $sheet) {
            $row_index = 0;
            
            foreach ($sheet->getRowIterator() as $row) {
                $row_index++;
                
                // Пропуск заголовка
                if ($row_index === 1) {
                    // Проверка структуры заголовка
                    $validation = $this->validateHeader($row, $expected_columns, $validation);
                    continue;
                }
                
                $validation['stats']['total_rows']++;
                
                // Проверка обязательных полей
                $has_required = true;
                foreach ($expected_columns as $col) {
                    if (empty($row[$col['index']])) {
                        $validation['errors'][] = [
                            'row' => $row_index,
                            'column' => $col['name'],
                            'message' => 'Обязательное поле пустое'
                        ];
                        $has_required = false;
                    }
                }
                
                if (!$has_required) {
                    $validation['stats']['invalid_rows']++;
                    continue;
                }
                
                // Проверка типов данных
                $validation = $this->validateDataTypes($row, $row_index, $validation);
                
                if (empty($validation['errors'])) {
                    $validation['stats']['valid_rows']++;
                } else {
                    $validation['stats']['invalid_rows']++;
                }
            }
        }
        
        $reader->close();
        
        $validation['valid'] = (count($validation['errors']) === 0);
        
        return $validation;
    }
    
    /**
     * Проверка структуры заголовка
     */
    private function validateHeader($header_row, $expected_columns, $validation) {
        foreach ($expected_columns as $col) {
            if (!isset($header_row[$col['index']]) || 
                $header_row[$col['index']] !== $col['name']) {
                $validation['errors'][] = [
                    'row' => 1,
                    'column' => $col['index'],
                    'message' => "Ожидаемый заголовок '{$col['name']}'"
                ];
            }
        }
        
        return $validation;
    }
    
    /**
     * Проверка типов данных
     */
    private function validateDataTypes($row, $row_index, $validation) {
        // Проверка цены
        if (!empty($row[2]) && !is_numeric($row[2])) {
            $validation['errors'][] = [
                'row' => $row_index,
                'column' => 'price',
                'message' => 'Цена должна быть числом'
            ];
        }
        
        // Проверка остатка
        if (!empty($row[3]) && (!is_numeric($row[3]) || $row[3] < 0)) {
            $validation['errors'][] = [
                'row' => $row_index,
                'column' => 'quantity',
                'message' => 'Остаток должен быть положительным числом'
            ];
        }
        
        // Проверка даты
        if (!empty($row[4]) && !strtotime($row[4])) {
            $validation['warnings'][] = [
                'row' => $row_index,
                'column' => 'date',
                'message' => 'Некорректный формат даты'
            ];
        }
        
        return $validation;
    }
}
```

## 29.9. Вопросы производительности

### Потоковая передача против загрузки

**Box Spout** использует потоковый подход, обеспечивающий значительные преимущества в производительности:

| Подход | Использование памяти | Скорость обработки | Лучше всего подходит для |
|--------|---------------------|-------------------|-------------------------|
| **Потоковая передача (Spout)** | O(1) - константа | По рядам | Большие наборы данных (>10 тыс. строк) |
| **Загрузка (PHPExcel)** | O(n) - линейный | Полный документ | Небольшие наборы данных (<10 тыс. строк) |

### Обработка больших наборов данных

Для экспорта данных, превышающих 100 000 строк, платформа реализует следующие функции:

#### Обработка пошаговых запросов

В запросах к базе данных для постраничной навигации используются `LIMIT`/`OFFSET`:

```php
class largeDataExport {
    /**
     * Экспорт больших объёмов данных с пагинацией
     */
    public function exportLargeDataset($total_count, $chunk_size = 1000) {
        $writer = WriterFactory::create(Type::XLSX);
        $export_file = PATH . '/exports/jobs/large_export_' . date('Ymd_His') . '.xlsx';
        $writer->openToFile($export_file);
        
        // Запись заголовков
        $writer->addRow(['ID', 'Название', 'Цена', 'Остаток']);
        
        $offset = 0;
        $processed = 0;
        
        while ($offset < $total_count) {
            // Получение данных порциями
            $products = $this->model->getProductsChunk($offset, $chunk_size);
            
            if (empty($products)) {
                break;
            }
            
            // Запись порции данных
            foreach ($products as $product) {
                $writer->addRow([
                    $product['id'],
                    $product['title'],
                    $product['price'],
                    $product['quantity']
                ]);
                $processed++;
            }
            
            $offset += $chunk_size;
            
            // Логирование прогресса
            if ($processed % 10000 === 0) {
                error_log("[EXPORT] Processed {$processed} rows...");
            }
            
            // Небольшая пауза между порциями для снижения нагрузки
            usleep(10000); // 10 мс
        }
        
        $writer->close();
        
        return [
            'file' => $export_file,
            'total' => $processed
        ];
    }
}
```

```php
            // Сброс буфера при достижении размера
            if (count($buffer) >= $buffer_size) {
                foreach ($buffer as $row) {
                    $writer->addRow($row);
                }
                $buffer = []; // Очистка буфера
            }
        }
        
        // Сброс оставшихся данных в буфере
        foreach ($buffer as $row) {
            $writer->addRow($row);
        }
        
        $writer->close();
        
        return $export_file;
    }
    
    /**
     * Использование кэша для часто запрашиваемых данных
     */
    public function exportWithCache($filters) {
        $cache_key = 'export_products_' . md5(serialize($filters));
        $cached = cmsCache::getInstance()->get($cache_key);
        
        if ($cached !== false) {
            // Возврат кэшированного результата
            return $cached;
        }
        
        // Генерация нового экспорта
        $export_file = $this->optimizedExport($filters);
        
        // Сохранение в кэш на 1 час
        cmsCache::getInstance()->set($cache_key, $export_file, 3600);
        
        return $export_file;
    }
}
```

### Оптимизация импорта

```php
class importOptimization {
    /**
     * Оптимизированный импорт с пакетными операциями
     */
    public function optimizedImport($file_path) {
        $reader = ReaderFactory::create(Type::XLSX);
        $reader->open($file_path);
        
        $batch = [];
        $batch_size = 100; // Размер пакета
        
        foreach ($reader->getSheetIterator() as $sheet) {
            foreach ($sheet->getRowIterator() as $row_index => $row) {
                if ($row_index === 1) continue;
                
                $batch[] = $this->prepareProductData($row);
                
                // Обработка пакета при достижении размера
                if (count($batch) >= $batch_size) {
                    $this->processBatch($batch);
                    $batch = []; // Очистка пакета
                }
            }
        }
        
        // Обработка оставшихся данных в пакете
        if (!empty($batch)) {
            $this->processBatch($batch);
        }
        
        $reader->close();
    }
    
    /**
     * Обработка пакета товаров
     */
    private function processBatch($batch) {
        // Отключение проверки внешних ключей для ускорения
        $this->db->query("SET FOREIGN_KEY_CHECKS=0");
        
        // Начало транзакции
        $this->db->beginTransaction();
        
        try {
            foreach ($batch as $product) {
                $this->db->insert('shop_products', $product);
            }
            
            // Фиксация транзакции
            $this->db->commit();
            
        } catch (\Exception $e) {
            // Откат при ошибке
            $this->db->rollBack();
            throw $e;
        }
        
        // Включение проверки внешних ключей
        $this->db->query("SET FOREIGN_KEY_CHECKS=1");
    }
    
    /**
     * Использование LOAD DATA INFILE для CSV (если доступно)
     */
    public function fastCsvImport($csv_file) {
        if (!function_exists('mysqli_query')) {
            return $this->standardImport($csv_file);
        }
        
        $sql = "
            LOAD DATA LOCAL INFILE '{$csv_file}'
            INTO TABLE shop_products
            FIELDS TERMINATED BY ',' 
            ENCLOSED BY '\"'
            LINES TERMINATED BY '\n'
            IGNORE 1 ROWS
            (sku, title, price, quantity)
        ";
        
        return $this->db->query($sql);
    }
}
```

```php
class errorHandling {
    /**
     * Комплексная обработка ошибок импорта/экспорта
     */
    public function processWithErrorHandler($operation, $data) {
        try {
            return $this->$operation($data);
            
        } catch (\Box\Spout\Common\Exception\IOException $e) {
            // Ошибки ввода-вывода
            $this->logError('IO_ERROR', $e->getMessage(), $data);
            return $this->handleIoError($e);
            
        } catch (\Box\Spout\Common\Exception\InvalidArgumentException $e) {
            // Некорректные аргументы
            $this->logError('INVALID_ARGUMENT', $e->getMessage(), $data);
            return $this->handleArgumentError($e);
            
        } catch (\Box\Spout\Common\Exception\UnsupportedTypeException $e) {
            // Неподдерживаемый формат файла
            $this->logError('UNSUPPORTED_TYPE', $e->getMessage(), $data);
            return $this->handleTypeError($e);
            
        } catch (\Exception $e) {
            // Общие ошибки
            $this->logError('GENERAL_ERROR', $e->getMessage(), $data);
            return $this->handleGeneralError($e);
        }
    }
    
    /**
     * Обработка ошибок ввода-вывода
     */
    private function handleIoError($e) {
        // Попытка повторного выполнения с задержкой
        for ($i = 0; $i < 3; $i++) {
            try {
                usleep(100000 * ($i + 1)); // Экспоненциальная задержка
                return $this->retryOperation();
            } catch (\Exception $retry_e) {
                if ($i === 2) {
                    throw $retry_e; // Последняя попытка не удалась
                }
            }
        }
    }
    
    /**
     * Логирование ошибок
     */
    private function logError($type, $message, $context = []) {
        $error_log = [
            'type' => $type,
            'message' => $message,
            'context' => $context,
            'timestamp' => date('Y-m-d H:i:s'),
            'file' => $context['file'] ?? 'unknown',
            'line' => $context['line'] ?? 0
        ];
        
        // Запись в файл лога
        $log_file = PATH . '/cache/logs/import_export_errors.log';
        file_put_contents($log_file, json_encode($error_log) . PHP_EOL, FILE_APPEND);
        
        // Отправка уведомления администратору
        $this->sendAdminNotification($error_log);
    }
    
    /**
     * Отправка уведомления администратору
     */
    private function sendAdminNotification($error_log) {
        $mailer = cmsMailer::getInstance();
        $mailer->setTo(cmsConfig::get('admin_email'));
        $mailer->setSubject('Ошибка импорта/экспорта');
        $mailer->setBody($this->renderErrorEmail($error_log));
        $mailer->send();
    }
}
```

### Стратегии обработки ошибок

Ошибки на уровне файлов:

- Файл не найден: Зарегистрируйте ошибку, отправьте уведомление администратору.
- Недостаточные права доступа: Зарегистрируйте ошибку, проверьте права доступа к каталогу.
- Исчерпано дисковое пространство: в журнале зафиксирована критическая ошибка, работа приостановлена.

Ошибки на уровне данных:

- Неверный формат строки: пропустить строку, записать в файл ошибок.
- Сбои проверки: продолжить обработку, отчет по завершении.
- Дублирующиеся ключи: зарегистрировать конфликт, применить стратегию разрешения конфликтов.

Ошибки системного уровня:

- Охват памяти: реализовать разбиение на блоки, уменьшить размер пакетов.
- Истекло время ожидания: разбить на более мелкие задачи, использовать выполнение через командную строку.
- Потеряно соединение с базой данных: реализовать логику повторной попытки с задержкой.

## 29.13. Примеры использования

### Типичный рабочий процесс экспорта

Ниже представлена концептуальная схема операции по экспорту продукции:

1. **Инициирование**: Администратор запускает экспорт или выполнение запланированных заданий cron
2. **Запрос данных**: Модель маркетплейса извлекает товары с фильтрами (категория, диапазон дат и т.д.)
3. **Создание объекта записи**: Фабрика создает экземпляр объекта записи XLSX
4. **Открытие файла**: Программа записи открывает выходной файл в каталоге экспорта
5. **Заголовочная строка**: Заголовки столбцов (артикул, название, цена и т.д.)
6. **Строки данных**: Информация о продуктах, проработанная и записанная построчно
7. **Закрытие файла**: Программа записи завершает обработку и закрывает файл
8. **Уведомление**: Администратор уведомлен о завершении и предоставлена ссылка для скачивания

### Типичный рабочий процесс импорта

Ниже представлена концептуальная схема операции импорта, осуществляемой партнером:

1. **Инициирование**: файл загружен в каталог для загрузки или выполнен в соответствии с запланированным запуском задания
2. **Создание программы чтения**: Фабрика создает подходящую программу чтения для данного формата файла
3. **Открытие файла**: Программа чтения открывает файл и начинает его анализ
4. **Выбор листа**: Выбирается первый лист (или указанный лист)
5. **Сопоставление заголовков**: Заголовки столбцов сопоставляются с полями базы данных
6. **Обработка строк**: Каждая строка проверяется и преобразуется
7. **Операции с базой данных**: Обновление или вставка товаров (INSERT или UPDATE)
8. **Отслеживание ошибок**: в отчет об ошибках регистрируются недопустимые строки
9. **Завершение**: Сгенерирован сводный отчет с указанием количества успешных и неудачных попыток

### Автоматическая загрузка

Классы **Box Spout** доступны через функцию автоматической загрузки **PSR-4** в **Composer**:

```
Box\Spout\Writer\Common\Creator\WriterFactory
Box\Spout\Reader\Common\Creator\ReaderFactory
Box\Spout\Writer\WriterInterface
Box\Spout\Reader\ReaderInterface
```

Автозагрузчик инициализируется во время начальной загрузки и управляется системой автозагрузки сторонних поставщиков **Composer**.

## 29.17. Заключение

Интеграция библиотеки **Box Spout** обеспечивает платформе **DST Platform** эффективные и экономичные в плане использования памяти операции с электронными таблицами для обмена критически важными для бизнеса данными. Её потоковая архитектура позволяет обрабатывать большие наборы данных без ограничений по памяти, а поддержка множества форматов гарантирует совместимость с различными внешними системами и требованиями партнёров.

### Основные выводы:

| Категория | Реализация |
|-----------|------------|
| **Производительность** | Потоковая обработка данных позволяет работать с наборами данных любого размера |
| **Гибкость** | Поддержка форматов CSV, XLSX и ODS |
| **Интеграция** | Бесшовная интеграция с модулем маркетплейса и автоматизацией по расписанию (Cron) |
| **Поддерживаемость** | Фабричный шаблон проектирования и чистые абстракции упрощают использование |
| **Масштабируемость** | Разработано для операций с данными в масштабах предприятия |

Система использует эту инфраструктуру для экспорта каталогов продукции, импорта данных партнёров, генерации отчётов и интеграции с внешними системами.

### Рекомендации по внедрению

1. **Начните с тестового режима**: Используйте тестовые данные для проверки интеграции
2. **Настройте кэширование**: Реализуйте многоуровневое кэширование для оптимизации производительности
3. **Реализуйте обработку ошибок**: Обеспечьте отказоустойчивость при сбоях базы данных или файловой системы
4. **Настройте мониторинг**: Внедрите сбор метрик и алертов для оперативного реагирования
5. **Документируйте интеграцию**: Создайте внутреннюю документацию для команды разработки
