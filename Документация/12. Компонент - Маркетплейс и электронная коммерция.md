# 12. Компонент — Маркетплейс и электронная коммерция

Данный документ содержит исчерпывающую техническую документацию по компоненту **«Маркетплейс и электронная коммерция»**, который составляет основу функциональности торговой площадки и интернет-маркетплейса DST Platform. Этот компонент реализует полноценную систему электронной коммерции, включая управление каталогом товаров, корзину покупок, обработку заказов, интеграцию с платёжными шлюзами, расчёт стоимости доставки и автоматическую синхронизацию данных.

Компонент `shop` представляет собой **бизнес-сторону** двойной архитектуры DST Platform, обеспечивая возможности электронной коммерции корпоративного уровня.

---

## 12.1. Основные компоненты

Компонент `shop` использует архитектурный шаблон MVC платформы DST Platform, дополненный специализированными уровнями для платежей, доставки и экспорта данных. Он тесно интегрирован с внешними сервисами (ЮKassa, CDEK) и обеспечивает автоматизацию посредством запланированных задач.

## 12.3. Схема обработки заказов

Обработка заказов осуществляется по схеме конечного автомата с множеством переходов между состояниями, что поддерживает как сценарии с одним поставщиком, так и сценарии с несколькими поставщиками на торговой площадке.

### Конечный автомат жизненного цикла заказа

```
┌─────────────┐
│   Создан    │
│   (created) │
└──────┬──────┘
       │
       ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Ожидает    │────▶│   Оплачен   │────▶│ В обработке │
│  оплаты     │     │  (paid)     │     │ (processing)│
│ (awaiting)  │     └──────┬──────┘     └──────┬──────┘
└─────────────┘            │                   │
                           │                   ▼
                           │            ┌─────────────┐
                           │            │  Отправлен  │
                           │            │  (shipped)  │
                           │            └──────┬──────┘
                           │                   │
                           │                   ▼
                           │            ┌─────────────┐
                           └───────────▶│ Завершён    │
                                        │ (completed) │
                                        └─────────────┘
                                        
Возможные отклонения:
• Отменён (cancelled) — из любого состояния до отправки
• Возврат (refunded) — после оплаты
• Возврат товара (returned) — после получения
```

### Последовательность создания заказа

```
1. Пользователь добавляет товары в корзину
   ↓
2. Переход к оформлению заказа
   ↓
3. Выбор способа доставки (расчёт через CDEK)
   ↓
4. Выбор способа оплаты (интеграция ЮKassa)
   ↓
5. Подтверждение заказа → создание записи в БД
   ↓
6. Генерация уникального номера заказа
   ↓
7. Отправка уведомлений (покупателю, продавцу)
   ↓
8. Переход в статус "Ожидает оплаты"
```

### Интеграция с ЮKassa SDK

Компонент `shop` использует официальный SDK ЮKassa (версия ^2.1):

```bash
composer require yoomoney/yookassa-sdk-php:^2.1
```

#### Ключевые точки интеграции

| Этап | Метод | Описание |
|------|-------|----------|
| **Создание платежа** | `createPayment()` | Генерация платёжного объекта при оформлении заказа |
| **Подтверждение платежа** | `webhookHandler()` | Обработка уведомлений от ЮKassa |
| **Проверка статуса** | `checkPaymentStatus()` | Периодическая проверка статуса платежа |
| **Возврат средств** | `refundPayment()` | Обработка возвратов при отмене заказа |

#### Пример инициализации клиента ЮKassa

```php
// В модели компонента payment
use YooKassa\Client as YooKassaClient;
use YooKassa\Model\PaymentInterface;

class modelPayment extends cmsModel {
    private $yookassa;
    
    /**
     * Инициализация клиента ЮKassa
     */
    private function initYooKassa() {
        if (!$this->yookassa) {
            $config = cmsConfig::getInstance();
            $this->yookassa = new YooKassaClient();
            $this->yookassa->setAuth(
                $config->get('yookassa_shop_id'),
                $config->get('yookassa_secret_key')
            );
        }
        return $this->yookassa;
    }
    
    /**
     * Создание платежа
     */
    public function createPayment($order_id, $amount, $currency = 'RUB', $return_url) {
        $client = $this->initYooKassa();
        
        $payment = $client->createPayment([
            'amount' => [
                'value' => number_format($amount, 2, '.', ''),
                'currency' => $currency
            ],
            'confirmation' => [
                'type' => 'redirect',
                'return_url' => $return_url
            ],
            'capture' => true,
            'description' => 'Оплата заказа #' . $order_id,
            'metadata' => [
                'order_id' => $order_id
            ]
        ], uniqid('', true));
        
        // Сохранение идентификатора платежа в БД
        $this->update('shop_orders', $order_id, [
            'payment_id' => $payment->getId(),
            'payment_status' => $payment->getStatus()
        ]);
        
        return $payment;
    }
    
    /**
     * Обработка webhook от ЮKassa
     */
    public function handleWebhook($event_data) {
        $payment_id = $event_data['object']['id'];
        $status = $event_data['object']['status'];
        
        // Поиск заказа по payment_id
        $order = $this->getItemByField('shop_orders', 'payment_id', $payment_id);
        
        if ($order && $status === PaymentInterface::STATUS_SUCCEEDED) {
            // Обновление статуса заказа
            $this->update('shop_orders', $order['id'], [
                'payment_status' => 'paid',
                'status' => 'paid'
            ]);
            
            // Запуск события
            cmsEventsManager::hook('shop_order_paid', $order);
            
            return true;
        }
        
        return false;
    }
}
```

#### Поддерживаемые способы оплаты

- Электронные кошельки (ЮMoney, Qiwi)
- Мобильные операторы (МТС, Билайн, Мегафон)
- Расчётные счета (для юридических лиц)
- Рассрочка и кредитование

### Конфигурация SDK CDEK

В компоненте `delivery` настроен официальный SDK CDEK (версия ^0.6.22):

```bash
composer require sanmai/cdek-sdk:^0.6.22
```

#### Основные возможности

| Функция | Метод SDK | Описание |
|---------|-----------|----------|
| **Расчёт тарифа** | `calculateTariff()` | Расчёт стоимости доставки по весу, габаритам и месту назначения |
| **Поиск ПВЗ** | `getDeliveryPoints()` | Поиск ближайших пунктов выдачи заказов |
| **Создание заказа** | `createOrder()` | Регистрация заказа в системе CDEK |
| **Отслеживание** | `getOrderStatus()` | Запрос статуса и местоположения заказа |
| **Генерация этикетки** | `createDeliveryRequest()` | Создание транспортной этикетки для печати |

#### Пример интеграции с CDEK

```php
// В модели компонента delivery
use CdekSDK\Client;
use CdekSDK\Requests\CalculatorRequest;

class modelDelivery extends cmsModel {
    private $cdek_client;
    
    /**
     * Инициализация клиента CDEK
     */
    private function initCdekClient() {
        if (!$this->cdek_client) {
            $config = cmsConfig::getInstance();
            $this->cdek_client = new Client(
                $config->get('cdek_account'),
                $config->get('cdek_secure')
            );
        }
        return $this->cdek_client;
    }
    
    /**
     * Расчёт стоимости доставки
     */
    public function calculateDelivery($params) {
        $client = $this->initCdekClient();
        
        $request = (new CalculatorRequest())
            ->setSenderCityId($params['sender_city_id'])
            ->setReceiverCityId($params['receiver_city_id'])
            ->addPackage([
                'weight' => $params['weight'], // в граммах
                'length' => $params['length'],
                'width' => $params['width'],
                'height' => $params['height']
            ]);
        
        $response = $client->sendCalculatorRequest($request);
        
        $tariffs = [];
        foreach ($response->getTariffs() as $tariff) {
            $tariffs[] = [
                'tariff_id' => $tariff->getTariffId(),
                'tariff_name' => $tariff->getTariffName(),
                'delivery_sum' => $tariff->getDeliverySum(),
                'delivery_days' => $tariff->getDeliveryPeriod(),
                'delivery_date_min' => $tariff->getPeriodMin(),
                'delivery_date_max' => $tariff->getPeriodMax()
            ];
        }
        
        return $tariffs;
    }
    
    /**
     * Поиск пунктов выдачи
     */
    public function getDeliveryPoints($city_id, $type = 'PVZ') {
        $client = $this->initCdekClient();
        
        $points = $client->getDeliveryPoints()
            ->setCityId($city_id)
            ->setType($type) // PVZ - пункты выдачи, POSTOMAT - постаматы
            ->execute();
        
        $result = [];
        foreach ($points as $point) {
            $result[] = [
                'code' => $point->getCode(),
                'name' => $point->getName(),
                'address' => $point->getAddress(),
                'work_time' => $point->getWorkTime(),
                'phones' => $point->getPhones(),
                'location' => [
                    'latitude' => $point->getLatitude(),
                    'longitude' => $point->getLongitude()
                ],
                'is_dressing_room' => $point->hasDressingRoom(),
                'have_cashless' => $point->hasCashless(),
                'have_cash' => $point->hasCash()
            ];
        }
        
        return $result;
    }
    
    /**
     * Создание заказа в CDEK
     */
    public function createCdekOrder($order_data) {
        $client = $this->initCdekClient();
        
        $request = (new \CdekSDK\Requests\CreateOrderRequest())
            ->setNumber($order_data['order_number'])
            ->setSenderCityId($order_data['sender_city_id'])
            ->setReceiverCityId($order_data['receiver_city_id'])
            ->setReceiverAddress($order_data['receiver_address'])
            ->setReceiverName($order_data['receiver_name'])
            ->setReceiverPhone($order_data['receiver_phone'])
            ->addPackage([
                'number' => '1',
                'weight' => $order_data['weight'],
                'items' => $order_data['items']
            ]);
        
        $response = $client->sendCreateOrderRequest($request);
        
        if ($response->hasErrors()) {
            throw new \Exception(implode(', ', $response->getErrors()));
        }
        
        return [
            'cdek_order_uuid' => $response->getOrder()->getUUID(),
            'cdek_order_number' => $response->getOrder()->getDispatchNumber(),
            'barcode' => $response->getOrder()->getBarcode()
        ];
    }
}
```

### Работа по экспорту продукции

В процессе экспорта данных о товарах создаются файлы электронных таблиц (Excel/CSV) для использования во внешних системах, центрах выполнения заказов или в целях составления отчётов.

#### Основные характеристики

| Параметр | Значение | Описание |
|----------|----------|----------|
| **Управление параллелизмом** | Файловая блокировка | Предотвращает повторные запуски |
| **Механизм выполнения** | События через `cmsEventsManager` | Делегирование `cron_export_products_job` |
| **Контекст выполнения** | Только CLI | Доступно только для выполнения из командной строки |
| **Проверка состояния** | Проверка включения компонента | Подтверждает, что компонент `shop` включён |
| **Файл блокировки** | `/cache/cron_export_lock` | Путь к файлу блокировки |
| **Тип блокировки** | `LOCK_EX \| LOCK_NB` | Неблокирующая эксклюзивная блокировка |
| **Поведение при блокировке** | Немедленный выход | Завершается, если блокировка недоступна |

| Каталог | Назначение |
|---------|------------|
| `/exports/jobs/tmp/` | Временные файлы во время генерации |

#### Библиотека электронных таблиц

Для экспорта используется **Box Spout** (версия ^3.3):

```bash
composer require box/spout:^3.3
```

| Формат | Расширение | Поддержка |
|--------|------------|-----------|
| Excel | `.xlsx` | Полная |
| CSV | `.csv` | Полная |
| OpenDocument | `.ods` | Полная |

#### Пример реализации экспорта

```php
// В файле /system/controllers/shop/hooks.php
class shop {
    /**
     * Хук для экспорта товаров
     */
    public function hookCronExportProductsJob() {
        // Проверка включения компонента
        $config = cmsConfig::getInstance();
        if (!$config->get('shop_enabled')) {
            return false;
        }
        
        // Получение товаров из БД
        $products = $this->model->getProductsForExport();
        
        // Инициализация Box Spout
        $writer = \Box\Spout\Writer\Common\Creator\WriterFactory::create(
            \Box\Spout\Common\Type::XLSX
        );
        
        $export_file = PATH . '/exports/jobs/products_' . date('Y-m-d_H-i-s') . '.xlsx';
        $writer->openToFile($export_file);
        
        // Запись заголовков
        $writer->addRow([
            'ID', 'Название', 'Артикул', 'Цена', 'Остаток',
            'Категория', 'Производитель', 'Дата создания'
        ]);
        
        // Потоковая запись товаров
        foreach ($products as $product) {
            $writer->addRow([
                $product['id'],
                $product['title'],
                $product['sku'],
                $product['price'],
                $product['quantity'],
                $product['category_title'],
                $product['manufacturer'],
                $product['date_created']
            ]);
        }
        
        $writer->close();
        
        // Логирование
        $this->model->logExport($export_file, count($products));
        
        return true;
    }
}
```

### Автоматизированная задача обновления цен

Управляет автоматическим изменением цен, акционными ценами и массовым обновлением цен.

**Скрипт**: `cron_test_run_set_change_price.php`

#### Основные характеристики

| Параметр | Значение |
|----------|----------|
| **Контекст выполнения** | Только через командную строку (404 для HTTP) |
| **Рабочий каталог** | Изменения в переменной `PATH`, если `chdir()` доступен |
| **Загрузка шаблона** | Инициализирует систему шаблонов для вспомогательных функций |
| **Обработка исключений** | Перехват и сохранение ошибок |
| **Хук** | `cron_set_change_price` |

#### Варианты использования

- Запланированные изменения цен в рамках рекламных акций
- Корректировка оптовых цен на основе правил
- Динамическое ценообразование в зависимости от рыночных условий
- Обновления цен для конкретных поставщиков

#### Пример реализации

```php
// В файле /system/controllers/shop/hooks.php
class shop {
    /**
     * Хук для автоматического обновления цен
     */
    public function hookCronSetChangePrice() {
        // Получение правил изменения цен
        $rules = $this->model->getPriceChangeRules();
        
        foreach ($rules as $rule) {
            // Фильтрация товаров по правилу
            $products = $this->model->getProductsWithFilter($rule['filter']);
            
            foreach ($products as $product) {
                $new_price = $this->calculateNewPrice($product, $rule);
                
                // Обновление цены
                $this->model->update('shop_products', $product['id'], [
                    'price' => $new_price,
                    'price_changed_at' => date('Y-m-d H:i:s')
                ]);
                
                // Логирование изменения
                $this->model->logPriceChange(
                    $product['id'],
                    $product['price'],
                    $new_price,
                    $rule['id']
                );
            }
        }
        
        return true;
    }
    
    /**
     * Расчёт новой цены по правилу
     */
    private function calculateNewPrice($product, $rule) {
        $current_price = $product['price'];
        
        switch ($rule['type']) {
            case 'fixed':
                // Фиксированная цена
                return $rule['value'];
                
            case 'percent_increase':
                // Увеличение на процент
                return $current_price * (1 + $rule['value'] / 100);
                
            case 'percent_decrease':
                // Уменьшение на процент
                return $current_price * (1 - $rule['value'] / 100);
                
            case 'formula':
                // Расчёт по формуле
                return eval('return ' . $rule['formula'] . ';');
                
            default:
                return $current_price;
        }
    }
}
```

#### Пример конфигурации

```php
// В конфигурации системы (/system/config/config.php)
'cache' => [
    'driver' => 'redis', // redis, memcached, files
    'host' => '127.0.0.1',
    'port' => 6379,
    'ttl' => 3600, // время жизни кэша в секундах
    'prefix' => 'dst_'
],

// В модели компонента shop
class modelShop extends cmsModel {
    /**
     * Получение товаров с кэшированием
     */
    public function getProducts($category_id, $limit = 20) {
        $cache_key = 'shop_products_' . $category_id . '_' . $limit;
        
        // Попытка получить из кэша
        $cached = cmsCache::getInstance()->get($cache_key);
        if ($cached !== false) {
            return $cached;
        }
        
        // Запрос к БД
        $products = $this->select('shop_products')
            ->filterEqual('category_id', $category_id)
            ->filterEqual('is_published', 1)
            ->orderBy('date_pub', 'DESC')
            ->limit($limit)
            ->getItems();
        
        // Сохранение в кэш
        cmsCache::getInstance()->set($cache_key, $products, 3600); // 1 час
        
        return $products;
    }
    
    /**
     * Инвалидация кэша при обновлении товара
     */
    public function updateProduct($id, $data) {
        $result = parent::update('shop_products', $id, $data);
        
        if ($result) {
            // Очистка всех кэшей, связанных с товарами
            cmsCache::getInstance()->delete('shop_products_*');
            cmsCache::getInstance()->delete('shop_product_' . $id);
        }
        
        return $result;
    }
}
```

### Пример интеграции с CRM

```php
// В файле /system/controllers/crm_integration/hooks.php
class crm_integration {
    /**
     * Синхронизация нового заказа с CRM
     */
    public function hookShopAfterCreateOrder($order) {
        // Подготовка данных для CRM
        $crm_data = [
            'external_id' => $order['id'],
            'customer' => [
                'name' => $order['user_name'],
                'email' => $order['user_email'],
                'phone' => $order['user_phone']
            ],
            'items' => array_map(function($item) {
                return [
                    'product_id' => $item['product_id'],
                    'name' => $item['product_title'],
                    'quantity' => $item['quantity'],
                    'price' => $item['price']
                ];
            }, $order['items']),
            'total' => $order['total'],
            'status' => 'new',
            'created_at' => $order['date_created']
        ];
        
        // Отправка в CRM через API
        $client = new \GuzzleHttp\Client();
        $response = $client->post('https://crm.example.com/api/orders', [
            'json' => $crm_data,
            'headers' => [
                'Authorization' => 'Bearer ' . $this->getApiKey()
            ]
        ]);
        
        if ($response->getStatusCode() === 201) {
            $crm_order_id = json_decode($response->getBody(), true)['id'];
            
            // Сохранение идентификатора CRM в заказе
            $this->model->update('shop_orders', $order['id'], [
                'crm_order_id' => $crm_order_id
            ]);
        }
        
        return $order;
    }
    
    /**
     * Обновление статуса заказа в CRM
     */
    public function hookShopOrderStatusChanged($order_id, $old_status, $new_status) {
        $order = $this->model->getItem('shop_orders', $order_id);
        
        if (empty($order['crm_order_id'])) {
            return;
        }
        
        $client = new \GuzzleHttp\Client();
        $client->put('https://crm.example.com/api/orders/' . $order['crm_order_id'], [
            'json' => [
                'status' => $this->mapStatus($new_status)
            ],
            'headers' => [
                'Authorization' => 'Bearer ' . $this->getApiKey()
            ]
        ]);
    }
    
    /**
     * Маппинг статусов
     */
    private function mapStatus($status) {
        $map = [
            'created' => 'new',
            'awaiting' => 'pending',
            'paid' => 'confirmed',
            'processing' => 'processing',
            'shipped' => 'shipped',
            'completed' => 'delivered',
            'cancelled' => 'cancelled',
            'refunded' => 'refunded'
        ];
        
        return $map[$status] ?? 'unknown';
    }
}
```
