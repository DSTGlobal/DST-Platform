# Часть I. Основы

## 53.1. Роль медиафайлов в платформе

DST Platform используется для 10+ типов проектов, где медиа — критичный элемент:

| Проект | Типы медиа | Объём |
|---|---|---|
| **Интернет-магазин** | Фото товаров (5–20 на товар) | 10 000–5 000 000 |
| **Маркетплейс** | Фото товаров, аватары продавцов, баннеры | Миллионы |
| **Мед Центр** | Фото врачей, документы, лицензии | Тысячи |
| **LMS** | Видео курсов, PDF, презентации | Тысячи (тяжёлые) |
| **Социальная сеть** | Аватары, посты, сторис, видео | Миллионы |
| **Доска объявлений** | Фото объявлений | Миллионы |
| **CRM** | Документы, скан-копии, подписи | Тысячи |

**Ключевые требования:**

1. **Скорость отдачи** — пользователь не должен ждать загрузки фото товара.
2. **Экономия трафика** — мобильные пользователи платят за мегабайты.
3. **SEO** — `alt`, `title`, оптимизированные размеры, `srcset`.
4. **Конверсия** — качественные фото → выше продажи.
5. **Безопасность** — пользовательские файлы не должны исполняться на сервере.

> 💡 **Правило DST.** Любое изображение, отображаемое пользователю, должно быть **оптимизировано под контекст** (пресет): миниатюра в списке, средний размер в карточке, полный — при клике. Никогда не отдавайте оригинал 4000×3000 в список товаров.

## 53.2. Типы медиафайлов

| Тип | Форматы | Обработка | Хранение |
|---|---|---|---|
| **Изображения** | JPEG, PNG, WebP, AVIF, GIF, SVG | Ресайз, кроп, watermark, фильтры | `/upload/images/` |
| **Документы** | PDF, DOCX, XLSX, ODT, TXT | Конвертация (опционально), превью | `/upload/files/` |
| **Видео** | MP4, WebM, MOV | Транскодирование (внешнее), превью | `/upload/video/` или S3 |
| **Аудио** | MP3, OGG, WAV | Конвертация (опционально) | `/upload/audio/` |
| **Архивы** | ZIP, RAR, 7z | Без обработки | `/upload/archives/` |
| **Шрифты** | WOFF2, TTF, OTF | Без обработки (для темы) | `/templates/*/fonts/` |
| **3D-модели** | GLB, GLTF | Без обработки (рендер на клиенте) | `/upload/3d/` |

> ⚠️ **Опасные форматы.** Исполняемые файлы (`.php`, `.exe`, `.sh`, `.bat`, `.js`) **никогда** не должны попадать в `/upload/`. Белый список — единственная защита (см. 53.36).

### 53.5.1. Расположение и роль

**Файл:** `/system/core/uploader.php`

**Ответственность:**

### 53.6.2. Контроллер

**Файл:** `/system/controllers/mycomp/frontend.php`

```php
<?php
declare(strict_types=1);

class mycomp extends cmsFrontend {

    /**
     * Действие: загрузка файла.
     */
    public function actionUpload() {

        // 1. Проверка авторизации
        if (!$this->cms_user->is_logged) {
            return $this->redirectToLogin();
        }

        // 2. Только POST
        if (!$this->request->isPost()) {
            return $this->renderUploadForm();
        }

        // 3. CSRF
        if (!$this->request->checkCSRF()) {
            cmsUser::addSessionMessage('Неверный CSRF-токен', 'error');
            return $this->redirectToAction('upload');
        }

        // 4. Проверка файла
        if (empty($_FILES['file']) || $_FILES['file']['error'] !== UPLOAD_ERR_OK) {
            cmsUser::addSessionMessage('Ошибка загрузки файла', 'error');
            return $this->redirectToAction('upload');
        }

        $entityId = (int)$this->request->get('entity_id', 0);
        if ($entityId <= 0) {
            cmsUser::addSessionMessage('Не указан объект', 'error');
            return $this->redirectToAction('upload');
        }

        // 5. Загрузка через cmsUploader
        $uploader = cmsUploader::getInstance();

        try {
            $result = $uploader->upload('file', [
                'entity_type' => 'mycomp_item',
                'entity_id'   => $entityId,
                'user_id'     => (int)$this->cms_user->id,
                'preset'      => 'mycomp_default',
            ]);

            if (!$result['success']) {
                cmsUser::addSessionMessage($result['error'], 'error');
                return $this->redirectToAction('upload');
            }

            // 6. Создание записи в cms_attachments (если не сделано в uploader)
            $attachmentId = $this->model->saveAttachment($result, [
                'entity_type' => 'mycomp_item',
                'entity_id'   => $entityId,
                'user_id'     => (int)$this->cms_user->id,
            ]);

            // 7. Хук — другие компоненты могут отреагировать
            cmsEventsManager::hook('mycomp_after_file_upload', [
                'attachment_id' => $attachmentId,
                'entity_id'     => $entityId,
                'user_id'       => (int)$this->cms_user->id,
                'file'          => $result,
            ]);

            cmsUser::addSessionMessage('Файл загружен', 'success');

            return $this->redirectToAction('item', [$entityId]);

        } catch (\Throwable $e) {
            error_log('[mycomp.upload] ' . $e->getMessage());
            cmsUser::addSessionMessage('Не удалось загрузить файл', 'error');
            return $this->redirectToAction('upload');
        }
    }

    private function renderUploadForm() {
        return $this->render('upload_form', [
            'items'       => $this->model->getItemsForUser((int)$this->cms_user->id),
            'max_size_mb' => round(cmsConfig::get('upload.max_file_size') / 1024 / 1024),
        ]);
    }
}
```

### 53.6.3. Реализация `cmsUploader::upload()`

**Файл:** `/system/core/uploader.php`

```php
<?php
declare(strict_types=1);

class cmsUploader {

    private static ?self $instance = null;

    public static function getInstance(): self {
        return self::$instance ??= new self();
    }

    /**
     * Загрузка одного файла.
     *
     * @param string $fieldName Имя поля в $_FILES
     * @param array  $options   Опции (entity_type, entity_id, user_id, preset)
     * @return array ['success' => bool, 'file' => array|null, 'error' => string|null]
     */
    public function upload(string $fieldName, array $options = []): array {
        // 1. Проверка наличия
        if (!isset($_FILES[$fieldName])) {
            return ['success' => false, 'error' => 'Файл не передан'];
        }

        $file = $_FILES[$fieldName];

        // 2. Ошибки PHP
        if ($file['error'] !== UPLOAD_ERR_OK) {
            return [
                'success' => false,
                'error'   => $this->getUploadErrorMessage($file['error']),
            ];
        }

        // 3. Размер
        $maxSize = (int)cmsConfig::get('upload.max_file_size', 10 * 1024 * 1024);
        if ($file['size'] > $maxSize) {
            return [
                'success' => false,
                'error'   => sprintf('Файл больше %d МБ', round($maxSize / 1024 / 1024)),
            ];
        }

        // 4. Расширение
        $originalName = $file['name'];
        $extension = mb_strtolower(pathinfo($originalName, PATHINFO_EXTENSION));

        $allowed = (array)cmsConfig::get('upload.allowed_extensions', []);
        $forbidden = (array)cmsConfig::get('upload.forbidden_extensions', []);

        if (in_array($extension, $forbidden, true)) {
            return ['success' => false, 'error' => 'Запрещённый тип файла'];
        }
        if (!in_array($extension, $allowed, true)) {
            return ['success' => false, 'error' => 'Недопустимый тип файла'];
        }

        // 5. MIME
        $mime = $this->detectMime($file['tmp_name']);
        if ($mime === false) {
            return ['success' => false, 'error' => 'Не удалось определить тип'];
        }

        // 6. Для изображений — доп. проверки
        $imageInfo = null;
        if (str_starts_with($mime, 'image/') && $mime !== 'image/svg+xml') {
            $imageInfo = @getimagesize($file['tmp_name']);
            if ($imageInfo === false) {
                return ['success' => false, 'error' => 'Файл не является изображением'];
            }

            $maxW = (int)cmsConfig::get('upload.image_max_width', 5000);
            $maxH = (int)cmsConfig::get('upload.image_max_height', 5000);

            if ($imageInfo[0] > $maxW || $imageInfo[1] > $maxH) {
                return [
                    'success' => false,
                    'error'   => sprintf('Изображение больше %dx%d px', $maxW, $maxH),
                ];
            }
        }

        // 7. Безопасное имя
        $safeName = $this->generateSafeName($extension);
        $relativePath = $this->buildRelativePath($extension, $safeName);
        $absolutePath = cmsConfig::get('upload.path') . '/' . $relativePath;

        // 8. Создание директории
        $dir = dirname($absolutePath);
        if (!is_dir($dir) && !mkdir($dir, 0775, true) && !is_dir($dir)) {
            return ['success' => false, 'error' => 'Не удалось создать директорию'];
        }

        // 9. Перемещение
        if (!move_uploaded_file($file['tmp_name'], $absolutePath)) {
            return ['success' => false, 'error' => 'Не удалось сохранить файл'];
        }

        chmod($absolutePath, 0644);

        // 10. Формирование результата
        $result = [
            'success'       => true,
            'file'          => [
                'filename'      => $safeName,
                'original_name' => $originalName,
                'path'          => $relativePath,
                'absolute_path' => $absolutePath,
                'url'           => '/upload/' . $relativePath,
                'mime'          => $mime,
                'size'          => $file['size'],
                'extension'     => $extension,
                'width'         => $imageInfo[0] ?? null,
                'height'        => $imageInfo[1] ?? null,
                'hash'          => hash_file('sha256', $absolutePath),
            ],
        ];

        // 11. Хук — обработка (пресеты, watermark и т.д.)
        $result = cmsEventsManager::hook('uploader_after_upload', $result);

        return $result;
    }

    /**
     * Генерация безопасного имени.
     */
    private function generateSafeName(string $extension): string {
        return date('Ymd_His') . '_' . bin2hex(random_bytes(8)) . '.' . $extension;
    }

    /**
     * Построение относительного пути: {type}/{Y}/{m}/{name}
     */
    private function buildRelativePath(string $extension, string $safeName): string {
        $type = $this->classifyExtension($extension);
        $year = date('Y');
        $month = date('m');

        return "{$type}/{$year}/{$month}/{$safeName}";
    }

    private function classifyExtension(string $ext): string {
        return match (true) {
            in_array($ext, ['jpg', 'jpeg', 'png', 'gif', 'webp', 'avif', 'svg'], true) => 'images',
            in_array($ext, ['mp4', 'webm', 'mov'], true) => 'video',
            in_array($ext, ['mp3', 'ogg', 'wav'], true) => 'audio',
            in_array($ext, ['pdf', 'doc', 'docx', 'xls', 'xlsx', 'odt', 'ods', 'txt'], true) => 'files',
            default => 'other',
        };
    }

    private function detectMime(string $path): string|false {
        if (function_exists('finfo_open')) {
            $finfo = finfo_open(FILEINFO_MIME_TYPE);
            $mime = finfo_file($finfo, $path);
            finfo_close($finfo);
            return $mime;
        }
        return mime_content_type($path);
    }

    private function getUploadErrorMessage(int $code): string {
        return match ($code) {
            UPLOAD_ERR_INI_SIZE, UPLOAD_ERR_FORM_SIZE => 'Файл слишком большой',
            UPLOAD_ERR_PARTIAL    => 'Файл загружен частично',
            UPLOAD_ERR_NO_FILE    => 'Файл не выбран',
            UPLOAD_ERR_NO_TMP_DIR => 'Нет временной директории',
            UPLOAD_ERR_CANT_WRITE => 'Ошибка записи',
            UPLOAD_ERR_EXTENSION  => 'Остановлено расширением PHP',
            default               => 'Неизвестная ошибка',
        };
    }
}
```

```php
public function importFromUrl(string $url, array $options = []): array {
    // 1. Валидация URL
    if (!filter_var($url, FILTER_VALIDATE_URL)) {
        return ['success' => false, 'error' => 'Неверный URL'];
    }

    // 2. Проверка схемы (только http/https)
    $scheme = parse_url($url, PHP_URL_SCHEME);
    if (!in_array($scheme, ['http', 'https'], true)) {
        return ['success' => false, 'error' => 'Разрешены только http/https'];
    }

    // 3. Скачивание через Guzzle (см. раздел 28)
    $client = new \GuzzleHttp\Client([
        'timeout'         => 30,
        'connect_timeout' => 10,
        'verify'          => true,
    ]);

    try {
        $resp = $client->get($url, [
            'headers' => [
                'User-Agent' => 'DST-Importer/1.0',
                'Accept'     => 'image/*,application/pdf,*/*;q=0.5',
            ],
            'sink'    => $tmpFile = tempnam(sys_get_temp_dir(), 'dst_import_'),
        ]);
    } catch (\Exception $e) {
        return ['success' => false, 'error' => 'Не удалось скачать файл: ' . $e->getMessage()];
    }

    // 4. Проверка размера (после скачивания)
    $size = filesize($tmpFile);
    $maxSize = (int)cmsConfig::get('upload.max_file_size');
    if ($size > $maxSize) {
        unlink($tmpFile);
        return ['success' => false, 'error' => 'Файл слишком большой'];
    }

    // 5. Эмуляция $_FILES
    $_FILES['imported'] = [
        'name'     => basename(parse_url($url, PHP_URL_PATH)) ?: 'imported',
        'tmp_name' => $tmpFile,
        'size'     => $size,
        'error'    => UPLOAD_ERR_OK,
        'type'     => $resp->getHeaderLine('Content-Type'),
    ];

    // 6. Загрузка через uploader
    $result = cmsUploader::getInstance()->upload('imported', $options);

    @unlink($tmpFile);

    return $result;
}
```

## 53.12. Ресайз (resize, crop, fit, fill)

### 53.12.1. Режимы

| Режим | Что делает | Когда |
|---|---|---|
| **`resize`** | Масштабирует до указанной ширины/высоты, сохраняя пропорции. Может быть меньше или больше | Универсальный |
| **`crop`** | Обрезает по центру до точных размеров | Аватары, миниатюры |
| **`fit`** | Вписывает в рамку, сохраняя пропорции. Пустоты — фон | Товары (без обрезки) |
| **`fill`** | Заполняет рамку, обрезая лишнее | Баннеры |

### 53.12.2. Реализация `ImageProcessor`

**Файл:** `/system/controllers/images/libs/ImageProcessor.php`

```php
<?php
declare(strict_types=1);

class ImageProcessor {

    private string $sourcePath;
    private ?\GdImage $image = null;
    private int $width;
    private int $height;
    private string $mime;

    public function __construct(string $sourcePath) {
        if (!file_exists($sourcePath)) {
            throw new \RuntimeException("File not found: {$sourcePath}");
        }

        $this->sourcePath = $sourcePath;
        $this->load();
    }

    private function load(): void {
        $info = getimagesize($this->sourcePath);
        if ($info === false) {
            throw new \RuntimeException('Invalid image');
        }

        $this->width = $info[0];
        $this->height = $info[1];
        $this->mime = $info['mime'];

        $this->image = match ($this->mime) {
            'image/jpeg' => imagecreatefromjpeg($this->sourcePath),
            'image/png'  => imagecreatefrompng($this->sourcePath),
            'image/gif'  => imagecreatefromgif($this->sourcePath),
            'image/webp' => imagecreatefromwebp($this->sourcePath),
            default      => throw new \RuntimeException("Unsupported mime: {$this->mime}"),
        };

        if ($this->image === false) {
            throw new \RuntimeException('Failed to load image');
        }
    }

    /**
     * Ресайз с сохранением пропорций.
     */
    public function resize(int $targetWidth, int $targetHeight, bool $upscale = false): self {
        if (!$upscale && $this->width <= $targetWidth && $this->height <= $targetHeight) {
            return $this; // не увеличиваем
        }

        $ratio = min($targetWidth / $this->width, $targetHeight / $this->height);
        $newWidth  = (int)round($this->width * $ratio);
        $newHeight = (int)round($this->height * $ratio);

        return $this->doResize($newWidth, $newHeight);
    }

    /**
     * Crop по центру.
     */
    public function crop(int $targetWidth, int $targetHeight): self {
        $srcRatio = $this->width / $this->height;
        $dstRatio = $targetWidth / $targetHeight;

        if ($srcRatio > $dstRatio) {
            // Источник шире — обрезаем по бокам
            $newHeight = $this->height;
            $newWidth = (int)round($this->height * $dstRatio);
            $srcX = (int)round(($this->width - $newWidth) / 2);
            $srcY = 0;
        } else {
            // Источник выше — обрезаем сверху/снизу
            $newWidth = $this->width;
            $newHeight = (int)round($this->width / $dstRatio);
            $srcX = 0;
            $srcY = (int)round(($this->height - $newHeight) / 2);
        }

        $dst = imagecreatetruecolor($targetWidth, $targetHeight);
        $this->preserveAlpha($dst);

        imagecopyresampled(
            $dst, $this->image,
            0, 0, $srcX, $srcY,
            $targetWidth, $targetHeight,
            $newWidth, $newHeight
        );

        $this->image = $dst;
        $this->width = $targetWidth;
        $this->height = $targetHeight;

        return $this;
    }

    /**
     * Fit — вписать в рамку, сохраняя пропорции. Пустоты — фон.
     */
    public function fit(int $targetWidth, int $targetHeight, string $background = '#FFFFFF'): self {
        $dst = imagecreatetruecolor($targetWidth, $targetHeight);

        // Заливка фоном
        $bgColor = $this->hexToRgb($background);
        $bg = imagecolorallocate($dst, $bgColor[0], $bgColor[1], $bgColor[2]);
        imagefill($dst, 0, 0, $bg);

        $ratio = min($targetWidth / $this->width, $targetHeight / $this->height);
        $newWidth  = (int)round($this->width * $ratio);
        $newHeight = (int)round($this->height * $ratio);
        $dstX = (int)round(($targetWidth - $newWidth) / 2);
        $dstY = (int)round(($targetHeight - $newHeight) / 2);

        imagecopyresampled(
            $dst, $this->image,
            $dstX, $dstY, 0, 0,
            $newWidth, $newHeight,
            $this->width, $this->height
        );

        $this->image = $dst;
        $this->width = $targetWidth;
        $this->height = $targetHeight;

        return $this;
    }

    /**
     * Fill — заполнить рамку с обрезкой.
     */
    public function fill(int $targetWidth, int $targetHeight): self {
        $ratio = max($targetWidth / $this->width, $targetHeight / $this->height);

        $scaledWidth  = (int)round($this->width * $ratio);
        $scaledHeight = (int)round($this->height * $ratio);

        $this->doResize($scaledWidth, $scaledHeight);

        return $this->crop($targetWidth, $targetHeight);
    }

    private function doResize(int $newWidth, int $newHeight): self {
        $dst = imagecreatetruecolor($newWidth, $newHeight);
        $this->preserveAlpha($dst);

        imagecopyresampled(
            $dst, $this->image,
            0, 0, 0, 0,
            $newWidth, $newHeight,
            $this->width, $this->height
        );

        $this->image = $dst;
        $this->width = $newWidth;
        $this->height = $newHeight;

        return $this;
    }

    private function preserveAlpha(\GdImage $image): void {
        if (in_array($this->mime, ['image/png', 'image/webp', 'image/gif'], true)) {
            imagealphablending($image, false);
            imagesavealpha($image, true);
            $transparent = imagecolorallocatealpha($image, 255, 255, 255, 127);
            imagefilledrectangle($image, 0, 0, imagesx($image), imagesy($image), $transparent);
            imagealphablending($image, true);
        }
    }

    private function hexToRgb(string $hex): array {
        $hex = ltrim($hex, '#');
        return [
            hexdec(substr($hex, 0, 2)),
            hexdec(substr($hex, 2, 2)),
            hexdec(substr($hex, 4, 2)),
        ];
    }

    /**
     * Сохранение в файл.
     */
    public function save(string $path, string $format = 'jpeg', int $quality = 85): bool {
        $dir = dirname($path);
        if (!is_dir($dir)) {
            mkdir($dir, 0775, true);
        }

        return match ($format) {
            'jpeg', 'jpg' => imagejpeg($this->image, $path, $quality),
            'png'         => imagepng($this->image, $path, 9),
            'webp'        => imagewebp($this->image, $path, $quality),
            'avif'        => function_exists('imageavif')
                ? imageavif($this->image, $path, $quality)
                : false,
            'gif'         => imagegif($this->image, $path),
            default       => false,
        };
    }

    public function __destruct() {
        if ($this->image instanceof \GdImage) {
            imagedestroy($this->image);
        }
    }
}
```

```php
public function addImageWatermark(string $watermarkPath, array $options = []): self {
    if (!file_exists($watermarkPath)) {
        return $this;
    }

    $watermark = imagecreatefrompng($watermarkPath);
    if ($watermark === false) {
        return $this;
    }

    $wmWidth  = imagesx($watermark);
    $wmHeight = imagesy($watermark);

    imagealphablending($scaled, false);
    imagesavealpha($scaled, true);
    imagecopyresampled($scaled, $watermark, 0, 0, 0, 0,
        $newWmWidth, $newWmHeight, $wmWidth, $wmHeight);

    $position = $options['position'] ?? 'bottom-right';
    $padding = $options['padding'] ?? 20;

    [$x, $y] = $this->calculatePosition(
        $this->width, $this->height,
        $newWmWidth, $newWmHeight,
        $position, $padding
    );

    imagecopy($this->image, $scaled, $x, $y, 0, 0, $newWmWidth, $newWmHeight);

    imagedestroy($watermark);
    imagedestroy($scaled);

    return $this;
}
```

## 53.14. Фильтры (grayscale, blur, sharpen)

### 53.14.1. Реализация

```php
public function applyFilter(string $filter): self {
    switch ($filter) {
        case 'grayscale':
            imagefilter($this->image, IMG_FILTER_GRAYSCALE);
            break;
        case 'blur':
            imagefilter($this->image, IMG_FILTER_GAUSSIAN_BLUR);
            break;
        case 'sharpen':
            // Не встроено в GD — эмуляция через convolution
            $matrix = [
                [-1, -1, -1],
                [-1, 16, -1],
                [-1, -1, -1],
            ];
            imageconvolution($this->image, $matrix, 8, 0);
            break;
        case 'brightness':
            imagefilter($this->image, IMG_FILTER_BRIGHTNESS, 20);
            break;
        case 'contrast':
            imagefilter($this->image, IMG_FILTER_CONTRAST, -20);
            break;
        case 'sepia':
            imagefilter($this->image, IMG_FILTER_GRAYSCALE);
            imagefilter($this->image, IMG_FILTER_COLORIZE, 90, 60, 30);
            break;
        case 'vintage':
            imagefilter($this->image, IMG_FILTER_GRAYSCALE);
            imagefilter($this->image, IMG_FILTER_BRIGHTNESS, 20);
            imagefilter($this->image, IMG_FILTER_COLORIZE, 50, 30, -20);
            break;
    }

    return $this;
}
```

## 53.15. Конвертация форматов (WebP, AVIF)

### 53.15.1. Поддержка форматов

| Формат | GD (PHP 7.4+) | Imagick | Браузеры |
|---|---|---|---|
| **JPEG** | ✅ | ✅ | Все |
| **PNG** | ✅ | ✅ | Все |
| **WebP** | ✅ (PHP 7.1+) | ✅ | 95 %+ |
| **AVIF** | ✅ (PHP 8.1+) | ✅ (libheif) | 85 %+ |
| **JPEG XL** | ❌ | ⚠️ | <10 % |

**Проверка поддержки:**

```php
if (function_exists('imageavif')) {
    // AVIF поддерживается
}

$gdInfo = gd_info();
if ($gdInfo['WebP Support']) {
    // WebP поддерживается
}
```

### 53.15.2. Автоматический формат (`format: auto`)

```php
public function detectBestFormat(): string {
    // Если AVIF поддерживается и клиент его принимает
    if (function_exists('imageavif') && $this->acceptsFormat('image/avif')) {
        return 'avif';
    }

    // WebP
    if (function_exists('imagewebp') && $this->acceptsFormat('image/webp')) {
        return 'webp';
    }

    // Fallback — JPEG
    return 'jpeg';
}

private function acceptsFormat(string $mime): bool {
    $accept = $_SERVER['HTTP_ACCEPT'] ?? '';
    return str_contains($accept, $mime);
}
```

> 💡 **Осторожно.** `Accept` — ненадёжный сигнал (браузер может поддерживать AVIF, но не заявить об этом). Используйте `<picture>` с `<source type="image/avif">` — браузер сам выберет поддерживаемый формат (см. 53.24).

### 53.16.2. Post-обработка

```php
public function optimizeFile(string $path, string $format): void {
    switch ($format) {
        case 'jpeg':
            // Lossless-оптимизация
            exec("jpegoptim --strip-all --all-progressive " . escapeshellarg($path));
            break;

        case 'png':
            // Lossy (если допустимо) + lossless
            exec("pngquant --quality=65-80 --strip --force --output " .
                 escapeshellarg($path) . " " . escapeshellarg($path));
            exec("oxipng -o 4 --strip safe " . escapeshellarg($path));
            break;

        case 'webp':
            // Уже оптимизирован при сохранении
            break;

        case 'avif':
            // Уже оптимизирован
            break;
    }
}
```

### 53.16.3. Безопасность `exec`

> ⚠️ **Никогда не передавайте пользовательский ввод в `exec`.** Используйте `escapeshellarg()` для всех аргументов. Ещё лучше — `proc_open` с массивом аргументов (без shell).

```php
// ✅ Безопасно
exec("jpegoptim " . escapeshellarg($path));

// ✅ Ещё безопаснее
$process = proc_open(
    ['jpegoptim', '--strip-all', $path],
    [1 => ['pipe', 'w'], 2 => ['pipe', 'w']],
    $pipes
);
```

## 53.17. EXIF и метаданные

### 53.17.1. Проблема

Смартфоны сохраняют в EXIF:

- GPS-координаты (приватность!).
- Модель камеры.
- Дату съёмки.
- Ориентацию (iPhone снимает «боком»).

### 53.17.2. Ориентация

```php
public function fixOrientation(): self {
    if (!function_exists('exif_read_data')) {
        return $this;
    }

    $exif = @exif_read_data($this->sourcePath);
    if ($exif === false) {
        return $this;
    }

    $orientation = $exif['Orientation'] ?? 1;

    $this->image = match ($orientation) {
        3 => imagerotate($this->image, 180, 0),
        6 => imagerotate($this->image, -90, 0),
        8 => imagerotate($this->image, 90, 0),
        default => $this->image,
    };

    // Обновление размеров
    $this->width = imagesx($this->image);
    $this->height = imagesy($this->image);

    return $this;
}
```

### 53.17.3. Удаление EXIF

```php
public function stripExif(string $path): void {
```

### 53.17.4. Чтение метаданных

```php
public function extractMetadata(string $path): array {
    $meta = [
        'width'      => null,
        'height'     => null,
        'orientation' => null,
        'camera'     => null,
        'date_taken' => null,
        'gps'        => null,
    ];

    $info = @getimagesize($path);
    if ($info) {
        $meta['width']  = $info[0];
        $meta['height'] = $info[1];
    }

    if (function_exists('exif_read_data') && preg_match('/\.jpe?g$/i', $path)) {
        $exif = @exif_read_data($path);
        if ($exif) {
            $meta['orientation'] = $exif['Orientation'] ?? null;
            $meta['camera'] = trim(($exif['Make'] ?? '') . ' ' . ($exif['Model'] ?? ''));
            $meta['date_taken'] = $exif['DateTimeOriginal'] ?? null;
            if (!empty($exif['GPSLatitude'])) {
                $meta['gps'] = [
                    'lat' => $this->gpsToDecimal($exif['GPSLatitude'], $exif['GPSLatitudeRef'] ?? 'N'),
                    'lon' => $this->gpsToDecimal($exif['GPSLongitude'], $exif['GPSLongitudeRef'] ?? 'E'),
                ];
            }
        }
    }

    return $meta;
}
```

## 53.20. Связь с сущностями (entity_type, entity_id)

### 53.20.1. Соглашение по `entity_type`

```
{component}_{entity}
```

| Значение | Компонент | Сущность |
|---|---|---|
| `shop_product` | shop | Товар |
| `shop_category` | shop | Категория товаров |
| `partner_avatar` | partner | Аватар продавца |
| `user_avatar` | users | Аватар пользователя |
| `content_item` | content | Запись контента |
| `content_category` | content | Категория контента |
| `mycomp_item` | mycomp | Элемент mycomp |

### 53.20.2. Правила

1. **Слабая связанность.** `entity_type` — строка, не FK. Компонент может быть отключён — записи остаются.
2. **Один тип — один компонент.** Не используйте `entity_type = 'image'` — непонятно, к чему относится.
3. **`is_primary`** — только один на `(entity_type, entity_id)`. Обеспечивается на уровне кода (или триггером).

### 53.20.3. Гарантия единственного `is_primary`

```php
public function setPrimary(int $attachmentId): void {
    $attachment = $this->getItem('cms_attachments', $attachmentId);
    if (!$attachment) {
        return;
    }

    $this->beginTransaction();

    try {
        // Снять флаг со всех
        $this->query("
            UPDATE cms_attachments
            SET is_primary = 0
            WHERE entity_type = ? AND entity_id = ?
        ", [$attachment['entity_type'], $attachment['entity_id']]);

        // Установить на выбранный
        $this->update('cms_attachments', $attachmentId, ['is_primary' => 1]);

        $this->commit();

    } catch (\Throwable $e) {
        $this->rollback();
        throw $e;
    }
}
```

```php
class LocalStorage implements StorageInterface {

class S3Storage implements StorageInterface {
    private \Aws\S3\S3Client $client;
    private string $bucket;

    public function __construct(array $config) {
        $this->client = new \Aws\S3\S3Client([
            'version'     => 'latest',
            'region'      => $config['region'],
            'endpoint'    => $config['endpoint'],
            'credentials' => [

                'Key'         => $path,
                'SourceFile'  => $localPath,
                'ContentType' => mime_content_type($localPath),
                'ACL'         => 'public-read',
                'CacheControl' => 'public, max-age=31536000, immutable',
            ]);
            return true;
        } catch (\Throwable $e) {
            error_log('[S3] ' . $e->getMessage());
            return false;
        }
    }

    public function url(string $path): string {
        return cmsConfig::get('storage.s3.public_url') . '/' . $path;
    }
    // ...
}
```

### 53.22.2. Приватные файлы

Некоторые файлы (документы, медицинские карты) не должны быть публично доступны.

**Стратегия 1: вне `webroot`.**

```
/var/www/dst-private/
└── uploads/
    └── medical_records/...
```

Отдача — через PHP-контроллер:

```php
public function actionDownload(string $token) {
    $attachment = $this->model->findByToken($token);
    if (!$attachment) {
        return $this->error404();
    }

    // Проверка прав
    if (!$this->canAccess($attachment)) {
        return $this->error403();
    }

    $path = cmsConfig::get('private_upload.path') . '/' . $attachment['path'];

    header('Content-Type: ' . $attachment['mime_type']);
    header('Content-Disposition: attachment; filename="' . $attachment['original_name'] . '"');
    header('Content-Length: ' . filesize($path));
    header('X-Content-Type-Options: nosniff');

    readfile($path);
    exit;
}
```

**Стратегия 2: `X-Accel-Redirect` (Nginx).**

```php
public function actionDownload(string $token) {

    header('Content-Type: ' . $attachment['mime_type']);
    header('Content-Disposition: attachment; filename="' . $attachment['original_name'] . '"');
    header('X-Accel-Redirect: /private-uploads/' . $attachment['path']);

}
```

```nginx
location /private-uploads/ {

}
```

Преимущество: Nginx отдаёт файл, PHP не тратит память.

## 53.23. Lazy loading и `loading="lazy"`

### 53.23.1. Базовое

```html
<img src="/upload/images/product_list/abc.webp"
     alt="Название товара"
     width="300"
     height="300"
     loading="lazy">
```

**Что даёт:**

- Браузер не загружает изображение, пока оно не приблизится к viewport.
- Экономия трафика: 40–60 % на длинных страницах.

**Когда НЕ использовать `loading="lazy"`:**

- Первое изображение «above the fold» (LCP) — замедлит загрузку.
- Логотип в шапке.

### 53.23.2. `fetchpriority="high"` для LCP

```html
     height="800"
```

## 53.24. `srcset` и `<picture>`

### 53.24.1. `srcset` (адаптивность по ширине)

```html
<img src="/upload/images/product_list/abc.jpg"
     srcset="/upload/images/product_list/abc-300.webp 300w,
             /upload/images/product_list/abc-600.webp 600w,
             /upload/images/product_list/abc-900.webp 900w"
     sizes="(max-width: 600px) 100vw,
            (max-width: 1200px) 50vw,
            33vw"
     alt="Товар"
     width="300"
     height="300"
     loading="lazy">
```

**Как работает:**

1. Браузер вычисляет слот (`sizes`).
2. Выбирает подходящий размер из `srcset`.

**Файл:** `/templates/default/assets/helpers/image.tpl.php`

```php
<?php
/**
 * Хелпер: генерация <picture> с пресетами.
 *
 * @param array  $attachment Метаданные из cms_attachments
 * @param string $preset     Имя пресета
 * @param string $alt        Alt-текст
 * @param array  $attrs      Доп. атрибуты
 */
function render_image(array $attachment, string $preset, string $alt = '', array $attrs = []): string {
    $baseUrl = '/upload/' . dirname($attachment['presets'][$preset] ?? $attachment['path']);
    $filename = pathinfo($attachment['presets'][$preset] ?? $attachment['path'], PATHINFO_FILENAME);

    $formats = [
        'avif' => "{$baseUrl}/{$filename}.avif",
        'webp' => "{$baseUrl}/{$filename}.webp",
        'jpg'  => "{$baseUrl}/{$filename}.jpg",
    ];

    $attrsStr = '';
    foreach ($attrs as $k => $v) {
        $attrsStr .= ' ' . $k . '="' . htmlspecialchars((string)$v, ENT_QUOTES) . '"';
    }

    $html = '<picture>';
    foreach (['avif', 'webp'] as $format) {
        if (file_exists(PATH . '/upload/' . $attachment['presets'][$preset])) {
            // Проверка существования — упрощённо; лучше через CDN head
            $html .= '<source type="image/' . $format . '" srcset="' . htmlspecialchars($formats[$format]) . '">';
        }
    }
    $html .= '<img src="' . htmlspecialchars($formats['jpg']) . '"
                   alt="' . htmlspecialchars($alt, ENT_QUOTES) . '"
                   width="' . ($attachment['width'] ?? '') . '"
                   height="' . ($attachment['height'] ?? '') . '"
                   loading="lazy"
                   ' . $attrsStr . '>';
    $html .= '</picture>';

    return $html;
}

// Использование в шаблоне:

    'class' => 'product-image',
]);
?>
```

## 53.25. Современные форматы (WebP, AVIF)

### 53.25.1. Экономия

| Формат | Размер (относительно JPEG) | Поддержка |
|---|---|---|
| **JPEG** | 100 % | 100 % |
| **WebP** | 25–35 % | 95 %+ |
| **AVIF** | 15–25 % | 85 %+ |

**Пример:** JPEG 200 КБ → WebP 60 КБ → AVIF 40 КБ.

### 53.25.2. Генерация (см. 53.15)

Для каждого пресета — генерируйте все три формата:

```

├── abc.jpg     (fallback)
├── abc.webp    (95 %)
└── abc.avif    (85 %)
```

### 53.25.3. Nginx — выбор формата по `Accept`

```nginx
# Автоматическая отдача WebP/AVIF, если клиент поддерживает
map $http_accept $webp_suffix {
    default "";
    "~*webp" ".webp";
}
map $http_accept $avif_suffix {
    default "";
    "~*avif" ".avif";
}

              /upload/images/$1.webp$is_args$args
```

## 53.26. Кэширование (HTTP, Nginx, CDN)

### 53.26.1. HTTP-заголовки


```php
public function getPrimaryAttachments(string $entityType, array $entityIds): array {
    if (empty($entityIds)) {
        return [];

    $rows = $this->query("

        WHERE entity_type = ?
          AND entity_id IN ($placeholders)
```

```php
public function getPrimaryAttachment(string $entityType, int $entityId): ?array {

        WHERE entity_type = ? AND entity_id = ? AND is_primary = 1
```

## 53.31. Применение пресета

### 53.31.1. При загрузке

**Хук `uploader_after_upload`** (в компоненте `images`):

```php
class images extends cmsAction {

    public function hookUploaderAfterUpload(array $result): array {
        if (!$result['success']) {
            return $result;
        }

        $file = $result['file'];

        // Только изображения
        if (!str_starts_with($file['mime'], 'image/')) {
            return $result;
        }

        // Сохраняем оригинал
        $originalPath = cmsConfig::get('upload.path') . '/images/original/'
            . date('Y/m/') . $file['filename'];

        // Копируем из upload
        $currentPath = $file['absolute_path'];
        $originalDir = dirname($originalPath);
        if (!is_dir($originalDir)) {
            mkdir($originalDir, 0775, true);
        }
        rename($currentPath, $originalPath);

        $file['path'] = 'images/original/' . date('Y/m/') . $file['filename'];

        // Генерируем пресеты
        $presets = $this->model->getPresets();
        $generated = [];

        foreach ($presets as $presetName => $config) {
            $presetPath = $this->generatePreset($originalPath, $presetName, $config);
            if ($presetPath) {
                $generated[$presetName] = $presetPath;
            }
        }

        $file['presets'] = $generated;

        $result['file'] = $file;

        return $result;
    }

    private function generatePreset(string $source, string $presetName, array $config): ?string {
        try {
            $processor = new ImageProcessor($source);

            // Применение режима
            match ($config['mode']) {
                'resize' => $processor->resize($config['width'], $config['height'], $config['upscale'] ?? false),
                'crop'   => $processor->crop($config['width'], $config['height']),
                'fit'    => $processor->fit($config['width'], $config['height'], $config['background'] ?? '#FFFFFF'),
                'fill'   => $processor->fill($config['width'], $config['height']),
                default  => throw new \RuntimeException("Unknown mode: {$config['mode']}"),
            };

            // Фильтры
            foreach ($config['filters'] ?? [] as $filter) {
                $processor->applyFilter($filter);
            }

            // Watermark
            if (!empty($config['watermark'])) {
                $wm = $config['watermark'];
                if (($wm['type'] ?? '') === 'text') {
                    $processor->addTextWatermark($wm['text'] ?? '', $wm);
                } elseif (($wm['type'] ?? '') === 'image') {
                    $processor->addImageWatermark($wm['path'] ?? '', $wm);
                }
            }

            // Сохранение
            $format = $config['format'] ?? 'webp';
            $quality = $config['quality'] ?? 85;
            $ext = $format === 'jpeg' ? 'jpg' : $format;
            $filename = pathinfo($source, PATHINFO_FILENAME) . '.' . $ext;
            $destPath = cmsConfig::get('upload.path') . "/images/{$presetName}/"
                . date('Y/m/') . $filename;

            if (!$processor->save($destPath, $format, $quality)) {
                return null;
            }

            return "images/{$presetName}/" . date('Y/m/') . $filename;

        } catch (\Throwable $e) {
            error_log("[images.generatePreset] {$presetName}: " . $e->getMessage());
            return null;
        }
    }
}
```

### 53.32.1. Когда нужно

- Обновлена библиотека обработки.

### 53.32.2. Скрипт регенерации

**Файл:** `/scripts/regenerate_presets.php`

```php
<?php
declare(strict_types=1);

require_once __DIR__ . '/../bootstrap.php';

$presetName = $argv[1] ?? null;
$batchSize = 100;
$offset = 0;
$total = 0;
$errors = 0;

$db = cmsDatabase::getInstance();

// Если пресет не указан — все
$presets = $presetName
    ? [$presetName => (include PATH . "/system/controllers/images/presets/{$presetName}.php")]
    : (new modelImages())->getPresets();

echo "Regenerating " . count($presets) . " preset(s)...\n";

do {
    $rows = $db->query("
        SELECT * FROM cms_attachments
        WHERE mime_type LIKE 'image/%'
        ORDER BY id
        LIMIT ? OFFSET ?
    ", [$batchSize, $offset])->getRows();

    foreach ($rows as $row) {
        $originalPath = cmsConfig::get('upload.path') . '/' . $row['path'];

        if (!file_exists($originalPath)) {
            error_log("[regenerate] Missing original: {$originalPath}");
            $errors++;
            continue;
        }

        $generated = [];

        foreach ($presets as $name => $config) {
            try {
                $processor = new ImageProcessor($originalPath);

                match ($config['mode']) {
                    'resize' => $processor->resize($config['width'], $config['height'], $config['upscale'] ?? false),
                    'crop'   => $processor->crop($config['width'], $config['height']),
                    'fit'    => $processor->fit($config['width'], $config['height'], $config['background'] ?? '#FFFFFF'),
                    'fill'   => $processor->fill($config['width'], $config['height']),
                };

                foreach ($config['filters'] ?? [] as $filter) {
                    $processor->applyFilter($filter);
                }

                if (!empty($config['watermark'])) {
                    $wm = $config['watermark'];
                    if ($wm['type'] === 'text') {
                        $processor->addTextWatermark($wm['text'] ?? '', $wm);
                    } else {
                        $processor->addImageWatermark($wm['path'] ?? '', $wm);
                    }
                }

                $format = $config['format'] ?? 'webp';
                $ext = $format === 'jpeg' ? 'jpg' : $format;
                $filename = pathinfo($originalPath, PATHINFO_FILENAME) . '.' . $ext;
                $destPath = cmsConfig::get('upload.path') . "/images/{$name}/"
                    . date('Y/m', strtotime($row['created_at'])) . '/' . $filename;

                if ($processor->save($destPath, $format, $config['quality'] ?? 85)) {
                    $generated[$name] = "images/{$name}/"
                        . date('Y/m', strtotime($row['created_at'])) . '/' . $filename;
                }

            } catch (\Throwable $e) {
                error_log("[regenerate] {$name}: " . $e->getMessage());
                $errors++;
            }
        }

        $db->update('cms_attachments', $row['id'], [
            'presets' => json_encode($generated, JSON_UNESCAPED_UNICODE),
        ]);

        $total++;
    }

    $offset += $batchSize;
    echo "Processed: $total, errors: $errors\n";

} while (count($rows) === $batchSize);

echo "=== Done. Total: $total, errors: $errors ===\n";
```

**Запуск:**

```bash

# Регенерация всех
php scripts/regenerate_presets.php
```

> ⚠️ **Регенерация — тяжёлая операция.** Для 1M изображений — часы. Запускайте в off-peak, батчами, с логированием.

```php
        } catch (\Throwable $e) {
            error_log('[images.upload] ' . $e->getMessage());
            return $this->error(1, 'Не удалось загрузить файл');
        }

        // 4. Сохранение в cms_attachments
        try {
            $attachmentId = $this->model->saveAttachment($result['file'], [
                'entity_type' => $entityType,
                'entity_id'   => $entityId,
                'created_by'  => (int)$this->cms_user->id,
            ]);
        } catch (\Throwable $e) {
            error_log('[images.upload] ' . $e->getMessage());
            return $this->error(1, 'Не удалось сохранить метаданные');
        }

        // 5. Формирование ответа
        $attachment = $this->model->getItem('cms_attachments', $attachmentId);
        $presets = json_decode($attachment['presets'] ?? '{}', true);

        $response = [
            'id'            => (int)$attachment['id'],
            'url'           => '/upload/' . $attachment['path'],
            'mime'          => $attachment['mime_type'],
            'size'          => (int)$attachment['size'],
            'width'         => (int)$attachment['width'],
            'height'        => (int)$attachment['height'],
            'original_name' => $attachment['original_name'],
            'presets'       => array_map(
                fn($path) => '/upload/' . $path,
                $presets
            ),
        ];

        // 6. Идемпотентность
        $this->model->saveIdempotentResult(
            $idempotencyKey,
            $response,
            (int)$this->cms_user->id,
            86400
        );

        $this->controller->output_success = $response;

        return true;
    }
}
```

# Часть VIII. Безопасность

## 53.36. Валидация типов

См. 53.5.2 и раздел 42.5. Ключевые проверки:

| Проверка | Функция | Риск при пропуске |
|---|---|---|
| **Расширение** | `pathinfo($name, PATHINFO_EXTENSION)` + белый список | `.php` попадёт в `/upload/` |
| **MIME** | `finfo_file()` | `.exe`, переименованный в `.jpg` |
| **Содержимое** | `getimagesize()` для изображений | «Изображение» с шелл-кодом |
| **Размер** | `$_FILES['size']` + `filesize()` | DoS через гигантский файл |
| **Размеры** | `getimagesize()` | DoS через декодирование 100000×100000 |

## 53.37. Защита от malicious-файлов

### 53.37.1. Полиглот-файлы

Файл может быть одновременно валидным JPEG и PHP:

```
FF D8 FF E0 ... <?php system($_GET['c']); ?> ... FF D9
```

**Защита:**

1. **Не полагаться на MIME** — `finfo_file()` тоже обманывается.
2. **Проверять структуру** — `getimagesize()` вернёт `false` для полиглотов.
3. **Пересохранять** — если пересохранить через `imagejpeg`, PHP-код удалится:

```php
// После загрузки — пересохранить
$img = imagecreatefromjpeg($path);
imagejpeg($img, $path, 90);
imagedestroy($img);
// PHP-код из EXIF/комментариев удалён
```

4. **Хранить вне webroot** (см. 53.22.2).

### 53.37.2. SVG-инъекции

SVG может содержать JavaScript:

```xml
<svg xmlns="http://www.w3.org/2000/svg">
    <script>alert(document.cookie)</script>
</svg>
```

**Защита:**

1. **Санитизация** через библиотеку (`enshrined/svg-sanitize`).
2. **Или отдавать как `Content-Disposition: attachment`** (не рендерить).
3. **Или запретить SVG** (для пользовательских загрузок).

```php
// Sanitize SVG
use enshrined\svgSanitize\Sanitizer;

$sanitizer = new Sanitizer();
$clean = $sanitizer->sanitize(file_get_contents($svgPath));
file_put_contents($svgPath, $clean);
```

```php
class modelImages extends cmsModel {

    public function processQueue(int $batch = 20): array {
        $stats = ['processed' => 0, 'failed' => 0];

        $items = $this->filterEqual('status', 'pending')
            ->orderBy('id', 'asc')
            ->limit($batch)
            ->get('media_queue');

        foreach ($items as $item) {
            $this->update('media_queue', $item['id'], ['status' => 'processing']);

            try {
                $this->generatePreset($item['attachment_id'], $item['preset_name']);
                $this->update('media_queue', $item['id'], [
                    'status'       => 'done',
                    'processed_at' => date('Y-m-d H:i:s'),

                $stats['processed']++;

            } catch (\Throwable $e) {
                $attempts = $item['attempts'] + 1;
                $this->update('media_queue', $item['id'], [
                    'status'     => $attempts >= 3 ? 'failed' : 'pending',
                    'attempts'   => $attempts,
                    'last_error' => $e->getMessage(),
                ]);
                $stats['failed']++;
            }
        }

        return $stats;
    }
}
```

## 53.47. Очистка «сиротских» файлов

### 53.47.1. Проблема

- Файл загружен, но запись в `cms_attachments` не создана (ошибка).
- Сущность удалена, а файл остался.
- Пресет устарел.

### 53.47.2. Скрипт

**Файл:** `/scripts/cleanup_orphan_files.php`

```php
<?php
declare(strict_types=1);

require_once __DIR__ . '/../bootstrap.php';

$db = cmsDatabase::getInstance();
$dryRun = in_array('--dry-run', $argv);

// 1. Файлы старше 24 часов, которых нет в БД
$files = glob(cmsConfig::get('upload.path') . '/images/original/*/*/*');
$deleted = 0;
$freedBytes = 0;

foreach ($files as $file) {
    if (!is_file($file)) continue;

    // Только старше 24 часов (свежие могут быть в процессе загрузки)
    if (filemtime($file) > time() - 86400) {
        continue;
    }

    $relativePath = str_replace(cmsConfig::get('upload.path') . '/', '', $file);

    $exists = $db->query("
        SELECT 1 FROM cms_attachments WHERE path = ? LIMIT 1
    ", [$relativePath])->getCell();

    if ($exists) {
        continue;
    }

    $size = filesize($file);

    if ($dryRun) {
        echo "[DRY-RUN] Would delete: $relativePath ({$size} bytes)\n";
    } else {
        unlink($file);
        echo "Deleted: $relativePath\n";
    }

    $deleted++;
    $freedBytes += $size;
}

echo "=== " . ($dryRun ? '[DRY-RUN] ' : '') . "Deleted: $deleted files, freed: " . round($freedBytes / 1024 / 1024, 2) . " MB ===\n";

// 2. Записи без файлов (битые)
$rows = $db->query("SELECT id, path FROM cms_attachments")->getRows();
$broken = 0;

foreach ($rows as $row) {
    $path = cmsConfig::get('upload.path') . '/' . $row['path'];
    if (!file_exists($path)) {
        $broken++;
        if (!$dryRun) {
            $db->query("DELETE FROM cms_attachments WHERE id = ?", [$row['id']]);
        }
    }
}

echo "=== " . ($dryRun ? '[DRY-RUN] ' : '') . "Broken records: $broken ===\n";
```

## 53.48. Обновление форматов

### 53.48.1. Миграция JPEG → WebP

```php
// scripts/migrate_to_webp.php
$db = cmsDatabase::getInstance();
$offset = 0;
$batch = 100;

do {
    $rows = $db->query("
        SELECT * FROM cms_attachments
        WHERE mime_type IN ('image/jpeg', 'image/png')

        LIMIT ? OFFSET ?
    ", [$batch, $offset])->getRows();

    foreach ($rows as $row) {
        $originalPath = cmsConfig::get('upload.path') . '/' . $row['path'];

        foreach ($presets as $name => $path) {
            // Если пресет уже WebP — пропускаем
            if (str_ends_with($path, '.webp')) {
                continue;
            }

            $presetPath = cmsConfig::get('upload.path') . '/' . $path;
            if (!file_exists($presetPath)) {
                continue;
            }

            $processor = new ImageProcessor($presetPath);
            $webpPath = preg_replace('/\.(jpe?g|png)$/i', '.webp', $presetPath);

            if ($processor->save($webpPath, 'webp', 85)) {
                $presets[$name . '_webp'] = preg_replace('/\.(jpe?g|png)$/i', '.webp', $path);
            }
        }

        $db->update('cms_attachments', $row['id'], [
            'presets' => json_encode($presets, JSON_UNESCAPED_UNICODE),
        ]);
    }

    $offset += $batch;

} while (count($rows) === $batch);
```

## 53.50. Заключение

Работа с медиафайлами в DST Platform строится на трёх принципах:

1. **Безопасность.** Белый список расширений, проверка MIME и содержимого, запрет исполнения в `/upload/`, санитизация SVG, удаление EXIF.
2. **Производительность.** Пресеты для каждого контекста, современные форматы (WebP, AVIF), lazy loading, `srcset`, CDN, асинхронная генерация.
3. **Масштабируемость.** Хранение в S3 (при росте), регенерация пресетов, очистка сирот, бэкапы.
