# 45. Поддержка PHP и миграция

Данный раздел описывает поддерживаемые версии PHP, системные требования, стратегию миграции и практические рекомендации по обновлению окружения для платформы DST Platform. Информация актуальна для версии платформы 2.0+.

---

## 45.1. Поддерживаемые версии PHP

### Официальная поддержка

| Версия PHP | Статус | Поддержка в DST Platform | Рекомендация |
|------------|--------|--------------------------|--------------|
| **PHP 8.3** | Активная | Полная | Рекомендуется для новых проектов |
| **PHP 8.2** | Активная | Полная | Рекомендуется для продакшена |
| **PHP 8.1** | Активная | Полная | Поддерживается |
| **PHP 8.0** | Поддержка безопасности | Полная | Миграция рекомендуется |
| **PHP 7.4** | EOL (с ноября 2022) | Частичная | Только для устаревших проектов |
| **PHP 7.3 и ниже** | Не поддерживается | Нет | Требуется обновление |

### Минимальные требования

- **Минимальная версия**: PHP 7.4 (только для устаревших проектов)
- **Рекомендуемая версия**: PHP 8.2+
- **Требуемый режим**: `strict_types` рекомендуется для всех новых компонентов

## 45.2. Системные требования и расширения

### Обязательные расширения PHP

| Расширение | Версия | Назначение | Используется в |
|------------|--------|------------|----------------|
| `mbstring` | Любая | Работа с многобайтовыми строками | Ядро, `phpfastcache` |
| `json` | Любая | Кодирование/декодирование JSON | Все SDK, API |
| `curl` | Любая | HTTP-запросы | Guzzle, CDEK, ЮKassa |
| `openssl` | Любая | SSL/TLS для безопасных соединений | Composer, внешние API |
| `libxml` | Любая | Парсинг XML | CDEK SDK, YML-фиды |
| `pdo_mysql` | Любая | Работа с базой данных | Ядро, все модели |
| `gd` | Любая | Обработка изображений | Загрузка файлов, миниатюры |
| `iconv` | Любая | Преобразование кодировок | Ядро, обработка текста |
| `filter` | Любая | Валидация входных данных | `cmsRequest`, безопасность |

### Опциональные расширения (для производительности)

| Расширение | Версия | Выгода | Рекомендация |
|------------|--------|--------|--------------|
| `redis` | 5.3+ | Высокопроизводительное кэширование | Для продакшена с высокой нагрузкой |
| `memcached` | 3.0+ | Распределённое кэширование | Для кластерных конфигураций |

| `igbinary` | 3.0+ | Быстрая сериализация | Для кэширования сложных структур |

### Проверка расширений

```php
<?php
/**
 * check_php_requirements.php
 * Скрипт проверки системных требований
 */

$required_extensions = [
    'mbstring', 'json', 'curl', 'openssl', 'libxml', 
    'pdo_mysql', 'gd', 'iconv', 'filter'
];

$missing_extensions = [];

foreach ($required_extensions as $ext) {
    if (!extension_loaded($ext)) {
        $missing_extensions[] = $ext;
    }
}

if (!empty($missing_extensions)) {
    echo "❌ Отсутствуют обязательные расширения PHP:\n";
    echo implode("\n", $missing_extensions);
    echo "\n\nУстановите расширения через пакетный менеджер:\n";
    echo "sudo apt install php-" . implode(" php-", $missing_extensions) . "\n";
    exit(1);
}

// Проверка версии PHP
$min_version = '7.4.0';
$current_version = PHP_VERSION;

if (version_compare($current_version, $min_version, '<')) {
    echo "❌ Требуется PHP >= {$min_version}, текущая версия: {$current_version}\n";
    exit(1);
}

// Проверка рекомендуемой версии
$recommended_version = '8.2.0';
if (version_compare($current_version, $recommended_version, '<')) {
    echo "⚠️  Рекомендуется обновить PHP до версии >= {$recommended_version}\n";
    echo "Текущая версия: {$current_version}\n\n";
}

echo "✅ Все системные требования выполнены\n";
echo "PHP версия: {$current_version}\n";
echo "Расширения: " . implode(', ', $required_extensions) . "\n";
exit(0);
```

```yaml
name: PHP Compatibility Test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        php: ['7.4', '8.0', '8.1', '8.2', '8.3']
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: ${{ matrix.php }}
          extensions: mbstring, json, curl, openssl, gd, pdo_mysql
          ini-values: memory_limit=512M, max_execution_time=300
          coverage: none
      
      - name: Install dependencies
        run: composer install --no-interaction --prefer-dist --optimize-autoloader
      
      - name: Run PHPStan
        run: vendor/bin/phpstan analyse system/ --level=7
      
      - name: Run PHPUnit tests
        run: vendor/bin/phpunit --testsuite unit
      
      - name: Check PHP compatibility
        run: |
          vendor/bin/phpcs --standard=PHPCompatibility \
            --runtime-set testVersion ${{ matrix.php }} \
            --ignore=*/vendor/*,*/cache/* \
            system/
```

## 45.8. Распространённые проблемы и решения

### Проблемы при миграции на PHP 8.x

| Проблема | Симптом | Решение | Пример исправления |
|----------|---------|---------|-------------------|
| **Изменение порядка параметров** | `TypeError: Argument #1 must be of type string, int given` | Явное приведение типов или изменение порядка | `$id = (int)$request->get('id');` |
| **Устаревшие функции** | `Deprecated: Function create_function() is deprecated` | Замена на анонимные функции | `function($x) { return $x * 2; }` |
| **Изменения в работе `json_encode()`** | `json_encode(): Passing null to parameter #1 is deprecated` | Проверка на null перед кодированием | `json_encode($data ?? [])` |
| **Строгая типизация в сигнатурах** | `TypeError: Return value must be of type string, null returned` | Использование union types или проверка | `public function getTitle(): ?string` |
| **Изменения в работе `unserialize()`** | `unserialize(): Error at offset` | Использование `igbinary` или проверка данных | `igbinary_unserialize($data)` |

### Примеры исправления кода

```php
// ДО (PHP 7.4)
class modelShop extends cmsModel {
    public function getProduct($id) {
        return $this->getItemById('shop_products', $id);
    }
}

// ПОСЛЕ (PHP 8.0+)
class modelShop extends cmsModel {
    public function getProduct(int $id): ?array {
        return $this->getItemById('shop_products', $id);
    }
}

// ДО (устаревшая функция)
$callback = create_function('$x', 'return $x * 2;');

// ПОСЛЕ (анонимная функция)
$callback = fn($x) => $x * 2;

// ДО (небезопасная работа с null)
$json = json_encode($data);

// ПОСЛЕ (безопасная работа с null)
$json = json_encode($data ?? [], JSON_THROW_ON_ERROR);
```

## 45.10. Практические примеры миграции

### Пример 1: Миграция компонента "Блог" на PHP 8.1

```php
// ДО (PHP 7.4)
class modelBlog extends cmsModel {
    private $perpage = 20;
    
    public function getPosts($filter = array()) {
        // ... логика
        return $posts;
    }
}

// ПОСЛЕ (PHP 8.1 с использованием новых возможностей)
class modelBlog extends cmsModel {
    public function __construct(
        private readonly int $perPage = 20
    ) {
        parent::__construct();
    }
    
    public function getPosts(array $filter = []): array {
        // Использование match вместо switch
        $status = match($filter['status'] ?? 'all') {
            'published' => 1,
            'draft' => 0,
            default => null,
        };
        
        // ... логика
        return $posts;
    }
    
    // Использование перечислений для статусов
    public function getStatusLabel(PostStatus $status): string {
        return match($status) {
            PostStatus::Published => 'Опубликован',
            PostStatus::Draft => 'Черновик',
            PostStatus::Deleted => 'Удалён',
        };
    }
}

// Перечисление для статусов постов
enum PostStatus: int {
    case Published = 1;
    case Draft = 0;
    case Deleted = -1;
}
```

```php
            // Использование атрибутов для метаданных

            $apiKey = getenv('EXPORT_API_KEY');
```

## 45.11. Рекомендации по обновлению

### Пошаговый план обновления

1. **Подготовка**
   - Создайте полную резервную копию кода и базы данных
   - Настройте тестовое окружение с целевой версией PHP
   - Запустите автоматическую проверку совместимости

2. **Тестирование**
   - Запустите все существующие тесты на новой версии PHP
   - Проверьте работу критически важных функций вручную
   - Протестируйте интеграции с внешними сервисами

3. **Исправление проблем**
   - Используйте Rector для автоматического исправления
   - Вручную исправьте оставшиеся проблемы
   - Обновите зависимости до совместимых версий

4. **Оптимизация**
   - Примените новые возможности языка для улучшения кода
   - Настройте OPcache и другие параметры производительности
   - Обновите документацию и комментарии

5. **Деплой**
   - Разверните обновлённую версию на staging-среде
   - Проведите финальное тестирование
   - Планируйте деплой в продакшен в период минимальной нагрузки

### Контрольный список перед деплоем

- [ ] Все тесты проходят успешно на целевой версии PHP
- [ ] Критические функции протестированы вручную
- [ ] Зависимости обновлены до совместимых версий
- [ ] Конфигурация PHP оптимизирована для продакшена
- [ ] Создана резервная копия перед деплоем
- [ ] Подготовлен план отката в случае проблем
- [ ] Уведомлена команда о предстоящем обновлении
- [ ] Настроено мониторинг после деплоя

## 45.12. Заключение

Поддержка современных версий PHP является критически важным аспектом развития и безопасности платформы DST Platform:

**Ключевые преимущества обновления:**
- **Производительность**: До 30% ускорения за счёт JIT и улучшенного OPcache
- **Безопасность**: Современные механизмы защиты и валидации
- **Поддержка**: Доступ к актуальным версиям зависимостей и исправлениям уязвимостей
- **Разработчикский опыт**: Новые возможности языка упрощают написание и поддержку кода

**Рекомендуемая стратегия:**
- Для новых проектов: Используйте PHP 8.2+ с полной типизацией
- Для существующих проектов: Планируйте миграцию на PHP 8.1+ в течение 6-12 месяцев
- Для устаревших проектов: Поддерживайте на PHP 7.4 только до полной миграции
