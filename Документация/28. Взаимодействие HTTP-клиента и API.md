# 28. Взаимодействие HTTP-клиента и API

Данный документ содержит исчерпывающую техническую спецификацию инфраструктуры HTTP-клиента на платформе DST Platform. Система реализована на базе библиотеки **Guzzle** и обеспечивает надёжную основу для всех внешних взаимодействий с API сторонних сервисов, включая платежные шлюзы, системы доставки, геолокационные сервисы и почтовые серверы.

> **Важно**: Данный документ описывает архитектуру и возможности HTTP-клиента на уровне платформы. Для получения информации о конкретных интеграциях см.:
> - *«Интеграция платежного шлюза»* — обработка платежей через YooKassa
> - *«Доставка и логистика»* — интеграция с системой доставки CDEK
> - *«Геолокационные службы»* — определение местоположения по IP-адресу
> - *«Почтовые сервисы»* — отправка электронной почты через SMTP

---

## 28.1. Обзор системы

Платформа DST использует **Guzzle HTTP Client** в качестве единого уровня для всех внешних HTTP-взаимодействий. Эта архитектура обеспечивает согласованное поведение, обработку ошибок и расширяемость через промежуточное ПО (middleware) для всех интеграций с внешними сервисами.

### Ключевые характеристики

| Характеристика | Реализация | Преимущество |
|----------------|------------|--------------|
| **Версия Guzzle** | 6.5.8 (фиксированная) | Стабильность, предсказуемость |
| **Соответствие стандартам** | Реализует PSR-7 (HTTP-сообщения), поддерживает PSR-18 (HTTP-клиент) | Совместимость с экосистемой PHP |
| **Асинхронность** | Встроенная поддержка промисов | Параллельные запросы, высокая производительность |
| **Расширяемость** | Стек промежуточного ПО | Гибкая модификация запросов/ответов |
| **Обработка ошибок** | Полная иерархия исключений | Предсказуемая обработка сбоев |
| **Сертификаты SSL** | Composer CA Bundle | Безопасные соединения по умолчанию |

### Архитектурные принципы

| Принцип | Реализация | Выгода |
|---------|------------|--------|
| **Единый транспортный уровень** | Все внешние вызовы через Guzzle | Согласованная обработка ошибок |
| **Соответствие стандартам PSR** | PSR-7 для сообщений, PSR-3 для логирования | Совместимость с экосистемой |
| **Ленивая инициализация** | Клиент создаётся по требованию | Экономия ресурсов |
| **Идемпотентность** | Поддержка идемпотентных ключей | Защита от дублирования запросов |
| **Безопасность по умолчанию** | Проверка сертификатов SSL, HTTPS | Соответствие стандартам безопасности |

## 28.4. Интерфейсы сообщений PSR-7

Guzzle реализует интерфейсы сообщений PSR-7, предоставляя стандартизированные объекты запросов и ответов на всей платформе.

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/159.png" alt="DST Platform">

### Основные интерфейсы PSR-7

| Интерфейс | Назначение | Реализация Guzzle | Пример использования |
|-----------|------------|-------------------|---------------------|
| `Psr\Http\Message\MessageInterface` | Базовое сообщение с заголовками и телом | `GuzzleHttp\Psr7\Message` | Общая обработка сообщений |
| `Psr\Http\Message\RequestInterface` | HTTP-запрос с методом, URI и заголовками | `GuzzleHttp\Psr7\Request` | Создание запросов |
| `Psr\Http\Message\ResponseInterface` | HTTP-ответ с кодом состояния | `GuzzleHttp\Psr7\Response` | Обработка ответов |
| `Psr\Http\Message\StreamInterface` | Поток тела сообщения | `GuzzleHttp\Psr7\Stream` | Чтение/запись тела |
| `Psr\Http\Message\UriInterface` | Представление URI/URL | `GuzzleHttp\Psr7\Uri` | Работа с адресами |

### Примеры использования

```php
use GuzzleHttp\Psr7\Request;
use GuzzleHttp\Psr7\Response;
use GuzzleHttp\Psr7\Uri;
use GuzzleHttp\Psr7\Stream;

// Создание запроса
$request = new Request(
    'POST',
    'https://api.example.com/v1/users',
    ['Content-Type' => 'application/json'],
    json_encode(['name' => 'John Doe'])
);

// Создание ответа
$response = new Response(
    200,
    ['Content-Type' => 'application/json'],
    json_encode(['id' => 1, 'name' => 'John Doe'])
);

// Создание потока
$stream = Stream::factory('Hello, World!');

// Создание URI
$uri = new Uri('https://api.example.com/v1/users');
```

### Неизменяемость объектов

Все объекты сообщений PSR-7 являются **неизменяемыми** (immutable). Методы, изменяющие сообщение, возвращают новые экземпляры, а не изменяют исходный объект:

```php
// ❌ Неправильно - исходный объект не изменится
$request->withHeader('X-API-Key', 'secret');

// ✅ Правильно - создаётся новый объект
$request = $request->withHeader('X-API-Key', 'secret');
```

### Преобразование между объектами

```php
// Преобразование массива в поток
use GuzzleHttp\Psr7\stream_for;

$body = stream_for(['name' => 'John', 'email' => 'john@example.com']);

// Преобразование строки в поток
$body = stream_for('Plain text content');

// Преобразование файла в поток
$body = stream_for(fopen('/path/to/file.txt', 'r'));
```

### Косвенное использование через SDK

Многие сторонние SDK используют Guzzle в качестве транспортного уровня HTTP:

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/160.png" alt="DST Platform">

### Создание экземпляра клиента

```php
use GuzzleHttp\Client;

// Базовая конфигурация
$client = new Client([
    'base_uri' => 'https://api.example.com',
    'timeout' => 30.0,
    'connect_timeout' => 5.0,
    'verify' => true, // Проверка сертификатов SSL
    'http_errors' => true, // Выбрасывать исключения для ошибок HTTP
    'decode_content' => true, // Автоматическая распаковка gzip
    'headers' => [
        'User-Agent' => 'DST Platform/1.0',
        'Accept' => 'application/json'
    ]
]);
```

### Параметры конфигурации

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|----------------------|----------|
| `base_uri` | string | `null` | Базовый URI для всех запросов |
| `timeout` | float | `0` (без ограничения) | Общее время ожидания запроса |
| `connect_timeout` | float | `0` (без ограничения) | Время ожидания подключения |
| `verify` | bool\|string | `true` | Проверка сертификатов SSL |
| `cert` | string\|array | `null` | Путь к клиентскому сертификату |
| `ssl_key` | string\|array | `null` | Путь к закрытому ключу SSL |
| `proxy` | string\|array | `null` | Настройки прокси-сервера |
| `http_errors` | bool | `true` | Выбрасывать исключения для ошибок HTTP |
| `decode_content` | bool | `true` | Автоматическая распаковка gzip |
| `headers` | array | `[]` | Заголовки по умолчанию для всех запросов |
| `allow_redirects` | bool\|array | `true` | Разрешить автоматические перенаправления |
| `debug` | bool | `false` | Включить отладочный вывод |

### Конфигурация для конкретных сервисов

```php
// Конфигурация для YooKassa (платёжный шлюз)
$yookassa_client = new Client([
    'base_uri' => 'https://api.yookassa.ru/v3',
    'timeout' => 60.0,
    'connect_timeout' => 10.0,
    'verify' => true,
    'headers' => [
        'Content-Type' => 'application/json',
        'Idempotence-Key' => uniqid('payment_', true)
    ],
    'auth' => [$shop_id, $secret_key] // HTTP Basic Auth
]);

// Конфигурация для CDEK (доставка)
$cdek_client = new Client([
    'base_uri' => 'https://integration.cdek.ru',
    'timeout' => 30.0,
    'connect_timeout' => 5.0,
    'verify' => true,
    'headers' => [
        'Content-Type' => 'application/json',
        'Accept' => 'application/json'
    ]
]);

// Конфигурация для отправки почты через SMTP
$mail_client = new Client([
    'base_uri' => 'smtp.yandex.ru:587',
    'timeout' => 60.0,
    'connect_timeout' => 10.0,
    'verify' => true
]);
```

### Управление сертификатами SSL/TLS

Guzzle использует этот composer/ca-bundle пакет для проверки SSL-сертификатов:

Комплект сертификатов: composer/ca-bundle v1.4.4

- Предоставляет пакет доверенных сертификатов центра сертификации Mozilla.
- Обеспечивает безопасные HTTPS-соединения.
- Проверяет SSL-сертификаты для всех запросов к внешним API.

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/161.png" alt="DST Platform">

Guzzle использует пакет **Composer CA Bundle** для проверки сертификатов SSL:

```php
// Использование сертификатов по умолчанию (рекомендуется)
$client = new Client([
    'verify' => true
]);

// Указание конкретного пути к сертификатам
$client = new Client([
    'verify' => '/path/to/cacert.pem'
]);

// Отключение проверки (только для разработки!)
$client = new Client([
    'verify' => false
]);
```

**Важно**: Отключение проверки сертификатов (`verify => false`) **категорически не рекомендуется** для использования в продакшн-среде.

## 28.6. Жизненный цикл HTTP-запроса

### Полная последовательность выполнения

```
┌─────────────────────────────────────────────────────────────┐
│              ЖИЗНЕННЫЙ ЦИКЛ HTTP-ЗАПРОСА                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. Создание запроса                                        │
│     ↓                                                       │
│  2. Оборачивание в объект PSR-7 Request                     │
│     ↓                                                       │
│  3. Применение промежуточного ПО (до запроса)               │
│     • Аутентификация                                        │
│     • Добавление заголовков                                 │
│     • Логирование                                           │
│     ↓                                                       │
│  4. Выполнение транспортного запроса                        │
│     • Установка соединения                                  │
│     • Отправка запроса                                      │
│     • Получение ответа                                      │
│     ↓                                                       │
│  5. Оборачивание ответа в объект PSR-7 Response             │
│     ↓                                                       │
│  6. Применение промежуточного ПО (после ответа)             │
│     • Логирование                                           │
│     • Кэширование                                           │
│     • Преобразование данных                                 │
│     ↓                                                       │
│  7. Возврат ответа приложению                               │
│     • Синхронный режим: объект Response                     │
│     • Асинхронный режим: промис                             │
│     ↓                                                       │
│  8. Обработка ответа                                        │
│     • Проверка статуса                                      │
│     • Извлечение данных                                     │
│     • Обработка ошибок                                      │
└─────────────────────────────────────────────────────────────┘
```

### Пример полного жизненного цикла

```php
use GuzzleHttp\Client;
use GuzzleHttp\Exception\RequestException;

// 1. Создание клиента
$client = new Client([
    'base_uri' => 'https://api.example.com',
    'timeout' => 30.0,
    'connect_timeout' => 5.0
]);

// 2. Создание запроса
try {
    // 3-7. Выполнение запроса и обработка промежуточного ПО
    $response = $client->request('POST', '/v1/users', [
        'json' => [
            'name' => 'John Doe',
            'email' => 'john@example.com'
        ],
        'headers' => [
            'Authorization' => 'Bearer ' . $api_token,
            'X-Request-ID' => uniqid()
        ],
        'on_stats' => function ($stats) {
            // Логирование статистики запроса
            error_log('Request time: ' . $stats->getTransferTime() . 's');
        }
    ]);
    
    // 8. Обработка ответа
    $statusCode = $response->getStatusCode();
    $contentType = $response->getHeaderLine('content-type');
    $body = $response->getBody()->getContents();
    
    // Декодирование JSON
    $data = json_decode($body, true);
    
    echo "Success! User ID: " . $data['id'];
    
} catch (RequestException $e) {
    // Обработка ошибок
    if ($e->hasResponse()) {
        $response = $e->getResponse();
        $statusCode = $response->getStatusCode();
        
        error_log("API Error: HTTP {$statusCode}");
        error_log("Response: " . $response->getBody());
    } else {
        error_log("Connection Error: " . $e->getMessage());
    }
}
```

Этапы жизненного цикла:

1. Создание запроса: Приложение создает запрос с указанием метода, URI и параметров.
2. PSR-7-обертка: Запрос преобразован в PSR-7 RequestInterface
3. Обработка промежуточным ПО: Предварительное промежуточное ПО изменяет запрос (аутентификация, заголовки, логирование).
4. Выполнение транспортного запроса: HTTP-транспорт (cURL/stream) отправляет запрос.
5. Обработка ответов: ответ API обернут в соответствии со стандартом PSR-7. ResponseInterface
6. Постобработка: Промежуточное ПО обрабатывает логирование, кэширование и преобразование данных.
7. Возвращаемое значение: Ответ, возвращенный приложению (синхронный режим) или разрешенный в промисе (асинхронный режим).

## 28.7. Асинхронная обработка запросов

### Поддержка промисов

Guzzle поддерживает асинхронные (неблокирующие) HTTP-запросы через библиотеку **Guzzle Promises**.

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/163.png" alt="DST Platform">

Библиотека Promise: guzzlehttp/promises v1.5.3

- Реализует Promises/спецификацию A+.
- Обеспечивает одновременное выполнение запросов.
- Предоставляет комбинаторы: all(), some(),settle()

### Базовые методы промисов

| Метод | Назначение | Пример |
|-------|------------|--------|
| `then($onFulfilled, $onRejected)` | Прикрепить обработчики выполнения и отклонения | `$promise->then($success, $error)` |
| `otherwise($onRejected)` | Сокращённый способ обработки ошибок | `$promise->otherwise($error)` |
| `wait($unwrap = true)` | Блокировка до разрешения промиса | `$result = $promise->wait()` |
| `settle()` | Дождаться выполнения всех промисов | `Promise\settle($promises)` |

### Пример асинхронного запроса

```php
use GuzzleHttp\Client;
use GuzzleHttp\Promise;

// Создание клиента
$client = new Client(['base_uri' => 'https://api.example.com']);

// Создание асинхронных запросов
$promises = [
    'users' => $client->getAsync('/users'),
    'posts' => $client->getAsync('/posts'),
    'comments' => $client->getAsync('/comments')
];

// Ожидание выполнения всех промисов
$results = Promise\settle($promises)->wait();

// Обработка результатов
foreach ($results as $key => $result) {
    if ($result['state'] === 'fulfilled') {
        $response = $result['value'];
        echo "Success for {$key}: " . $response->getStatusCode() . "\n";
    } else {
        $exception = $result['reason'];
        echo "Error for {$key}: " . $exception->getMessage() . "\n";
    }
}
```

### Параллельные запросы

```php
use GuzzleHttp\Client;
use GuzzleHttp\Pool;
use GuzzleHttp\Psr7\Request;
use GuzzleHttp\Promise;

// Создание клиента
$client = new Client(['base_uri' => 'https://api.example.com']);

// Создание пула запросов
$requests = function ($total) {
    $uri = '/product/';
    for ($i = 1; $i <= $total; $i++) {
        yield new Request('GET', $uri . $i);
    }
};

$pool = new Pool($client, $requests(100), [
    'concurrency' => 10, // Количество одновременных запросов
    'fulfilled' => function ($response, $index) {
        // Обработка успешного ответа
        echo "Request #{$index} completed\n";
    },
    'rejected' => function ($reason, $index) {
        // Обработка ошибки
        echo "Request #{$index} failed: " . $reason->getMessage() . "\n";
    }
]);

// Запуск пула и ожидание завершения
$promise = $pool->promise();
$promise->wait();
```

```php
use Psr\Http\Message\RequestInterface;
use Psr\Http\Message\ResponseInterface;

// Простое промежуточное ПО
$middleware = function (callable $handler) {
    return function (RequestInterface $request, array $options) use ($handler) {
        // Код до отправки запроса
        error_log('Request: ' . $request->getMethod() . ' ' . $request->getUri());
        
        // Выполнение запроса
        return $handler($request, $options)->then(
            function (ResponseInterface $response) use ($request) {
                // Код после получения ответа
                error_log('Response: ' . $response->getStatusCode());
                return $response;
            }
        );
    };
};

// Добавление промежуточного ПО к клиенту
use GuzzleHttp\HandlerStack;

$stack = HandlerStack::create();
$stack->push($middleware, 'logger');

$client = new \GuzzleHttp\Client(['handler' => $stack]);
```

### Иерархия исключений Guzzle

```
Exception (PHP)
└── GuzzleHttp\Exception\TransferException
    ├── GuzzleHttp\Exception\RequestException
```

### Типы исключений

| Исключение | Код статуса HTTP | Описание | Пример |
|------------|------------------|----------|--------|
| `ConnectException` | Н/Д | Не удалось подключиться к серверу (DNS, сеть, брандмауэр) | Таймаут соединения |
| `ClientException` | 400-499 | Ошибки клиента (неверный запрос, несанкционированный доступ, не найдено) | 404 Not Found |
| `ServerException` | 500-599 | Ошибки сервера (внутренняя ошибка, недоступность сервиса) | 500 Internal Server Error |
| `TooManyRedirectsException` | 3xx | Превышен максимальный лимит перенаправлений | Бесконечный редирект |
| `RequestException` | Любой | Типичная ошибка запроса, но ответ доступен | Любая ошибка с ответом |

### Пример обработки ошибок

```php
use GuzzleHttp\Client;
use GuzzleHttp\Exception\RequestException;
use GuzzleHttp\Exception\ConnectException;
use GuzzleHttp\Exception\ClientException;
use GuzzleHttp\Exception\ServerException;

$client = new Client(['base_uri' => 'https://api.example.com']);

try {
    $response = $client->request('GET', '/resource');
    
    // Обработка успешного ответа
    $data = json_decode($response->getBody(), true);
    
} catch (ConnectException $e) {
    // Ошибки подключения
    error_log('Connection error: ' . $e->getMessage());
    
} catch (ClientException $e) {
    // Ошибки клиента (4xx)
    $response = $e->getResponse();
    $statusCode = $response->getStatusCode();
    
    error_log("Client error: HTTP {$statusCode}");
    error_log("Response: " . $response->getBody());
    
} catch (ServerException $e) {
    // Ошибки сервера (5xx)
    $response = $e->getResponse();
    $statusCode = $response->getStatusCode();
    
    error_log("Server error: HTTP {$statusCode}");
    error_log("Response: " . $response->getBody());
    
} catch (RequestException $e) {
    // Общая обработка ошибок запроса
    if ($e->hasResponse()) {
        $response = $e->getResponse();
        error_log('Request failed: ' . $response->getStatusCode());
    } else {
        error_log('Request failed: ' . $e->getMessage());
    }
}
```

```php
            error_log("GeoIP2 API Error ({$response->getStatusCode()}): " . $response->getBody());
```

## 28.13. Производительность и оптимизация

### Объединение и повторное использование соединений

Guzzle автоматически повторно использует HTTP-соединения, когда это возможно, снижая накладные расходы на множественные запросы к одному и тому же хосту.

Преимущества:

- Снижены накладные расходы на установление TCP-соединения.
- Повторное использование сессий SSL/TLS
- Улучшена задержка для последовательных запросов.

```php
// Создание клиента с настройками пула соединений
$client = new \GuzzleHttp\Client([
    'base_uri' => 'https://api.example.com',
    'timeout' => 30.0,
    'connect_timeout' => 5.0,
    'http_errors' => false,
    'verify' => true
]);

// Выполнение нескольких запросов к одному хосту
// Соединения будут автоматически переиспользованы
for ($i = 0; $i < 10; $i++) {
    $response = $client->request('GET', "/resource/{$i}");
    // Обработка ответа
}
```

### Настройка таймаутов

| Тип таймаута | По умолчанию | Рекомендуется | Назначение |
|--------------|--------------|---------------|------------|
| `connect_timeout` | 0 (без ограничений) | 5-10 секунд | Время установления соединения |
| `timeout` | 0 (без ограничений) | 30-60 секунд | Общее время ожидания запроса |
| `read_timeout` | По умолчанию `timeout` | 30 секунд | Время чтения тела ответа |

### Оптимизация одновременных запросов

Для выполнения массовых операций (например, синхронизации маркетплейсов) используйте параллелизм на основе промисов в Guzzle:

Шаблон параллельных запросов:

1. Создайте несколько асинхронных запросов, используя requestAsync()
2. Собирайте промисы в массив.
3. Используйте Promise\settle($promises) для параллельного выполнения.
4. Результаты процесса после его завершения.

Преимущество: Позволяет сократить общее время выполнения с последовательного O(n × задержка) до параллельного O (максимальная задержка).

### Оптимизация параллельных запросов

```php
use GuzzleHttp\Client;
use GuzzleHttp\Pool;
use GuzzleHttp\Psr7\Request;
use GuzzleHttp\Promise;

// Создание клиента
$client = new Client([
    'base_uri' => 'https://api.example.com',
    'timeout' => 30.0
]);

// Создание пула запросов
$requests = function ($total) {
    for ($i = 1; $i <= $total; $i++) {
        yield new Request('GET', "/product/{$i}");
    }
};

$pool = new Pool($client, $requests(100), [
    'concurrency' => 10, // Количество одновременных запросов
    'fulfilled' => function ($response, $index) {
        // Обработка успешного ответа
        $data = json_decode($response->getBody(), true);
        // Сохранение данных
    },
    'rejected' => function ($reason, $index) {
        // Обработка ошибки
        error_log("Request #{$index} failed: " . $reason->getMessage());
    }
]);

// Запуск пула
$promise = $pool->promise();
$promise->wait();
```

### Кэширование ответов

```php
use GuzzleHttp\Client;
use GuzzleHttp\HandlerStack;
use Kevinrob\GuzzleCache\CacheMiddleware;
use Kevinrob\GuzzleCache\Storage\Psr6CacheStorage;
use Kevinrob\GuzzleCache\Strategy\PrivateCacheStrategy;

// Создание хранилища кэша (например, через Redis)

// Добавление к стеку

    'handler' => $stack,
```

```php
// Ограничение скорости запросов
use GuzzleHttp\Middleware;
use GuzzleHttp\Promise\PromiseInterface;

$rateLimitMiddleware = function (callable $handler) {
    $last_request_time = 0;
    $min_interval = 100000; // 100 мс между запросами
    
    return function ($request, $options) use ($handler, &$last_request_time, $min_interval) {
        $now = microtime(true) * 1000000;
        $elapsed = $now - $last_request_time;
        
        if ($elapsed < $min_interval) {
            $sleep_time = ($min_interval - $elapsed) / 1000000;
            usleep($sleep_time * 1000000);
        }
        
        $last_request_time = microtime(true) * 1000000;
        
        return $handler($request, $options);
    };
};

$stack->push($rateLimitMiddleware, 'rate_limit');
```

### Сбор метрик

```php
use GuzzleHttp\Middleware;
use GuzzleHttp\Promise\PromiseInterface;

$metricsMiddleware = function (callable $handler) {
    return function ($request, $options) use ($handler) {
        $start_time = microtime(true);
        
        return $handler($request, $options)->then(
            function ($response) use ($request, $start_time) {
                $duration = microtime(true) - $start_time;
                $status_code = $response->getStatusCode();

                    $request->getUri(),
                    $status_code,
                    $duration * 1000
                ));
                
                return $response;
            },
            function ($exception) use ($request, $start_time) {
                $duration = microtime(true) - $start_time;
                
                // Логирование ошибок
                error_log(sprintf(
                    '[HTTP ERROR] %s %s - Duration: %.3f ms, Error: %s',
                    $request->getMethod(),
                    $request->getUri(),
                    $duration * 1000,
                    $exception->getMessage()
                ));
                
                throw $exception;
            }
        );
    };
};
```

```php
use GuzzleHttp\Client;
use GuzzleHttp\HandlerStack;
use GuzzleHttp\Middleware;
use Monolog\Logger;
use Monolog\Handler\StreamHandler;

class SafeHttpClient {
    private $client;
    
    public function __construct($base_uri, $api_key) {
        // Создание логгера
        $logger = new Logger('http_client');
        $logger->pushHandler(new StreamHandler('/var/log/http_client.log', Logger::DEBUG));
        
        // Создание стека промежуточного ПО
        $stack = HandlerStack::create();
        
        // Логирование
        $stack->push(Middleware::log($logger, new \GuzzleHttp\MessageFormatter()), 'logger');
        
        // Повторные попытки
        $stack->push(Middleware::retry(function ($retries) {
            return $retries < 3;
        }, function ($retries) {
            return pow(2, $retries) * 1000;
        }), 'retry');
        
        // Ограничение скорости
        $last_request = 0;
        $stack->push(function (callable $handler) use (&$last_request) {
            return function ($request, $options) use ($handler, &$last_request) {
                $now = microtime(true);
                if ($now - $last_request < 0.1) { // 100 мс между запросами
                    usleep(100000);
                }
                $last_request = microtime(true);
                return $handler($request, $options);
            };
        }, 'rate_limit');
        
        // Создание клиента
        $this->client = new Client([
            'base_uri' => $base_uri,
            'handler' => $stack,
            'timeout' => 30.0,
            'connect_timeout' => 5.0,
            'verify' => true,
            'headers' => [
                'Authorization' => 'Bearer ' . $api_key,
                'User-Agent' => 'DST Platform/1.0',
                'Accept' => 'application/json'
            ]
        ]);
    }
    
    public function get($uri, $query = []) {
        return $this->client->request('GET', $uri, ['query' => $query]);
    }
    
    public function post($uri, $data = []) {
        return $this->client->request('POST', $uri, ['json' => $data]);
    }
    
    public function put($uri, $data = []) {
        return $this->client->request('PUT', $uri, ['json' => $data]);
    }
    
    public function delete($uri) {
        return $this->client->request('DELETE', $uri);
    }
}
```
