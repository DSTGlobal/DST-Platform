# Часть I. Основы

## 52.1. Терминология: i18n vs l10n vs g11n

Термины часто путают. В DST Platform мы разделяем их строго:

| Термин | Расшифровка | Что означает | Кто делает |
|---|---|---|---|
| **i18n** (internationalization) | inter**n**atio**n**alizatio**n** (18 букв между i и n) | **Инфраструктура** для поддержки разных языков. Код, готовый к переводу | Разработчик |
| **l10n** (localization) | **l**ocalizatio**n** (10 букв) | **Адаптация** продукта под конкретный регион: перевод, форматы, валюта | Переводчик + разработчик |
| **g11n** (globalization) | **g**lobalizatio**n** (11 букв) | **Совокупность** i18n + l10n + бизнес-процессы | Менеджер продукта |

**Правило DST Platform:** код должен быть **i18n-ready** (готов к переводу) с самого начала. Перевод (l10n) добавляется позже, без изменения кода.

**Пример:**

```php
// ❌ НЕ i18n-ready (хардкод)
echo 'Добро пожаловать на сайт';

// ✅ i18n-ready (ключ, перевод отдельно)
echo cmsLang::get('WELCOME_MESSAGE');
```

## 52.2. Архитектура локализации в DST Platform

```
┌────────────────────────────────────────────────────────────────────┐
│              АРХИТЕКТУРА ЛОКАЛИЗАЦИИ DST PLATFORM                  │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │                    ПРИЛОЖЕНИЕ                                │  │
│  │  (контроллеры, модели, шаблоны, API, JS)                     │  │
│  └──────────────────────────┬───────────────────────────────────┘  │
│                             │                                      │
│                             ▼                                      │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │         cmsLang  (единая точка доступа)                      │  │
│  │  • get($key, $params, $namespace)                            │  │
│  │  • setLocale($locale)                                        │  │
│  │  • getLocale()                                               │  │
│  │  • loadFile($locale)                                         │  │
│  └──────┬────────────────────────────────────┬──────────────────┘  │
│         │                                    │                     │
│         ▼                                    ▼                     │
│  ┌──────────────────────────┐    ┌─────────────────────────────┐   │
│  │  УРОВЕНЬ 1: ФАЙЛЫ        │    │  УРОВЕНЬ 2: БД              │   │
│  │  /system/languages/      │    │  cms_translations           │   │
│  │  /templates/*/languages/ │    │  (для админ-редактирования) │   │
│  │  /controllers/*/languages/│   │                             │   │
│  └──────────────────────────┘    └─────────────────────────────┘   │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │                    КЭШ (cmsCache)                            │  │
│  │  Ключ: lang:{locale}:{namespace}                             │  │
│  │  TTL: 1 час (сбрасывается при обновлении через админку)      │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │                    FALLBACK-ЦЕПОЧКА                          │  │
│  │  текущая локаль → config.locale_default → 'en'               │  │
│  └──────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

**Ключевые принципы:**

1. **Единая точка входа** — `cmsLang` (не хардкод в шаблонах).
2. **Двухуровневое хранение** — файлы (статика, для разработчиков) + БД (динамика, для переводчиков).
3. **Кэширование** — переводы не читаются при каждом запросе.
4. **Fallback** — если перевода нет, используется локаль по умолчанию.
5. **Плюрализация** — учёт правил множественного числа для каждого языка.

## 52.4. Что локализуется, а что — нет

| Элемент | Локализуется | Как |
|---|---|---|
| **UI-строки** (кнопки, меню, ошибки) | ✅ | `cmsLang::get()` |
| **Сообщения валидации** | ✅ | `cmsLang::get()` (см. 42) |
| **Email-шаблоны** | ✅ | Файлы + `cmsLang::get()` |
| **Ошибки API** | ✅ | `cmsLang::get()` + `Accept-Language` |
| **Типы контента** (названия, поля) | ✅ | Таблица `cms_content_types_translations` |
| **Категории, теги** | ✅ | Колонка `translations` (JSON) |
| **Записи контента** | ✅ | Колонка `translations` (JSON) |
| **Даты и время** | ✅ | `cmsLang::formatDate()` |
| **Числа, валюты** | ✅ | `cmsLang::formatNumber()` |
| **URL-адреса** | ⚠️ Опционально | Префикс `/en/`, `/de/` |
| **SEO (title, description)** | ✅ | Поля в `translations` |
| **Имена файлов и путей** | ❌ | Технические, не переводятся |
| **Ключи БД и конфигов** | ❌ | Технические |
| **Логи** | ❌ | Технические (обычно на английском) |
| **Имена переменных** | ❌ | Технические |
| **Код страны/валюты** | ❌ | ISO 3166-1 / ISO 4217 (не переводятся, только отображаются) |

> ⚠️ **Важно.** Локализация ≠ перевод. Локализация включает:
> - Перевод текста.
> - Форматирование дат (`12/31/2024` vs `31.12.2024`).
> - Форматирование чисел (`1,234.56` vs `1 234,56`).
> - Валюту (USD, RUB, EUR).
> - Направление текста (LTR, RTL для арабского, иврита).
> - Культурные особенности (цвета, изображения, иконки).

### 52.5.3. Правила для файлов

| Правило | Почему |
|---|---|
| `return [...]` — не `define()` | Массив быстрее, кэшируется PHP |
| Ключи — `UPPER_SNAKE_CASE` | Единый стиль, легко искать |
| Значения — UTF-8, без BOM | Корректная обработка |
| Одинаковые ключи во всех локалях | Легко проверять покрытие |
| Плейсхолдеры — `{name}` | Не конфликтуют с HTML |
| Комментарии-секции | Навигация |

### 52.5.4. Загрузка (внутри `cmsLang`)

```php
class cmsLang {
    private static array $cache = [];
    private static string $locale = 'ru';

    public static function loadFile(string $locale, string $namespace = 'core'): array {
        $cacheKey = "{$locale}:{$namespace}";

        if (isset(self::$cache[$cacheKey])) {
            return self::$cache[$cacheKey];
        }

        $path = self::resolvePath($locale, $namespace);

        if (!file_exists($path)) {
            // Fallback на локаль по умолчанию
            $fallback = cmsConfig::get('locale_default', 'ru');
            if ($locale !== $fallback) {
                return self::loadFile($fallback, $namespace);
            }
            return [];
        }

        $messages = include $path;
        if (!is_array($messages)) {
            return [];
        }

        self::$cache[$cacheKey] = $messages;
        return $messages;
    }

    private static function resolvePath(string $locale, string $namespace): string {
        return match (true) {
            $namespace === 'core' => PATH . "/system/languages/{$locale}.php",
            str_starts_with($namespace, 'template:') =>
                PATH . "/templates/" . substr($namespace, 9) . "/languages/{$locale}.php",
            default => PATH . "/system/controllers/{$namespace}/languages/{$locale}.php",
        };
    }
}
```

## 52.6. Таблица `cms_translations` (динамика)

### 52.6.1. Схема

**Миграция:** `2024_07_05_100000_core__create_translations_table.sql` (см. раздел 51.27.1)

```sql
CREATE TABLE IF NOT EXISTS `cms_translations` (
    `id` INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    `locale` VARCHAR(10) NOT NULL,
    `namespace` VARCHAR(100) NOT NULL DEFAULT 'core',
    `key_name` VARCHAR(255) NOT NULL,
    `value` TEXT NOT NULL,
    `is_custom` TINYINT(1) NOT NULL DEFAULT 0
        COMMENT '1 = переопределение файла, 0 = только в БД',
    `updated_by` INT UNSIGNED DEFAULT NULL,
    `created_at` DATETIME NOT NULL,
    `updated_at` DATETIME DEFAULT NULL,

    UNIQUE INDEX `uniq_locale_ns_key` (`locale`, `namespace`, `key_name`),
    INDEX `idx_namespace` (`namespace`),
    INDEX `idx_locale` (`locale`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 52.6.2. Назначение

Таблица `cms_translations` используется для:

1. **Переопределения** переводов из файлов (клиент хочет сказать «Корзина» вместо «Корзина покупок»).
2. **Динамических** переводов (контент, создаваемый в админке).
3. **Переводов, добавленных переводчиком** без доступа к коду.

## 52.7. Гибридная модель и приоритеты

```
┌────────────────────────────────────────────────────────────────┐
│                  ПРИОРИТЕТ ИСТОЧНИКОВ ПЕРЕВОДА                 │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  1. cms_translations (is_custom=1)  ← НАИВЫСШИЙ                │
│     (переопределение из админки, «клиент хочет так»)           │
│                                                                │
│  2. cms_translations (is_custom=0)  ← СРЕДНИЙ                  │
│     (динамические переводы, добавленные переводчиком)          │
│                                                                │
│  3. Файлы (/system/languages/...)   ← БАЗОВЫЙ                  │
│     (переводы от разработчиков)                                │
│                                                                │
│  4. Fallback (config.locale_default) ← НИЗШИЙ                  │
│     (если перевода нет совсем)                                 │
│                                                                │
│  5. Ключ (KEY)                       ← ПОСЛЕДНИЙ РЕЗЕРВ        │
│     (если перевода нет нигде — вернуть сам ключ)               │
└────────────────────────────────────────────────────────────────┘
```

### 52.7.1. Алгоритм `cmsLang::get()`

```php
public static function get(string $key, array $params = [], string $namespace = 'core'): string {
    $locale = self::$locale;

    // 1. Проверка в БД (переопределение, is_custom=1)
    $custom = self::findInDb($locale, $namespace, $key, true);
    if ($custom !== null) {
        return self::interpolate($custom, $params);
    }

    // 2. Файлы
    $messages = self::loadFile($locale, $namespace);
    if (isset($messages[$key])) {
        return self::interpolate($messages[$key], $params);
    }

    // 3. БД (обычный перевод, is_custom=0)
    $db = self::findInDb($locale, $namespace, $key, false);
    if ($db !== null) {
        return self::interpolate($db, $params);
    }

    // 4. Fallback на локаль по умолчанию
    $fallback = cmsConfig::get('locale_default', 'ru');
    if ($locale !== $fallback) {
        return self::get($key, $params, $namespace); // рекурсивно, но с fallback-локалью
    }

    // 5. Ключ как последний резерв
    error_log("[i18n] Missing translation: {$namespace}.{$key} ({$locale})");
    return $key;
}
```

> 💡 **Почему DB раньше файлов в первой проверке?** Переопределение (`is_custom=1`) должно выигрывать у файла. Но обычный перевод из БД (`is_custom=0`) — проигрывает файлу, чтобы разработчик мог обновить перевод в файле без изменения БД.

### 52.8.2. Соглашение по ключам

```
{SECTION}_{ENTITY}_{ATTRIBUTE}
```

| Часть | Назначение | Пример |
|---|---|---|
| `SECTION` | Раздел (AUTH, CART, PRODUCT) | `AUTH` |
| `ENTITY` | Сущность (LOGIN, TITLE, PRICE) | `LOGIN` |
| `ATTRIBUTE` | Атрибут (ERROR, HINT, PLACEHOLDER) | `ERROR` |

**Примеры:**

| Ключ | Значение (ru) |
|---|---|

### 52.8.3. Рекомендации по ключам

| Практика | Пример |
|---|---|
| ✅ **Семантический ключ** | `CART_EMPTY` |
| ❌ **Текст как ключ** | `'Корзина пуста' => 'Cart is empty'` — плохо для изменения текста |
| ✅ **Группировка по секциям** | `AUTH_*`, `CART_*` |

| ✅ **Плейсхолдеры** | `WELCOME {name}` |

## 52.13. Плюрализация (plural forms)

### 52.13.1. Проблема

В русском языке — 3 формы множественного числа:

|---|---|---|
| 1 | one | 1 товар |
| 2–4 | few | 2 товара |

| 21 | one | 21 товар |

В английском — 2 формы (1 item, 2 items). В арабском — 6 форм. В китайском — 1.

### 52.13.2. Синтаксис ICU MessageFormat

**Файл:** `/system/languages/ru.php`

```php
    many{# элементов}
    other{# элемента}
}',
```

**Файл:** `/system/languages/en.php`


### 52.13.3. Реализация через `intl`

```php
public static function interpolate(string $message, array $params): string {
    // Простые {name} — быстрая замена
    if (!str_contains($message, ', plural,') && !str_contains($message, ', select,')) {
        foreach ($params as $k => $v) {
            $message = str_replace('{' . $k . '}', (string)$v, $message);
        }
        return $message;
    }

    // ICU MessageFormat через intl
    if (class_exists(\MessageFormatter::class)) {
        $formatter = new \MessageFormatter(self::$locale, $message);
        $result = $formatter->format($params);
        if ($result !== false) {
            return $result;
        }
    }

    // Fallback: простая замена
    foreach ($params as $k => $v) {
        $message = str_replace('{' . $k . '}', (string)$v, $message);
    }
    return $message;
}
```

# Часть IV. Управление локалями

## 52.15. Определение текущей локали

### 52.15.1. Приоритеты

```
1. Явно заданная в URL:   /en/shop/...             ← НАИВЫСШИЙ
2. Явно заданная в запросе: ?locale=en             ← ВЫСОКИЙ
3. Сохранённая в сессии:  $_SESSION['locale']      ← СРЕДНИЙ
4. Сохранённая в cookie:  dst_locale=en            ← НИЗКИЙ
5. Accept-Language:       en-US,en;q=0.9           ← САМЫЙ НИЗКИЙ
6. По IP (геолокация):    GeoIP2 → 'ru'            ← АВТО
7. Конфиг:                config.locale_default    ← ПОСЛЕДНИЙ
```

### 52.15.2. Реализация

```php
class cmsLang {
    public static function detectLocale(): string {
        // 1. URL (если включены URL-префиксы, см. 52.17)
        if (cmsConfig::get('i18n_url_prefix')) {
            $urlLocale = self::extractLocaleFromUrl($_SERVER['REQUEST_URI'] ?? '');
            if ($urlLocale && self::isSupported($urlLocale)) {
                return $urlLocale;
            }
        }

        // 2. Query-параметр
        $queryLocale = $_GET['locale'] ?? null;
        if ($queryLocale && self::isSupported($queryLocale)) {
            return $queryLocale;
        }

        // 3. Сессия
        if (!empty($_SESSION['locale']) && self::isSupported($_SESSION['locale'])) {
            return $_SESSION['locale'];
        }

        // 4. Cookie
        $cookieLocale = $_COOKIE['dst_locale'] ?? null;
        if ($cookieLocale && self::isSupported($cookieLocale)) {
            return $cookieLocale;
        }

        // 5. Accept-Language
        $acceptLocale = self::parseAcceptLanguage($_SERVER['HTTP_ACCEPT_LANGUAGE'] ?? '');
        if ($acceptLocale) {
            return $acceptLocale;
        }

        // 6. По IP (если включена геолокация, см. раздел 23.6)
        if (cmsConfig::get('i18n_geo_detect')) {
            $geoLocale = self::detectByIp($_SERVER['REMOTE_ADDR'] ?? '');
            if ($geoLocale) {
                return $geoLocale;
            }
        }

        // 7. Конфиг
        return cmsConfig::get('locale_default', 'ru');
    }

    private static function parseAcceptLanguage(string $header): ?string {
        if (empty($header)) {
            return null;
        }

        // Парсинг: "en-US,en;q=0.9,ru;q=0.8"
        $langs = [];
        foreach (explode(',', $header) as $part) {
            $pieces = explode(';', trim($part));
            $code = strtolower(substr(trim($pieces[0]), 0, 2)); // 'en', 'ru'
            $q = 1.0;
            if (isset($pieces[1]) && preg_match('/q=([\d.]+)/', $pieces[1], $m)) {
                $q = (float)$m[1];
            }
            if ($q > 0) {
                $langs[$code] = $q;
            }
        }

        arsort($langs);

        foreach (array_keys($langs) as $code) {
            if (self::isSupported($code)) {
                return $code;
            }
        }

        return null;
    }
}
```

## 52.17. URL-стратегии (префикс, домен, cookie)

### 52.17.1. Три стратегии

| Стратегия | Пример URL | Плюсы | Минусы |
|---|---|---|---|
| **Query-параметр** | `/shop?locale=en` | Просто | Плохо для SEO |
| **URL-префикс** | `/en/shop` | SEO, кэш | Сложнее роутинг |

```php
// Хелпер для генерации URL с учётом локали
function locale_url(string $path, ?string $locale = null): string {

    $default = cmsConfig::get('locale_default', 'ru');

        return $path;

    return '/' . $locale . '/' . ltrim($path, '/');
```

```php
public static function formatDate(string $datetime): string {
    $locales = include PATH . '/system/config/locales.php';
    $format = $locales[self::$locale]['date_format'] ?? 'd.m.Y';

    $dt = new \DateTime($datetime);
    return $dt->format($format);
}

public static function formatRelative(string $datetime): string {
    $ts = strtotime($datetime);
    $diff = time() - $ts;

    if ($diff < 60) {
        return cmsLang::get('TIME_JUST_NOW');
    }

    if ($diff < 3600) {
        $minutes = (int)($diff / 60);
        return cmsLang::get('TIME_MINUTES_AGO', ['count' => $minutes]);
    }

    if ($diff < 86400) {
        $hours = (int)($diff / 3600);
        return cmsLang::get('TIME_HOURS_AGO', ['count' => $hours]);
    }

    $days = (int)($diff / 86400);
    return cmsLang::get('TIME_DAYS_AGO', ['count' => $days]);
}
```

## 52.34. Множественное число (plural rules)

### 52.34.1. Правила по языкам

| Язык | Формы | Пример (1, 2, 5, 21, 22) |
|---|---|---|
| **Русский** | one, few, many | 1 товар, 2 товара, 5 товаров, 21 товар, 22 товара |
| **Английский** | one, other | 1 item, 2 items |
| **Немецкий** | one, other | 1 Element, 2 Elemente |
| **Французский** | one, many, other | 1 élément, 2 éléments |
| **Арабский** | zero, one, two, few, many, other | 6 форм |
| **Китайский** | other | 1 个, 2 个 |
| **Японский** | other | 1 個, 2 個 |

### 52.34.2. Использование ICU

Уже описано в 52.13. `intl` автоматически применяет правила языка.

**Без `intl`** (fallback):

```php
private static function simplePlural(string $message, array $params): string {
    if (!isset($params['count'])) {
        return $message;
    }

    $count = (int)$params['count'];
    $locale = self::$locale;

    // Простая эвристика для ru/uk/be
    if (in_array($locale, ['ru', 'uk', 'be'])) {
        $mod10 = $count % 10;
        $mod100 = $count % 100;

        if ($mod10 === 1 && $mod100 !== 11) {
            $form = 'one';
        } elseif ($mod10 >= 2 && $mod10 <= 4 && ($mod100 < 10 || $mod100 >= 20)) {
            $form = 'few';
        } else {
            $form = 'many';
        }

        // Извлечение формы из строки
        if (preg_match('/' . $form . '{([^}]*)}/', $message, $m)) {
            return str_replace('{count}', (string)$count, $m[1]);
        }
    }

    // Fallback: заменить {count}
    return str_replace('{count}', (string)$count, $message);
}
```

## 52.36. Локализация ошибок API

### 52.36.1. Определение локали запроса

## 52.38. Заголовки `Accept-Language` / `Content-Language`

### 52.38.1. `Accept-Language` (запрос)

```
Accept-Language: de-DE,de;q=0.9,en;q=0.8
```

Парсинг — см. 52.15.2.

### 52.38.2. `Content-Language` (ответ)

```php
// В ответе API
header('Content-Language: ' . cmsLang::getLocale());
```

**Зачем:** клиент понимает, на каком языке пришёл ответ (важно для `Vary` кэширования, см. 52.39).

## 52.39. Кэширование локализованных ответов

### 52.39.1. Проблема

`/api/method/content.get.news` возвращает **разные** ответы для `ru`, `de`, `en`. Кэш без учёта локали — баг.

### 52.39.2. Решение: `Vary`

```php
// В ответе
header('Vary: Accept-Language, Accept-Encoding');
header('Content-Language: ' . cmsLang::getLocale());
```

Это говорит HTTP-кэшу (и CDN), что ответ зависит от `Accept-Language`.

### 52.39.3. Серверный кэш

```php
// Ключ кэша включает локаль
$cacheKey = "api:content.get.news:{$locale}:page={$page}";

$cached = cmsCache::getInstance()->get($cacheKey);
if ($cached !== false) {
    return $cached;
}

$result = $this->buildResult();
cmsCache::getInstance()->set($cacheKey, $result, 300);

return $result;
```

### 52.39.4. CDN

Если используется CDN (CloudFlare, Akamai), настройте `Vary: Accept-Language`. Учтите: **`Vary` снижает hit rate**, так как CDN хранит копию для каждой локали. Обычно допустимо (5–10 локалей).

# Часть IX. Эксплуатация

## 52.40. Производительность

### 52.40.1. Кэширование

Уже реализовано в `cmsLang` (статический кэш + `cmsCache`). Дополнительно:

| Уровень | Что | TTL |
|---|---|---|
| **Statics (PHP)** | `cmsLang::$cache` | На время запроса |
| **Redis** | `lang:{locale}:{namespace}` | 1 час |
| **APCu** | То же | 1 час |
| **OPcache** | Скомпилированные файлы | До перезапуска |

**Сброс при обновлении:**

```php
// В админке при сохранении перевода
cmsCache::getInstance()->deleteByTag('translations');
// или
cmsCache::getInstance()->delete("lang:{$locale}:*");
```

### 52.40.2. Ленивая загрузка

Не загружайте **все** неймспейсы сразу. Только те, что нужны:

```php
// ❌ Плохо — загружает всё
foreach (glob(PATH . '/system/controllers/*/languages/' . $locale . '.php') as $f) {
    include $f;
}

// ✅ Хорошо — только при первом обращении
cmsLang::get('CART_TITLE', [], 'shop'); // загрузит только shop
```

### 52.40.3. Размер кэша

Для 7 локалей × 100 000 ключей × 100 байт = ~70 МБ. Кэшируется в Redis с TTL 1 час. Для больших проектов — рассмотреть:

- Разделение по неймспейсам (загружать только нужные).
- Сжатие (`gzcompress`).
- CDN для статических файлов (если переводы в файлах — они кэшируются Nginx).

## 52.42. Обновление переводов

### 52.42.1. При обновлении платформы

Новые ключи в файлах **не переводятся автоматически**. Процесс:

1. После обновления платформы — запустить `check_locale_coverage.php`.
2. Найти отсутствующие ключи.
3. Перевести через админку (или CSV-импорт).
4. Экспортировать в файлы (опционально) — чтобы не потерять при следующем обновлении.

### 52.42.2. Синхронизация файлов и БД

```php
// При старте (или по cron) — синхронизировать файлы в БД
// Это позволяет редактировать переводы через админку

$locales = cmsLang::getSupported();

foreach (array_keys($locales) as $locale) {
    $files = glob(PATH . '/system/languages/' . $locale . '*.php');

    foreach ($files as $file) {
        $messages = include $file;
        $namespace = basename($file, '.php');

        foreach ($messages as $key => $value) {
            $db->query("
                INSERT INTO cms_translations (locale, namespace, key_name, value, is_custom, created_at)
                VALUES (?, ?, ?, ?, 0, NOW())
                ON DUPLICATE KEY UPDATE
                    value = IF(is_custom = 0, VALUES(value), value),
                    updated_at = NOW()
            ", [$locale, $namespace, $key, $value]);
        }
    }
}
```

> ⚠️ **Осторожно:** если переводчик изменил значение через админку (и оно `is_custom=1`), синхронизация его **не перезапишет** (благодаря `IF(is_custom = 0, ...)`).

## 52.44. Заключение

Локализация DST Platform строится на трёх принципах:

1. **i18n-ready код.** Все строки — через `cmsLang::get()`. Никакого хардкода. Плейсхолдеры вместо конкатенации.
2. **Двухуровневое хранение.** Файлы (статика, для разработчиков) + БД (динамика, для переводчиков). Приоритеты: БД (custom) → файлы → БД (обычные) → fallback → ключ.
3. **Полная локализация.** Не только текст, но и даты, числа, валюты, множественное число, направление (RTL).

**Ключевые компоненты:**

| Компонент | Назначение | Расположение |
|---|---|---|
| **`cmsLang`** | Единая точка доступа | `/system/core/lang.php` (пример) |
| **`/system/languages/`** | Файлы ядра | В корне проекта |
| **`.../languages/`** | Файлы компонентов | В каждом компоненте |
| **`/system/config/locales.php`** | Реестр локалей | В конфиге |
| **`cms_translations`** | Динамические переводы | БД |
| **`cms_content_*_translations`** | Переводы контента | БД |
| **`translations` (JSON)** | Переводы записей | Колонки БД |
