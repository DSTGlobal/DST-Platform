# 25. Доставка и логистика

Данный документ содержит исчерпывающую техническую спецификацию подсистемы доставки и логистики в платформе DST Platform. Система реализует интеграцию с поставщиком услуг доставки CDEK через официальный SDK, обеспечивая автоматический расчёт стоимости доставки, создание заказов, отслеживание отправлений и управление логистическими процессами в рамках экосистемы электронной коммерции.

> **Важно**: Данный документ описывает архитектуру и технические детали интеграции с системой доставки CDEK. Для получения информации о компоненте `delivery` и его взаимодействии с маркетплейсом см. раздел *«Компонент — Маркетплейс и электронная коммерция»*. Общую архитектуру внешних интеграций см. в разделе *«Внешняя интеграция»*.

---

## 25.1. Обзор системы

Подсистема доставки и логистики реализована через сочетание сторонней библиотеки интеграции (CDEK SDK) и собственных компонентов платформы. Система обеспечивает полный жизненный цикл логистических операций — от расчёта стоимости доставки до отслеживания статуса заказа.

### Ключевые характеристики

| Характеристика | Реализация |
|----------------|------------|
| **Интеграция с поставщиком** | CDEK (СДЭК) через официальный SDK |
| **Расчёт стоимости** | Автоматический на основе веса, габаритов, расстояния |
| **Создание заказов** | Интеграция с системой управления заказами |
| **Отслеживание** | Реальное время через веб-хуки и периодические запросы |
| **Поддержка методов** | Курьерская доставка, ПВЗ, почта, международная |
| **Кэширование** | Многоуровневое для оптимизации производительности |
| **Обработка ошибок** | Комплексная с резервными механизмами |

### Архитектурные принципы

| Принцип | Реализация | Преимущество |
|---------|------------|--------------|
| **Слабая связанность** | Интеграция через хуки событий | Расширяемость без модификации ядра |
| **Идемпотентность** | Уникальные идентификаторы заказов | Защита от дублирования |
| **Асинхронность** | Фоновое обновление статусов через cron | Высокая производительность |
| **Кэширование** | Многоуровневое (кэш, сессия, БД) | Снижение нагрузки на внешние API |
| **Обработка ошибок** | Резервные механизмы и откаты | Надёжность при сбоях |

### Инициализация клиента CDEK

```php
// /system/controllers/delivery/classes/CdekIntegration.php
use CdekSDK\Client;
use CdekSDK\Requests\CalculationRequest;
use CdekSDK\Requests\CreateOrderRequest;
use CdekSDK\Requests\StatusReportRequest;

class CdekIntegration {
    private $client;
    private $config;

    /**
     * Инициализация клиента CDEK
     */
    public function __construct() {
        $this->config = cmsConfig::getInstance();
        
        $this->client = new Client(
            $this->config->get('cdek_account'),
            $this->config->get('cdek_secure_password')
        );
        
        // Настройка логирования (опционально)
        $logger = new \Monolog\Logger('cdek');
        $logger->pushHandler(new \Monolog\Handler\StreamHandler(
            PATH . '/cache/logs/cdek.log'
        ));
        $this->client->setLogger($logger);
    }

    /**
     * Получение экземпляра клиента
     */
    public function getClient() {
        return $this->client;
    }

    /**
     * Расчёт стоимости доставки
     */
    public function calculateShipping($params) {
        $request = (new CalculationRequest())
            ->setSenderCityId($params['sender_city_id'])
            ->setReceiverCityId($params['receiver_city_id'])
            ->addPackage([
                'weight' => $params['weight'], // в граммах
                'length' => $params['length'],
                'width' => $params['width'],
                'height' => $params['height']
            ]);
        
        try {
            $response = $this->client->sendCalculatorRequest($request);
            
            $tariffs = [];
            foreach ($response->getTariffs() as $tariff) {
                $tariffs[] = [
                    'tariff_id' => $tariff->getTariffId(),
                    'tariff_name' => $tariff->getTariffName(),
                    'delivery_sum' => $tariff->getDeliverySum(),
                    'delivery_days' => $tariff->getDeliveryPeriod(),
                    'delivery_date_min' => $tariff->getPeriodMin(),
                    'delivery_date_max' => $tariff->getPeriodMax(),
                    'currency' => $tariff->getCurrency()
                ];
            }
            
            return $tariffs;
            
        } catch (\Exception $e) {
            error_log('[CDEK] Calculation error: ' . $e->getMessage());
            throw new \Exception('Ошибка расчёта доставки: ' . $e->getMessage());
        }
    }

    /**
     * Поиск пунктов выдачи заказов (ПВЗ)
     */
    public function getDeliveryPoints($city_id, $type = 'PVZ') {
        try {
            $points = $this->client->getDeliveryPoints()
                ->setCityId($city_id)
                ->setType($type)
                ->execute();
            
            $result = [];
            foreach ($points as $point) {
                $result[] = [
                    'code' => $point->getCode(),
                    'name' => $point->getName(),
                    'address' => $point->getAddress(),
                    'address_full' => $point->getFullAddress(),
                    'work_time' => $point->getWorkTime(),
                    'phones' => $point->getPhones(),
                    'email' => $point->getEmail(),
                    'location' => [
                        'latitude' => $point->getLatitude(),
                        'longitude' => $point->getLongitude()
                    ],
                    'is_dressing_room' => $point->hasDressingRoom(),
                    'have_cashless' => $point->hasCashless(),
                    'have_cash' => $point->hasCash(),
                    'allowed_cod' => $point->isAllowedCod(),
                    'nearest_station' => $point->getNearestStation(),
                    'work_time_list' => $point->getWorkTimeList()
                ];
            }
            
            return $result;
            
        } catch (\Exception $e) {
            error_log('[CDEK] Delivery points error: ' . $e->getMessage());
            return [];
        }
    }

    /**
     * Создание заказа в CDEK
     */
    public function createCdekOrder($order_data) {
        try {
            $request = (new CreateOrderRequest())
                ->setNumber($order_data['order_number'])
                ->setSenderCityId($order_data['sender_city_id'])
                ->setReceiverCityId($order_data['receiver_city_id'])
                ->setReceiverAddress($order_data['receiver_address'])
                ->setReceiverName($order_data['receiver_name'])
                ->setReceiverPhone($order_data['receiver_phone'])
                ->setReceiverEmail($order_data['receiver_email'] ?? null)
                ->setComment($order_data['comment'] ?? '')
                ->setDeliveryRecipientCost($order_data['delivery_cost'] ?? 0)
                ->setTariffId($order_data['tariff_id']);
            
            // Добавление товаров в заказ
            foreach ($order_data['items'] as $item) {
                $request->addPackage([
                    'number' => $item['package_number'] ?? '1',
                    'weight' => $item['weight'],
                    'length' => $item['length'],
                    'width' => $item['width'],
                    'height' => $item['height'],
                    'items' => [[
                        'ware_key' => $item['sku'],
                        'cost' => $item['price'],
                        'payment' => 0,
                        'weight' => $item['weight'],
                        'amount' => $item['quantity'],
                        'name' => $item['name'],
                        'payment' => 0
                    ]]
                ]);
            }
            
            $response = $this->client->sendCreateOrderRequest($request);
            
            if ($response->hasErrors()) {
                throw new \Exception(implode(', ', $response->getErrors()));
            }
            
            return [
                'cdek_order_uuid' => $response->getOrder()->getUUID(),
                'cdek_order_number' => $response->getOrder()->getDispatchNumber(),
                'barcode' => $response->getOrder()->getBarcode(),
                'status' => $response->getOrder()->getStatus()
            ];
            
        } catch (\Exception $e) {
            error_log('[CDEK] Order creation error: ' . $e->getMessage());
            throw new \Exception('Ошибка создания заказа в CDEK: ' . $e->getMessage());
        }
    }

    /**
     * Отслеживание статуса заказа
     */
    public function trackOrder($dispatch_number) {
        try {
            $order = $this->client->getOrderByDispatchNumber($dispatch_number);
            
            if (!$order) {
                return null;
            }
            
            $statuses = [];
            foreach ($order->getStatuses() as $status) {
                $statuses[] = [
                    'code' => $status->getCode(),
                    'name' => $status->getName(),
                    'date' => $status->getDate(),
                    'description' => $status->getDescription()
                ];
            }
            
            return [
                'dispatch_number' => $order->getDispatchNumber(),
                'status_code' => $order->getStatusCode(),
                'status_name' => $order->getStatusName(),
                'status_date' => $order->getStatusDate(),
                'statuses' => $statuses,
                'delivery_date' => $order->getDeliveryDate(),
                'recipient_name' => $order->getRecipientName(),
                'recipient_address' => $order->getRecipientAddress()
            ];
            
        } catch (\Exception $e) {
            error_log('[CDEK] Tracking error: ' . $e->getMessage());
            return null;
        }
    }
}
```

| **Вес посылки** | Общий вес товаров в корзине | `Package::setWeight()` | Общий вес в граммах |
| **Размеры посылки** | Рассчитано или сконфигурировано | `Package::setLength()`, `setWidth()`, `setHeight()` | Размеры в сантиметрах |
| **Стоимость товаров** | Итого заказа | `CalculationRequest::setGoods()` | Заявленная стоимость для страхования |

### Пример расчёта в контроллере

```php
// /system/controllers/shop/delivery/calculate.php
class shopDeliveryCalculate {
    private $cdek;

    public function __construct() {
        $this->cdek = new CdekIntegration();
    }

    /**
     * Расчёт стоимости доставки для корзины
     */
    public function calculateForCart($cart_items, $destination_city_id) {
        // Расчёт общего веса и габаритов
        $total_weight = 0;
        $max_length = 0;
        $max_width = 0;
        $max_height = 0;
        
        foreach ($cart_items as $item) {
            $total_weight += $item['weight'] * $item['quantity'];
            
            // Расчёт габаритов (упрощённый)
            $max_length = max($max_length, $item['length']);
            $max_width = max($max_width, $item['width']);
            $max_height += $item['height'] * $item['quantity'];
        }
        
        // Получение кода города отправителя из конфигурации
        $config = cmsConfig::getInstance();
        $sender_city_id = $config->get('cdek_sender_city_code', 44); // 44 = Москва
        
        // Расчёт стоимости
        $shipping_options = $this->cdek->calculateShipping([
            'sender_city_id' => $sender_city_id,
            'receiver_city_id' => $destination_city_id,
            'weight' => $total_weight,
            'length' => $max_length,
            'width' => $max_width,
            'height' => $max_height
        ]);
        
        // Фильтрация и форматирование результатов
        $available_methods = [];
        foreach ($shipping_options as $option) {
            // Фильтрация по доступным тарифам
            if (in_array($option['tariff_id'], [136, 137, 138])) {
                $available_methods[] = [
                    'id' => $option['tariff_id'],
                    'name' => $option['tariff_name'],
                    'cost' => $option['delivery_sum'],
                    'days' => $option['delivery_days'],
                    'date_min' => $option['delivery_date_min'],
                    'date_max' => $option['delivery_date_max']
                ];
            }
        }
        
        return $available_methods;
    }

    /**
     * Получение пунктов выдачи для выбранного города
     */
    public function getPickupPoints($city_id) {
        return $this->cdek->getDeliveryPoints($city_id, 'PVZ');
    }
}
```

### Реализация создания заказа

```php
// /system/controllers/delivery/model.php
class modelDelivery extends cmsModel {
    private $cdek;

    public function __construct($controller) {
        parent::__construct($controller);
        $this->cdek = new CdekIntegration();
    }

    /**
     * Создание заказа в CDEK
     */
    public function createOrderInCdek($order_id) {
        // Получение данных заказа
        $order = $this->getItem('shop_orders', $order_id);
        if (!$order) {
            throw new \Exception('Заказ не найден');
        }
        
        // Получение товаров заказа
        $items = $this->getOrderItems($order_id);
        
        // Подготовка данных для CDEK
        $order_data = [
            'order_number' => $order['id'],
            'sender_city_id' => cmsConfig::get('cdek_sender_city_code', 44),
            'receiver_city_id' => $this->getCityIdByAddress($order['delivery_address']),
            'receiver_address' => $order['delivery_address'],
            'receiver_name' => $order['user_name'],
            'receiver_phone' => $order['user_phone'],
            'receiver_email' => $order['user_email'],
            'comment' => 'Заказ #' . $order['id'],
            'delivery_cost' => $order['delivery_cost'],
            'tariff_id' => $order['delivery_method_id'],
            'items' => array_map(function($item) {
                return [
                    'sku' => $item['sku'],
                    'name' => $item['title'],
                    'price' => $item['price'],
                    'quantity' => $item['quantity'],
                    'weight' => $item['weight'],
                    'length' => $item['length'],
                    'width' => $item['width'],
                    'height' => $item['height']
                ];
            }, $items)
        ];
        
        // Создание заказа в CDEK
        $cdek_response = $this->cdek->createCdekOrder($order_data);
        
        if (!$cdek_response) {
            throw new \Exception('Ошибка создания заказа в CDEK');
        }
        
        // Сохранение данных в БД
        $this->update('shop_orders', $order_id, [
            'cdek_order_uuid' => $cdek_response['cdek_order_uuid'],
            'cdek_dispatch_number' => $cdek_response['cdek_order_number'],
            'cdek_barcode' => $cdek_response['barcode'],
            'cdek_status' => $cdek_response['status'],
            'delivery_status' => 'processing'
        ]);
        
        // Логирование
        $this->logDeliveryEvent($order_id, 'order_created', [
            'cdek_order_uuid' => $cdek_response['cdek_order_uuid'],
            'dispatch_number' => $cdek_response['cdek_order_number']
        ]);
        
        return $cdek_response;
    }

    /**
     * Обновление статуса заказа
     */
    public function updateOrderStatus($order_id) {
        $order = $this->getItem('shop_orders', $order_id);
        
        if (!$order['cdek_dispatch_number']) {
            return false;
        }
        
        // Получение статуса из CDEK
        $tracking_data = $this->cdek->trackOrder($order['cdek_dispatch_number']);
        
        if (!$tracking_data) {
            return false;
        }
        
        // Сохранение статуса
        $this->update('shop_orders', $order_id, [
            'cdek_status_code' => $tracking_data['status_code'],
            'cdek_status_name' => $tracking_data['status_name'],
            'cdek_status_date' => $tracking_data['status_date'],
            'delivery_tracking_data' => json_encode($tracking_data),
            'delivery_status' => $this->mapCdekStatusToPlatform($tracking_data['status_code'])
        ]);
        
        // Логирование
        $this->logDeliveryEvent($order_id, 'status_updated', [
            'status_code' => $tracking_data['status_code'],
            'status_name' => $tracking_data['status_name']
        ]);
        
        // Запуск события для уведомлений
        cmsEventsManager::hook('delivery_order_status_changed', [
            'order_id' => $order_id,
            'old_status' => $order['delivery_status'],
            'new_status' => $tracking_data['status_code']
        ]);
        
        return true;
    }

    /**
     * Сопоставление статусов CDEK со статусами платформы
     */
    private function mapCdekStatusToPlatform($cdek_status_code) {
        $mapping = [
            'CREATED' => 'pending',
            'READY_FOR_SHIPMENT' => 'processing',
            'SENT_FROM_SENDER_CITY' => 'shipped',
            'RECEIVED_AT_DELIVERY_CITY' => 'in_transit',
            'ACCEPTED_AT_DELIVERY_WAREHOUSE' => 'ready_for_pickup',
            'DELIVERED' => 'delivered',
            'RETURNED' => 'returned'
        ];
        
        return $mapping[$cdek_status_code] ?? 'unknown';
    }
}
```

### Статусы заказов

| Код статуса CDEK | Статус платформы | Описание |
|------------------|------------------|----------|
| `CREATED` | pending | Заказ принят в системе CDEK |
| `READY_FOR_SHIPMENT` | processing | Заказ готов к отправке от отправителя |
| `SENT_FROM_SENDER_CITY` | shipped | Посылка отправлена из города отправителя |
| `RECEIVED_AT_DELIVERY_CITY` | in_transit | Посылка прибыла в город получателя |
| `ACCEPTED_AT_DELIVERY_WAREHOUSE` | ready_for_pickup | Доступно для получения в ПВЗ |
| `DELIVERED` | delivered | Успешно доставлено клиенту |
| `RETURNED` | returned | Возвращено отправителю |

### Автоматические обновления статуса

Платформа поддерживает автоматическое обновление данных отслеживания через запланированные задания cron:

Ожидаемое задание Cron: cron_cdek_tracking_update.php

Структура этой задачи будет аналогична структуре других заданий cron на платформе:

1. Механизм блокировки файлов для предотвращения одновременного запуска.
2. Запросить все активные поставки CDEK из базы данных
3. Запросы статуса пакета к API CDEK
4. Обновить статус заказа в базе данных
5. Запускать события уведомлений об изменениях статуса

```php
// cron_cdek_tracking_update.php
#!/usr/bin/env php
<?php
/**
 * Автоматическое обновление статусов заказов CDEK
 * Запускается по расписанию через системный cron
 */
if (PHP_SAPI !== 'cli') {
    http_response_code(403);
    exit('Access denied. CLI only.');
}

require_once __DIR__ . '/bootstrap.php';

// Блокировка файла
$lock_file = cmsConfig::get('cache_path') . 'cron_cdek_tracking_lock';
$lockfp = fopen($lock_file, 'w');

if (!$lockfp || !flock($lockfp, LOCK_EX | LOCK_NB)) {
    error_log('[CDEK TRACKING] Another process is running. Exiting.');
    exit(1);
}

register_shutdown_function(function() use ($lockfp, $lock_file) {
    if ($lockfp) {
        flock($lockfp, LOCK_UN);
        fclose($lockfp);
        @unlink($lock_file);
    }
});

try {
    // Получение модели доставки
    $delivery_model = cmsCore::getModel('delivery');
    
    // Получение всех активных заказов с отслеживанием CDEK
    $orders_to_track = $delivery_model->getOrdersForTracking([
        'provider' => 'cdek',
        'status_not_in' => ['delivered', 'returned', 'cancelled'],
        'last_tracking_update' => ['<' => date('Y-m-d H:i:s', strtotime('-1 hour'))]
    ]);
    
    $updated_count = 0;
    $error_count = 0;
    
    foreach ($orders_to_track as $order) {
        try {
            $delivery_model->updateOrderStatus($order['id']);
            $updated_count++;
            
            // Пауза между запросами для предотвращения лимитов
            usleep(100000); // 100 мс
            
        } catch (\Exception $e) {
            error_log(sprintf(
                '[CDEK TRACKING] Error updating order #%d: %s',
                $order['id'],
                $e->getMessage()
            ));
            $error_count++;
        }
    }
    
    error_log(sprintf(
        '[CDEK TRACKING] Completed: %d updated, %d errors',
        $updated_count,
        $error_count
    ));
    
    exit(0);
    
} catch (\Exception $e) {
    error_log('[CDEK TRACKING] Critical error: ' . $e->getMessage());
    exit(1);
}
```

```php
// /system/controllers/shop/checkout.php
class shopCheckout {
    private $delivery_calculator;

    public function __construct() {
        $this->delivery_calculator = new shopDeliveryCalculate();
    }

    /**
     * Действие: выбор способа доставки
     */
    public function actionSelectDelivery() {
        $user = cmsUser::getInstance();
        if (!$user->is_logged) {
            $this->redirect('/auth/login?redirect=' . urlencode($this->request->uri));
        }
        
        // Получение корзины
        $cart = $this->model->getCart($user->id);
        if (empty($cart['items'])) {
            $this->redirect('/shop/cart');
        }
        
        // Обработка формы
        if ($this->request->has('submit')) {
            $delivery_data = $this->request->get('delivery', []);
            
            // Валидация данных
            $errors = $this->validateDeliveryData($delivery_data);
            if (!empty($errors)) {
                return $this->render('select_delivery', [
                    'cart' => $cart,
                    'errors' => $errors,
                    'delivery_data' => $delivery_data
                ]);
            }
            
            // Расчёт стоимости доставки
            $shipping_cost = $this->calculateShippingCost($cart['items'], $delivery_data);
            
            // Сохранение данных доставки в сессии
            $_SESSION['checkout_delivery'] = array_merge($delivery_data, [
                'cost' => $shipping_cost
            ]);
            
            // Переход к выбору оплаты
            $this->redirect('/shop/checkout/select-payment');
        }
        
        // Получение доступных методов доставки
        $delivery_methods = $this->getAvailableDeliveryMethods($cart['items']);
        
        return $this->render('select_delivery', [
            'cart' => $cart,
            'delivery_methods' => $delivery_methods
        ]);
    }

    /**
     * Расчёт стоимости доставки
     */
    private function calculateShippingCost($cart_items, $delivery_data) {
        // Определение города назначения
        $city_id = $this->getCityIdByAddress($delivery_data['address']);
        
        // Расчёт стоимости через CDEK
        $shipping_options = $this->delivery_calculator->calculateForCart(
            $cart_items,
            $city_id
        );
        
        // Поиск выбранного метода
        $selected_method = array_filter($shipping_options, function($method) use ($delivery_data) {
            return $method['id'] == $delivery_data['method_id'];
        });
        
        return reset($selected_method)['cost'] ?? 0;
    }

    /**
     * Получение доступных методов доставки
     */
    private function getAvailableDeliveryMethods($cart_items) {
        // Получение города пользователя (или по умолчанию)
        $user_city_id = $this->getUserCityId() ?: 44; // 44 = Москва
        
        // Расчёт всех доступных методов
        $methods = $this->delivery_calculator->calculateForCart(
            $cart_items,
            $user_city_id
        );
        
        // Фильтрация по настройкам
        $config = cmsConfig::getInstance();
        $enabled_tariffs = $config->get('delivery.methods', []);
        
        return array_filter($methods, function($method) use ($enabled_tariffs) {
            return in_array($method['id'], array_column($enabled_tariffs, 'cdek_tariff'));
        });
    }
}
```

## 25.9. Обработчики событий

Система доставки интегрирована с системой событий DST Platform, что обеспечивает возможность её расширения.

### Доступные хуки

| Название хука | Срабатывает при | Параметры | Вариант использования |
|---------------|-----------------|-----------|----------------------|
| `delivery_calculate_before` | Перед расчётом стоимости доставки | `['destination' => ..., 'weight' => ...]` | Изменение входных данных для расчётов, применение пользовательских правил |
| `delivery_calculate_after` | После расчёта стоимости доставки | `['method' => ..., 'cost' => ...]` | Корректировка итоговой стоимости, добавление дополнительных сборов |
| `delivery_order_create_before` | Перед созданием заказа CDEK | `['order_id' => ..., 'data' => ...]` | Проверка данных, предотвращение создания |
| `delivery_order_create_after` | После создания заказа CDEK | `['order_id' => ..., 'dispatch_number' => ...]` | Отправка уведомлений, регистрация событий |
| `delivery_tracking_update` | При изменении статуса отслеживания | `['order_id' => ..., 'old_status' => ..., 'new_status' => ...]` | Уведомление клиента, обновление данных на складе |

```php
// /system/controllers/custom_delivery/hooks.php
class custom_delivery {
    /**
     * Хук: после расчёта стоимости доставки
     * Добавляет страховку для заказов дороже 10000 рублей
     */
    public function hookDeliveryCalculateAfter($calculation_data) {
        // Проверка стоимости заказа
        $order_total = $calculation_data['order_total'] ?? 0;
        
        if ($order_total > 10000) {
            // Добавление страховки (2% от стоимости заказа)
            $insurance_cost = round($order_total * 0.02, 2);
            
            $calculation_data['cost'] += $insurance_cost;
            $calculation_data['insurance_cost'] = $insurance_cost;
            $calculation_data['insurance_included'] = true;
            
            // Логирование
            error_log(sprintf(
                '[DELIVERY] Insurance added for order total %.2f: %.2f',
                $order_total,
                $insurance_cost
            ));
        }
        
        return $calculation_data;
    }

    /**
     * Хук: после создания заказа в CDEK
     * Отправляет уведомление менеджеру склада
     */
    public function hookDeliveryOrderCreateAfter($order_data) {
        $mailer = cmsMailer::getInstance();
        $mailer->setTo(cmsConfig::get('warehouse_email'));
        $mailer->setSubject('Новый заказ на отгрузку #' . $order_data['order_id']);

            'order_id' => $order_data['order_id'],
            'dispatch_number' => $order_data['dispatch_number'],
            'items_count' => $order_data['items_count'],
            'delivery_address' => $order_data['delivery_address']
        ]));
        $mailer->send();
        
        return $order_data;
    }

    /**
     * Хук: при обновлении статуса отслеживания
     * Отправляет уведомление покупателю

        $order_model = cmsCore::getModel('shop');
        $order = $order_model->getItem('shop_orders', $tracking_data['order_id']);
        
        if (!$order) {
            return $tracking_data;

        $significant_statuses = ['shipped', 'in_transit', 'ready_for_pickup', 'delivered'];
        
        if (in_array($tracking_data['new_status'], $significant_statuses)) {
            $user = cmsUser::getInstance($order['user_id']);
            
            $mailer = cmsMailer::getInstance();

                'order_id' => $order['id'],
                'status_name' => $this->getStatusName($tracking_data['new_status']),
                'tracking_url' => cmsConfig::get('host') . '/shop/order/' . $order['id'] . '/tracking'

        return $tracking_data;

            'ready_for_pickup' => 'Готов к получению',
            'delivered' => 'Доставлен',
            'returned' => 'Возвращён'
        ];
        
        return $statuses[$status_code] ?? $status_code;
    }
```

### Структура ключа кэша

Ключи кэша генерируются на основе параметров расчётов для обеспечения точных попаданий в кэш:

**Ключевой формат**: `shipping_calc_{method_id}_{city_hash}_{weight}_{dimensions_hash}`

**Пример**: `shipping_calc_5_a3f2d_2500_b8e1c`

Где:
- `5` = Идентификатор метода CDEK
- `a3f2d` = MD5-хеш города назначения (первые 5 символов)
- `2500` = Вес в граммах
- `b8e1c` = MD5-хеш размеров (первые 5 символов)

### Реализация кэширования

```php
// /system/controllers/delivery/classes/ShippingCalculator.php
class ShippingCalculator {
    private $cache;
    private $cdek;

    public function __construct() {
        $this->cache = cmsCache::getInstance();
        $this->cdek = new CdekIntegration();
    }

    /**
     * Расчёт стоимости доставки с кэшированием
     */
    public function calculateWithCache($params) {
        // Генерация ключа кэша
        $cache_key = $this->generateCacheKey($params);
        
        // Попытка получить из кэша
        $cached_result = $this->cache->get($cache_key);
        
        if ($cached_result !== false) {
            error_log('[DELIVERY] Cache hit for key: ' . $cache_key);
            return $cached_result;
        }
        
        error_log('[DELIVERY] Cache miss for key: ' . $cache_key);
        
        // Расчёт через API CDEK
        $result = $this->cdek->calculateShipping($params);
        
        // Сохранение в кэш (1 час)
        $ttl = cmsConfig::get('delivery.cdek.cache_ttl', 3600);
        $this->cache->set($cache_key, $result, $ttl);
        
        // Сохранение в БД для долгосрочного хранения
        $this->saveToDatabaseCache($cache_key, $result, $ttl);
        
        return $result;
    }

    /**
     * Генерация ключа кэша
     */
    private function generateCacheKey($params) {
        $key_parts = [
            'method' => $params['tariff_id'] ?? 'default',
            'sender' => $params['sender_city_id'],
            'receiver' => md5($params['receiver_city_id']),
            'weight' => $params['weight'],
            'dimensions' => md5($params['length'] . $params['width'] . $params['height'])
        ];
        
        return 'shipping_calc_' . implode('_', $key_parts);
    }

    /**
     * Сохранение в БД для долгосрочного кэширования
     */
    private function saveToDatabaseCache($cache_key, $data, $ttl) {
        $model = cmsCore::getModel('delivery');
        
        $model->insertOrUpdate('delivery_cache', [
            'cache_key' => $cache_key,
            'data' => json_encode($data),
            'expires_at' => date('Y-m-d H:i:s', time() + $ttl)
        ], ['cache_key' => $cache_key]);
    }

    /**
     * Очистка кэша
     */
    public function clearCache($cache_key = null) {
        if ($cache_key) {
            // Очистка конкретного ключа
            $this->cache->delete($cache_key);
            
            // Удаление из БД
            $model = cmsCore::getModel('delivery');
            $model->delete('delivery_cache', ['cache_key' => $cache_key]);
        } else {
            // Очистка всех кэшей доставки
            $this->cache->deleteByTag('delivery_calculations');
            
            // Очистка БД
            $model = cmsCore::getModel('delivery');
            $model->delete('delivery_cache', [
                'expires_at' => ['<' => date('Y-m-d H:i:s')]
            ]);
        }
    }

    /**
     * Триггеры аннулирования кэша
     */
    public function invalidateCacheOnConfigChange() {
        // Очистка кэша при изменении конфигурации
        $this->clearCache();
        
        error_log('[DELIVERY] Cache invalidated due to config change');
    }
}
```

### Триггеры аннулирования кэша

| Триггер | Действие | Причина |
|---------|----------|---------|
| Изменение конфигурации способа доставки | Очистка всех кэшей | Изменение параметров расчёта |
| Очистка кэша вручную в панели администратора | Очистка всех кэшей | Административное действие |
| Истечение TTL | Автоматическая очистка | Устаревание данных |
| Ошибки ответов API CDEK | Не кэшировать ошибки | Предотвращение кэширования сбоев |

## 25.11. Обработка ошибок

Интеграция с CDEK реализует комплексную обработку ошибок для корректного решения проблем, возникающих при сбоях API.

### Категории ошибок

| Тип ошибки | Пример | Ответ платформы | Влияние на пользователей |
|------------|--------|-----------------|--------------------------|
| **Ошибка аутентификации** | Неверные учётные данные CDEK | Зарегистрировать ошибку, отключить методы CDEK | Возврат к методам ручной доставки |
| **Сетевой таймаут** | API CDEK недоступен | Использовать кэшированные расчёты, если доступны | Может отображать устаревшие цены с предупреждением |
| **Неверный адрес** | Город не входит в зону покрытия CDEK | Возвращать пользователю конкретную ошибку | Запрос на исправление адреса |
| **Ограничения на упаковку** | Вес/габариты превышают допустимые пределы | Отфильтровать методы CDEK | Показать только совместимые методы |
| **Превышен лимит скорости** | Слишком много запросов к API | Реализовать экспоненциальную задержку | Временное замедление работы, использовать кэш |

### Реализация обработки ошибок

```php
// /system/controllers/delivery/classes/CdekIntegration.php
class CdekIntegration {
    // ... предыдущий код ...

    /**
     * Расчёт стоимости доставки с обработкой ошибок
     */
    public function calculateShipping($params) {
        $max_retries = cmsConfig::get('delivery.cdek.retry_attempts', 3);
        $retry_delay = cmsConfig::get('delivery.cdek.retry_delay', 1000);
        
        for ($attempt = 1; $attempt <= $max_retries; $attempt++) {
            try {
                return $this->performCalculation($params);
                
            } catch (\CdekSDK\Exceptions\ApiClientException $e) {
                // Ошибки клиента (неверные параметры, аутентификация)
                $this->handleClientError($e, $params);
                throw new \Exception('Ошибка расчёта доставки: ' . $e->getMessage());
                
            } catch (\CdekSDK\Exceptions\ApiServerException $e) {
                // Ошибки сервера CDEK
                $this->handleServerError($e, $params, $attempt);
                
                if ($attempt < $max_retries) {
                    // Экспоненциальная задержка перед повторной попыткой
                    $delay = $retry_delay * pow(2, $attempt - 1);
                    usleep($delay * 1000);
                    continue;
                }
                
                // Все попытки исчерпаны - возвращаем кэшированные данные или ошибку
                $cached_result = $this->getCachedCalculation($params);
                
                if ($cached_result) {
                    error_log('[CDEK] Using cached calculation after API failure');
                    return $cached_result;
                }
                
                throw new \Exception('Сервис доставки временно недоступен. Попробуйте позже.');
                
            } catch (\Exception $e) {
                // Неизвестные ошибки
                $this->handleUnknownError($e, $params);
                throw $e;
            }
        }
    }

    /**
     * Обработка ошибок клиента
     */
    private function handleClientError($exception, $params) {
        $error_code = $exception->getCode();
        $error_message = $exception->getMessage();
        
        // Логирование
        error_log(sprintf(
            '[CDEK CLIENT ERROR] Code: %d, Message: %s, Params: %s',
            $error_code,
            $error_message,
            json_encode($params)
        ));
        
        // Отключение интеграции при ошибках аутентификации
        if (in_array($error_code, [401, 403])) {
            cmsConfig::set('delivery.cdek.enabled', false);
            error_log('[CDEK] Integration disabled due to auth error');
        }
    }

    /**
     * Обработка ошибок сервера
     */
    private function handleServerError($exception, $params, $attempt) {
        $error_code = $exception->getCode();
        $error_message = $exception->getMessage();
        
        // Логирование
        error_log(sprintf(
            '[CDEK SERVER ERROR] Attempt %d/%d, Code: %d, Message: %s',
            $attempt,
            cmsConfig::get('delivery.cdek.retry_attempts', 3),
            $error_code,
            $error_message
        ));
        
        // Отслеживание частоты ошибок
        $this->trackErrorRate($error_code);
    }

    /**
     * Отслеживание частоты ошибок
     */
    private function trackErrorRate($error_code) {
        $cache_key = 'cdek_error_rate_' . date('Y-m-d');
        $error_counts = $this->cache->get($cache_key) ?: [];
        
        $error_counts[$error_code] = ($error_counts[$error_code] ?? 0) + 1;
        $this->cache->set($cache_key, $error_counts, 86400); // 24 часа
        
        // Отправка алерта при превышении порога
        $threshold = 100; // 100 ошибок в день
        if ($error_counts[$error_code] >= $threshold) {
            $this->sendErrorAlert($error_code, $error_counts[$error_code]);
        }
    }

    /**
     * Отправка алерта об ошибках
     */
    private function sendErrorAlert($error_code, $count) {
        $mailer = cmsMailer::getInstance();
        $mailer->setTo(cmsConfig::get('admin_email'));
        $mailer->setSubject('CDEK API Error Alert');
        $mailer->setBody(sprintf(
            "Обнаружено %d ошибок API CDEK с кодом %d за сегодня.\n\n" .
            "Рекомендуется проверить:\n" .
            "- Состояние сервиса CDEK\n" .
            "- Учётные данные интеграции\n" .
            "- Лимиты запросов",
            $count,
            $error_code
        ));
        $mailer->send();
    }

    /**
     * Получение кэшированного расчёта
     */
    private function getCachedCalculation($params) {
        $cache_key = $this->generateCacheKey($params);
        return $this->cache->get($cache_key);
    }
}
```

| **Пакетные расчёты** | Расчёт нескольких вариантов доставки в одном запросе | Сокращает количество вызовов API на 60-80% |
| **Агрессивное кэширование** | Расчёты кэша производятся за 1 час, для популярных маршрутов — дольше | Показатель попадания в кэш составляет более 90% |
| **Ленивая загрузка** | Стоимость доставки рассчитывается только при переходе пользователя к оформлению заказа | Исключает ненужные расчёты |
| **Асинхронные обновления** | Обновлять статус отслеживания через cron, а не при загрузке страницы | Более быстрое время отклика страниц |
| **Индексирование баз данных** | Индекс на `orders.tracking_number`, `shipping_orders.dispatch_number` | Быстрый поиск отслеживания |
| **Ограничение скорости запросов** | Очередь запросов с экспоненциальной задержкой | Предотвращает блокировку API |

### Меры по смягчению последствий

```php
// /system/controllers/delivery/classes/RateLimiter.php
class RateLimiter {
    private $cache;
    private $limits = [
        'calculation' => ['limit' => 100, 'window' => 60], // 100/минуту
        'order_create' => ['limit' => 30, 'window' => 60], // 30/минуту
        'tracking' => ['limit' => 50, 'window' => 60] // 50/минуту
    ];

    public function __construct() {
        $this->cache = cmsCache::getInstance();
    }

    /**
     * Проверка лимита запросов
     */
    public function checkLimit($type, $identifier = 'global') {
        $limit_config = $this->limits[$type] ?? $this->limits['calculation'];
        $cache_key = "rate_limit_{$type}_{$identifier}";
        
        $requests = $this->cache->get($cache_key) ?: [];
        $window_start = time() - $limit_config['window'];
        
        // Удаление устаревших запросов
        $requests = array_filter($requests, function($timestamp) use ($window_start) {
            return $timestamp > $window_start;
        });
        
        // Проверка лимита
        if (count($requests) >= $limit_config['limit']) {
            $retry_after = $limit_config['window'] - (time() - min($requests));
            return [
                'allowed' => false,
                'retry_after' => $retry_after,
                'remaining' => 0,
                'limit' => $limit_config['limit']
            ];
        }
        
        // Добавление текущего запроса
        $requests[] = time();
        $this->cache->set($cache_key, $requests, $limit_config['window']);
        
        return [
            'allowed' => true,
            'remaining' => $limit_config['limit'] - count($requests),
            'limit' => $limit_config['limit'],
            'reset' => $window_start + $limit_config['window']
        ];
    }

    /**
     * Ожидание до следующего разрешённого запроса
     */
    public function waitForLimit($type, $identifier = 'global') {
        $result = $this->checkLimit($type, $identifier);
        
        if (!$result['allowed']) {
            error_log(sprintf(
                '[RATE LIMIT] Waiting %d seconds for %s',
                $result['retry_after'],
                $type
            ));
            
            sleep($result['retry_after']);
            return $this->waitForLimit($type, $identifier);
        }
        
        return $result;
    }
}

// Использование в интеграции
$rate_limiter = new RateLimiter();

// Перед каждым запросом к API
$limit_result = $rate_limiter->waitForLimit('calculation');

if ($limit_result['allowed']) {
    $result = $cdek_client->calculateShipping($params);
}
```

```php
public function calculateBatch($calculations) {
    $results = [];
    $cache_hits = 0;
    $api_calls = 0;
    
    foreach ($calculations as $calculation) {

        $cached = $this->cache->get($cache_key);
        
        if ($cached !== false) {
            $results[] = $cached;
            $cache_hits++;
            continue;
        }
        
        // Проверка лимита перед запросом

        $rate_limiter->waitForLimit('calculation');
        
        $result = $this->cdek->calculateShipping($calculation);

        $api_calls++;

        $this->cache->set($cache_key, $result, 3600);
        
        // Пауза между запросами для предотвращения лимитов
        usleep(100000); // 100 мс
    }

        count($calculations),
        $cache_hits,
        $api_calls
    ));
```

### Учётные данные API

Учётные данные CDEK должны храниться в безопасности:

| Метод | Рекомендация | Причина |
|-------|--------------|---------|
| **Хранение** | Переменные окружения или зашифрованная конфигурация | Предотвращение утечки в репозиторий |
| **Доступ** | Только компонент доставки и контроллеры администрирования | Минимизация поверхности атаки |
| **Передача** | Всегда использовать HTTPS для обмена данными через API | Шифрование в транзите |
| **Ротация** | Регулярная смена паролей (каждые 90 дней) | Снижение риска компрометации |

### Проверка данных

Все предоставленные пользователем данные о доставке должны быть проверены перед отправкой в API CDEK:

| Поле | Проверка | Профилактика |
|------|----------|--------------|
| **Адрес назначения** | Санитизация, проверки максимальной длины | SQL-инъекции, атаки с переполнением |
| **Вес посылки** | Числовые, положительные, максимальные пределы | Путаница типов, DoS-атака через слишком большие посылки |
| **Размеры посылки** | Числовые, положительные, реалистичные диапазоны | Недействительные API-запросы |
| **Заявленная стоимость** | Числовой, соответствует общей сумме заказа | Предотвращение мошенничества |
| **Номер телефона** | Проверка формата, только цифры | Ошибки отклонения API |

### Защита от атак

```php
/**
 * Защита от атак на интеграцию доставки
 */
class DeliverySecurity {
    private $cache;
    
    public function __construct() {
        $this->cache = cmsCache::getInstance();
    }
    
    /**
     * Проверка частоты запросов от пользователя
     */
    public function checkUserRateLimit($user_id, $action) {
        $cache_key = "delivery_rate_user_{$user_id}_{$action}";
        $attempts = $this->cache->get($cache_key) ?: 0;
        
        // Лимит: 10 запросов в минуту на пользователя
        if ($attempts >= 10) {
            error_log("[SECURITY] Rate limit exceeded for user {$user_id}, action: {$action}");
            return false;
        }
        
        $this->cache->set($cache_key, $attempts + 1, 60);
        return true;
    }
    
    /**
     * Проверка подозрительной активности
     */
    public function checkSuspiciousActivity($data) {
        $suspicious_patterns = [
            // Проверка на автоматизированные запросы
            'rapid_requests' => function($data) {
                $cache_key = 'delivery_requests_' . $_SERVER['REMOTE_ADDR'];
                $requests = $this->cache->get($cache_key) ?: [];
                
                $requests[] = time();
                $recent = array_filter($requests, function($t) {
                    return $t > (time() - 10); // Последние 10 секунд
                });
                
                $this->cache->set($cache_key, $requests, 60);
                
                return count($recent) > 5; // Более 5 запросов за 10 секунд
            },
            
            // Проверка на подозрительные адреса
            'suspicious_address' => function($data) {
                $suspicious_keywords = ['test', 'fake', 'invalid', 'null'];
                $address = strtolower($data['address'] ?? '');
                
                foreach ($suspicious_keywords as $keyword) {
                    if (strpos($address, $keyword) !== false) {
                        return true;
                    }
                }
                
                return false;
            }
        ];
        
        foreach ($suspicious_patterns as $name => $check) {
            if ($check($data)) {
                error_log("[SECURITY] Suspicious activity detected: {$name}");
                return true;
            }
        }
        
        return false;
    }
    
    /**
     * Блокировка подозрительных IP
     */
    public function blockSuspiciousIp($ip) {
        $blocked_ips = $this->cache->get('delivery_blocked_ips') ?: [];
        $blocked_ips[$ip] = time() + 3600; // Блокировка на 1 час
        
        $this->cache->set('delivery_blocked_ips', $blocked_ips, 86400);
    }
    
    /**
     * Проверка заблокированных IP
     */
    public function isIpBlocked($ip) {
        $blocked_ips = $this->cache->get('delivery_blocked_ips') ?: [];
        
        if (isset($blocked_ips[$ip])) {
            if ($blocked_ips[$ip] > time()) {
                return true;
            } else {
                // Удаление просроченной блокировки
                unset($blocked_ips[$ip]);
                $this->cache->set('delivery_blocked_ips', $blocked_ips, 86400);
            }
        }
        
        return false;
    }
}
```

| Категория | Реализация |
|-----------|------------|
| **Интеграция с поставщиком** | Полнофункциональная интеграция с системой доставки CDEK через официальный SDK |
| **Модульная архитектура** | Чёткое разделение между компонентом доставки, интеграцией с маркетплейсом и внешним SDK |
| **Оптимизация производительности** | Многоуровневое кэширование с использованием phpfastcache, хранилище сессий и кэширование в БД |

| **Устойчивость к ошибкам** | Комплексная обработка ошибок с механизмами резервного копирования |

| **Мониторинг** | Детальное логирование, метрики производительности, панель мониторинга |
