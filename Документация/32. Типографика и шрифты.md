# 32. Типографика и шрифты

В данном разделе описана система типографики в DST Platform: используемые веб-шрифты, механизмы их загрузки, типографические шкалы и интеграция с системой стилей. Типографика реализована через два ключевых файла, обеспечивающих фирменный стиль при сохранении кроссбраузерной совместимости.

**Связанные разделы:**
- *«Структура стилей»* — общая организация CSS-файлов
- *«Конвейер ресурсов»* — загрузка и обработка шрифтов
- *«CSS-фреймворк: кастомизация Bootstrap»* — интеграция типографики с фреймворком

---

## 32.1. Обзор типографической системы

Типографическая система DST Platform построена на сочетании двух профессиональных веб-шрифтов с резервными системными шрифтами для обеспечения доступности на всех устройствах.

### Ключевые принципы
- **Двойная система шрифтов**: Основной и акцентный шрифты для визуальной иерархии
- **Постепенное улучшение**: Резервные шрифты гарантируют отображение текста при любых условиях
- **Оптимизация производительности**: Поддержка современных форматов (WOFF2) для уменьшения размера файлов
- **Семантическая типографика**: Чёткая иерархия от заголовков до вспомогательного текста

## 32.3. Загрузка шрифтов через @font-face

Платформа загружает пользовательские шрифты с помощью CSS- @font-face деклараций, поддерживая несколько форматов для обеспечения кроссбраузерной совместимости.

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/184.png" alt="DST Platform">

Система использует современный подход к загрузке шрифтов с поддержкой нескольких форматов для максимальной совместимости.

### Объявление шрифтов
```css
/* /css/fonts.css */

/* GT Eesti Pro Display Bold */
@font-face {
    font-family: 'GT Eesti Pro Display';
    font-style: normal;
    font-weight: 700;
    font-display: swap;
    src: local('GT Eesti Pro Display Bold'),
         local('GT-Eesti-Pro-Display-Bold'),
         url('/fonts/fonts/GTEestiProDisplay-Bold.woff2') format('woff2'),
         url('/fonts/fonts/GTEestiProDisplay-Bold.woff') format('woff'),
         url('/fonts/fonts/GTEestiProDisplay-Bold.ttf') format('truetype');
}

/* Styrene A Web Regular */
@font-face {
    font-family: 'Styrene A Web';
    font-style: normal;
    font-weight: 400;
    font-display: swap;
    src: url('/fonts/StyreneAWeb-Regular.eot');
    src: url('/fonts/StyreneAWeb-Regular.eot?#iefix') format('embedded-opentype'),
         url('/fonts/StyreneAWeb-Regular.woff2') format('woff2'),
         url('/fonts/StyreneAWeb-Regular.woff') format('woff'),
         url('/fonts/StyreneAWeb-Regular.ttf') format('truetype');
}
```

### Ключевые атрибуты
| Атрибут | Значение | Назначение |
|---------|----------|------------|
| `font-display: swap` | swap | Позволяет мгновенно отобразить текст резервным шрифтом (предотвращает невидимый текст) |
| `local()` | Название шрифта | Проверяет наличие шрифта на устройстве пользователя (экономия трафика) |
| `format()` | Тип формата | Помогает браузеру выбрать подходящий формат |

## 32.4. Поддерживаемые форматы файлов

Система поддерживает четыре формата шрифтов для охвата всех браузеров.

### Сравнение форматов
| Формат | Поддержка браузеров | Размер файла | Назначение |
|--------|---------------------|--------------|------------|
| **WOFF2** | Современные (2015+) | Наименьший (~30% меньше WOFF) | Основной формат для современных браузеров |
| **WOFF** | Все современные | Средний | Резервный для более старых браузеров |
| **TTF** | Универсальный | Наибольший | Универсальный резервный вариант |
| **EOT** | Internet Explorer | Средний | Специальная поддержка IE (только Styrene A Web) |

### Стратегия загрузки
```
Браузер запрашивает шрифт
    ↓
Проверка локальной установки (local())
    ↓ (если не найден)
Попытка загрузки WOFF2
    ↓ (если не поддерживается)
Попытка загрузки WOFF
    ↓ (если не поддерживается)
Попытка загрузки TTF
    ↓ (для IE)
Попытка загрузки EOT
    ↓
Отображение резервного шрифта
```

## 32.6. Резервные стеки шрифтов

Для обеспечения отображения текста при любых условиях определены резервные стеки системных шрифтов.

### Стек шрифтов без засечек
```css
:root {
    --font-family-sans-serif: -apple-system, BlinkMacSystemFont, "Segoe UI",
                              Roboto, "Helvetica Neue", Arial, sans-serif,
                              "Apple Color Emoji", "Segoe UI Emoji",
                              "Segoe UI Symbol", "Noto Color Emoji";
}
```

**Применение:** Основной текст, интерфейсные элементы
```css
body {
    font-family: var(--font-family-sans-serif);
    font-size: 1rem;        /* 16px */
    font-weight: 400;
    line-height: 1.5;
    color: #0b1f35;
}
```

### Моноширинный стек
```css
:root {
    --font-family-monospace: SFMono-Regular, Menlo, Monaco, Consolas,
                             "Liberation Mono", "Courier New", monospace;
}
```

**Применение:** Код, технические элементы
```css
code, kbd, pre, samp {
    font-family: var(--font-family-monospace);
}
```

## 32.9. Процесс интеграции и загрузки

Система обеспечивает корректную загрузку шрифтов в правильной последовательности.

### Порядок загрузки ресурсов
```
1. Загрузка шаблона (cmsTemplate)
2. Подключение fonts.css (объявления @font-face)
3. Подключение базовых стилей (стили текста, переменные)
4. Подключение кастомизированного Bootstrap
5. Подключение специфичных стилей компонентов
```

### Критически важные моменты
- **Порядок подключения**: `fonts.css` должен загружаться **до** `bootstrap.css`
- **Асинхронная загрузка**: Браузер загружает шрифты асинхронно
- **Поведение при загрузке**: Используется стратегия **FOUT** (Flash of Unstyled Text)
  - Текст отображается немедленно резервным шрифтом
  - После загрузки шрифта происходит перерисовка

### Управление через систему шаблонов
```php
// В контроллере или шаблоне
$this->template->addMainCSS('css/fonts.css');      // Сначала шрифты
$this->template->addMainCSS('css/bootstrap.css');   // Затем фреймворк
```

**Важно:** Система шаблонов автоматически управляет порядком загрузки, но при ручном подключении соблюдайте эту последовательность.

## 32.10. Процесс интеграции CSS

<img src="https://github.com/DSTGlobal/DST-Platform/blob/main/images/188.png" alt="DST Platform">

### Порядок погрузки

1. Для обеспечения доступности определений шрифтов файл fonts.css необходимо загрузить перед файлом bootstrap.css.
2. Запрос пользовательских шрифтов осуществляется браузером асинхронно.
3. Текст отображается мгновенно с использованием резервных шрифтов (FOUT — Flash of Unstyled Text).
4. При загрузке текст перерисовывается с использованием пользовательских шрифтов.

Обычно это решается системой шаблонов путем загрузки CSS в правильном порядке. Подробную информацию о том, как шаблоны включают эти таблицы стилей, см. в разделе «Конвейер ресурсов».

## 32.12. Оптимизация производительности

Система включает несколько механизмов для минимизации влияния шрифтов на производительность.

### Стратегии оптимизации
| Метод | Описание | Эффект |
|-------|----------|--------|
| **WOFF2** | Современный формат сжатия | Уменьшение размера на 30% по сравнению с WOFF |
| **font-display: swap** | Отображение резервного шрифта | Предотвращение невидимого текста (FOIT) |
| **local()** | Проверка локальной установки | Экономия трафика при наличии шрифта |
| **Кэширование** | HTTP-кэширование шрифтов | Ускорение повторных загрузок |
| **Подмножества** | Загрузка только нужных символов | Уменьшение размера (планируется) |

### Рекомендации по кэшированию
```apache
# .htaccess или конфигурация веб-сервера
<FilesMatch "\.(woff2|woff|ttf|eot)$">
    Header set Cache-Control "public, max-age=31536000, immutable"
</FilesMatch>
```

**Объяснение:**
- `max-age=31536000` — кэширование на 1 год
- `immutable` — файл никогда не изменяется (браузер не будет проверять обновления)

## 32.13. Кастомизация типографики

При создании кастомных тем можно переопределить типографические настройки.

### Создание кастомных шрифтов
1. **Добавьте файлы шрифтов** в `/templates/{theme}/fonts/`
2. **Создайте файл** `/templates/{theme}/css/custom-fonts.css`
3. **Объявите шрифты** через `@font-face`
4. **Переопределите переменные** в `:root`

### Пример кастомизации
```css
/* /templates/my_theme/css/custom-fonts.css */

/* Новый основной шрифт */
@font-face {
    font-family: 'Custom Font';
    font-weight: 400;
    font-display: swap;
    src: url('/templates/my_theme/fonts/custom-regular.woff2') format('woff2');
}

/* Переопределение переменных */
:root {
    --font-family-sans-serif: 'Custom Font', -apple-system, BlinkMacSystemFont,
                               "Segoe UI", Roboto, sans-serif;
}

/* Переопределение стилей текста */
body {
    font-family: var(--font-family-sans-serif);
}
```

### Подключение в теме
```php
// В контроллере темы
$this->template->addMainCSS('templates/my_theme/css/custom-fonts.css');
```

## 32.14. Диагностика и решение проблем

### Распространённые проблемы и решения

| Проблема | Возможная причина | Решение |
|----------|------------------|---------|
| **Шрифты не загружаются** | Неправильный путь к файлам | Проверьте структуру `/fonts/` |
| **FOIT (невидимый текст)** | Отсутствует `font-display: swap` | Добавьте атрибут в `@font-face` |
| **Неправильное отображение кириллицы** | Шрифт не поддерживает кириллицу | Используйте шрифты с поддержкой кириллицы |
| **Медленная загрузка** | Большие файлы шрифтов | Используйте WOFF2, рассмотрите подмножества |
| **Кэширование старой версии** | Отсутствует версионирование | Добавьте `?v={timestamp}` к URL |

### Инструменты диагностики
```javascript
// Проверка загруженных шрифтов в консоли браузера
document.fonts.forEach(font => {
    console.log(`${font.family} (${font.weight}): ${font.status}`);
});
```

## 32.15. Лучшие практики

### ✅ Рекомендуется
- **Используйте систему шаблонов** для подключения шрифтов
- **Соблюдайте порядок загрузки**: сначала `fonts.css`, затем остальные стили
- **Тестируйте на разных браузерах** для проверки совместимости
- **Оптимизируйте размеры файлов** через WOFF2
- **Используйте `font-display: swap`** для предотвращения FOIT

### ❌ Избегайте
- **Прямого подключения шрифтов** через `<link>` в шаблонах
- **Изменения структуры `/fonts/`** без обновления путей в `fonts.css`
- **Использования большого количества весов** одного шрифта (увеличивает размер)
- **Отключения резервных шрифтов** (нарушает доступность)
- **Загрузки шрифтов в `<head>`** через инлайн-стили (нарушает кэширование)

### Пример правильного подхода
```php
// ✅ Правильно: через систему шаблонов
$this->template->addMainCSS('css/fonts.css');
$this->template->addMainCSS('css/bootstrap.css');

// ❌ Неправильно: прямое подключение в шаблоне
// <link rel="stylesheet" href="/css/fonts.css">
// <link rel="stylesheet" href="/css/bootstrap.css">
```
