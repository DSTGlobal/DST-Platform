# 2. Возможности DST Маркетплейс

DST Маркетплейс — это гибридная экосистема уровня Enterprise на базе DST Platform, объединяющая мощь системы управления контентом (CMS) и гибкость фреймворка для разработки (CMF). Ниже представлен исчерпывающий обзор возможностей системы DST Маркетплейс, структурированный по ключевым бизнес-направлениям.

## 1. Система управления пользователями

Комплексный модуль для управления жизненным циклом всех участников маркетплейса: от обычных покупателей до продавцов и сотрудников администрации. Обеспечивает гибкое разграничение прав и персонализированный опыт.

### 1.1. Авторизация и регистрация
Многоуровневая система входа для покупателей, продавцов, модераторов и администраторов с поддержкой социальной авторизации и восстановления доступа.

| Компонент | Описание |
|---|---|
| **Авторизация и регистрация** | Многоуровневая система входа с поддержкой авторизации по email, телефону или через социальные сети. |
| **Восстановление пароля** | Автоматизированная система восстановления доступа по email или SMS с генерацией временных токенов. |

### 1.2. Управление группами и ролями
Конструктор пользовательских групп с возможностью тонкой настройки прав доступа к любому разделу, контенту или действию в системе.

| Компонент | Описание |
|---|---|
| **Создание группы** | Инструмент для создания неограниченного количества групп пользователей (операторы, менеджеры, модераторы, VIP-клиенты и т.д.). |
| **Права группы** | Назначение группам индивидуальных возможностей (добавление комментариев, создание записей, модерация контента, управление рейтингами и т.д.). |
| **Доступ в разделы** | Гранулярное управление правами доступа к разделам административной панели (заказы, каталог, атрибуты, компоненты, импорт/экспорт, документооборот и т.д.). |
| **Настройка полей профиля** | Конструктор индивидуальных полей для профилей пользователей конкретной группы (должность, город, ИНН, аватар, телефон и т.д.). |
| **Правила и автоматизация** | Настройка автоматических правил перевода пользователей между группами по условиям (рейтинг, сумма покупок, время регистрации). |

### 1.3. Личный кабинет покупателя
Единое пространство для управления покупками, коммуникациями и персональными данными.

| Компонент | Описание |
|---|---|
| **Анкетные данные** | Управление базовой информацией профиля пользователя. |
| **Моя компания** | Управление реквизитами юридического лица для корпоративных покупателей и выставления счетов. |
| **Система уведомлений пользователя** | Центр управления рассылками и новостями от администрации маркетплейса. |
| **Система автоматических уведомлений** | Настройка системных оповещений о ходе обработки заказов, доставке, модерации и т.д. |
| **Моя скидка** | Просмотр и управление персональными накопительными скидками и бонусами. |
| **Сообщения** | Внутренний мессенджер для переписки с администрацией, технической поддержкой или продавцом. |
| **Документооборот** | Полный цикл электронного документооборота (ЭДО): загрузка, хранение и выгрузка счетов, актов и договоров с продавцами. |
| **Связанные аккаунты** | Управление связанными профилями для возможности покупок от разных юридических или физических лиц. |
| **Моя корзина** | Управление отложенными покупками, распределенная корзина для товаров от разных продавцов. |
| **История заказов** | Детальная история всех заказов с логами изменений статусов и возможностью повторного заказа. |
| **Избранное** | Персональный список сохраненных товаров. |
| **Сравнение** | Инструмент для сравнения товаров по заданным характеристикам. |
| **Тендеры** | Управление созданными тендерами и закупками (см. компонент «Тендеры»). |
| **Мой блог** | Персональный блог пользователя для публикаций (см. компонент «Клуб»). |
| **Мои темы** | История созданных тем и обсуждений на форуме (см. компонент «Форум»). |
| **Мои вопросы** | История заданных вопросов о товарах и услугах (см. компонент «Вопросы-ответы»). |
| **Отзывы на товары** | Управление оставленными отзывами на приобретенные товары. |
| **Отзывы о продавцах** | Управление репутационными отзывами о магазинах и поставщиках. |
| **Комментарии** | Сводная лента всех комментариев пользователя на платформе (см. компонент «Комментарии»). |
| **Реферальная программа** | Статистика, аналитика и управление реферальными ссылками для привлечения продавцов и получения вознаграждения. |
| **Настройки профиля** | Управление основными данными: имя, почта, телефон и пароль. |
| **Настройки уведомлений** | Гранулярное управление каналами и типами получаемых уведомлений. |
| **Безопасность** | Управление устройствами, история активности, текущий IP-адрес и принудительное завершение сеансов. |

### 1.4. Личный кабинет продавца (Vendor Dashboard)

| **Безопасность продавца** | Настройки доступа, история входов и управление уведомлениями. |

### 1.5. Личный кабинет УЭБ (Управление экономической безопасностью)

| Компонент | Описание |
|---|---|

## 2. Система управления товарами

Мощный движок каталога, способный выдерживать миллионы SKU. Поддерживает сложные иерархии, вариативность и богатый медиаконтент.

### 2.1. Каталог товаров
Публичная витрина с продвинутыми механизмами навигации и отображения.

| Компонент | Описание |
|---|---|
| **Поиск по каталогу** | Живой поиск с возможностью добавления товаров в корзину прямо из результатов выдачи и генерацией отдельного URL. |
| **Системы фильтрации** | Фильтрация по цене, типу, бренду и заданным атрибутам с автоматической подгрузкой результатов и генерацией SEO-URL. |
| **Сортировка товаров** | Сортировка по цене, скидке, новизне, популярности и рейтингу отзывов. |
| **Режимы отображения** | Переключение между выводом товаров плиткой и списком. |
| **Страницы брендов** | Автоматическая генерация списка и страниц брендов, представленных в каталоге. |
| **Баннерные позиции** | Вставка баннеров в категории (с поддержкой слайдера) для продвижения акций. |
| **Быстрые действия** | Функции «Купить в 1 клик» и «Заказать обратный звонок» прямо из миниатюры карточки товара. |
| **Маркировка товаров** | Автоматическое отображение ярлыков «Скидка», «Новинка», «Хит» и т.д. |
| **Умные категории** | Автоматический вывод вложенных подкатегорий и релевантных брендов в родительских категориях. |
| **Оформление категорий** | Визуальный редактор для загрузки изображений и HTML-описания категорий. |
| **Геолокация региона** | Автоматическая фильтрация и определение домашнего региона покупателя для показа актуальных цен и доставки. |

### 2.2. Товарная карточка
Детальная страница товара, оптимизированная для максимальной конверсии.

| Компонент | Описание |
|---|---|
| **Типы товаров** | Поддержка обычных и вариативных товаров (с разными ценами и остатками для опций). |
| **Сведения о товаре** | Наименование, подробное описание, код, артикул и характеристики. |
| **Медиагалерея** | Интерактивная фотогалерея с зумом и добавлением видео (через редактор или ссылку YouTube). |
| **Ценообразование** | Отображение старой, новой цены и размера скидки. |
| **Быстрые действия** | Кнопки «Купить в 1 клик», «Заказать обратный звонок», «Написать продавцу». |
| **Наличие и доставка** | Индикация остатков и доступных способов получения, подключенных продавцом. |
| **Социальные функции** | Кнопки «Поделиться» в соцсетях и мессенджерах. |
| **Избранное и сравнение** | Быстрое добавление товара в личные списки пользователя. |
| **Отзывы и вопросы** | Блок отзывов к товарам с поддержкой фото-отзывов покупателей. |
| **Информация о продавце** | Вывод названия, аватара, ИНН, КПП, адреса и рейтинга магазина продавца. |
| **Дополнительные блоки** | «Часто задаваемые вопросы», «С этим товаром покупают», «Вы недавно смотрели», «Предложения других продавцов». |

### 2.3. Панель управления: Управление товарами
Инструменты администратора для модерации и глобального управления каталогом.

| Компонент | Описание |
|---|---|
| **Управление атрибутами** | Создание глобальных характеристик и их привязка к конкретным категориям. |
| **Управление публикациями** | Массовая публикация или снятие с публикации товаров в категориях и подкатегориях. |
| **Поиск и фильтрация** | Расширенный поиск товаров в административной панели по любым параметрам. |
| **Расширенные редакторы** | WYSIWYG-редакторы для описаний и SEO-полей. |

## 3. Система управления заказами

Оптимизированный конвейер обработки заказов, спроектированный специально для мульттивендорной (многосторонней) архитектуры маркетплейса.

| Компонент | Описание |
|---|---|
| **Корзина** | Управление выбранными товарами с калькуляцией номенклатуры и стоимости. |
| **Оформление заказа (1 страница)** | Максимально упрощенный чекаут на одной странице для повышения конверсии. |
| **Распределенная корзина** | Автоматическое разделение заказа на субзаказы по разным продавцам с индивидуальным оформлением и оплатой для каждого. |
| **Калькуляция доставок** | Динамический расчет стоимости доставки на основе выбранных товаров и адреса. |
| **Быстрые действия** | Функции «Купить в 1 клик» и «Заказать обратный звонок» в обход полной корзины. |
| **Выбор способа оплаты** | Интеграция с методами оплаты, настроенными как платформой, так и конкретным продавцом. |
| **Выбор способа доставки** | Интеграция с методами доставки, настроенными продавцом. |
| **Установка статусов заказа** | Гибкий конвейер статусов (Новый, В обработке, Отправлен, Доставлен, Отменен). |
| **Автооповещения покупателей** | Триггерные email/SMS уведомления при смене статуса заказа. |
| **Фильтрация и сортировка заказов** | Мощные инструменты поиска заказов в админке по дате, сумме, статусу, продавцу или покупателю. |

## 4. Система управления платежами

Безопасный и гибкий финансовый шлюз, поддерживающий как прямые платежи маркетплейсу, так и сплитование (разделение) платежей между платформой и продавцом.

| Компонент | Описание |
|---|---|
| **Интеграция шлюзов** | Готовые модули для Яндекс Кассы (ЮKassa), Robokassa, Т-Банка и других популярных систем. |
| **Настройка эквайринга** | Возможность подключения платежных методов как на уровне маркетплейса, так и в личном кабинете продавца (через токены). |
| **Управление комиссиями** | Настройка процента или фиксированной комиссии платформы с каждого заказа или товарной группы. |
| **Отчеты о продажах поставщика** | Детализация начислений и удержаний для каждого продавца. |
| **Возвраты и транзакции** | Управление возвратами средств и просмотр истории финансовых операций. |
